# 术语表

## 核心概念

| 中文术语 | 英文/来源 | 简要释义 |
|---------|----------|---------|
| 原生家庭 | Family of Origin | 一个人出生和成长的家庭，对人格形成有根本性影响 |
| 首属群体 | Primary Group | 萨提亚认为家庭是每个人的第一个群体 |
| 萨提亚模式 | Satir Model | 由维吉尼亚·萨提亚创立的家庭治疗模式，强调沟通、冰山、成长 |
| 三次出生 | Three Births | ①精卵结合（生命力）②从子宫出生（行为模式形成）③重新选择做自己 |
| 等级模式 | Hierarchical Mode | 僵化封闭的家庭系统，由上而下，不允许质疑 |
| 平等模式 | Equal Mode | 流动允许的系统，人格平等、心理平等 |
| 应对姿态 | Coping Stance | 压力下自动反应的四种沟通方式 |
| 一致性 | Congruence | 同时照顾到自己、他人和情境的健康沟通状态 |
| 冰山模型 | Iceberg Model | 行为是水面上的冰山一角，水面下是感受、想法、期待、渴望、生命力 |
| 心理营养 | Psychological Nutrition | 心理层面所需的养分，如同身体需要食物 |
| 五大天性 | Five Natures | 爱与被爱、连接感、高价值、独立自主、安全感 |
| 强迫性重复 | Compulsive Repetition | 不由自主地重复某些行为、情绪或关系模式 |
| 内在父母 | Internal Parents | 内化在心中的父母形象，影响成年后的行为 |

## 四种应对姿态

| 姿态 | 特点 | 忽略 | 内在感受 | 资源 |
|------|------|------|---------|------|
| 指责型 | 声音大、有力量 | 忽略他人 | 悲伤 | 有领导力、目标感强 |
| 讨好型 | 温和、妥协 | 忽略自己 | 委屈、愤怒（被压住） | 情感敏感、善解人意 |
| 超理智型 | 讲道理、不表露情感 | 忽略自己与他人 | 害怕被证明是错的 | 博学、雄辩 |
| 打岔型 | 逃避、转移话题 | 三者都忽略 | 无所谓（伪装） | 幽默、灵活、有智慧 |

## 冰山模型各层

| 层次 | 说明 | 问题示例 |
|------|------|---------|
| 行为 | 可见的外部行动 | 他大声吼我 |
| 感受 | 情绪体验 | 愤怒、委屈、悲伤 |
| 想法 | 信念、假设、观点 | "他不尊重我" |
| 期待 | 对别人/别人对自己/自己对自己 | 期待他道歉 |
| 渴望 | 心理营养层面的需求 | 渴望被重视、被接纳 |
| 生命力 | 五大天性的绽放状态 | 爱与被爱、价值感等 |

## 五大心理营养

| 营养 | 关键期 | 核心供给者 | 缺失表现 |
|------|--------|-----------|---------|
| 无条件接纳 | 0-3个月 | 妈妈（本体胺） | 总在证明自己值得被爱 |
| 重视感 | 0-3个月 | 妈妈 | 不断确认"我是不是最重要的" |
| 安全感 | 3个月-3岁 | 妈妈（情绪平和+夫妻关系稳定） | 害怕分离、控制欲强 |
| 被欣赏被肯定 | 4-6岁 | 爸爸 | 自我价值感低 |
| 模范 | 6-12岁 | 父母 | 不知道如何面对冲突和处理情绪 |

## 爱的五种语言

| 语言 | 含义 | 示例 |
|------|------|------|
| 肯定的言词 | 口头赞美和肯定 | "你今天穿这件衣服很好看" |
| 高品质的陪伴 | 全神贯注的个别时间 | 每周固定单独陪伴 |
| 送礼物 | 用礼物表达心意 | 即使是一块捡到的漂亮石头 |
| 服务的行为 | 为对方做事 | 做饭、洗衣服、修理东西 |
| 身体的接触 | 肢体亲昵 | 拥抱、拉手、摸头 |

## 一致性沟通公式

```
事实（客观可验证） + 感受（情绪词） + 想法（我的观点） + 期待（具体请求）
```
