# 第10课：立足边界表达需求

## 学习目标

- 理解"边界"在沟通中的关键作用
- 掌握"以我开头，我有困难，需要你的帮助"的沟通公式

## 边界：分清楚是谁的事

妻子在做饭，嫌丈夫不帮忙，吼了一句："你看不见我有多忙吗？"丈夫也生气了："要帮忙你就说一声，但你能不能好好说话？"

这段争吵中其实有两个不同的边界战场：
1. **做饭是谁的事？**——妻子希望这是两个人的事，丈夫认为是妻子一个人的事
2. **态度是谁的事？**——丈夫在维护自己被吼的边界

> [!TIP] 
> 我们对话的时候，内容都是表面上的，核心是 **关系**。别人踏入你的边界，代表你的事情他可以替你做主。

## "以我开头"的沟通公式

**核心公式：以我开头 + 我有困难 + 需要你的帮助**

| ❌ 越界表达 | ✅ 边界内表达 |
|---|---|
| 你怎么这么没教养 | 我受不了这个声音 |
| 你能不能安静一点 | 我需要一个安静的环境 |
| 你为什么不来帮我 | 我不想一个人做饭，我想你来陪我 |
| 你说话声音太大了 | 你那么大声吼，我有点紧张 |
| 你要多穿衣服不然会冷 | 我怕冷，你要不要为了我多穿一点 |

注意最后一句——"我怕冷关别人什么事？"你这么一想，反而会发现：**如果影响不到我，那人家爱怎么做就怎么做吧**。

## 怎么想，就怎么说

沟通之前先 **往内看**：
1. 在这个事情里，我的感受和需要是什么？
2. 如果我不舒服，不舒服到底在哪里？

比如丈夫吃饭吧唧嘴：
- 如果只是听着不舒服 → "我受不了这个声音，你可不可以照顾一下我"
- 如果是担心影响社交形象 → "我担心在外人面前，这些细节会影响形象"

**你看到自己在乎的是什么，语言自然就准确了。**

## 实践练习

回忆一个你最近最不愉快的沟通场景，试着用"以我开头，我有困难，需要你的帮助"的公式重新组织语言：

1. 原来你是怎么说的？
2. 改用"我"开头怎么说？
3. 你说出来的感觉有什么不同？
