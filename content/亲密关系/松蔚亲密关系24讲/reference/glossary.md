# 核心术语表

## 基础概念

| 术语 | 英文 | 定义 |
|---|---|---|
| 亲密 | intimacy | 你可以跟另一个人一起分享，分享的程度决定亲密的程度 |
| 激情 | passion | 爱情三元素之一，因相互吸引产生的高强度美好体验，高峰平均半年 |
| 承诺 | commitment | 爱情三元素之一，通过法律、道德、信仰约束的契约 |
| 亲密（三元素） | intimacy | 爱情三元素之一，分享感受、脆弱、思想的心理连接 |
| 确定性 | certainty | 人对稳定、可预测、可控的心理需求 |
| 不确定性 | uncertainty | 亲密关系中不可避免的风险和未知 |

## 核心模型

| 模型 | 说明 |
|---|---|
| 规划模型 | 认为所有问题都可以提前设计出最优解决方案，适用于物理世界 |
| 漂流模型 | 接受不确定性，一边努力一边顺应更大的力量，适用于亲密关系 |
| 一致性模型 | 追求两个人的一致，认为不一致是问题 |
| 互补性模型 | 接受不一致，让差异形成合力，一加一大于二 |

## 沟通原则

| 术语 | 说明 |
|---|---|
| 边界 | 分清楚一件事是谁的事 |
| 需求 | 以我开头表达"我需要什么" |
| 问题取向 | 关注"问题是怎么来的、谁造成的" |
| 资源取向 | 关注"问题怎么解决、谁能帮忙" |
| 认可（validate） | 承认对方的感受在ta那里是有效的 |
| 新符号系统 | 用语言之外的道具、行动等创造新的沟通方式 |

## 关系现象

| 术语 | 说明 |
|---|---|
| 第三条路 | 不强制不委屈不评判，让双方同时满足的解决方案 |
| 三角化 | 两个人之间的问题通过第三个人（通常是孩子）来传递和消化 |
| 互补 | 不一致的两个人互相配合补足，形成合力 |
| 自我实现预言 | 先入为主的结论扭曲对信息的解读，最终让结论成真 |
| 内部冲突外部化 | 把内心的矛盾投射到关系中的另一半身上 |

## 结束与告别

| 术语 | 说明 |
|---|---|
| 成熟分离 | 主动选择结束关系，带着祝福各自向前 |
| 仪式 | 用象征性行为完成心理上的告别 |
| 哀伤 | 从愤怒到接受的心理转变过程 |
