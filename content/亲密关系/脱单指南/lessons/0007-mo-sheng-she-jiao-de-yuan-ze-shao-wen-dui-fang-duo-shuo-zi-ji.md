# 第07课：陌生社交的原则——少问对方多说自己

## Learning Objectives
- 掌握"一问一接"的对话技巧，避免查户口式提问
- 理解男人"猎人心理"对社交的负面影响，学会主动展示自己
- 能够在和陌生女孩交流时，自然地交替提问和自我介绍

## Core Idea

陌生社交中最大的错误是什么？**查户口。** 很多男生在搭讪时像警察审讯一样连环发问——"你叫什么？""你多大了？""你做什么工作的？""你家住哪？"——让对方感觉极度不适。

正确的原则是：**少问对方，多说自己。** 可以提问，但不能只提问。每问一个问题，把对方的回答接过来，做自我介绍。

```mermaid

    subgraph 错误模式：查户口
        A1[你叫什么？] --> A2[XX]
        A2 --> A3[你多大？]
        A3 --> A4[XX]
        A4 --> A5[你做什么工作？]

    subgraph 正确模式：一问一接
        B1[你做什么工作？] --> B2[我是设计师]
        B2 --> B3[哦设计师啊，\n我是做编程的，\n我们算是半个同行]
        B3 --> B4[真的吗？\n你做什么类型编程？]
        B4 --> B5[我做前端开发，\n就是网页那些……]
    end
```

**"一问一接"公式**：提问 → 对方回答 → 你根据回答做自我介绍 → 对方自然对你产生了解 → 气氛变轻松。

> [!TIP] Key Insight
> 男人的"猎人心理"让他们习惯于隐藏自己、打探对方——这是狩猎时代留下的本能。但在追求女孩这件事上，你必须**克服这种本能**。你要勇敢地走到对方面前，展示你是谁，而不是躲在暗处搜集她的信息。主动展示自己不是炫耀，而是给对方一个"了解你"的机会。

> [!NOTE] 关于紧张
> 搭讪时紧张是正常的，但紧张时的本能反应往往是"不说话"或"连环提问"。意识到这个倾向后，可以刻意练习"多说自己"。如果你不知道说什么，就说你此刻的感受——"其实我有点紧张，因为很少做这种事，但我觉得不过来认识你会后悔。"这本身就是一个很好的自我介绍。

## Worked Example

**场景**：你在咖啡店搭讪了一个女孩，她说她正在备考研究生。

**查户口模式**：
你："考哪个学校？"（她回答）
你："考什么专业？"（她回答）
你："什么时候考？"（她开始觉得不舒服）

**一问一接模式**：
你："考哪个学校？"
她："XX大学。"
你："哦，我也是那个学校毕业的！（或者）我朋友也在那里读过，听说校园特别漂亮。我当时读书的时候经常去那边蹭课……"
（然后她可以接着你的话说，再之后你可以继续问她为什么选这个专业）

看出来区别了吗？同样的信息——考哪个学校——你通过一问一接的方式，让对话变得自然流动，而不是一问一答的审问。

## Practice

> [!QUESTION] Self-check
> 假设你搭讪了一个女孩，她说她是个宠物医生。你的下一句应该说什么？请用"一问一接"的模式写出你的回答——先写出提问（如果你想问问题的话），再写出你在此基础上做的自我介绍。

参考示范（不需要完全照搬）：
"宠物医生！这个工作好有意思。（接对方的回答做反馈）
我小时候一直想当兽医，但因为怕血就没去成，现在做互联网。（自我介绍）
对了，你平时工作主要看猫还是看狗？"（合理提问，让对话继续）

注意观察：这里虽然也问了问题，但在此之前你先做了**反馈**和**自我介绍**，这样就避免了"查户口"的感觉。关键在于**永远不要连续提问**，每个问题之间都要插入关于你自己的内容。
