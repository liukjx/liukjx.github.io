# 术语表 GLOSSARY

## 核心概念

| 术语 | 英文 | 定义 |
|------|------|------|
| 原生家庭 | Family of Origin | 一个人出生和成长的家庭，对个人性格、价值观和关系模式有深远影响 |
| 家庭忠诚 | Family Loyalty | 子女在无意识中对父母命运、行为模式的复制和认同 |
| 自恋 | Narcissism | 人天生具有的核心自恋，是发展的原动力；健康自恋vs不健康自恋vs恶性自恋 |
| 投射性认同 | Projective Identification | 一个人诱导他人以特定方式行为，以确认自己内心投射的过程 |
| 三角关系 | Triangulation | 当两人系统遇到问题时，把第三个人拉进来减轻情绪冲击的关系模式 |
| 客体关系 | Object Relations | 早期与重要他人（客体）的互动经验内化为内在关系模式，影响未来所有关系 |
| 内在关系模式 | Internal Working Model | 童年与父母互动形成的对自我和他人的认知模板，影响亲密关系 |
| 强迫性重复 | Repetition Compulsion | 无意识地重复童年创伤情境或关系模式的现象 |
| 个体化 | Individuation | 从与父母融合的状态中分离出来，成为独立个体的心理过程 |
| 依恋理论 | Attachment Theory | 描述婴儿与照顾者之间的情感纽带如何影响成人关系的理论 |

## 依恋类型

| 类型 | 特征 |
|------|------|
| 安全型依恋 | 低焦虑+低回避，能建立健康亲密关系 |
| 迷恋型依恋 | 低回避+高焦虑，过度依赖和控制伴侣 |
| 冷漠型依恋 | 高回避+低焦虑，回避亲密和情感连接 |
| 恐惧型依恋 | 高回避+高焦虑，既渴望亲密又害怕受伤 |

## 沟通模式（萨提亚）

| 模式 | 特征 |
|------|------|
| 讨好 | 忽略自己，迎合他人，害怕被抛弃 |
| 指责 | 忽略他人，证明自己正确，贬低对方 |
| 超理智 | 忽略情感，只讲逻辑和事实，缺乏共情 |
| 打岔 | 忽略情境，回避冲突和尴尬 |
| 一致性沟通 | 兼顾自我、他人和情境，真诚表达 |

## 其他关键概念

| 术语 | 定义 |
|------|------|
| 冰山原理 | 萨提亚理论：人的自我像冰山，行为可见（水面上），感受、期待、渴望等在水面下 |
| 共情 | 看见并感受他人的情绪和处境，是建立深层链接的能力 |
| 分化 Separation | 从家庭情感融合中独立出来，保持自我同时维持亲密的能力 |
| 边界 | 家庭中个体之间的心理界限，健康的边界保护自主性和亲密感 |
| 家庭动力 | 家庭成员之间的情感流动模式，影响家庭氛围和个体发展 |
| 情绪蔓延 | 家庭成员之间情绪的相互感染和传递 |
| 仪式感 | 通过固定仪式维持家庭情感链接和归属感 |
| 家庭角色 | 家庭成员在系统中扮演的功能性角色（照顾者、拯救者、替罪羊等） |
