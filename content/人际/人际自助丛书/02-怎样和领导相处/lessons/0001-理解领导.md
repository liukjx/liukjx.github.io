# 第01课：理解领导

## 本节导读

要与领导和谐相处，首先需要理解领导。本章从经验主义和实用主义的态度出发，揭示领导行为背后的真实原因，帮助下属从环境和人性的角度去接受、理解、分析领导，进而想办法去适应和改造他。

---

## 一、领导为什么需要"架子"

"架子"实质上是一种**距离感**，领导需要利用它来：

### 1. 显示权力
- 通过有意识地保持与下属的距离，使下属认识到权力等级的存在
- 威严感会给领导形成一种威慑力，使下属感到"服从也许是最好的选择"
- 如果领导过分随和，下属可能因轻慢权威而怠惰、拖延甚至破坏

### 2. 带来神秘感
- 领导处于各种利益和矛盾的焦点，需要懂得掩藏自己，使心机不被窥破
- 如果下属很容易揣摩到领导的心思，就可能利用来达到自己的目的

### 3. 有助于处理政务
- 距离感为领导处理人际关系及政务提供了回旋余地
- 领导可随时根据需要通过调节距离来调动不同人的积极性

### 4. 增加仪表魅力
- 得体的"架子"会增加领导的气势和威严感
- 有助于增加自信、意志力，从形象上唤起别人的敬佩和好感

### 5. 产生满足感
- 通过获取权力来实现人生价值是中国人重要的衡量标准
- 领导也需要人生价值得以实现的满足感

> 戴高乐在《剑锋》中写道："没有神秘就不可能有威信，因为对于一个人太熟悉了就会产生轻蔑之感。"

## 二、刚升任领导为什么就"傲起来了"

很多时候，领导不是"傲起来了"，而是由于下属未能正确理解领导：

### 工作压力方面的原因
领导刚一高就，面临打开工作局面、站稳脚跟、干出成绩等巨大压力，几乎把所有心思都放在工作上，可能忽视了与别人的交往。

### 人际关系方面的原因
领导升任新职后，面临更广阔的人际关系网络，每个人在领导眼中的地位都会发生相应变化。正如一勺盐放到一碗汤与放到一锅汤，效果肯定不同。

### 利益格局方面的原因
领导为了做出更大的成绩，可能有意地冷落或疏远某些人。下属应理解利益关系，更加努力地工作，提高自己在领导心中的重要性。

### 权力地位方面的原因
当副职转为正职时，会产生扬眉吐气的感觉。领导必须遵循"权力金字塔"中的等级规则。

## 三、领导为什么更有权力发火

### 发脾气会帮助领导推进工作
发火是对未能按要求完成任务的惩戒，比温和的批评更强烈、更有效。有些领导善于运用"发脾气"来达到"一张一弛"的管理效果。

### 领导负有责任，心理压力大
领导必须承担相应责任，在巨大压力下，心情难免紧张，很容易为下属的不理解、不争气而感到恼火。

### 领导事务缠身，心情烦躁
领导处于各种矛盾的焦点上，必须处理最棘手的问题、听最不好听的话、做最不愿做的事。这些都会使领导心情烦躁，容易发脾气。

> 毛泽东曾对卫士说："我工作多，脑子里想事多，睡不容易，烦躁，情绪就不好控制。我也是人么，人总是有点脾气，我们要相互体谅。"

## 四、领导的责任和压力有多大

| 压力类型 | 具体表现 |
|---------|---------|
| 位高而责重 | 必须干出成绩，否则失去上级信任 |
| 官大一级压死人 | 要处理好与上级的关系，承受各种人情压力 |
| 关系复杂 | 中国是"关系"社会，搞工作不如搞关系 |
| 权力角逐 | 怕被取代、怕部下勾结、怕盟友背叛 |
| 文山会海 | 开不完的会、批不完的文件、喝不完的酒席 |
| 明枪暗箭 | 得罪人后可能被流言蜚语中伤 |
| 时间紧张 | 生活节奏紧张，很少有时间和心情发展爱好 |
| 情感与理智 | 常在故情旧谊与现实需要之间做出痛苦选择 |
| 家庭遗憾 | 没有时间陪伴家人，子女教育可能出问题 |
| 内心苦闷 | 角色冲突、左右为难、被人出卖等心理痛苦 |

## 五、领导其实更在乎下属的态度

聪明的领导很在意下级的态度，因为：

1. **下级是工作成绩的真正创造者** —— 领导的谋划要成为现实，离不开下级的细致工作
2. **下级手中握有选票** —— 民主评议制使群众的态度越来越重要
3. **下级可帮助领导树立良好的社会形象** —— "痒要自己抓，好要别人夸"
4. **重视下级可防止"后院起火"** —— 堡垒最容易从内部攻破

> 马基雅维里在《君主论》中写道："遽然勃兴的国家，如同自然界迅速滋生长大的其他一切东西一样，不能够根深蒂固、枝桠交错，一旦遇到一场狂风暴雨就把它摧毁了。"
