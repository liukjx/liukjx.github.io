## 本课概要

本章通过记者的第一人称视角，讲述了寻访脸皮学院的经过。记者受社会上关于"LP证书"（脸皮学院证书拼音缩写）的传闻驱动，追踪到一家神秘的研究机构——中国脸皮研究所，亲眼目睹了高科技的脸皮指数测量系统，并与学院总务长进行了深入交流。

## 核心知识点

### 1. "LP证书"现象

- 社会上流传着拥有"LP证书"的人更容易找工作、心理素质更好、交际能力更强
- 甚至有人开始盗印"LP证书"牟取暴利
- 这反映了社会对心理素质和人际能力的重视

### 2. 脸皮指数（Face Quotient）

脸皮学院开发了一套"脸皮指数"测量系统，运用了以下技术：

| 技术手段 | 用途 |
|----------|------|
| 虚拟现实电子视屏 | 模拟各种生活和工作的尴尬场景 |
| 生物传感器 | 检测血压、心率、皮肤温度等生理变化 |
| 中央处理器 | 汇总分析数据，得出脸皮指数 |

- **标准值**: 100（最为正常）
- **超过100**: 心理素质超强
- **低于100**: 脸皮偏薄，需加强训练

### 3. 关键人物案例：小张的转变

- 从小被教育"要听话"，形成强烈依赖性和自我压抑
- 特别害怕与人交往，丢一回脸就深以为耻
- 大学毕业后因无法适应人际关系，一年换多份工作
- 经过脸皮学院训练，脸皮指数提高了12个百分点
- 最终重获自信，开始了新生活

### 4. 脸皮学院的教学方式

| 教学方式 | 内容 |
|----------|------|
| 观看录像 | 美国总统电视辩论或竞选演说 |
| 小组讨论 | 热烈讨论，走到黑板前演示主张 |
| 催眠疗法 | 以暗示方式增强心理能力 |
| 体力训练 | 严格甚至残酷的体能训练 |
| 表演课 | 模仿各种表情，练习公开表演 |

### 5. "败絮其外，金玉其中"的教学理念

- 脸皮学院的主楼外观寒酸破旧，内部却精致典雅
- 这本身就是一种教学理念的体现：**不要被外表所迷惑，要注重内在的"里子"**
- 一个人如果能够从形式上领悟到这一寓意，就算是"小有所通"

## 实用启示

1. **脸皮是可以通过科学方法训练的**——不要认为"脸皮薄"是天生无法改变的性格缺陷
2. **自我压抑是心理健康的敌人**——长期屈从于他人看法，会损害正常的社会功能
3. **外在的朴素与内在的丰富并不矛盾**——不必过分在意外在形式，关键是内在实力的提升
