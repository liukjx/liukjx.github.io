# 第03课：小人的危险之处

## 第一节 小人难以识别

小人戴着假面，做伪技术的高妙令人叹为观止。当人们被需求的满足搞得欣欣然、醺醺然时，往往会放松警惕，小人常常靠满足他人而乘虚而入。

**郑袖的案例：** 郑袖为了除掉魏美人，表面上对她关怀备至，暗中却设计让楚王以为魏美人嫌他体臭，最终魏美人被处以割鼻之刑。

## 第二节 一般人为什么怕得罪小人

**五大原因：**

| 原因 | 说明 |
|------|------|
| 明枪易躲，暗箭难防 | 一般人在明处，小人在暗处 |
| 没有原则立场 | 小人没有道德约束，一般人招架不住 |
| 谋人不谋事 | 一般人忙正事没时间纠缠，小人专攻算计 |
| 小人记仇 | 一点小事可能招来疯狂报复 |
| 小人本质胆小 | 害过你一次后还会继续害你，直到你丧失报复能力 |

## 第三节 小人不怕坏大事

小人只顾自己的利益，从来不怕因自己的小利益而破坏他人或群体的大利益。

**李林甫的案例：** 为了堵死将帅入相之路，建议重用胡人将领，结果造成了安禄山等人拥兵自重，为唐王朝埋下巨大隐患。

**刘义康的案例：** 因嫉妒大将檀道济的才能，将其陷害致死，自毁长城。

## 第四节 小人勇于充当某种势力的作恶工具

一旦成为恶势力的工具，小人往往具备更大的破坏性。戴笠就是典型的例子——成为蒋介石手下的特务头子，以残忍、冷酷、卑劣的手段服务于蒋介石的权力需求。

## 自我测试

2. 为什么说"一般人在明处，小人在暗处"？
3. 面对小人的威胁，除了躲避，还有哪些应对策略？
