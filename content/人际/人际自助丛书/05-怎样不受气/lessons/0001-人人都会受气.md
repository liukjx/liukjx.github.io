## 核心知识点

### 一、什么是"受气"

受气是指一个人因为不能避免已经发生或尚未发生的种种挫折、困难、压力、打击、报复、嘲笑、挖苦等消极事态，而在心理上产生的与生气相伴随的委屈、羞辱、窝囊和愤怒的感受。

> 受气 = 外部负面刺激 × 主观心理结构

### 二、为什么人人都会受气

#### 1. 客观原因：社会充满利益矛盾

- 资源稀缺导致竞争，竞争产生强弱，强弱带来"受气"与"不受气"的分别
- 人们的利益诉求不同，同一事件对不同人有不同影响
- 越是对众人有吸引力的地方（权力、财富、职称），利益之争越激烈

#### 2. 主观原因：心理结构无法避免消极情绪

- 环境不安全、不稳定时，心理状态必然呈现消极特征
- 欲望受挫时，必然产生消极情绪和"受气"感受
- 适度的"受气"对心理成长反而是必需的

#### 3. "气往低处流"的传播规律

受气现象遵循"气往低处流"的准则——强势者向弱势者施气，弱势者再向更弱者转嫁。通过连锁反应，受气现象在人群中普遍扩散。

> 漫画故事：局长骂科长→科长骂办事员→办事员骂老婆→老婆骂顾客→顾客是局长夫人→回家骂局长

#### 4. 大人物同样受气

> 叶剑英元帅在文革期间忍辱负重，面对江青无理取闹，为大局只能压住火气。开国元勋尚且如此，何况普通人。

### 三、中国人为什么容易受气

| 原因 | 说明 |
|------|------|
| 封建专制残余 | 权力缺乏监督，官僚主义盛行 |
| 个人力量弱小 | 缺乏个性，强调服从，一盘散沙 |
| "窝里斗"传统 | 内耗严重，恶化人际关系 |
| 信息沟通不畅 | 缺乏合理发泄渠道 |
| 经济发展水平低 | 不注重效益，纠缠于小事 |

### 四、关键是怎样看待受气

#### 角度决定感受

同一件事，视角不同，结论完全不同。将受气视为磨练和考验，心态就会不同。

> 晋公子重耳乞食得土块，初以为侮辱，后听从劝告将土块视为"土地象征"，转怒为喜。

#### 高度决定视野

站在低处看问题总觉得大得不得了，从更高处审视，不过是沧海一粟。

> 毛泽东劝柳亚子："牢骚太盛防肠断，风物长宜放眼量。"

#### 利益权衡决定反应

值不值得生气？生气对事情有补救作用吗？答案经常是否定的。

> 东汉刘宽被夫人故意泼汤弄脏朝服，不怒反问"烫伤手没有"——与其发火浪费时间，不如泰然处之抓紧补救。

### 五、大人物看待受气的三种方式

| 方式 | 代表人物 | 核心做法 |
|------|----------|----------|
| 对外施气，对内不气 | 李敖 | 对俗人使气，自己却绝不生气 |
| 识大体顾大局 | 周恩来 | 为大局忍辱负重，"我不下地狱谁下地狱" |
| 以结果为取向 | 韩信、司马懿 | 受胯下之辱、受女裙之辱，只为最终胜利 |

### 六、不受气的四大原则（总纲）

1. **确定自己行为的界限** — 知道自己是干什么的，不和"一般见识"
2. **培养自己的正气** — 站在多数人立场上处理人际关系
3. **塑造不好惹的形象** — 气往低处流，不好惹的人不受气
4. **勇敢突破第一次** — 跨过第一次反抗的门槛

## 总结

受气是人生的常态，人人都无法避免。认识到这一点本身就具有释压作用。解决问题的关键不在于"不受气"，而在于如何看待它、处理它。大人物之所以不大受气，不是因为没人给他们气受，而是因为他们站得更高、看得更远、算得更清。**心态把握在我们自己手中，气与不气，关键在于我们自己怎么看。**
