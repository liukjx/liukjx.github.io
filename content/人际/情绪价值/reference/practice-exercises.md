# 练习手册

## 使用说明

- 每个练习约 5-15 分钟
- 建议每课学完后 24 小时内完成配套练习
- 准备一个**专属练习本**或备忘录，记录所有练习
- 不要追求一次性做完美，关键是**坚持做**

---

## 第01课配套练习：情绪价值扫描

### 练习A：识别日常中的情绪收益与成本（5分钟）

回想过去一周你和伴侣/密友的互动，按公式列出：

| 我给了对方哪些情绪收益？ | 我给了对方哪些情绪成本？ |
|------------------------|------------------------|
| _(例：夸他做饭好吃)_ | _(例：他晚回消息时我发了脾气)_ |
| | |
| | |

**反思**：你的情绪收益 > 情绪成本吗？如果不是，差距在哪里？

### 练习B：区分讨好 vs 情绪价值（10分钟）

想一个你最近讨好别人的场景，回答：

1. 当时我这么做，是因为"我想给"还是"我怕不给"？
2. 如果对方没有回应/感谢，我会难受吗？
3. 我对这段关系有"我付出了这么多"的计较感吗？

**关键**：只要第2或第3题答案是"是"，那更接近讨好。

## 第02课配套练习：差异理解

### 练习A：识别你的思维倾向（5分钟）

你是更倾向于：
- A：遇到问题先找解决方案 → 偏向男性思维
- B：遇到问题先倾诉感受 → 偏向女性思维
- C：都能切换 → 偏向复合型思维

### 练习B：理解对方的思维（10分钟）

想一个你最近和伴侣/朋友的冲突：

1. 对方当时的做法是什么？（客观描述）
2. 如果用对方的思维模式来解释，TA为什么会这么做？
3. 如果按照对方需要的方式来回应，你会怎么做？

> **提示**：不是要你认同对方，只是先理解。理解≠同意。

## 第03课配套练习：筛选自查

### 练习A：自我对照（5分钟）

对照五种"不值得付出"的类型，诚实地问自己：

| 类型 | 我有这个倾向吗？ |
|------|----------------|
|6
| 贪心索取 — 总在计算谁付出得多 | |
| 高估自己 — 觉得自己条件好就该被哄 | |
| 矛盾需求 — 想要A面又不接受B面 | |
| 靠情绪价值高攀 — 基础价值不够还不想提升 | |
| 对别人不会夸 — 觉得夸人是丢脸 | |

### 练习B：对方筛查（10分钟）

如果正在考虑一段关系，对照这五点给对方打打分。任何一点明显存在，建议重新评估是否值得投入。

## 第04课配套练习：情绪稳定训练

### 练习A：情绪日记模板（每日，连续7天）

| 日期 | 触发事件 | 我的感受 | 背后未被满足的需要 | 如果我冷静处理会怎样 |
|------|---------|---------|------------------|-------------------|
| | 他回消息慢了 | 生气、不安 | 我需要被重视 | 他在忙，晚点再聊 |
| | | | | |

**至少写7天**，你就能看清自己的情绪触发模式。

### 练习B：顿感力训练（每日）

选一件你今天因为别人无心的言行而耿耿于怀的事，问自己：

- 这件事5年后还重要吗？
- 对方是不是故意的？如果只是无心，我何必内耗？

## 第05课配套练习：六步法实操

### 练习：情绪模拟（15分钟）

选一个"历史重演"的场景——比如上次你和伴侣吵架的事情——用六步法重走一遍：

1. **认知提升**：把自己放在强者位置——"我不需要跟他吵，我是主动选择包容"
2. **觉察记录**：写下来——哪个点触发了我？
3. **控制语气**：想象自己在那个场景中放慢语速、压低声音
4. **停止行动**：告诉自己"现在停下来，什么都不做比做什么好"
5. **正向思考**：这件事能带给我什么？暴露了什么问题？
6. **复盘**：如果我下次再遇到同样情况，我怎么做更好？

## 第06课配套练习：复合思维训练

### 练习A：男性思维模拟（10分钟）

遇到一个情绪困扰时，问自己：

> "如果我现在是一个极度理性的CEO，我会怎么处理这个问题？"

不要想感受，只想解决方案。

### 练习B：观察"一体两面"（每日）

今天留意伴侣/同事让你不舒服的一个特质，然后问：

> "这个特质的反面，对应的优势是什么？"

| 让我不舒服的点 | 它对应的优势 |
| 我是否愿意为这个优势接受这个不舒服？ |
|--------------|------------|-----------------------------------|
| | | |

## 第07课配套练习：夸人训练

### 练习A：七种夸法轮练（第一周，每天一种）

- 周一：反向夸奖 — 把一个缺点说成特点
- 周二：夸细节 — 发现一个别人看不到的优点
- 周三：夸投入 — 夸他花时间的事
- 周四：夸过程 — 夸他还没成果但坚持的事
- 周五：夸影响 — 用他教的方法，然后反馈
- 周六：强化正向 — 只夸好的，忽略不好的
- 周日：偏爱句式 — 用"只有你可以"等

### 练习B：反向学习法（持续）

当别人夸你让你感觉很受用时，立刻记下来：

> **时间**：______ **场景**：_______**对方说了什么**：_______**我当时的感觉**：_______**我学到了什么**：________

积累20条以上，你就有自己的"夸人素材库"。

## 第08课配套练习：自我诊断

### 练习：找出你的惯性错误（10分钟）

对比六种误区，找出你最容易犯的1-2种：

1. 用甜言蜜语包裹索取？
2. 道德绑架式夸奖？
3. 套路化夸奖（冷读术）？
4. "虽然……但是……"明褒暗贬？
5. 打着关心旗号干预？
6. 表面夸对方实际夸自己？

**这周专注于改掉其中一种**。

## 第09课配套练习：事业型伴侣模拟

### 练习A：需求分析（10分钟）

如果你的伴侣是事业型（或你希望成为事业型），完成：

1. 他目前最缺的是什么？（时间？信任？空间？）
2. 我能给他的、对他最轻松的是什么？
3. 我有没有在用他最难给的方式提要求？

### 练习B：提要求三句式（5分钟）

把三个要求从"命令式"改成"撒娇式"：

| 原来的说法 | 改成撒娇式 |
|-----------|-----------|
| 你怎么又这么晚回来 | |
| 你能不能多陪陪我 | |
| 你一点都不在乎我 | |

## 第10课配套练习：风险评估

### 练习：关系审计（15分钟）

针对你当前或最近的一段关系：

1. __对方提供情绪价值的同时，他图我什么？__
   - 什么也不图（相互付出） → 健康
   - 图我的资源/人脉 → 注意风险
   - 图我的钱 → 警惕

2. __如果对方得到他想要的东西后停止提供情绪价值，我能接受吗？__

3. __我有自己的成长路径吗？还是把全部安全感建立在对方提供的情绪价值上？__

## 第11课配套练习：男性视角

### 练习A：倾听 vs 解决（男性专用，7天）

每天记录一次伴侣向你倾诉的时刻：

| 她说的事 | 我本能想做的事 | 我试着做了的事 | 结果 |
|---------|-------------|-------------|------|
| 抱怨工作 | 给建议 | 先听她说，"那确实烦人" | 她说"你懂我" |

**目标**：7天后，把"先共情再解决"变成习惯。

### 练习B：主动给予（男性专用，7天）

每天做一个主动给予情绪价值的小动作：

- 说一句"辛苦了"
- 发一条非事务性的消息（不是"几点回来？"而是"今天天气不错"）
- 主动拥抱一下
- 记住她随口提的一件事，过两天问一下

## 进阶练习：21天情绪价值计划

| 周 | 主题 | 每日任务 |
|----|------|---------|
| 第1周 | 觉察 | 每天写情绪日记，只观察不动手 |
| 第2周 | 止损 | 每天减少一次负面反馈，增加一次正向反馈 |
| 第3周 | 给予 | 每天主动做一件给予情绪价值的事 |

> [!TIP] 最重要的原则
> **不要追求完美。第一天做不好很正常，第21天能做好的事，第1天做不到是应该的。** 关键在于坚持。
