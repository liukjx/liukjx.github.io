# 《增广贤文》金句速查表

本表收录课程中涉及的核心金句及核心观点，按四大板块分类。

| 版块 | 课号 | 金句 | 核心智慧 | 经典案例 |
|------|------|------|----------|----------|
| 知人 | 第1课 | 虎生犹可近，人熟不可亲 | 熟人之间要保持界限感——心灵上不过高期望，行为上不过分亲密 | 张耳陈馀刎颈之交反目成仇；苏青张爱玲闺蜜反目 |
| 知人 | 第2课 | 相逢好似初相识，到老终无怨恨心 | 越熟越要保持刚认识时的界限感和尊重；期望越低，失望越小 | 范增对项羽没有界限感；杜甫管闲事招祸 |
| 知人 | 第3课 | 结交须胜己，似我不如吾 | 交朋友是资源互换和优势互补。先让自己成为高质量有用的人 | 王安石结交韩维、吕夷简走上宰相之路 |
| 知人 | 第4课 | 知音说与知音听，不是知音莫与谈；志不同己，不必强合；相识满天下，知心能几人 | 交友的"断舍离"——断（三观不合不交往）、舍（发现不合果断舍弃）、离（分清知己和人脉） | 管宁割席；嵇康与山涛绝交书 |
| 知人 | 第5课 | 栽树要栽松柏，结交要结君子；易涨易退山溪水，易反易复小人心 | 识别小人四个特征：无底线、怕规则、善变化、最喜欢君子 | 冯道（四朝十帝的宰相）；沈括（陷害苏轼） |
| 知人 | 第6课 | 一人不得二人计，宋江难结万人缘 | 不可能让所有人都喜欢你。不要做讨好型人格 | 蒋方舟的讨好型人格经历 |
| 小事 | 第7课 | 逢人只说三分话，未可全抛一片心 | 别轻易劝人出主意；交情无论深浅话别说太深；自己的秘密别跟人说，别人的秘密别打听 | 唐小姐故事；太子赵竑因话多被废 |
| 小事 | 第8课 | 与人方便，与己方便；当面留一线，过后好相见 | 做人要厚道。给别人留后路就是给自己留活路 | 林志玲巧答记者问；楚庄王绝缨之宴；孙传芳做得太绝被刺杀 |
| 小事 | 第9课 | 无求到处人情好，不饮任他酒价高；人不走不亲，水不打不浑 | 万事不求人只是不招人讨厌，要想关系近必须互相走动互相求 | 管鲍之交（管仲不断求鲍叔牙，关系越来越铁） |
| 小事 | 第10课 | 力微休负重，言轻莫劝人；一言不中，千言不用 | 劝人要有地位、说得对。要把握被劝者的性格和心理倾向 | 张飞地位低说话没人听；陈宫劝吕布失败；颍考叔劝郑庄公 |
| 小事 | 第11课 | 听君一席话，胜读十年书 | 顿悟的前提是已有十年积累。没有积累，一席话没用 | 张无忌（九阳真经+乾坤大挪移）；段永平请巴菲特吃饭 |
| 小事 | 第12课 | 得宠思辱，居安思危；人无远虑，必有近忧；晴带雨伞，饱带饥粮 | 未雨绸缪。做最好的准备，做最坏的打算 | 诸葛亮杀魏延；周公未雨绸缪 |
| 小事 | 第13课 | 听人劝，得一半 | 听人劝只完成了开始的一半——要有肚量、判断目的、判断内容质量 | 刘邦听萧何劝拜韩信；曹操听庞统献连环计 |
| 小事 | 第14课 | 男大当婚，女大当嫁；不婚不嫁，惹出笑话 | 到了一定年龄该独立成家。不结婚还跟父母住容易产生啃老和矛盾 | — |
| 修心 | 第15课 | 吃亏是福 | 吃亏是技术活：吃小亏不吃大亏、吃主动亏不吃被动亏、吃眼前亏不吃长远亏 | 俞敏洪主动打水扫地四年；亚马逊早期亏损占市场 |
| 修心 | 第16课 | 人老心不老，人穷志不穷 | 克服中年危机的两件法宝：目标常在（不忘初心）和勇气信心常在 | 刘备髀肉复感叹息；安藤百福48岁发明方便面 |
| 修心 | 第17课 | 自恨枝无叶，莫怨太阳偏；责人之心责己，恕己之心恕人 | 同理心三层递进：先在自己身上找原因、别揪着别人错不放、用责己标准责人用恕己标准恕人 | 将相和；蒋琬"宰相肚里能撑船" |
| 修心 | 第18课 | 黄金未为贵，安乐值钱多 | 城市选择的核心是内心安乐——性格决定能扛多少压力，刚需决定最终去向 | 陶渊明（性格归隐）、李白（性格漂泊）、史大成（刚需尽孝） |
| 笃行 | 第19课 | 养男莫听狂言，养女莫叫离母 | 穷养儿富养女和钱无关——养男核心：规则意识+精神支持；养女核心：情感满足+见世面 | 陶侃母亲教子之道（割发待客、退鱼诫子、搬砖锻炼） |
| 笃行 | 第20课 | 出家如初，成佛有余 | 不忘初心。坚持一开始的信念，不被诱惑偏离轨道 | 洪秀全从追求平等到腐败独裁；夫差忘了杀父之仇；勾践卧薪尝胆 |
| 笃行 | 第21课 | 三思而行，再思可矣；出入行业三年事成 | 战略阶段三思而行（多想大方向），战术阶段再思可矣（只思考失败能否承受） | 袁绍好谋无决（失去先机、被牵着走、失去人心）；铁杵磨成针的反思 |
