## 一、模板修改入口

修改模板有3个入口：

| 入口 | 操作路径 | 特点 |
|------|---------|------|
| **菜单栏** | 工具→管理笔记模板→选择模板→卡片 | 无法看到实时预览 |
| **添加窗口** | 添加按钮→填写内容→卡片按钮 | 有内容后可看到预览 |
| **复习时** | 编辑→卡片按钮 | 实时看到当前笔记效果 |

> [!NOTE] 重要
> 每个模板的修改只针对当前模板。如果修改了问答模板，填空题模板不受影响。修改后可以通过同步在手机上生效。

## 二、基本CSS样式

把CSS当成英语单词来学就可以了。以下是最常用的样式：

| 属性 | 作用 | 示例值 |
|------|------|--------|
| `font-family` | 字体 | Arial, "Microsoft YaHei" |
| `font-size` | 字号 | 20px |
| `text-align` | 对齐方式 | left（建议左对齐） |
| `color` | 文字颜色 | #333333 |
| `background-color` | 背景色 | white |
| `font-weight` | 字重 | bold / lighter |
| `line-height` | 行间距 | 1.8 或 30px |
| `letter-spacing` | 字间距 | 1px |

```css
/* Anki 默认卡片样式示例 */
.card {
  font-family: Arial;
  font-size: 20px;
  text-align: left;  /* 建议改为 left */
  color: black;
  background-color: white;
}
```

### 注意事项

- 所有字符使用**英文半角**（`:` `;` `{` `}` 都要英文）
- 属性名和属性值之间用英文冒号
- 每个属性结尾用英文分号
- 复制别人的代码时注意依葫芦画瓢

## 三、增强按钮样式

Anki 编辑器自带加粗（B）、斜体（I）、下划线（U）按钮，默认样式很朴素。我们可以自定义这些标签的样式。

```css
/* 在样式区添加 */
b { color: white; background-color: #e74c3c; padding: 2px 5px; border-radius: 4px; }
i { color: white; background-color: #3498db; padding: 2px 5px; border-radius: 4px; }
u { color: white; background-color: #2ecc71; padding: 2px 5px; border-radius: 4px; }
```

效果：加粗的文字变成红底白字 + 圆角，斜体蓝底白字，下划线绿底白字。设置一次后，所有使用该模板的笔记都会应用此样式。

### 去除默认样式

如果不想保留原来的加粗效果，可以加一行 `all: unset;` 取消默认样式再应用自定义样式。

## 四、更换字体

1. 在网上搜索并下载字体文件（.ttf）
2. 将字体文件放入 Anki 的媒体文件夹（工具→插件→查看文件→返回上级→账户名→collection.media）
3. 重命名为拼音/英文，以 `_` 开头，如 `_xxhk.ttf`
4. 在模板样式区底部添加 @font-face 引用
5. 在 .card 样式中修改 font-family 为字体名称

```css
/* 在样式区最底部添加 */
@font-face {
  font-family: xxhk;
  src: url("_xxhk.ttf");
}

/* 然后修改 .card 的 font-family */
.card { font-family: xxhk; }
```

## 五、添加字段与创建模板

### 创建新模板

1. 工具→管理笔记模板→添加
2. 选择系统自带模板或基于已有模板复制
3. 重命名→创建完成

### 添加字段

1. 在模板窗口点击"字段"→添加
2. 输入字段名（如"引用""例子"）
3. 点击"卡片"→在代码中用 `{{字段名}}` 引用

### 提示字段（点击显示）

在字段名前加 `hint:`，如 `{{hint:引用}}`。内容默认隐藏，点击后才显示，适合放引用原文。

### 自定义字段样式

在字段两端加自定义标签，在样式区设置样式：

```css
/* 模板中：<yy>{{引用}}</yy> */
yy { font-size: 18px; color: gray; }
```

## 六、卡片与笔记的区别

| 对比 | 笔记（Note） | 卡片（Card） |
|------|-------------|-------------|
| 类比 | 浏览器窗口 | 窗口里的标签页 |
| 一个笔记可以有 | 唯一 | 多张卡片 |
| 操作影响范围 | 所有关联卡片 | 仅当前卡片 |

### 产生多卡片的场景

- 问答翻转模板：一次添加→正向+反向两张
- 填空题挖多个空：每个空一张卡片
- 图片遮盖：每个遮盖区域一张卡片

### 如何切换卡片/笔记视图

浏览窗口中，中间滑块可切换"卡片"和"笔记"视图。两种模式下右键菜单的作用对象不同。

## 📝 自我检测

> [!QUESTION] Q1：修改模板后，以前使用该模板的旧笔记会生效吗？

<details>
<summary>查看答案</summary>

**会生效**。模板的修改会影响所有使用该模板的笔记（包括旧笔记）。如果不想影响旧的，请"添加"新模板而非修改现有模板。

</details>

> [!QUESTION] Q2：一张填空题挖了3个空，点击"暂停笔记"会暂停几张卡片？

<details>
<summary>查看答案</summary>

**3张全暂停**。暂停笔记作用于笔记层面，所有关联卡片（3个空）都会被暂停。

</details>

> [!QUESTION] Q3：更换字体时，字体文件应该放在哪个文件夹？

<details>
<summary>查看答案</summary>

**collection.media 文件夹**。路径：工具→插件→查看文件→返回上一级→账户名→collection.media。文件名需要用拼音/英文，以下划线开头。

</details>
