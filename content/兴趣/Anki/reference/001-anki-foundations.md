# Anki 基础概念参考

> 涵盖：课程 01-1 介绍、01-2 安装、01-3 速览

## 一、闪卡（Flash Card）核心概念

### 1. 定义

- **形式**：正面问题 / 背面答案，或文字 / 图片，正反互换
- **核心机制**：主动回忆（Active Recall）— 看正面想背面，而非将正反面放在一起阅读
- **信息粒度**：极小，一张卡片只承载一个原子知识点

### 2. 闪卡的进步

- 信息量小 → 符合认知负荷，容易记、容易用
- 主动回忆 → 评估更准确，避免"以为自己理解其实不理解"

### 3. 闪卡的局限

- 长周期大规模场景下手工制卡麻烦
- 纸质卡片数量多了以后无法管理
- 需要软件来解决

---

## 二、非纸质闪卡的变体形式

| 工具 | 方法 |
|------|------|
| **大纲笔记**（幕布、Workflowy） | 把下级折叠，看上级问题主动回忆下级答案 |
| **思维导图**（XMind、MindNode） | 前面写问题、后一级写答案，折叠后看问题回忆 |
| **书边笔记** | 在书右侧边缘记关键词，复习时看关键词回忆正文 |

## 三、闪卡的三代演进

### 第一代：莱特纳盒子（Leitner Box）

- 实体盒子，5个盒子构成
- 复习正确 → 移入下一个盒子；复习错误 → 移回前一个盒子
- Anki 的 4 个评估按钮本质同理

### 第二代：Supermemo

- **算法贡献**：SM-2 算法被 Anki 沿用
- **增量学习**：内容很难，但每次只学一点
- **渐进阅读**：成果巩固、任务切换、进度保留

### 第三代：Anki

- **主动回忆**：看问题想答案，切忌被动浏览
- **间隔复习**：把集中突击复习前置并分散成几次

## 四、Anki 的四大优势

| 优势 | 说明 |
|------|------|
| **自定义内容** | 笔记是自己思考成果的固化 |
| **多平台同步** | 手机/电脑/平板进度一致，分散学习效果更好 |
| **本地化（离线可用）** | 同步后可离线使用，稳定不丢数据 |
| **插件生态** | 开源社区不断贡献，可扩展各种功能 |

## 六、适用对象与学科

- **对象**：考试考证、校内同步课、终身学习者
- **学科**：法律、医学、语言、外语、艺术、计算机、工程、文史哲

---

## 七、选材原则

- 选有意义的、平时学的、自己加工过的内容
- 不要随意从网上复制粘贴
- 不可能从无意义内容里通过间隔复习感受到意义
- **单词的问题**：单词本身没有实际使用价值

## 八、安装注册与版本

### 注册与账号

- 官网：`ankyweb.net`，Sign Up 注册，Login 登录
- **找回密码**：登录按钮下方 Reset Password → 邮箱收重置链接

### 版本分类

| 分类 | 说明 |
|------|------|
| 2.1.49 分界线 | 旧系统无法安装新版时退回此版本 |
| 正式版 | 纯数字，如 24.04（24年4月） |
| RC（候选版） | Release Candidate |
| 公测版（Beta） | 名字带 beta |
| 内测版（Alpha） | 最早期版本 |

### 各平台注意事项

- **iOS**：国区需备案，可能需从美区下载
- **Android**：可从 Google Play 或官网/网盘下载
- **HarmonyOS**：纯血鸿蒙后的方案待定

## 九、桌面版快捷键速查

| 快捷键 | 功能 | 适用场景 |
|--------|------|---------|
| **Space / Enter** | 显示答案 | 复习时切换问题→答案 |
| **1 / 2 / 3 / 4** | 选 Again / Hard / Good / Easy | 显示答案后快速评估 |
| **Ctrl + Enter** | 添加笔记 | 添加窗口编辑完成后提交 |
| **E** | 编辑当前笔记 | 复习时快速修改卡片 |
| **@** | 添加/编辑标签 | 复习时为卡片打标签 |
| **B** | 打开浏览窗口 | 需要搜索/批量操作时 |
| **F** | 旗标菜单 | 给卡片加颜色标记 |
| **/** | 搜索 | 浏览窗口中快速搜索 |

> 建议花5分钟练熟 Space(显示答案) + 1/2/3/4(评估) 的组合。

---

## 十、Anki 六大模块速览

1. **添加笔记**：选模板→选牌组→编辑内容→添加
2. **复习**：点击牌组→回想→显示答案→评估
3. **编辑与操作**：复习时编辑、旗标、搁置、暂停
4. **浏览窗口**：左侧边栏查看全部卡片
5. **同步**：云端存储，双向同步
6. **菜单**：Windows 在窗口顶部，Mac 在屏幕顶端
