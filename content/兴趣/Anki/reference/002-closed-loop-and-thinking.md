# 闭环与思考体系参考

> 涵盖：课程 02 闭环、03-1 定义、03-2 策略、03-3 方法

## 一、最小闭环模型

思考 → 记录 → 复习 → 致用（然后回到思考，螺旋上升）

### 核心目的

1. **成果保存**：避免"上三步退两步"，每次学习都 Ctrl+S
2. **意义挖掘**：避免长期复习的乏味，持续提升学习层次

### 两个类比

- **Ctrl+S**：每天关机前保存，明天接着干
- **接力赛**：四棒选手缺一不可，某环节拖后腿 = 整体失败

### 易错点

| 类型 | 表现 |
|------|------|
| 流程重复 | 思考不记录→下次重新理解；同一笔记多平台各记一遍 |
| 流程缺失 | 不记录（不屑于）；不致用（死扛复习） |

### 核心原则

| 原则 | 含义 |
|------|------|
| 以终为始（倒推） | 能复习多少 → 就记多少 → 就思考多少 |
| 改进（找瓶颈） | 找瓶颈环节集中改进 |
| 克制囤积欲 | 不完成闭环的新知识，宁可不学 |
| 质量优先 | 质量=1，速度=0 |

## 二、思考的 9 个角度

| 角度 | 核心 | 笔记示范 |
|------|------|---------|
| **是什么-为什么-怎么办** | 澄清概念→追问动机→落到行动 | Q: 什么是扩展式练习？A: 需要记忆的内容从少到多 |
| **转述** | 用自己的话重新表达 | Q: 什么是高原现象？A: 刚开始进步快后来变慢 |
| **类比** | 用熟悉之物解释陌生之物 | Q: 理解力像什么？A: 像强力胶，粘合新旧知识 |
| **举例** | 抽象概念配具体场景 | Q: 情绪如何改善记忆？A: 同事争吵多年还记得 |
| **比较** | 找相同点和不同点 | Q: 考点和知识点有什么不同？A: 知识点孤立，考点关联 |
| **联系** | 新知↔已知、理论↔实践 | Q: 为什么加微信群能帮自己进步？A: 看到被忽略的角度 |
| **边界** | 适用条件/不适用条件 | Q: 什么时候才应画思维导图？A: 先打结再织网 |
| **利弊** | 好处与代价并陈 | Q: 通用规则的优缺点？A: 数量少易理解，难解决实际问题 |
| **因果/规律** | 寻找逻辑关系 | Q: 如何进入心流？A: 相对最小化原则 |

### 思考的三重特性

- **滞后性**：第一遍只能"看见"，第二遍才能"联系"
- **迭代性**：微弱想法记下来，下次就有基础产生新思考
- **按需性**：联系要有边界，围绕目标

## 三、工作记忆-常识记忆模型

**阿特金森-谢夫林三阶段模型**：感觉记忆（0.5-2秒）→ 工作记忆（4项容量）→ 常识记忆（长期仓库）

> "思考能力取决于掌握的事实性知识。"——《为什么学生不喜欢上学》

### 易错点

- **方法不对**：不复习或集中复习 → 知识无法转入常识记忆
- **态度不对**：理解后不屑于复习

## 四、促进思考的宏观策略

### 1. 经常提问

- 用问答笔记替代陈述笔记
- 通过提问跳出书的限制
- 通过提问明确价值

### 2. 碎片化的必要性与解决方案

**为什么需要碎片化**：降低难度、明确价值、提升兴趣、自由组合

**如何避免过度碎片化**：①源头保持专注 ②结合大纲笔记 ③先分后总 ④相同前缀 ⑤多级标签 ⑥搜索筛选 ⑦翻书看目录

### 3. 必要难度

- 能力提升后笔记难度不变 → 乏味
- 必要难度 ≠ 事实性困难
- Anki 方法：一个学科一个牌组、顺序→乱序、增加间隔

### 4. 渐进学习

在一段时间内交替学习不同内容。三个核心：成果巩固、进度跟踪、任务切换。

## 五、具体思考方法速查

| 方法 | 说明 |
|------|------|
| **是什么/为什么/怎么办** | 对同一段话从三个层面分别记笔记 |
| **转述** | 费曼技巧的变体（讲给自己听） |
| **类比** | 以熟代新，把未知化为已知 |
| **例子+抽象互转** | 抽象→具体帮助理解；具体→抽象利于迁移 |
| **综合↔分析** | 拆解整段为多条笔记（分析），或合并分散内容（综合） |
| **复杂↔简单** | 复杂内容概括为关键词 |
| **联系（知识↔知识）** | 多本书相同主题互相促进理解 |
| **联系（理论↔实践）** | 用书上道理解释使用现象 |
| **边界/利弊** | 明确适用条件和反例，防止用错 |

### 核心建议

- 不要只追求"把书读薄"，也要"把书读厚"
- 同一知识点从不同角度记多条笔记不是重复
- 先选自己感兴趣的练熟，再挑两三个角度刻意练习
