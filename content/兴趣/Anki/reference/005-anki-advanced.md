# Anki 进阶操作参考

> 涵盖：课程 07-1 至 11

## 一、统计窗口解读

| 统计项 | 含义 | 健康参考值 |
|--------|------|---------|
| 到期卡片 | 今天需要复习的卡片 | 与复习上限匹配 |
| 新增卡片 | 今天新学的卡片 | ≤30（建议10-20） |
| 学习中的卡片 | 尚未毕业的新卡片 | 不宜过多积压 |
| 复习中的卡片 | 已毕业定期复习的卡片 | 总数的60%以上 |
| 保留率 | 回忆成功的比例 | 80-90% |
| 预测 | 未来7/30天复习量 | 预判工作负荷 |

### 主界面三列状态流转

| 列名 | 含义 | 来源 |
|------|------|------|
| **未学习** | 从未学过的新卡片 | 新添加，受每日新学上限限制 |
| **学习中** | 当天正在反复学的卡片 | 新学选了<1d 或 复习选了Again |
| **待复习** | 已到期的复习卡片 | 上次复习后间隔到期 |

### 统计窗口进阶解读

| 统计项 | 解读方法 | 健康参考 |
|--------|---------|---------|
| **按钮统计** | Again/Hard/Good/Easy分布 | Again < 20%，Good 40-60%，Easy < 10% |
| **简易度分布** | 值越大=卡片越简单 | 整体右移说明熟练度提升 |
| **复习间隔分布** | 左低右高=卡片越来越熟 | 右移表示进入长期记忆 |

## 二、学习计划（牌组选项）

### 新卡片

| 参数 | 功能 | 说明 |
|------|------|------|
| 每天新卡片上限 | 控制每天新增量 | 核心控制参数 |
| 新卡片步长 | 学习阶段间隔 | 默认1 10（分钟） |
| 毕业间隔 | 学习→复习所需天数 | 默认1天 |

### 复习

| 参数 | 功能 | 说明 |
|------|------|------|
| 每天复习上限 | 每天最多复习多少张 | 默认200 |
| 最大间隔 | 卡片最多间隔多少天 | 默认36500天 |
| 间隔倍数 | 整体调整复习频率 | 调高→复习更少 |
| 简单奖励 | 点Easy额外加间隔 | 默认130% |

### 10倍法则

> **复习量 ≈ 新增量 × 10**。每天新增10张→每天约100张复习。

## 三、SM-2 算法

Anki 默认算法，由 SuperMemo 的 SM-2 改进而来。

### 核心公式

- 新卡学习：分两步（默认1分钟→10分钟）
- 毕业后间隔：`前次间隔 × 间隔倍数`
- Again → 重置到学习阶段
- Hard → 间隔 × 1.2
- Good → 标准间隔
- Easy → 间隔 × 简单奖励

### 局限

- 对所有卡片"一视同仁"
- 间隔增长固定倍数
- 不能根据历史表现动态调整

## 四、FSRS 算法

新一代算法（Free Spaced Repetition Scheduler），Anki 23.10+ 内置。

### DSR 模型

| 参数 | 全称 | 含义 |
|------|------|------|
| **D** | Difficulty（难度） | 卡片的固有难度（稳定但可变化） |
| **S** | Stability（稳定性） | 记忆能保持多久 |
| **R** | Retrievability（可提取性） | 能回忆起来的概率 |

### 优势

- 为每张卡片建立独立记忆模型
- 根据个人历史数据优化参数
- 支持设置期望保留率（0.8-0.9）
- 难卡片和简单卡片差异化安排

### 启用 FSRS

1. 牌组→齿轮→选项→FSRS 栏
2. 启用 FSRS 并运行优化
3. 设置期望保留率（默认 0.9）
4. 配合 FSRS4Anki Helper 插件

## 五、模板修改（CSS 速查）

| 样式属性 | 作用 | 示例值 |
|---------|------|--------|
| `font-family` | 字体 | Arial, serif |
| `font-size` | 字号 | 20px |
| `text-align` | 对齐方式 | left, center |
| `color` | 文字颜色 | #333, black |
| `background-color` | 背景色 | white, #f5f5f5 |
| `font-weight` | 字重 | bold, lighter |
| `line-height` | 行高 | 1.8, 30px |
| `letter-spacing` | 字间距 | 1px |
| `padding` | 内边距 | 2px 5px |
| `border-radius` | 圆角 | 4px |

### 字段标签

- `{{字段名}}` 引用字段
- `{{hint:字段名}}` 点击显示
- `{{edit:字段名}}` 复习时直接编辑（配合插件）

### 模板入口

1. 工具→管理笔记模板→选择模板→卡片
2. 添加窗口→卡片按钮
3. 复习时→编辑→卡片按钮

## 六、卡片与笔记的区别

| 对比 | 笔记（Note） | 卡片（Card） |
|------|-------------|-------------|
| 类似 | 浏览器窗口 | 窗口中的标签页 |
| 一个笔记可以有 | 唯一 | 多张卡片 |
| 影响范围 | 所有关联卡片 | 仅当前卡片 |

## 八、浏览窗口技能

### 复合搜索

| 逻辑 | 按键 | 示例 |
|------|------|------|
| **或** (OR) | Shift + 点击 | 选中"重要"或"不重要" |
| **与** (AND) | Ctrl + 点击 | 某牌组 + 某标签 |
| **非** (NOT) | Ctrl+Alt + 点击 | 排除不需要的 |

### 常用操作

- 保存搜索条件：保存到侧边栏，下次直接点击
- 更改笔记模板：同类模板间切换
- 更改所属牌组：批量移动卡片
- 查找并替换：批量替换文字
- 批量设置到期日：将卡片推迟到指定日期
- 合并标签：右键→重命名

## 九、数据管理

### 同步

- 默认双向同步：手机↔服务器↔电脑
- 触发单向同步：删除模板/字段、删除学习计划
- **好习惯**：使用前同步一次，使用后再同步一次

### 数据优化三件套

1. **检查数据库**：大量增删后重建索引
2. **检查媒体**：清理已删除笔记残留的媒体文件
3. **清理空卡片**：移除残填空卡片

### 备份与恢复

| 方式 | 操作 | 特点 |
|------|------|------|
| 自动备份 | 设置→备份（不含媒体文件） | 定期自动执行 |
| 手动备份（单牌组） | 牌组齿轮→导出→.apkg | 可分享 |
| 手动备份（全部） | 文件→导出→.colpkg | 覆盖整个库 |
| 通过同步恢复 | 单向同步从另一设备拉取 | 设备间恢复 |

### 文件夹结构

```text
Anki根目录/
├── addons21/                    # 插件（所有账户共用）
└── [账户名]/
    ├── backups/                 # 自动备份
    ├── collection.media/        # 媒体文件
    └── collection.media.trash/  # 被清理的媒体（可恢复）
```
