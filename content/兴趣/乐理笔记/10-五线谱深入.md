# 第十一部分：五线谱

### 第99课：简谱的多声部

- **单声部**：只有单一旋律线条，同时只发一个音（如清唱）
- **多声部**：同一时刻有多个声部同时进行（如合唱、钢琴）
- 多声部乐器（如钢琴）可同时奏响多个音
- 简谱中纵向多个音 = 同时弹奏
- 不同声部节奏不同时，需要理解"声部分离"

**关键概念：**
- 大括号框起来的多行谱 = 同时演奏
- 钢琴谱：上面高音谱号对应右手，下面低音谱号对应左手

> [!TIP] 需要记住的重点
1. 简谱1～99课至此全部结束，涵盖：1～38课（调号/找调）、39～84课（拍号/节奏）、85～99课（标记/多声部）
2. 遇到多声部时，要将谱面在视觉上拆分为独立声部分别理解

### 第100课：是否需要学习五线谱

- 简谱优势：记录**首调**、**单声部**方便
- 五线谱优势：记录**固定调**、**多声部**方便
- 只想唱歌的人：简谱足够
- 学民乐器、只演奏传统曲目：简谱基本足够
- 学**西洋乐器**：必须学五线谱
- 搞**创作/编曲**：必须学五线谱

**关键概念：**
- 五线谱更适合乐器的固定调识谱
- 吉他用六线谱、贝斯用四线谱（操作谱），但最好也懂五线谱
- 古琴必须用减字谱

> [!TIP] 需要记住的重点
1. 五线谱不算难，每天十多分钟，两三个月可熟练
2. 是否学五线谱取决于你的需求

### 第101课：五线谱的构造、谱号是什么

- 五线谱的构造与简谱对应：上方标题、右上方词曲作者、左上方调号/拍号/情绪速度
- 五线谱额外多出**谱号**，每行乐谱最前面书写
- 谱号的作用：**先缩小音高范围**（确定两三个组），再在范围内找具体音
- 书写顺序：谱号 → 调号 → 拍号 → 音符
- 从第二行起不用再写拍号，但谱号和调号每行必写

**关键概念：**
- 谱号 = 确定五线谱音高范围的标识

> [!TIP] 需要记住的重点
1. 谱号帮助快速定位音高范围
2. 情绪速度写在五线谱上方，其余要素直接写在正文里
3. 谱号和调号每行都要写，拍号只在第一行写

### 第102课：高音谱号

- 五线谱有五线四间，从下往上依次命名为一线到五线、一间到四间
- 需要时可加线：上加一线/二线/三线、下加一线/二线/三线
- **高音谱号**本质是 **G谱号**，由字母G的花体演变而来
- 高音谱号从**第二线**开始画，确定第二线 = 小字一组的G1
- 由此推出：下加一线 = 中央C（C1），上加三线 ≈ E3
- 高音谱号覆盖范围：小字组F到小字三组E3

**关键概念：**
- 黑键通过升降号表示，不单独分配线/间
- 高音谱号下加一线 = 中央C

> [!TIP] 需要记住的重点
1. 高音谱号本质：确定第二线是G1
2. 所有其他音通过从G1往上或往下逐步推出
3. 熟练方法：每天出20道推理题，坚持1～2个月形成图像记忆
4. **不要使用口诀记忆法**

### 第103课：低音谱号

- **低音谱号**本质是 **F谱号**，由字母F演变而来
- 从**第四线**开始画，确定第四线 = 小字组的F
- 由此推出：上加一线 = 中央C（C1）
- 低音谱号覆盖范围：大字一组A1到小字一组G1
- 钢琴谱：上面高音谱号（右手），下面低音谱号（左手），大括号框起

**关键概念：**
- 高音谱号和低音谱号覆盖了钢琴中间最常用的区域
- 两者以中央C为交界

> [!TIP] 需要记住的重点
1. 低音谱号本质：确定第四线是小字组的F
2. 高音谱号和低音谱号都必须熟练掌握
3. 练习方法：每天10道高音 + 10道低音，坚持推理

### 第104课：中音谱号、次中音谱号（※选学）

- **中音谱号**（C谱号）：两个反折C夹住**第三线**，确定第三线 = C1（中央C）
- **次中音谱号**：与中音谱号造型相同，但整体上移一间，夹住**第四线** = C1
- 谱号选择取决于乐器/人声常用的音域范围
- 只有学习中提琴、大提琴、长号、大号、巴松等中低音乐器才需要熟练掌握

**关键概念：**
- 中音谱号覆盖区域介于高音谱号和低音谱号之间
- 次中音谱号比中音谱号整体高一个间

> [!TIP] 需要记住的重点
1. 99%的需求只需高音谱号和低音谱号
2. 中音/次中音谱号知道原理即可，不需死记
3. 谱号选择应根据乐器实际音域，避免过多加线

### 第105课：谱号拓展（※选学）

- G谱号不一定要从第二线画（可以一线、三线等），F谱号同理
- 历史上存在过很多种谱号变体
- 现代只保留四种标准谱号：高音（G在二线）、低音（F在四线）、中音（C在三线）、次中音（C在四线）
- 其他历史谱号基本遇不到，除非考音乐史

> [!TIP] 需要记住的重点
1. 谱号的本质是图案对准某条线来确定音高
2. 现代只需掌握四种标准谱号，本课仅为课外补充

### 第106课：八度记号

- **8va**（ottava above）：写在音符上方，表示提高一个八度演奏
- **8vb**（ottava below）：写在音符下方，表示降低一个八度演奏
- 用虚线框标明影响范围
- 作用：避免加线过多（超过三条线就难辨认）

**关键概念：**
- 纯八度 = 相邻两组中相同音名的距离
- 八度记号使高/低音的记录更简洁

> [!TIP] 需要记住的重点
1. 遇到8va/8vb时，先认出谱面上的音，再平移一个八度
2. 谱面上的音应在加线三条以内的熟悉范围内

### 第107课：十五度记号

- **15ma**（quindicesima above）：提高两个八度
- **15mb**（quindicesima below）：降低两个八度
- 为什么是15不是16：两个八度 = 8+8-1 = 15（避免重复计算交界音）
- 与8度记号配合，可覆盖钢琴全部88键

> [!TIP] 需要记住的重点
1. 八度记号和十五度记号已足以表示所有乐器的音域
2. 没有更高的（如22度）记号
3. 重点仍须掌握高音谱号和低音谱号

### 第108课：五线谱的拍号、音符与写法

- **拍号**写在谱号和调号之后，分子占上面两间、分母占下面两间
- 四四拍可写成"C"，二二拍可写成"C加一竖"（不是字母C，是残缺圆圈）
- 五线谱音符构成：**符头**（空心/实心圈）、**符干**（竖线）、**符尾**（小尾巴）
  - 全音符：空心符头，无符干无符尾
  - 二分音符：空心符头 + 符干
  - 四分音符：实心符头 + 符干
  - 八分音符起：实心符头 + 符干 + 符尾（八分1根、十六分2根、三十二分3根...）
- 符头位置确定音高，整体外观确定时值
- 符干朝向：三线以下朝上，三线以上朝下（美观考虑，非强制）
- 符尾永远朝右

> [!TIP] 需要记住的重点
1. 拍号概念与简谱完全相同（参考39～53课）
2. 音符只有外观变了，内涵不变
3. 二全音符（倍全音符）已基本绝迹

### 第109课：五线谱的附点、休止符、连线、延音线

- **附点**：永远写在符头右方，含义与简谱相同（延长原音符时值一半）
- **休止符**写法（五线谱特有外观）：
  - 全休止符：实心长方形贴第四线下方
  - 二分休止符：实心长方形贴第三线上方
  - 四分休止符：闪电形
  - 八分休止符：一根横曲线 + 一根斜线（像数字7）
  - 十六分起：横曲线数与符尾数对应
- **全休止符的特殊用法**：整个小节休止时，无论几拍都写一个全休止符
- **连线**和**延音线**：意义与简谱完全相同（连接不同音 = 连线，连接相同音 = 延音线）

> [!TIP] 需要记住的重点
1. 全休止符有两种含义：①休止四拍；②休止整个小节
2. 区分方法：整个小节只有一个全休止符 = 休止整个小节
3. 附点、连线、延音线与简谱完全一致

### 第110课：五线谱的速度

- 情绪与速度的文字标记与简谱完全相同（参考57课）
- 五线谱速度表示：**音符 = 数字**的形式，以一分钟为单位
  - 四分音符 = 80 → 每分钟80个四分音符 → 每分钟80拍
- **八三拍/八六拍**的速度常写成"附点四分音符 = 数字"
  - 表示每分钟多少个三拍集体
  - 节拍器若要每拍响一次，需将数字乘以3

> [!TIP] 需要记住的重点
1. 所有"音符 = 数字"的速度标记都以一分钟为单位
2. 八三/八六拍的速度标记要注意集体数的计算
3. 核心概念与简谱完全一致

### 第111课：五线谱的节奏型、打拍子

- 节奏型与简谱完全对应，只是将简谱的横线替换为五线谱的**符杠**
- 简谱下方几根横线 = 五线谱几根符杠/符尾
- 四四拍中，小于一拍的音符符尾要连起来形成符杠，构成一拍一拍的外观
- 八三/八六拍中，每三拍为一集体，符尾连在一起
- 打拍子方法与简谱完全相同：四拍子用V字、八三/八六拍用三角形

> [!TIP] 需要记住的重点
1. 节奏型、打拍子的核心知识全在简谱60～79课
2. 五线谱只是换了外观，内涵不变
3. 练习五线谱节奏时，先用"大/空"替代唱名，不管音高

### 第112课：五线谱的调号（一）

- 五线谱的调号写在谱号右边、拍号左边
- 调号的作用：提前告知整个乐谱中哪些音需要升降
- 调号中有几个升降号 = 该调音阶中有几个音需要升降
- 升降号在调号中的位置对应需要升降的音名
- 每个调的调号外观是**固定的、唯一的、全球统一的**
- 调号对**所有组**的同名音生效，不仅限于标记处

**关键概念：**
- 如D大调调号（两个升号在F和C的位置）表示所有组的F和C都是升F和升C

> [!TIP] 需要记住的重点
1. 调号的本质是音阶升降信息的浓缩表示
2. 调号外观固定，不能随意换位置写
3. 前提是必须掌握1～23课的调号基础知识

### 第113课：五线谱的调号（二）

- 一共**15个调号**：C调（0升降）+ 7个升号调 + 7个降号调
- **升号调**升号出现的顺序固定为：F → C → G → D → A → E → B
- **降号调**降号出现的顺序固定为：B → E → A → D → G → C → F（与升号顺序相反）
- 升号调外观有叠加规律：记住7个升号的完全体，依次从右边减去就能得到1～6个升号
- 降号调同理：记住7个降号的完全体，依次减去

> [!TIP] 需要记住的重点
1. 调号数量 = 1+7+7
2. 升号/降号的出现顺序是固定的
3. 本课只要求理解调号的外观规律，不需死记

### 第114课：快速识别五线谱的调号

- **三条规则**：
  1. **死记**C调（无升降）和F调（一个降号）
  2. **升号调**：最后一个升号是升什么音 → 该调就是"升X加半音"调（如最后升号在F → 升F+半音 = G大调）
  3. **降号调**（F调除外）：倒数第二个降号是降什么音 → 该调就是降什么调（如倒数第二降号在B → 降B调）
- **口诀**：FCGDAEB / BEADGCF（或用固定调唱名"发do索re拉mi西 / 西mi拉re索do发"）
  - 前半句用于升号调（升号出现顺序）
  - 后半句用于降号调（降号出现顺序）

> [!TIP] 需要记住的重点
1. 三条规则必须牢记并会实际运用
2. F调单独死记是因为它只有一个降号，没有"倒数第二个"
3. 口诀也需要牢记，用于无五线谱时的推导

### 第115课：五线谱的练习方式

- 练习五线谱**不要使用口诀/捷径**
- 每天20分钟，分两步：
  - 前10分钟：不管音高，用"大/空"打拍子练节奏
  - 后10分钟：不管节奏，用**固定调唱名**认音名（注意把调号的升降号也念出来）
- 两步分别熟练后，再合并练习
- 认音速度达到一定水平后（约3秒一个音），可进入综合阶段

> [!TIP] 需要记住的重点
1. 五线谱必须用**固定调唱名**练习，不要用首调
2. 前期一定要把调号中的升降号念出来
3. 节奏和认音先分开练，再合起来
4. 坚持练习，快的两三周、慢的两三个月可基本熟练

### 第116课：音值组合法（一）（※选学）

- 音值组合法：将乐谱中的音符按规则组合，使节奏一目了然
- **四X拍**的三条规则：
  1. 将小于一拍的音符组合成一拍，形成一拍接一拍的外观
  2. 一拍的整数倍音符（二分、附点二分、全音符等）直接写，不必拆分
  3. 大附点和大切分（整体两拍）不用拆分；**但横跨复拍子/混合拍子中两个单拍子时必须拆分**

> [!TIP] 需要记住的重点
1. 音值组合法主要对**艺考生**和**写谱创作者**有用
2. 只看谱的人基本不需要学，因为正规乐谱已经遵循了组合规则
3. 第三条后半句（横跨单拍子时必须拆分）是考试重点

### 第117课：音值组合法（二）（※选学）

- **分母≥8的拍号**（八X拍、十六X拍等）的规则：
  - 将每一个**单拍子集体**组合在一起
  - 单拍子与单拍子之间要断开
- 如八六拍 = 八三+八三，两个三拍集体各自内部连线，中间断开
- 八五拍：可能是八三+八二或八二+八三，作曲家会通过组合方式告诉你

> [!TIP] 需要记住的重点
1. 核心原则：每个单拍子集体内部连在一起，不同集体之间断开
2. 从组合方式可以判断拍号内部的具体结构

### 第118课：音值组合法（三）（※选学）

- 考试题型主要有两种方向：
  - 给组合好的片段判断拍号，或判断组合是否正确
  - 给零散音符，按指定拍号正确组合
- **借取法**：不能直接凑一拍时，从后面的音符"借"一部分时值
  - 被借取的音符必须用**延音线**连接拆分后的部分
- 解题通用方法：先以四分音符为一拍数拍数，再验证组合规则

> [!TIP] 需要记住的重点
1. 借取后千万别忘了画延音线
2. 音值组合法考试需要大量刷题
3. 基础不牢的需先补拍号和音符的知识

### 第119课：五线谱的标记

- 五线谱中的标记与简谱85～98课的内容**几乎完全相同**
- 唯一区别：五线谱中**跳音**（小圆点，奏1/2时值）和**断音**（黑色小三角，奏1/4时值）是两种不同记号；简谱中统一用小三角
- 连跳音在五线谱中常将小三角换成小圆点
- 补充：**长倚音**已基本废除——它占据后音符时值的一半（附点音符则占2/3），实际效果完全可以直接写出来，因此无存在必要

> [!TIP] 需要记住的重点
1. 力度、速度、反复、保持音、滑音、刮奏、琶音、波音、回音、颤音、倚音——全部与简谱一致
2. 唯一不同：跳音（圆点）vs 断音（三角）
3. 长倚音了解即可，基本不会遇到

### 第120课：五线谱的多声部与指法问题

- 五线谱多声部与简谱99课完全对应
- 钢琴谱中纵向上多个音符同时弹奏；相邻线间的音同时弹时要**岔开**写
- 同一根符干串起的音一定同时弹
- 一行谱中记录多声部时，要能在视觉上拆分为不同声部
- **指法标记**：谱上的1/2/3/4/5对应手指（非简谱唱名）
  - 右手：1=大拇指，2=食指，...，5=小指
  - 左手同理
- 指法没有唯一正确答案，以**顺手**为原则

> [!TIP] 需要记住的重点
1. 初学阶段先单独练右手、再练左手，最后合起来
2. 谱上的数字是指法标记，不是唱名
3. 指法以顺手方便为原则，不同乐器有不同的指法标记体系

### 第121课：五线谱的临时变音记号规则

- 三条规则：
  1. **变音记号对同一小节后续所有同名音生效**（跨小节清零）
  2. **出现新的变音记号时，直接以新记号为准**，完全不管调号
  3. **同一小节同名音没有任何变音记号时，以调号为准**
- **核心原则**：临时变音记号**不要和调号或其他临时变音记号做叠加或抵消运算**
  - 写了什么就直接是什么

**关键概念：**
- 还原号（♮）：取消之前的升降（包括调号的升降），恢复到白键
- 临时变音记号只管一小节，到下一小节自动失效

> [!TIP] 需要记住的重点
1. 临时变音记号一旦出现，调号就被"屏蔽"了
2. 绝不能将临时变音记号与调号叠加或抵消
3. 变音记号只管本小节，下一小节全部重置
4. 这条规则是五线谱识谱中最容易出错的地方
