# 🎵 零基础学乐理（第二季）完整笔记

> 讲师：西蒙 · 共178课 · 15大模块

本笔记基于西蒙《零基础学乐理（第二季）》视频课程整理，从零开始覆盖基础乐理的全部核心知识点。

---

## 📚 学习路线

1. **基础概念**：唱名、音名、键盘 → 调号、调式 → 拍号、节奏
2. **识谱训练**：简谱 → 记号 → 五线谱
3. **和声入门**：音程 → 和弦 → 和声模板
4. **调式拓展**：大小调体系 → 五声调式 → 中古调式
5. **补充知识**：律制、泛音列、五度圈

## 🎯 学习建议

- 按模块顺序学习，每个模块内的课程有先后逻辑
- 重点掌握：**全全半全全全半**（自然大调规律）和 **EF/BC紧邻关系**
- 理论学完后，配合视唱练习和实际乐器操作效果更佳
- 标记为"※选学"的课程可先跳过，不影响主线学习
