# 第09课：常见推理错误识别指南

## Learning Objectives

- 识别8种常见推理错误，准确说出其名称与特征
- 在日常对话中快速判断对方是否犯了某种推理错误
- 掌握针对每种错误的回应策略，避免被带偏节奏

## Core Idea

推理错误之所以常见，是因为它们表面上"听起来有道理"。学会识别它们，是逻辑防身术的基本功。

### 1. 诉诸不可靠权威

不是不能诉诸权威——专家意见本身就是重要的论证依据。关键是**诉诸的权威是否可靠**：

- "朋友圈说吃这个能抗癌" —— 发布者是谁？有专业背景吗？
- "爱因斯坦也信上帝" —— 爱因斯坦说的"上帝"和宗教说的"上帝"是同一个吗？
- "名人名言"泛化到不相关的领域 —— 演员说怎么养孩子，凭什么比儿科医生更有说服力？

### 2. 循环论证

结论被当作理由，论证绕了一圈回到原点。

- "爸爸妈妈一定是为了孩子好的，我还能不为你好吗？"
- "我说不行就是不行"

真正的循环论证往往无法被质疑，因为它本身就是发言者的"底层逻辑"。拆解的方法是：要求对方提供**独立于结论之外的证据**。

### 3. 伪问题

问题本身的前提就不成立，因此无法被直接回答。

- "当今的法国国王是不是秃子？" —— 法国已经没有国王了
- "你的衬衫上一根头发都没有，秃头女孩是谁？" —— 前提（有女孩掉头发）不成立
- "你什么时候不打老婆了？" —— 预设了你以前打老婆

遇到伪问题，不要直接回答，而要**质疑问题本身的前提**。

### 4. 滑坡谬误

从第一步出发，沿着一条必然性的链条推导到灾难性结论，但中间的每一步都不必然成立。

```mermaid
flowchart LR
    A[不好好学习] --> B[上不了好高中]
    B --> C[上不了好大学]
    C --> D[找不到好工作]
    D --> E[扫大街]
```

- "两个男人能结婚 → 什么都能结婚 → 人类灭亡"
- 每一步都排除了其他可能性，制造了虚假的必然性

**回应方法**：指出链条中每一步的不确定性，并提及其他可能的走向。

### 5. 稻草人谬误

先把对方的观点**矮化、简化**成一个可笑版本，再攻击这个"稻草人"。

- "朴素唯物主义/朴素辩证法" —— 把复杂的思想简化为简陋版本再批判
- "唯心主义就是先有意识后有物质" —— 实际上唯心主义的核心主张远没有这么简单
- "你们女权不就是想骑在男人头上吗？"

稻草人谬误之所以有效，是因为简化后的观点确实容易被驳倒。但被驳倒的不是对方的真实立场。

### 6. 人身攻击与情感替代

不讨论对错本身，转而攻击说话者的态度或身份。

- "你这是什么态度？""你翅膀硬了是吧？"
- "不许你这么说他！"
- 反问句和加强语气（"你难道不觉得……"）替代了论证

这些手法的本质是：**用立场表态代替事实讨论**。不是"你的论证哪里错了"，而是"你不配说这话"。

### 7. 因果关系推理错误

出现在事件链条中，不代表参与了因果关系。

- "今天没去马尔代夫因为xx" —— 其实真正原因还是没钱
- 把**时间上的先后**等同于**逻辑上的因果**

### 8. 幸存者偏差

只看到"幸存者"的数据，忽略了"沉默者"的信息。

- "去那儿的人都不回来，说明那个地方很好" —— 也许他们回不来了
- "人人都说 dictator 好" —— 说不好的人都被处理了
- "狄仁杰断案无人喊冤" —— 无人喊冤不一定代表公正，可能嘴被封上了

### 总结对照

| 错误类型 | 核心问题 | 应对策略 |
|----------|----------|----------|
| 诉诸不可靠权威 | 权威不可靠/不相关 | 质疑权威资质 |
| 循环论证 | 理由=结论 | 要求独立论据 |
| 伪问题 | 前提不成立 | 质疑前提 |
| 滑坡谬误 | 每一步不必然 | 指出其他可能 |
| 稻草人谬误 | 矮化对方观点 | 还原真实立场 |
| 人身攻击 | 攻击人而非观点 | 拉回议题 |
| 因果错误 | 先后≠因果 | 区分相关与因果 |
| 幸存者偏差 | 只看幸存者 | 追问沉默者 |

> [!TIP] Key Insight
> 学会命名一种推理错误，你就获得了对它的话语权。能说出"你这是滑坡谬误"本身就在扭转对话的主动权。

## Worked Example

**场景**：妈妈对你说："你现在不好好学习，将来就只能去扫大街。"

**问题分析**：这是典型的**滑坡谬误**。从"不好好学习"到"扫大街"之间，存在大量中间环节和替代可能性：
- 可以不通过高中阶段，通过职业教育获得技能
- 可以先工作再补学历
- 可以创业、从艺、自由职业

这个推理错误的关键在于：**排除了所有其他可能性**，制造了一条"如果A则必然B"的虚假链条。更合理的说法是"不好好学习可能会让你将来选择更少"，而不是直接跳到"扫大街"。

## Practice

> [!QUESTION] Self-check
> 判断以下对话包含哪种推理错误：
>
> A："我认为公司应该实行弹性工作制，这样可以提高效率。"
> B："你这是不守纪律！要是人人都想几点来就几点来，公司不就乱套了？"
>
> 请分析B的回答有什么问题。

<details>
<summary>Reveal answer</summary>

B的回答同时包含了**两到三种推理错误**：

1. **稻草人谬误** —— B把A的"弹性工作制"（通常指在一定时间范围内自由安排）歪曲成了"想几点来就几点来"（完全无纪律），然后攻击这个被歪曲的版本。

2. **滑坡谬误** —— B从"弹性工作制"直接推导到"公司乱套"，中间跳过了大量可能的缓冲机制（如核心时段、任务截止期等管理手段）。

3. **情感替代** —— "你这是不守纪律"通过道德标签（不守纪律）替代了事实论证。

正确的回应方式：先指出对方的误解（"弹性工作制不是无纪律，而是在保证工作总量的前提下灵活安排时间"），再讨论具体方案。
</details>
