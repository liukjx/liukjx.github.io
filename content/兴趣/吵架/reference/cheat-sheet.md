# 吵架万能话术速查表

> 把话术背下来，形成肌肉记忆。**注意：这些是对外人用的，别用在家人伴侣身上。**

## 万能公式

### 人格否定法（来自吵架气人教程）

```
盯着对方2秒 → 冷笑 → 看向旁边 → 转回头挑眉 → 说：
"你不觉得自己很【选词】吗？"
→ 翻白眼 → 迅速撤离
```

**可选形容词**：小肚鸡肠、没有教养、三观不正、戾气太重

### 冷静回击

> "你说的话很没有逻辑，而且前后矛盾，你自己想想。我觉得咱们已经没有必要再谈下去了。"

### 终结对话

> "吵不吵吧，我在听。你说的这些话不会对我的情绪有任何影响，只会让你自己发癫。"

## 场景话术

### 被人身攻击

| 对方说 | 你回 |
|--------|------|
| 各种辱骂 | "我是不会和你一般见识的。我很理解你的心情，毕竟以你的认知水平，很难理解我。" |
| 继续攻击 | "你对我的诋毁，构不成千分之一的我，却暴露了一览无余的你自己。" |
| 情绪激动 | "你照照镜子吧，你现在什么样自己知道吗？不讲道理的样子真的很丑。" |
| 持续输出 | "狗叫。"（反复使用，直到对方破防） |

### 被"对对对"敷衍

> （居高临下的微笑）
> "这么多年你悲惨的人生，不就是一直在卑躬屈膝、对所有人按全马首是瞻中度过吗？"

> "真没想到跟你萍水相逢，你这么认同我的观点。"

### 反衬托（让对方自曝）

| 对方说 | 你回 |
|--------|------|
| "你真恶心" | "我也这么觉得。你有一个很善于发现的眼睛。你展开说说，我听着。" |
| 各种攻击 | "亲爱的，你平复一下心情。我知道你现在情绪特别不稳定，我可以理解的。" |

### 被人说"你态度有问题"

> "咱讲道理。我说的到底是对还是不对？如果是对的，我们可以看看能不能达成共识。如果是错的，你说我错在哪。不要攻击我的态度。"

### 法律话术防暴力

> "根据治安管理处罚法第43条，殴打他人处5日以下拘留……如果情节严重，刑法第234条，3年以下有期徒刑。这一拳打下来，你以后孩子可能就没法考公进体制了。来吧，左脸还是右脸？"

## 收场话术

### 给台阶下（吵架高潮之后）

> "算了吧，别吵了，都没意义。"

### 对外人

> "兄弟/姐妹，别吵了，交个朋友，没事吧。"

### 自己反思

> "我为什么跟他吵？我有哪里不对？"

## 肢体语言

### 三步法

1. **双手抱拳，脖子往后仰**
2. **眼神上下扫视对方**
3. **给对方一个不屑的笑**

### 原则

- 用最小的幅度发挥最大的肢体语言
- 不要用手指人（挑衅），用手掌或扫视
- 保持表情冷漠、居高临下

## 铁律

| 原则 | 说明 |
|------|------|
| 不要想赢 | 想赢就会输得更惨，赢在损失最小 |
| 不让矛盾升级 | 只揪这个点，不翻旧账 |
| 不扩大范围 | 不拉第三人进来 |
| 不讲道理 | 吵架是纯主观的，讲道理只会更气 |
| 发泄到后果上 | "如果你一定要这样，后果就是……" |
| 吵完要修复 | 认识错误、修缮关系、看清身边人 |
