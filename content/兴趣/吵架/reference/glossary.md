# 吵架课术语表

> 吵架是一门技术，也有自己的术语体系。掌握这些概念是系统学习的第一步。

## 核心概念

| 术语 | 含义 | 相关课次 |
|------|------|----------|
| 社交行为 | 吵架的本质——与人发生互动的一种行为，有好有坏 | 第01课 |
| 矛盾升级 | 吵架中翻旧账、问候祖宗、发出死亡邀约——双输行为 | 第04课 |
| 范围扩大 | 把无关的第三人拉入争吵 | 第04课 |
| 结果展示 | 把怒气发泄在后果上而非攻击对方——给双方警示降温 | 第04课 |
| 人格否定法 | 攻击对方的"自我方式"而非逻辑漏洞——让对方一秒跳脚 | 第05课 |
| 反衬托 | 用平静的态度让对方情绪失控——"你展开说说" | 第05课 |
| 认知三要素 | 不接话、不顺着他思考、保持冷静 | 第05课 |
| 理智回归瞬间 | 吵架第一阶段高潮后的停顿——给台阶下的最佳时机 | 第07课 |
| 不要想赢 | 核心原则——赢在损失最小、赢在人心而非胜负 | 第04/07课 |
| 概念歧异性 | 同一语词在不同语境下含义不同 | 第08课 |
| 循环论证 | 把结论本身当作理由来论证 | 第09课 |
| 滑坡谬误 | 从A推到B推到C推到Z，每一步都不必然，却排除其他可能性 | 第09课 |
| 稻草人 | 把对方观点矮化成可笑的观点再攻击 | 第09课 |
| 双标 | 信奉彼此矛盾的前提，根据实际需要跳来跳去 | 第10课 |
| 大道理唬人 | 用正确的大前提跳过具体情况的论证，让人无法反驳 | 第10课 |
| 底层信念 | 构成内心迷宫的"墙壁"——决定一个人的认知和反应模式 | 第10课 |
| 内心迷宫 | 每个人由底层信念构成的独特内心世界 | 第10课 |
| 吵后修复三件事 | 认识错误、修缮关系、看清身边的人 | 第11课 |
| 破壁者 | 勇敢拆除自己内心错误底层信念的人 | 第10课 |

## 场景术语

| 术语 | 含义 | 例 |
|------|------|-----|
| 死亡邀约 | 把矛盾推向不可收拾的挑衅 | "你是不是不服气？" |
| 感情牌 | 用情感替代事实讨论 | "你翅膀硬了是吧" |
| 神逻辑 | 看似有道理实际错误的推理 | 滑坡谬误、循环论证等 |
| 对对对破解法 | 当对方敷衍时用居高临下的姿态反击 | "没想到你这么认同我的观点" |
| 法律话术 | 引用法律条文让对方意识到暴力后果 | 治安管理处罚法第43条 |
