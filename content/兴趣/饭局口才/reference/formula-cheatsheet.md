# 套路公式速查卡

> [!TIP] 使用说明
> 所有公式中"+"表示模块组合，可根据实际情况增删模块。
> 熟悉场合可省略"称呼"和"回忆过去"模块。

## 一、即兴发言12大套路

### 套路 1-9（通用结构：**称呼 + X + 回忆过去 + 祝福未来**）

| # | X（核心模块） | 要点 |
|---|-------------|------|
| 1 | **感谢2人** | 感谢最主要的人（主人/组织者/大家认可的人，非自己认可的人） |
| 2 | **赞美** | 直接赞美 或 利用第三者赞美 |
| 3 | **故事** | 经典故事为主，说完要有合乎主题的感悟 |
| 4 | **用潜意为人说的话** | 从他们说过的话中挑出有意义的一句 |
| 5 | **问两个问题** | 最好和主题相关，可配合互动活跃气氛 |
| 6 | **名人名言** | 泛指名言、俗语、谚语、歇后语等 |
| 7 | **悬疑** | 先说意想不到的结果→再合理化解（不适合婚礼） |
| 8 | **谦虚** | 自谦开场 |
| 9 | **心情** | 表达此时此刻的内在感觉 |

> [!NOTE] 精简规则
> 第一层精简：去掉"回忆过去"
> 第二层精简：再去掉"称呼"，保留"祝福未来"
> 正式场合称呼一般保留

### 套路 10（正式会议/培训/讨论）

$$
\textbf{称呼 + 我发现 + 我认为 + 我建议 + 我相信}
$$

### 套路 11（非正式场合/熟悉关系）

$$
\textbf{有没有发现 + 我想是不是（或：我想可能 + 如果 + 我估计）}
$$

### 套路 12（借力感悟）

$$
\textbf{称呼 + 借力感悟 + 祝福未来}
$$

**借力3层次：** 天气（雨/大风/雪） → 历史事件（历史上的今天） → 突发事件（突然看到的景象/人）

## 二、委婉拒绝3大方面

### 方面一：接力 + 缓力 + 歉意/感谢

> 适用范围：绝大多数拒绝场合，影响降到最低

**接力4切入点**（可叠加使用）：

| # | 切入点 |
|---|--------|
| 1 | 对人的肯定和赞美 |
| 2 | 对双方关系的肯定认可和关心 |
| 3 | 对阶段的感同身受 |
| 4 | 对事情的积极态度 |

**缓力6切入点**（可叠加使用）：

| # | 切入点 | 说明 |
|---|--------|------|
| 1 | 延长答复 | 明确答复时间 |
| 2 | 提高对方 | 抬高对方+贬低自己 |
| 3 | 借人与物 | 把拒绝权转给他人 |
| 4 | 对方立场 | 站在对方角度 |
| 5 | 模糊应对 | 不明确具体信息 |
| 6 | 转折原因 | 给出具体理由 |

**歉意/感谢规则：** 对方明显请求→用歉意；对方共谋性请求（出发点好）→用感谢
**例外：** 缓力使用"延长答复"时，一般不加歉意/感谢；隐形拒绝也可不加

### 方面二：接力 + 原力 + 歉意

> 慎用！可让对方不但不生气还感激你
> **原力2核心：** ① 假意真做（假意要做→对方自动放弃） ② 什么都没做但让对方以为你做了

### 方面三：步步否决

> 精髓：**坚持说不**，防止被对方语言催眠形成惯性
> 对方说"天气不错"→答"预报说有雨"
> 对方说"办公室视野真好"→答"我更喜欢看车流"

## 三、快速聊天系统

### 总公式

$$
\textbf{自身铺垫 + 话题准备 + 灵活交锋 + 话后反思 + 执行完善}
$$

### 自身铺垫8要素

> 积极心态 + 学会微笑 + 充分自信 + 礼貌待人 + 干净整洁 + 多去付出 + 发现兴趣 + 热爱运动

### 话题准备2大部分

**候补亮点4方面：**
1. 历史上的今天（搜3个备用）
2. 当天天气匹配的故事/笑话
3. 当天交通匹配的故事/笑话
4. 谈话载体形式匹配的故事/笑话（如聚餐→菜品典故）

**共同话题7方面：**
1. 时下热点（百度事件 + 微博网友评论）
2. 参与者所在行业的发展/状态
3. 参与者感兴趣事情的最新信息
4. 参与者的人生大事（结婚/生子/升职/开业）
5. 大家关注的最新政策（要有自己看法+网友评论）
6. 聊天地点的了解（餐馆特色/菜品/八大菜系）
7. 参与者方言特色

### 灵活交锋2大部分

**聊天6大注意事项：** 主动打招呼 → 遵守时间 → 合理幽默（五线三点法）→ 不夸耀 → 多听为主（冷场救场）→ 多赞美

**4大魅力切入点：**
1. 联想自身经历（好玩/搞笑/有意思）
2. 幼稚话题双向处理（领导不参与，否则假装热情）
3. 不懂/违背原则的问题→模糊处理
4. 对方刚经历/现在状态/将来打算的延伸

### 话后反思 + 执行完善

- 聊完后记下待改进点 → 回家写笔记本 → 睡前回想 → 一周后翻看
- 临界点：**30次使用量**
- 执行原则：**不三过**（同问题最多犯两次）

## 四、酒桌聊天套路

### 组局者公式 × 4场景

| 场景 | 公式 |
|------|------|
| **请领导吃饭** | 合理邀约 + 点餐到位 + 合适主题 + 迎合 + 请教 + 合适敬酒 + 固定填补 + 细节言辞 + 伴手礼 + 圆满结尾 |
| **请朋友吃饭** | 点餐到位 + 节奏敬酒 + 聊天话题 + 适当迎合 + 主导话题不冷场 + 固定填补 + 细节言辞 + 圆满结尾 |
| **请客户吃饭（有领导）** | 点餐到位 + 合适主题 + 迎合 + 请教 + 合适敬酒 + 固定填补 + 细节言辞 + 圆满结尾（先客户后领导，配合领导讲话） |
| **请家人吃饭（有长辈）** | 点餐到位 + 合适主题 + 迎合 + 请教 + 合适敬酒 + 固定填补 + 细节言辞 + 圆满结尾（类似领导，心理可放松） |

> **主导话题不冷场5切入点：** ① 自己讲话题 ② 让某人谈论自己 ③ 借助敬酒活跃气氛 ④ 讲故事/笑话 ⑤ 固定填补方式

| 场景 | 公式 |
|------|------|
| **领导请吃饭** | 合理要求点餐 + 谨慎言行 + 适当迎合 + 适当合适主题 + 请教 + 合适敬酒 + 固定填补 + 细节言辞 + 感谢圆满结尾 |
| **陪领导被请吃饭** | 合理要求点餐 + 合适主题 + 适当迎合 + 请教 + 合适敬酒 + 固定填补 + 细节言辞 + 感谢圆满结尾 |
| **朋友请吃饭** | 合理要求点餐 + 聊天话题 + 适当迎合 + 请教 + 合适敬酒 + 固定填补 + 细节言辞 + 感谢圆满结尾 |
| **客户请吃饭** | 合理要求点餐 + 合适话题 + 适当迎合 + 请教 + 合适敬酒 + 固定填补 + 细节言辞 + 感谢圆满结尾 |

> **谨慎言行4层意思：** ① 领导请吃饭也不要过于兴奋 ② 顺其自然，多做好观众 ③ 不提工作问题 ④ 充分利用敬酒机会展现自己
>
> **前半场时刻：** 少说话多吃饭多观察，积极回馈，为下半场铺垫

## 五、敬酒套路

### 核心公式

$$
\textbf{称呼 + 敬酒铺垫 + 敬酒主题模块(灵活组合) + 祝福未来 + 喝酒引导}
$$

### 敬酒铺垫

| 类型 | 方法 | 使用范围 |
|------|------|----------|
| **正式敬酒** | ① 告知敬酒数量+具体数量提示 ② 直接告知具体数量 | ① 跨地区人群 ② 同地区人群 |
| **自由敬酒** | ① 含有敬酒词的敬酒（直接提出/请示提出）② 直接表达喝酒意思（兄弟喝一个） | ① 领导/不熟的人 ② 熟悉的人 |

### 17个敬酒主题模块（自由组合，通常2个以上）

> 欢迎 → 感谢 → 祝贺 → 借力感悟 → 谦虚 → 荣幸 → 相似点 → 敬佩 → 层次渐进 → 引用对方话语 → 心情 → 名人名言 → 缘分 → 第一次 → 赞美 → 问题互动 → 俗话说+押韵句子

### 祝福未来2切入点

| 切入点 | 用法 |
|--------|------|
| **希望** | ① 常来常往（欢迎外地客人） ② 多多指教/关照 |
| **祝福祝愿** | 根据对方现状态决定：合作成功/身体健康/工作顺利/心想事成/福如东海/寿比南山 |

### 喝酒引导3切入点

| # | 方法 | 适用 |
|---|------|------|
| 1 | 以茶代酒 | 不喜欢喝酒的领导或客人 |
| 2 | 我干了，您随意 | 第一次见的客人/朋友/领导 |
| 3 | 直接说明干杯 | 一般场合 |

### 关键升华点（少/缓/多）

| 技法 | 具体方法 | 推荐度 |
|------|----------|--------|
| **少** | 撒（洒酒）、掺（掺水）、吐（吐毛巾/茶杯）、倒（倒地） | ❌ 不提倡 |
| **缓** | **解**（解酒药）+ **垫**（吃东西垫底）+ **淡**（多喝水冲淡）+ **慢**（慢慢喝）+ **躲**（去洗手间）+ **吐**（主动催吐）+ **卖**（倒给别人）+ **说**（多闲聊）+ **闪**（借机离开） | ✅ 推荐 |
| **多** | **水对水多喝水**：不喝酒时自己喝多倍水，让对方喝水 | ✅ 推荐 |
