# 公司治理术语表

## 核心概念

| 术语 | 英文 | 定义 | 相关课程 |
|---|---|---|---|
| 公司治理 | Corporate Governance | 确保投资者收回投资并取得合理回报的各种制度总和 | 第01课 |
| 代理冲突 | Agency Conflict | 委托代理关系下，信息不对称导致委托人与代理人之间的利益冲突 | 第03课 |
| 合约不完全 | Incomplete Contract | 合约无法穷尽未来事项，无法严格约束经理人的固有局限 | 第03课 |
| 所有权与经营权分离 | Separation of Ownership and Control | 股东拥有资本所有权，经理人掌握经营决策权 | 第03课 |
| 信息不对称 | Information Asymmetry | 代理人比委托人更了解资金打理情况的状况 | 第03课 |
| 现金流权 | Cash Flow Right | 股东实际投入资金的比例，决定分红比例和责任承担能力 | 第05课 |
| 控制权 | Control Right | 股东在股东大会/董事会的表决影响力 | 第05课 |
| 同股同权 | One Share One Vote | 一股一票，出资越多持股越多，话语权越大 | 第09课 |
| 同股不同权 | Dual-Class Share Structure | 同一家公司发行不同投票权的多类股票 | 第10课 |

## 制度与机制

| 术语 | 英文 | 定义 |
|---|---|---|
| 股权激励计划 | Equity Incentive Plan | 授予经理人股票，使经理人像股东一样思考的"金手铐" |
| 身股 | — | 明清晋商制度，经财东同意授予掌柜和资深伙计的分红权 |
| 日落条款 | Sunset Clause | AB双重股权中，规定超级投票权在何种条件下自动失效的条款 |
| 一致行动协议 | Voting Agreement | 股东就特定事项约定按事先方式行使表决权的协议 |
| 员工持股计划 | Employee Stock Ownership Plan (ESOP) | 让员工持有公司股份，兼具激励和防御功能的制度 |
| 超额委派董事 | Over-boarding | 主要股东委派董事比例超过其持股比例的做法 |
| 合伙人制度 | Partnership System | 管理团队以股东身份集中持股，集体扮演大股东角色 |
| 有限合伙构架 | Limited Partnership Structure | 基于有限合伙投资协议的多层次控制权安排 |

## 市场角色

| 术语 | 定义 |
|---|---|
| 野蛮人 | 通过二级市场举牌增持股票谋取控制权的投资者 |
| 白衣骑士 | 通过持有大比例股份帮助管理团队反接管的投资者 |
| 金融大鳄 | 隐身于金字塔式控股结构背后的实际控制人 |
| 中国式内部人 | 利用政治关联、社会连接等控制公司谋取私利的经理人 |
| 创业达人 | 互联网时代中，掌握独特业务模式但让投资者看不懂的创业者 |
| GP（普通合伙人） | 负责投资管理、代表有限合伙人履行股东权益的合伙人 |
| LP（有限合伙人） | 以认缴出资额为限承担责任、参与风险分担的合伙人 |

## 关键持股比例

| 比例 | 含义 | 法律效果 |
|---|---|---|
| 50% | 绝对控股 | 控制性股东，对一般事项有决定权 |
| 1/3 | 相对控股 | 一票否决权，可阻止重大事项 |
| 10% | 提议权 | 可提议召开临时股东大会 |
| 5% | 举牌线 | 一次性购买超过5%需发公告披露 |
| 3% | 提案权 | 可向股东大会提出议案 |
