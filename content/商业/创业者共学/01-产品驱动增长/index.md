# 怎样用产品驱动增长

> 增长 = 需求 x 方案 x 共识 x 体验 x 场域 x 效率 x 口碑 x 流量

## 课程简介

本课程由李睿主讲，系统性地提出了一套**产品驱动增长的乘法公式**。与传统"漏斗式增长"不同，本课程将增长拆解为八个独立可优化的因子——需求、方案、共识、体验、场域、效率、口碑、流量，每一个因子都可以取大于1的值，通过乘积效应实现倍级增长。

课程核心思想：**产品是满足用户需求而被用户感知到的所有环节的总和**，增长不是靠烧钱买流量，而是靠产品本身的力量驱动。

### 核心公式

```
增长 = 需求 × 方案 × 共识 × 体验 × 场域 × 效率 × 口碑 × 流量
```

> 所有因子相乘，每个因子都可以大于1。相比于漏斗式增长（增长 = 流量 × 转化率1 × 转化率2 × ...），产品驱动增长的核心在于：**前七个因子会放大流量的价值**。

### 与传统漏斗式的对比

| 维度 | 漏斗式增长 | 产品驱动增长 |
|------|-----------|-------------|
| 核心视角 | 流量数据 | 真实用户 |
| 转化率 | <1，相互掣肘 | 可>1，相互放大 |
| 用户定位 | 抽象数据 | 具体的人 |
| 增长瓶颈 | 流量枯竭 | 持续突破 |
| 团队协作 | 部门内耗 | 共识一致 |

## 讲师介绍

**李睿**，资深产品增长专家，拥有多年产品驱动增长的实战经验。成功打造过多个由产品自身驱动增长的业务，也曾经历过不成功的产品，在实践中深刻体会到"好产品驱动增长"的力量。坚信产品的增长应该向内求，从需求出发，一步步通过八个因子的乘法效应实现可持续增长。

## 学习目标

完成本课程学习后，你将能够：

1. 掌握产品驱动增长的乘法公式，建立系统的增长思维框架
2. 学会深入挖掘用户真实需求的三个方法：**深访、原话、反着问**
3. 能够制定不超过三句话的产品解决方案，并确保其有效
4. 在团队内实现横向拉齐和纵向坚定的共识机制
5. 设计真正让用户满意的用户体验，绘制用户体验地图
6. 找到并创建目标用户聚集的场域
7. 运用"聚焦、参与、一致"六字心法提升共识效率
8. 理解转介绍的本质，让产品自己会说话
9. 掌握产品不同发展阶段与流量匹配的原则
10. 实现不内耗、不失焦、不浪费、不外求的增长境界

## 适合人群

- **创业者与CEO**：希望依靠产品自身力量实现持续增长，摆脱"烧钱买流量"的困境
- **产品经理**：希望建立系统化的产品增长思维，从需求到流量全链路掌控
- **运营负责人**：希望理解增长的本质不是漏斗转化，而是与用户达成共识
- **业务团队管理者**：希望解决团队内耗问题，建立以解决方案为纲领的协作机制
- **所有做产品和做业务的人**：希望用"向内求"的方式，通过产品本身来驱动增长
