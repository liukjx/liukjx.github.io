# 第01课：导论：重新定义产品和增长的乘法公式

## 课程核心框架

本课是整套课程的**总纲**，重新定义了"产品"和"增长"两个核心概念，提出**产品驱动增长的乘法公式**，为后续八讲的学习铺设完整的地图。

### 核心概念对比

| 维度 | 传统理解 | 课程定义 |
|------|---------|---------|
| **产品** | 一个东西或一项服务 | 为了满足用户需求而被用户感知到的**所有环节的总和** |
| **增长** | 流量 x 转化率1 x 转化率2 x ... | 需求 x 方案 x 共识 x 体验 x 场域 x 效率 x 口碑 x 流量 |

## 关键知识点详解

### KP-002：产品的用户视角定义

站在用户视角，产品不只是核心功能，而是用户能感知到的一切：

- **iPhone案例**：除了通讯功能，摄像头（视觉延伸）、触控操作（触觉延伸）、品牌宣传、广告店面、网站售后、升级换代——**这些都是产品的一部分，也包含在价格中**
- **一本书案例**：线上线下宣传海报、封面装帧设计、附带卡片、二维码介质、读者社群——**都是产品的一部分**

> 核心：当我们讨论产品时，要站在用户视角看"他能获得什么"。

### KP-006：漏斗式增长公式及其三大致命问题

**漏斗公式：增长 = 流量 x 转化率1 x 转化率2 x 转化率3 x ...**

问题一：**转化率之间互相掣肘**
- 卖汽车案例：为了提升"试驾率"做活动送礼物，试驾率上去了，但从试驾到购买的转化率反而下降了
- 如果不同转化率由不同部门负责，就会产生**内耗**

问题二：**每个转化率因子都小于1**
- 如果进群到付费转化率=1%，增长1000用户需要10万流量
- 可能目标用户总共不到10万人——流量瓶颈

问题三：**不把用户当人看**
- 用户被当作流量、抽象数据
- 长期使用漏斗思维，团队会失去对用户的直观感知和理解
- 数据分析做得再好，讨论也是**空中楼阁**

### KP-001：产品驱动增长乘法公式

```
增长 = 需求 x 方案 x 共识 x 体验 x 场域 x 效率 x 口碑 x 流量
```

八因子预览：

| 因子 | 核心问题 | 对应课时 |
|------|---------|---------|
| 需求 | 无需求便无产品，如何抓住真实需求？ | 第02课 |
| 方案 | 用什么方式满足需求？如何做减法？ | 第03课 |
| 共识 | 团队是否在做同一个产品？如何避免内耗？ | 第04课 |
| 体验 | 什么是好的用户体验？如何落地？ | 第05课 |
| 场域 | 哪里能找到目标用户？如何自建场域？ | 第06课 |
| 效率 | 用什么方式让用户真正认识产品？ | 第07课 |
| 口碑 | 如何让用户成功转介绍？ | 第08课 |
| 流量 | 如何用小流量撬动大增长？ | 第09课 |

## 案例和例子

**iPhone产品边界案例**：传统理解iPhone是"能上网能打电话的东西"，但用户视角下，摄像头（视觉延伸）、触控（触觉延伸）、品牌、广告、店面、售后、升级换代——都是产品的一部分。

**汽车试驾内耗案例**：为了提升试驾率做送礼活动，试驾率上升但购车率下降，各部门目标冲突导致内耗。

## 金句摘录

> "产品是为了满足用户的某个需求，而被用户感知到的所有的环节的总和。"

> "这个公式里并没有把用户当做人来看待，而是当做流量或者是一个抽象的数据来看待。"

> "长期使用漏斗作为增长的基础，会让团队失去对用户的直观感知和理解。"

> "增长 = 需求 x 方案 x 共识 x 体验 x 场域 x 效率 x 口碑 x 流量。"

## 自检问题

**Q1**：用你的产品举例，用户能感知到哪些环节？这些环节中，有多少是你之前忽略的？

<details>
<summary>答案</summary>
思考路径：从用户第一次接触产品开始，整个链条上的每一个触点——广告、搜索、了解、购买、使用、售后、推荐等。你可能会发现自己之前只关注了核心功能，而忽略了大量用户能感知到的环节。
</details>

**Q2**：你现在使用的增长公式，是否也面临漏斗式增长的三大问题？哪个问题最致命？

<details>
<summary>答案</summary>
对照三个问题检查：部门之间是否有内耗？增长是否高度依赖流量投入？团队是否在做数据分析时对用户缺乏直观感知？最致命的问题往往是"不把用户当人"，因为这会导致所有决策偏离用户真实需求。
</details>
