# 第03课：方案：怎么能更好地传递产品核心价值

## 课程核心框架

**方案**（解决方案/价值主张）是满足用户需求的方式。它的本质是**做减法**——从所有可能的方法中选出3条以内的一定要坚持的，作为公司一切管理和沟通行为的**总纲领**。

### 方案制定的三大原则

```
好的解决方案三原则：
┌────────────────────────────────────────┐
│ ① 不能是承诺性描述                      │
│    → 要说明"怎么做"而不是"承诺结果"      │
├────────────────────────────────────────┤
│ ② 与需求有因果关系                      │
│    → 用"因为...所以..."句式检测          │
├────────────────────────────────────────┤
│ ③ 说人话（通俗易懂）                    │
│    → 团队内人人都能明白，能指导行为       │
└────────────────────────────────────────┘
```

## 关键知识点详解

### KP-014：解决方案的本质是做减法

**核心思想**：从所有能满足需求的方法中，选出3条以内一定要坚持的，作为价值主张（总纲领）。

**为什么不超过3条**：
- 定了10条，资源分散，每条都做不好
- 方案是**帮团队做减法**的取舍工具
- 围绕有限的方案深耕探索，更容易出成绩

### KP-016：原则一——不能是承诺性描述

- 承诺性描述承诺结果而非方法（如"孩子喜欢""学完有效果"）
- 用户更关心**怎么有效果**，而不是你说有效果
- 删掉承诺性描述是在**倒逼你更清晰自己的产品究竟创造了什么价值**

### KP-017：原则二——解决方案与需求之间有因果关系

**检测句式**：`因为 [解决方案]，所以 [需求]`

**宾馆案例**：
- "因为创造了安静的环境，所以客人可以睡得更好" → 符合常识

**教育产品反例**：
- "因为团队拥有17年研究经验，所以可以提升用户知识水平" → 因果不完整
- 补充完整："因为我们17年经验归纳了10个最难理解的点，给出了和传统不一样的方法，所以能提升知识水平" → **这才是真正的解决方案**

### KP-018：原则三——说人话

**什么是"不说人话"**：
- 舞蹈教育产品的方案："身心灵的统一造就的美誉"
- 写的人自己都说不清楚是什么意思

**如何改善**：
- 写出来后让团队里不同岗位的人看
- 确保每个人都能明白、都能指导行为
- "虽然不是最精炼的，但至少是用户听得懂的"

### KP-020：行业底线 vs 方案内事务

**解决方案没说到的，就一定不能做吗？** —— 不一定。

- **行业底线**：宾馆必须有窗帘、提供热水、提供电源等——即使没写在方案里，也必须做
- **解决方案内优先做**：方案里的事，优先投入资源
- **方案是减法工具**：纠结做不做时，用方案来判断优先级

## 案例和例子

**开宾馆案例**：
- 需求：让顾客睡好
- 可能的方案（很多）：舒适床垫、恒温空调、隔音、香薰蜡烛、多种枕头、遮光窗帘、白噪音机、个性化睡眠方案...
- **精简后的方案**：
  1. 创造安静的环境
  2. 提供舒适的床和床上用品
- 有了这两条，决策就清晰了：选安静的地方（不在机场边）、门墙做隔音、下水道特殊处理——所有投入都花在刀刃上

**教育产品方案因果检测案例**：
- 原始方案："团队拥有17年的研究经验"——与"提升知识水平"之间缺乏因果关系
- 完善后："归纳了10个最难理解的点，给出与教科书不同的讲法"——这才是真正的方案

## 金句摘录

> "解决方案是帮我们做减法。如果一件事我们再纠结要不要做，那就用我们写的解决方案来进行判断。"

> "承诺性描述承诺了一个结果，而不是怎么做。其实用户更关心的是怎么有效果。"

> "解决方案不是宣传语，而是和用户需求有因果关系的行动指南。"

> "当团队所有人围绕着两三个解决方案不断深耕探索，想不出成绩都很难。"

## 自检问题

**Q1**：为你的产品写出不超过三句话的解决方案。试试用"因为...所以..."句式检测因果关系。

<details>
<summary>答案</summary>
先明确产品的核心需求，然后用"因为[方案]，所以[需求]"的句式测试每一条方案。如果因果链不完整，说明拆解得不够细，需要进一步分解到可执行的行动层面。
</details>

**Q2**：检视你现在的产品描述中是否有承诺性表述？删除后，你能不能更清楚地说明产品到底创造了什么价值？

<details>
<summary>答案</summary>
删除承诺性表述（如"保证有效""孩子一定喜欢"）后，你需要用更具体的语言描述产品做了什么、怎么做的。这个过程本身就是在倒逼产品设计者想清楚核心价值。
</details>
