# 第08课：口碑：怎么让产品被用户成功转介绍

## 课程核心框架

**转介绍的本质**：用户向其他用户介绍产品的解决方案。只要用户能说对解决方案，转介绍就在客观发生。

### 转介绍的底层逻辑

```
转介绍 ≠ 用户主观意愿
转介绍 = 用户客观介绍产品的解决方案

能说对产品方案的人 → 都可能转介绍
│
├── 认同产品的铁粉 → 主动转介绍
├── 普通购买者     → 无意中转介绍
├── 退款用户       → 也可能转介绍
└── 未购买的用户   → 认同方案就是种子
```

## 关键知识点详解

### KP-050：转介绍的本质

在体验、场域、效率三个因子上，我们一直在做一件事——**和用户就解决方案达成共识**。转介绍的本质就是用户向其他用户介绍这个解决方案。

转介绍不是活动，不是转发朋友圈送礼物：
- 转发有奖活动更像一种品牌广告
- 把广告费从给品牌商平均分给每个愿意把朋友圈变成广告位的人
- 这些活动可以存在，但与真正的转介绍不同

### KP-051：核心用户的标准

**核心用户 ≠ 购买多的、花钱多的、到处夸的、意见领袖**

**核心用户 = 愿意说 + 能说对产品解决方案的人**

**关键点**：即使没有购买也可以成为核心用户。
- 课程讲师案例：分析一个家庭教育产品，觉得做得非常好，经常推荐——实际上没有购买
- 核心标准：是否认同方案、能否说对方案

### KP-052：退款用户也可能转介绍

**案例**——鼓励型培训产品：
- 方案：关注和激励
- A用户：认同激励，主动推荐"老师特别负责，每次表扬我家孩子"
- B用户：认为"我需要压力不需要激励"→ 退款
- B退款后对朋友说："他们就知道鼓励人，不给压力"
- 朋友说："哎呀我就是缺爱，我希望有人夸我！"
- B的抱怨 → 成功转介绍

**启示**：只要用户能说对产品的解决方案，不管他是正面还是负面评价，都可能实现转介绍。

### KP-053：基于正确方案的转介绍才有效

**健身房案例**：
- 方案：24小时开放 + 离社区近 + 便捷
- 用户A介绍："这个健身房好，不远，随时去有位置"
- 用户B介绍："这个健身房好，正对着花园，环境好"
- 用户C介绍："这个健身房好，教练很帅"
- 只有A的转介绍是有效的（与方案一致）
- B和C的转介绍还不如不做——B的朋友去后发现在地下室"对着logo"，非常失望

> 如果B和C在办卡时就清楚知道方案，就会意识到"正对着花园"和"教练帅"不是必然提供的。

### KP-054：转发有奖 ≠ 转介绍

- 转发有奖活动可以适当做
- 想效果好，模板中要突出解决方案
- 英语口语产品案例：模板应该是"用户开口次数/视频"，而不是"早安生活多美好"

### KP-055：退款与负面口碑

**退款不等于负面口碑**：
1. **第一种退款**：购买时不知道方案是什么（被忽悠进来的）
   → 几乎全部是负面口碑
   → 超出方案框架的承诺 = 过度承诺
2. **第二种退款**：购买时达成共识，但实际未兑现/用户想法改变
   → 处理得当，用户可能给第二次机会
   → 近乎全负面案例：新产品bug多，用户卸载，修好后用户愿意再试

## 案例和例子

**鼓励型培训产品转介绍案例**：
- 方案：关注和激励
- 铁粉转介绍："老师特别负责，教了作业立马给反馈"
- 退款用户转介绍：抱怨"只鼓励不批评"→ 吸引到"需要鼓励"的新用户

**健身房转介绍案例**：
- A说对方案：有效转介绍
- B说环境、C说教练帅：无效甚至有害转介绍

**核心用户案例**：
- 讲师本人没有购买某个家庭教育产品，但因为认同方案经常推荐
- 这是比购买用户更有价值的核心用户

## 金句摘录

> "转介绍的本质是用户向其他用户介绍我们产品的解决方案。只要他能介绍出来，转介绍就在客观发生。"

> "核心用户的标准是——愿意说，且能说对我们的产品解决方案的人。没有购买也可以。"

> "基于正确的解决方案的转介绍，越多越好。超出解决方案框架的转介绍，还不如不介绍。"

> "超出解决方案框架的承诺，都属于过度承诺。"

> "退款用户也可能是转介绍的来源——关键是他说不说的对产品的解决方案。"

## 自检问题

**Q1**：找出你的产品5个最活跃的"推荐者"。他们能说对你们产品的解决方案吗？

<details>
<summary>答案</summary>
分别访谈这5个推荐者，让他们用自己的话描述"为什么推荐你的产品"。对比他们的描述与你们的产品解决方案——如果偏差较大，说明你的产品虽然在传播，但传播的信息不是解决方案的核心价值。与其纠结转化率，不如想办法让这些推荐者说"对"。
</details>

**Q2**：如果你的一个用户退款了并到处抱怨，他抱怨的内容是否说中了你的解决方案？这可能是好事还是坏事？

<details>
<summary>答案</summary>
如果他说对了方案只是不认可（"这个产品就是过度激励我不需要"），那可能吸引到相反需求的人。如果他说错了方案（"这个产品根本没效果"），那才是真正的负面口碑。关键在于：用户是否知道你们的产品到底是什么。
</details>
