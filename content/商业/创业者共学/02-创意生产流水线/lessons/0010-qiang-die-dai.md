# 第09课｜强迭代：怎样让创意流水线保持生命力

> **流程一旦停止迭代，立刻就会成为死流程。迭代才是做流程的目的，流程本身不是目的。**

---

## 核心概念

- **流程迭代是目的**：不是打造一个完美的流水线，而是打造一个可以不断迭代的流水线。迭代才是组织存在的目的。
- **每周硬性迭代**：每个部门每周必须提交迭代报告，不管好的坏的都要迭代。
- **流程委员会**：由中层业务骨干组成，负责审议迭代提案。中层离一线战斗最近，又有管理经验积累。
- **犯错文化**：犯错不是坏事——犯错会暴露流程上的漏洞，给组织提供迭代和改善的机会。**"我犯错，我光荣，我得奖。"**
- **动作要僵化·流程要迭代**：员工在未迭代之前必须严格按照现有流程做，同时把问题反馈上去。

---

## 关键知识点详解

### 1. 为什么说"没有完美流程"？

> "就连华为基本法，在诞生的当天就已经失效了。"

**道理**：
- 如果流程不变，组织就会死亡、腐化，变成一潭死水
- 从1913年到今天，汽车流水线经过110年迭代：700小时 → 12小时28分钟（第一条流水线） → **45秒**（特斯拉）
- 创意流水线只是1913年的水平——简陋、粗糙、充满漏洞和多余动作
- 需要几十甚至上百年的不断迭代

### 2. 迭代机制的三个步骤

#### 第一步：员工发现问题→提案

**日常反馈渠道**：
- **晨会/晚会**：每天上班第一个会/下班前一个会
- 当天发现问题 → 当天在晨晚会上提出
- 每周汇总提交

**迭代提案模板**（标准化）：
- 日期
- 提案人
- 编号
- 流程类型（红/黄/绿）
- 滴漏描述（哪里有问题）
- 真因寻找
- 迭代方案
- 需要协同的部门

**示例**：
2023年2月20日，编辑部刘子齐提出：新同事不知道怎么确定一本书的定价 → 红流程 → 动作编号Y-Y1-5 → 真因：动作描述中缺少公式 → 迭代方案：补充从成本到销售价格的定价公式 → 需销售部协同

#### 第二步：流程委员会审议

**委员会组成**：
- 1名董事合伙人带领
- 各部门的中层业务骨干组成
- 既有一线经验，又有管理能力

**评估标准**：
1. 该问题是个人没遵守流程，还是流程本身的问题？
2. 该提案是否能提高工作效率、减少出错概率和浪费？

#### 第三步：奖励

- 每周一颁发上周提案奖金
- 华楠亲自颁发，每人**100元现金**
- 必须是**连号的新钱**（强化"每个动作都是连号的"）
- 每季度评选"提案数量最多"和"最有价值"提案
- 获奖者照片张贴在电梯里表彰

### 3. 动作要僵化，流程要迭代

**核心原则**：
- 员工执行时必须严格按流程 —— **动作要僵化**
- 如果发现流程有问题 → 依然按流程做 + 把问题反馈上去
- 等下周流程委员会通过新流程 → 新流程才能被执行
- "即便发现它不对、有滴漏、有多余动作，也依然按照这个流程来做"

**为什么？**
> 不做多余的动作，你就不知道它是多余的。先做，然后反馈、然后迭代、然后消除。

### 4. 犯错文化

**核心理念**：
> "一个员工在执行流程的过程中犯了错，就说明这个流程有一个迭代的空间，有一个改善的机会。"

"我犯错，我光荣，我得奖"——犯错等于为组织进化做出贡献。

**真实案例**：
创意流水线运行以来有两次创意产品不合格的情况（母体描述阶段出错）。
- 分析结论：不是员工不够努力/不够聪明/不够负责
- 流程问题：定母体的环节中流程描述有纰漏
- **迭代补丁**：增加母体超级词根的判断依据——消费者原话 + 作者写作初衷 + 同品类读者评论，三者的交叠处出现的词根才是超级词根
- 迭代之后再也没出过类似错误

### 5. 员工是流程的主人

> "公司4500多个动作，没有任何一个动作是我定的或者我想出来的。这4500多个动作都是大家自己生成出来、自己和周围同事一起去迭代的。"

**三合一角色**：
- **流程的执行人**：严格按流程操作
- **流程的制定者**：通过动作显形记录流程
- **流程的迭代者**：通过提案改善流程

**职业晋升通道**：
对流程理解最深 + 执行最彻底 + 迭代贡献最大 → 成为流程的管理者 → 教别人使用流水线 → 职业上升台阶

## 案例和例子

### 华为基本法的启示
"华为基本法在诞生的当天就已经失效了"——任正非的这句话让华楠深受震撼。制度必须是活的，必须不断变化。

### 特斯拉 vs 福特流水线
1913年：700小时/台 → 第一条流水线：12小时28分钟 → 今天特斯拉：45秒下线一台车。110年迭代了数不清的版本。

### 刘子齐的定价公式提案
编辑发现新同事不会定价 → 红流程 → 动作编号Y-Y1-5 → 缺计算公式 → 迭代方案：补充公式 → 协同销售部

### 母体描述错误的迭代
两次不合格产品复盘 → 母体描述环节有纰漏 → 补丁：超级词根必须来自消费者原话+作者写作初衷+同品类读者评论的交叠处 → 之后再未发生类似错误

## 金句摘录

1. "流程必须处于永恒的迭代当中。流程一旦停止迭代，立刻就会成为死流程。"
2. "改善才是我们做流程的目的，而不是说流程本身是目的。"
3. "华为基本法在诞生的当天就已经失效了。"
4. "全公司的同事，都是流程的执行人，同时也是流程的制定者，还是这个流程的迭代者。"
5. "我犯错，我光荣，我得奖。"
6. "不做多余的动作，你就不知道它是多余的。"
7. "4500多个动作，没有任何一个动作是我定的。"

## 自检问题

1. 你团队的流程上一次迭代是什么时候？有没有定期迭代的机制？
2. 你的团队有没有流程委员会或类似的审议机构？谁有权力决定流程变更？
3. 你的员工发现流程问题时，是选择将错就错还是主动反馈？
4. 你有没有鼓励犯错的文化？员工犯了错是害怕被责备，还是把它视为改善的机会？
5. 如果所有流程都要每周迭代一次，你团队能承受吗？
