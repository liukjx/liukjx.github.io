# 第03课：明确方向——怎样定义产品的核心价值？

## 核心概念

- **价值公式**：产品核心价值 = **谁** + **问题** + **方案**，用于拆解需求背后的真实问题
- **五问法**：连续以五个"为什么"追问根本原因，直至找到问题的本质
- **叠叠乐分析法**：模拟"抽积木"游戏，分析从业务中抽走哪个角色会导致整个体系崩塌，以此识别关键角色

## 知识点详解

### 1. 产品经理的核心职责：看好资源，确保投入产出

- 产品经理要尽全力确保资源（时间、人力、资金）的投入产出是划算的
- 每分钱花在刀刃上，不断为产品的核心价值加码
- 错误的决定越早被叫停，代价越小
- 一个产品创意一旦投入设计和研发才发现问题，代价就太大了

### 2. 方法一：套用价值公式，定义核心问题

**大多数"需求"其实是伪装成需求的解决方案**：
- 业务同事说"增加订单列表排序功能"——这是方案，不是问题
- 老板说"加一个转发朋友圈解锁付费内容的功能"——这是方案，不是问题

**价值公式**：
```
产品核心价值 = 谁 + 问题 + 方案
```

做产品决策时，不断代入这个公式，分析：
- 需求背后究竟是想要解决**谁**的问题？
- 具体是什么**问题**？
- 用什么**方案**？

**五问法应用示例**（以"转发朋友圈解锁付费内容"为例）：

1. 问老板为什么要做这个功能 → "获得更多用户"
2. 为什么用户规模更重要，甚至愿意放弃收入 → "投资人在考核规模增长"
3. 为什么股东更关注增长而不是收入 → 可能处于市场扩张期
4. 问用户：为什么愿意转发解锁 → "不知道内容质量如何，想先免费看看"
5. 为什么不直接给用户免费试看，而要转发 → "需要用户付出代价，也想获得传播"

通过层层追问，找到三个核心问题：
- 投资人的诉求：用户规模增长
- 用户的诉求：不清楚内容是否值得付费
- 用户隐性问题：社交人设维护

### 3. 方法二：叠叠乐分析法，优先解决关键角色的问题

**叠叠乐游戏原理**：从积木塔中抽积木，哪块积木被抽出时让塔垮掉，谁就输了。

**应用到产品决策**：如果某个角色因为利益未被满足而离开，整个业务会垮掉且无法挽救——这个角色就是当前阶段的关键角色。

**网约车平台案例分析**：

| 阶段 | 关键角色 | 原因 | 对应策略 |
|------|----------|------|----------|
| 早期 | **司机** | 抽走司机运力为零，平台瞬间垮掉；抽走乘客还能苟延残喘 | 降低准入标准、默许刷单、直接补贴司机 |
| 成熟期 | **乘客** | 运力充沛，抽走部分司机不影响大盘；但抽走乘客会流失到竞品 | 获客、提升乘客体验 |

**关键洞察**：关键角色和核心问题是随着产品生命周期动态变化的，产品的核心价值也会随之调整。

### 4. 决策优先级排序

找到核心问题后，根据方案的成本和时效性，选择性价比更高的事情优先做：
1. 套用价值公式 -> 找出所有需求方和核心问题
2. 叠叠乐分析 -> 确定现阶段关键角色
3. 成本时效评估 -> 选择性价比最高的事情

## 案例

- **得到APP转发解锁功能**：老板提需求"转发朋友圈免费解锁付费内容"，通过价值公式和五问法拆解出投资人（规模增长）、用户（内容价值不确定+社交人设）三方诉求
- **网约车平台早期 vs 成熟期**：早期司机是关键角色（运力为零则平台垮掉），成熟期乘客是关键角色（容易流失到竞品）

## 金句

> "大多数所谓的需求并不是真正的需求，而是伪装成需求的解决方案。"

> "错误的决定，越早被叫停，代价就会越小。"

> "产品的核心价值会随着产品的生命周期不断调整。"

## 自检问题

1. 你最近接到的一个"需求"，用价值公式拆解一下，它背后真正的问题是什么？
2. 在你的业务中，谁是当前阶段的"关键角色"？用"叠叠乐"的方法分析一下。
3. 你的产品核心价值是否随着生命周期的变化而调整过？还是从一而终没有变化？
