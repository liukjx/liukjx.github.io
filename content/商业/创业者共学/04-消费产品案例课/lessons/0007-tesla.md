# 第07课：特斯拉——怎样靠产业效率实现性价比和利润双赢

## 案例背景

2023年新能源车和燃油车掀起大规模**降价潮**，超过30个电动车品牌宣布降价。而这场价格战的**源头是特斯拉**——2023年1月全线产品降价2-4.8万，创下历史新低。特斯拉是主动发起者，其他车企只能被动跟随。降价后特斯拉如何保持利润？答案是：**极致的成本控制能力**。

## 核心商业逻辑

### 汽车行业的本质竞争

```
汽车竞争 = 价格 × 性能的博弈
谁能在大众化价格段用更低成本提供更好性能，谁就能赢
```

| 阶段 | 特斯拉策略 | 目标用户 |
|------|-----------|----------|
| 早期 | 做电动车代名词，吸引尝鲜用户 | 高端/先锋用户 |
| 现在 | 降价扩大目标消费群 | 大众市场消费者 |
| 未来 | 软件订阅服务盈利 | 所有特斯拉车主 |

### 成本控制的三驾马车

#### 第一驾马车：电池管理系统（BMS）

- 电池占整车物料成本的50%
- 特斯拉自研智能BMS系统：
  - 实时监控电池状态，防止过充浪费
  - 监测漏电并报警
  - 配合温控系统维持电池在最佳工作温度
  - 延长续航，缓解"里程焦虑"
- **固定成本摊薄逻辑**：系统研发好之后，卖100万辆车和1000万辆车都用同一套系统，销量越大单辆车分摊的研发成本越低

#### 第二驾马车：一体化压铸

| 对比 | 传统车企 | 特斯拉 |
|------|----------|--------|
| 生产方式 | 大量零部件拼凑焊接 | 车身一次成型 |
| 零部件数量 | 多 | 少（大量减少） |
| 原材料利用率 | 低 | 高 |
| 车身重量 | 重 | 轻 |

- 上海超级工厂自建，自动化率达95%+
- 自建工厂让特斯拉可以自由创新生产流程
- 边际成本随着销量增加不断降低

#### 第三驾马车：自动驾驶软件订阅

- 汽车和自动驾驶软件**分开卖**
- 降价 → 卖更多车 → 收集更多驾驶数据 → 自动驾驶体验更好 → 更多用户订阅
- **未来商业模式**：卖车不赚钱，靠软件订阅赚钱
- 自动驾驶的竞争 = 数据收集的竞争，数据量越大，技术越精准

### 特斯拉"不花钱"的地方

- **不投广告**：财报中几乎没有广告支出
- **不造多车型**：只做一两款车（Model 3/Y），不给消费者过多选择
- **不在不重要的地方花钱**：将资源集中在真正形成壁垒的地方

## 关键知识点

### 1. 固定成本摊薄效应

前期投入巨大（研发、建厂），但一旦完成，每多卖一辆车的**边际成本极低**。销量越大的企业，成本优势越明显。

### 2. 自建工厂的战略价值

- 可以自由创新生产流程（如一体化压铸）
- 不用给代工厂付额外费用
- 长期看，自建工厂的单车利润率更高

### 3. 硬件引流+软件盈利

硬件降价获取规模和数据，软件（自动驾驶订阅）成为未来的利润中心。这是一种**双层盈利模式**。

## 可迁移的方法论

1. **找到行业里"值得深挖的产业环节"**：不是所有环节都值得投，找到能形成壁垒的关键环节持续投入
2. **判断消费者购买决策中最看重的因素**：找准这个农才能在正确的方向投入
3. **在能形成竞争壁垒的地方坚定投入**，在不能形成壁垒的地方**坚决不花冤枉钱**
4. **用规模摊薄固定成本**：前期投入大不可怕，关键看能否通过销量摊薄
5. **硬件+软件的复合盈利模式**：硬件可以降价获客，通过软件服务实现持续收入

## 金句摘录

- "汽车行业的竞争，本质上就是价格和性能的博弈。"
- "特斯拉是在能做出竞争壁垒的地方坚定投入，而且是不断地持续投入。"
- "如果特斯拉未来能实现自动驾驶，他可以在卖车的环节不赚钱，而是靠卖软件赚钱。"
- "不是所有行业都像车一样有复杂的产业环节，但每一个做产品的企业，都应该找到自己行业里值得深挖的产业环节，然后持续不断地投入进去。"
