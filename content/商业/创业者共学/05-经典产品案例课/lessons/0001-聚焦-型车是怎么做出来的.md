# 第01课：聚焦——T型车是怎么做出来的

## 案例背景

- **公司**：福特汽车公司（1903年成立）
- **时代**：19世纪末20世纪初，汽车行业犹如后来的互联网泡沫，1895-1905年间美国成立了3000多家汽车公司
- **人物**：亨利·福特（Henry Ford），此前已是汽车行业的连续创业者，前两次创业不成功，T型车之前已推出八款车
- **产品**：福特T型车（1908年推出），福特第九款车型，生命周期内卖出超过1500万辆

## 核心产品逻辑分析

### 1. 市场洞察：为普通人生产汽车

福特不认同当时汽车行业"生产昂贵汽车"的主流路线。他在自传中宣言：**要为广大的普通人生产汽车**。这是"现代史上最伟大的范式转变之一"（布林克利《福特传》）。

### 2. 产品设计上的实用主义

| 设计要点 | 具体做法 | 目的 |
|---------|---------|------|
| 空间大 | 可坐5人 | 实用性 |
| 车身轻 | 使用钒钢（比钢更轻更结实） | 降低油耗 |
| 底盘高 | 适应糟糕路况 | 农村地区也可使用 |
| 易操作 | 降低操作难度 | 快速上手，女性也能开 |
| 维护成本低 | 年均不到100美元 | 对比行业平均1500美元/年 |
| 售后服务 | 专职代理商、配件齐全、专业机械师 | 让用户放心 |

### 3. 杀手锏：不断降低的价格

- 1908年发售价：850美元
- 1925年售价：260美元（美国人平均年收入的1/8）
- 目标是让普通工人毫无负担地买一辆T型车

### 4. 低价背后的三驾马车

**第一：简单和聚焦**
- 福特不认同每年推出新车型刺激消费的做法
- 1909年宣布只生产T型车一种车型
- 1914年起只卖黑色（黑色车漆干得最快——1.5天，其他颜色需2周）
- 极简设计、单一车型、单一颜色 = 最大规模制造

**第二：流水线**
- 把工人动作的复杂性降到最低
- 通过传送带把零部件送到下一工位
- 效率对比：林肯公司6000人年产5000辆车；福特15000人年产180万辆T型车——效率差距约200倍

**第三：规模效应的经济规律**
- 大规模制造 = 更低生产成本
- 更低价格 = 更多需求
- 更多需求 = 更大规模
- 更大规模 = 更低成本
- 形成正向循环

## 关键知识点

- **聚焦策略**：一款产品做到极致，超越所有竞争对手
- **供给侧规模优势**：规模越大，单位生产成本越低
- **垂直整合**：福特自己生产几乎所有汽车配件
- **价格驱动市场**：降价不是被动行为，而是主动扩大市场的战略

## 历史启示与现实意义

福特的产品思维在今天仍被大量应用：高度聚焦、把一款产品做到极致、通过降低价格来扩大市场。特斯拉等新能源车企也在沿用类似策略——先做高端、再推大众款。

## 金句摘录

> "生产这些车（豪华车）可以赚钱，但不能改变世界。"
