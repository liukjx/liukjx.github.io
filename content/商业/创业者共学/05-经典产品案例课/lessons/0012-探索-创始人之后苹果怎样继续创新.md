# 第12课：探索——创始人之后，苹果怎样继续创新

## 案例背景

乔布斯2011年因癌症去世（56岁），正值苹果巅峰时期。他留下的挑战：一个做出伟大产品的公司如何创造自己的护城河？离开创始人之后，公司能否继续成功？

## 核心内容分析

### 1. 乔布斯的愿望：造钟而非报时

> "我的激情所在，是打造一家可以传世的公司。这家公司里的人动力十足地创造伟大的产品……你要打造一家再过一两代人仍然屹立不倒的公司。" ——乔布斯

吉姆·克林斯在《基业长青》中提出"造钟vs报时"：造钟人创造可以自己运行的系统，报时人只在当下正确。乔布斯虽然性格不像"造钟人"，但他在打造的是"钟"。

### 2. 库克——乔布斯的运营高手

| 加入时间 | 1998年，康柏电脑挖来 |
|---------|-------------------|
| 加入原因 | 见了乔布斯后，"抛开理性分析，完全依赖直觉和本能做的决定" |
| 核心贡献 | 减少供应商、压缩库存、缩短生产周期、将生产外包到亚洲 |
| 角色定位 | 运营高手，不是产品型的人 |

> "库克其实就是乔布斯最伟大的发明之一。" ——段永平

### 3. 艾福——苹果的设计灵魂

- 乔布斯回归后一系列产品的设计核心（iMac到iPhone和iPad）
- 在苹果：工程师满足设计师的创意和概念（而非设计师为工程师服务）
- 曾因设计分歧与鲁宾斯坦争执，后绕过鲁宾斯坦直接找乔布斯
- 乔布斯此后让艾福直接向他汇报，确保艾福成为苹果内仅次于CEO的二号人物

> "没有人可以告诉他该做什么或让他滚开。我就是这么安排的。" ——乔布斯

### 4. Apple Watch：后乔布斯时代的第一款重磅产品

| 维度 | 表现 |
|------|------|
| 发布时间 | 2014年9月 |
| 初始思路 | 艾福强调时尚感，请安娜·温特尔等时尚界人士背书 |
| 思路转变 | 慢热销售后从时尚转向科技+健康 |
| 销量 | 第一年约1200万只，占全球智能手表出货量61% |
| 营收占比 | 2015年手表等其他硬件仅占4.3% |

**关键困难**：与iPod和iPhone不同，Apple Watch面对的问题不是"如何做一个更好的手表"，而是"用户需不需要一块更好的手表"。

### 5. 库克时代苹果的真正增长点——服务业务

库克围绕iPhone不断提升体验和服务：
- 苹果服务：音乐、视频、健康、金融
- 隐私承诺：不惜和FBI对簿公堂
- 2022年：服务收入占苹果营收19.8%

**持续增长的iPhone**（2022年全球手机出货量下滑13%的情况下）：
- 苹果增长3%
- 三星下滑18%
- 原因：苹果赢得了"最好用手机"的品牌认知

### 6. 苹果护城河的构建

> "苹果在一点一点把自己的护城河挖深。"

- 开发者生态
- 苹果硬件与服务之间的协同
- 不断提升的用户体验

### 7. 两种声音的评价

| 正面评价 | 负面评价 |
|---------|---------|
| 库克是伟大CEO，很好继承苹果文化 | 苹果丧失创新精神，没有拿出像iPhone、iPad一样的新产品 |
| 市值从3444亿到突破3万亿 | 只是对iPhone进行升级（更大屏幕、更好摄像头、更多颜色） |
| 营收从1086亿到3943亿 | 苹果汽车迟迟未面世 |

## 关键知识点

- **造钟vs报时**：创始人离开后公司能否继续运行
- **服务化转型**：从硬件销售转向通过服务赚取更多价值
- **后创始人时代的两个路径**：硬件突破（Apple Watch）& 服务深化（隐私、订阅）
- **品牌认知优势**：成为"最好用的手机"本身就是护城河

## 历史启示与现实意义

库克时代苹果的增长证明了创始人之后公司仍然可以成功。但"是否能继续拿出有创新的产品"仍然是市场对这家公司的核心期待。苹果的混合现实头戴设备因此备受关注。
