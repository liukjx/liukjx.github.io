# 第14课：结语——等待下一个伟大产品

## 课程回顾

前面各讲介绍了T型车、Walkman、iPod和iPhone四款经典产品。他们的共同特点：**开创性、商业上巨大成功、超越商业的影响力**。

## 伟大产品创造者的四个共性

### 共性一：狂热分子

他们都对自己的某个信念有宗教般的热情：
- **福特**：汽车应该是低价的普及产品
- **盛田昭夫**：东方美学+科技+精良制造的产品可以在全世界风靡
- **乔布斯**：端到端的控制能做出完美产品，消费者愿意为正版付费

> "他相信消费者不会只是满足于便宜但粗糙的产品。他也相信人性中美好的一面——比如人们愿意为正版的音乐付费，只要有人能够提供良好的购买体验与合理的价格。"

### 共性二：在公司内拥有几乎不可挑战的话语权

社会学家马克斯·韦伯把权威来源分为三类：
1. **个人魅力型（克里斯玛型）**
2. **传统型**（建立在习惯和传统上）
3. **法理型**（法律和程序赋予）

这些创造者把三种权威融合到了自己身上：
- 他们具有魅力
- 他们是创始人
- 他们努力通过程序把权力集中在自己手里

**福特和乔布斯都曾被赶出自己创办的公司**。卷土重来后，他们学到了教训。福特在第三次创业后不断把股权集中，乔布斯回苹果后第一件事就是要求董事会辞职。

盛田昭夫：索尼历史的记录者惊叹，"随着公司的发展，权力越来越向创始人手中集中"。

### 共性三：超越利润之上的追求

单纯对钱的渴望无法支撑他们去克服那么多障碍：
- 福特本可以满足于为富人生产豪华轿车
- 盛田昭夫本可以让索尼做代工或低价市场
- 乔布斯本可以放任盗版音乐快速赚钱

### 共性四：为产品可以牺牲一切的组织

福特时期的福特和乔布斯时期的苹果有很多共同之处：
- 像庞大网络，创始人在中心，高度扁平
- 其他一切（包括人的自尊）都要为产品让步
- 盛田时期的索尼虽不同（东方公司），但"大家庭"氛围也让员工做出更多牺牲

## 硬币的两面

| 优点 | 缺点 |
|------|------|
| 对自己信念的坚持 | 无视现实变化（福特对市场变化视而不见） |
| 不容挑战的话语权 | 糟糕决策无人能阻止（索尼收购哥伦比亚电影） |
| 超越利润的追求 | 财务纪律难以坚持 |
| 为产品架设组织 | 只能聚焦极少数目标 |

## 什么是产品的护城河？（巴菲特-芒格理论）

| 护城河类型 | 含义 | 案例 |
|-----------|------|------|
| 供给侧规模优势 | 大规模生产本身带来的成本优势 | 福特T型车、特斯拉 |
| 需求侧规模优势 | 用户增长带来优势（网络效应） | 脸书、微信 |
| 品牌 | 品牌忠诚度（但存在争议） | - |
| 专利 | 技术垄断 | 高通（按售价3-5%收专利费） |
| 牌照 | 监管带来的准入限制 | 金融等重监管领域 |

> "用户其实没有忠诚度。"

**各家公司的护城河**：
- **福特**：供给侧规模优势（但福特本人后期未认识到市场变化）
- **索尼**：试图通过软硬件内容一体化构建护城河（但内部协作失败）
- **苹果**：应用商店生态 + 硬件服务协同 + 隐私承诺

## 对下一个伟大产品的期待

> "我们想要的是会飞的汽车，但得到了的是140个字的推特……这一代最出名的头脑，都浪费在怎么让人去点击更多的广告，怎么让人对毫无营养的应用程序上瘾。" ——彼得·蒂尔

## 对"产品迷思"的最终回答

> "伟大产品不应该建立在对于人性弱点和欲望的利用上。伟大产品被创造出来，是创造者想做出一些卓越之物，想创造出伟大产品，想回馈社会，在历史的长河中再添一笔，想让人类的生活更美好。"

## 金句摘录

> "我们想要的是会飞的汽车，但得到的是140个字的推特。" ——彼得·蒂尔

> "伟大产品不应该建立在对于人性弱点和欲望的利用上。"

> "我们试图用我们有的天分去表达我们深层的感受，去表达我们对前人所有贡献的感激，给历史长河加上一点什么。那就是推动我的力量。" ——乔布斯

## 自检问题

- 这门课介绍的四个案例中，哪一个对你触动最大？为什么？
- 反思你自己的产品——它是在利用人性弱点，还是在"让人类的生活更美好"？
- 你的公司有没有建立自己的护城河？属于哪一类型？
