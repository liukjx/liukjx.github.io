# 第04课："0-1"之后：怎样重新理解战略、组织和产品

## 核心概念

### 0-1之后的残酷现实

> "你创业最激情、最快乐的一段时间基本上就结束了。"

- 0-1阶段：简单规则、精悍团队、热情驱动、虽然辛苦但有新鲜感和兴奋感
- 0-1之后：煎熬、痛苦、反思、蜕变、成长

**雷总的话**："创业是阿猫阿狗才干的事情。"

### 创业考验的不是激情，而是韧性

```
创业考验：
    表层：激情、好奇心
    底层：韧劲、坚持、底层支撑力量
```

## 阶段模型详解

### 创业者大概率会犯的两个错误

#### 错误一：把自己的能力当成成功的最重要要素

**正确认知**：
- 0-1的成功 = 发现需求 + 用好的方式满足需求（为用户创造价值）
- 外部因素的作用可能远超想象
- 时势造英雄，顺势而为
- 核心永远不能忘：**用户价值**

**典型偏差**：
```
以为核心能力=美学/设计
    ↓
将能力放在其他领域
    ↓
用户不认可/边际效应差
    ↓
挫败感
```

#### 错误二：被资本绑架——以估值为导向

**错误逻辑**：
```
投资人要求算清估值账
    ↓
创业者渴望高估值
    ↓
从估值反向倒算盈利模型
    ↓
动作变形、边际效应递减
    ↓
最终商业崩塌
```

**类比**：一家餐馆单店盈利模型好 → 资本要求估值增长100-1000倍 → 倒算100家店模型 → 快速扩张 → 边际效应递减 → 亏损

**IPO陷阱**：以IPO为中局目标 → 战略/营收/组织都围绕IPO反向决策 → 忘记用户价值

### 创业者面临的三大困扰

| 困扰 | 核心问题 | 原因 |
|------|----------|------|
| **困扰一：战略缺失** | 公司没有战略意识 | 0-1成功靠机会驱动，不需要底层战略；战略需要目标+策略+计划+执行，是系统性的 |
| **困扰二：组织缺位** | 不知道什么是真正的管理者 | 创业者不知道什么样的人才支持1-10；从"特种部队/团伙"到"正规军"的转型困难 |
| **困扰三：产品扩张** | 从单品到产品矩阵的扩张 | 创始人精力分散；对业务的判断力只停留在个人层面；不具有可持续性 |

## 操作方法和步骤

### 关于"什么是管理者"——两张关键书单

| 书籍 | 作者 | 核心启发 |
|------|------|----------|
| 《卓有成效的管理者》 | 彼得·德鲁克 | 理清管理的概念和管理者的概念 |
| 《给经理人的第一课》 | 安迪·格鲁夫 | 理解管理者的角色和责任 |

### 组织建设的两个维度

1. **识别管理者**：从实操者（特种部队成员）转向有管理意识和担当意识的人
2. **组织对战略的支撑**：口号喊出来容易，但没有组织支撑=空口号

### 肌肉记忆比喻

**案例**：商学院同学刘烨（运动医学专家）

跑步动作做不出来 → 那块肌肉没有形成肌肉记忆 → 薄弱点不能支撑完整动作

**类比到企业**：
```
我的目标是跑完北京马拉松（2小时40分）
    ↓
需要调整：作息、训练计划、有氧适应性、
         肌肉群、跑步姿势、装备、饮食习惯
    ↓
个人层面：清楚

企业层面：所有的人都困惑、迷惘
        不知道如何"解题"
```

**解题方法**：
```
设定目标
    ↓
分解目标（需要哪些条件）
    ↓
制定策略
    ↓
执行→遇到问题→诊断→重新规划→再行动
    ↓
循环进化
```

## 案例参考

### 智米的"美学执念"反思

```
团队认为：美学/审美 = 核心能力
    ↓
把美学放在其他领域 → 用户不买单
    ↓
反思：美学是产品的加成项
      并不是产品的底层核心价值
    ↓
产品是用来用的
核心 = 功能如何满足用户需求
```

### 创业0-1之后的被动蜕变

**关键认知**：几乎没有创业者能主动完成这个过渡过程
- 都需要经历痛苦、纷争、矛盾
- 跌入谷底 → 反思复盘 → 重整思路 → 走上正确发展道路
- 这是客观必然发生的过程
- 只要调整好心态 → 这是迈向下一个阶段（1-10健康增长）的必经之路

## 金句摘录

> "创业最大的快乐是在0到1那个阶段，之后基本上你就不再会有这种快乐的感受了。"

> "外部因素的作用可能远远超乎你的想象——时势造英雄，顺势而为。"

> "所有的核心点在于需求、用户价值，在于你在对的时间点做了对的事。"

> "酒香不怕巷子深，它本身有一个很好的盈利模型——但用资本估值反向倒算，快速扩张，边际效应会快速递减，直到形成巨大的亏损。"

> "从激情的驱动到使命愿景，其实是你蹲下来，让自己的根基更扎实，再往前继续走的核心点。"

> "从特种部队到正规军，怎么走、怎么调、原来的人是不是能胜任——在这大概率是要打问号的。"

> "如果这个判断力只停留在创始人个人身上，其实风险非常高——即使第二次能做对、第三次能做对，它也没有可持续性。"

## 自检问题

<details>
<summary>点击展开自检问题</summary>

1. **第一个错误**：你是否曾把自己的核心能力放大了，以为它能"放之四海而皆准"？用户真正需要的是什么，和你以为的"优势"是否一致？
2. **资本考量**：你的公司/项目是否存在"以估值为导向"的倾向？你能否把"以终为始"（从用户需求出发）作为衡量标准？
3. **战略意识**：你的公司有战略吗？还是只是在"找机会"？战略需要的目标、策略、计划、执行，你具备哪几项？
4. **组织诊断**：你的团队目前是"特种部队/团伙"还是"正规军"？从0-1到1-10，团队里谁需要升级、谁需要替换？
