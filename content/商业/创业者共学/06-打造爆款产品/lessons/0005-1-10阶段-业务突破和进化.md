# 第05课："1-10"阶段：怎样实现业务的突破和进化

## 核心概念

### 达利欧五步法——企业进化的基本逻辑

```
设定目标 → 行动 → 遇到问题 → 诊断识别 → 重新规划 → 再行动
    ↑                                                  │
    └────────────────── 循环进化 ──────────────────────┘
```

企业 = 生命体 → 遇到问题 → 接受反馈 → 重新调整 → 适应环境 → 进化

## 阶段模型详解

### 从1到10的四大关键步骤

| 步骤 | 动作 | 核心内容 |
|------|------|----------|
| 1 | 回归初心 | 识别使命/愿景/价值观，挖到最底层的原动力 |
| 2 | 制定战略 | 从机会主义到战略规划，从口号到系统 |
| 3 | 产品延展 | 从单一爆品到产品矩阵（纵深/横向） |
| 4 | 组织升级 | 从业务驱动 → 业务架构 + 精细化运营 |

## 操作方法和步骤

### 第一步：回归初心——从激情驱动到使命愿景

**为什么必须回归初心？**

因为后续所有的动作（战略制定、组织调整、业务运营系统建立）都是痛苦的。如果没有最底层原生动力的支撑，很难坚持做下去。

**如何识别底层原动力？**
- 可能是潜意识、童年经历、某件事对心理状态的改变
- 需要深入挖掘内心最底层
- 挖得越深、找得越准，根基越扎实

**苏峻的原动力**：
- 父母都是老师，原有人生规划是在大学完成职业生涯
- 驱动力：对产品的热爱 + 对市场上粗制滥造产品的反感
- "感动人心的家用电器"——产品的底层力量
- 人跟物之间有微妙的连接关系，好产品能触发和影响人

### 第二步：制定战略——从机会主义到战略规划

| 错误认知 | 正确理解 |
|----------|----------|
| "我要三年达到100亿营收"（口号） | 目标+策略+资源支撑+执行（系统规划） |
| 靠个人洞察直指核心 | 共识共创、持续迭代 |
| 战略制定了就不能改变 | 需要管理团队共同拼图、持续迭代 |

**阿里巴巴的启示**（曾铭教授）：
- 战略不是CEO个人制定的
- 首席战略官 = 战略运营官（组织大家一起共识和共创战略）
- 创始人可以依托团队，获得资源支持和心理支撑

### 第三步：产品延展——从单一爆品到产品矩阵

#### 延展逻辑一：纵深发展（垂直迭代）

**适用条件**：行业没有完全穿透，还存在机会

**做法**：持续迭代，在每个阶段领先对手一步

**案例**：iPhone从第一代 → iPhone4 → iPhone6 → iPhoneX
- 持续的纵深发展
- 每一步都与对手产生差异化
- 消费者持续认同品牌

#### 延展逻辑二：横向延展（基于场景）

**适用条件**：品类技术迭代天花板不高

**做法**：按照生活场景扩展，形成有特点的产品矩阵

**案例**：
- 小米生态链IoT品类扩展 = 基于场景的延展
- 智米科技：环境电器矩阵
  - 核心定位：提供24小时无感的舒适健康智能生活空间
  - 产品之间相互连带，产生系统性购买决策

```
纵深发展（垂直）             横向延展（场景）
      │                          │
 一个品类持续迭代          基于生活场景扩展
 如：iPhone 1→4→6→X      如：智米环境电器矩阵
```

### 第四步：组织升级——从业务驱动到架构驱动

**组织进化的三个阶段**：

```
0-1阶段：不需要HR部门，不需要组织发展部门
    ↓   （业务驱动+产品上升=最大激励）
1-10阶段：需要业务架构+精细化运营驱动
    ↓   （不建立体系=每天解决琐碎问题）
成熟阶段：产品能力沉淀在组织上
    （组织 > 产品）
```

**核心认知转变**：

> "产品重要还是组织重要？"
> 最初答案（产品主义者）：产品重要
> 深刻理解后：**组织重要**
> 原因：产品是组织打造的，产品能力必须沉淀在组织之上

## 案例参考

### 产品矩阵逻辑对比

| 逻辑 | 特点 | 适用场景 | 案例 |
|------|------|----------|------|
| 纵深发展 | 一个品类做深做透 | 技术天花板高、迭代空间大 | iPhone |
| 横向延展 | 场景化扩展 | 技术天花板低、场景关联性强 | 智米环境电器 |

### 智米的产品矩阵示例

```
智米科技
    ├── 空气净化器（核心爆品）
    ├── 加湿器
    ├── 电暖器
    ├── 风扇
    └── 空调
        定位：24小时无感的舒适健康智能生活空间
```

## 金句摘录

> "企业像生命体一样——遇到问题，接受反馈，重新调整自己，重新适应环境，形成进化。"

> "人最大的快乐就是人的价值的最大化。"

> "从激情的驱动到使命愿景，其实是你蹲下来，让自己的根基更扎实。"

> "口号不叫战略。战略要涉及达成目标需要用什么样的策略、什么样的资源支撑、什么样的执行跟行动。"

> "战略实际上是一个共识和共创的过程，是一个持续迭代的过程。"

> "如果你想要持续发展，做一家持续为用户提供价值的企业——你的产品能力不能简单地沉淀在个人身上，必须转换成组织的能力。"

> "肯定是组织重要——产品是组织打造的，产品的能力必须沉淀在组织之上。"

## 自检问题

<details>
<summary>点击展开自检问题</summary>

1. **使命追问**：你创业最底层的原动力是什么？当你遇到巨大困难时，什么力量能支撑你坚持下去？
2. **战略诊断**：你的"战略"是口号还是系统？目标、策略、资源、执行四个要素，你缺哪个？
3. **产品矩阵评估**：你的产品线是"纵深"还是"横向"逻辑？还是打一枪换一个地方？产品之间是否有协同效应？
4. **组织阶段判断**：你的组织处于哪个阶段（特种部队/团伙/正规军）？是否需要引入管理者？产品能力是否已沉淀在组织上？
