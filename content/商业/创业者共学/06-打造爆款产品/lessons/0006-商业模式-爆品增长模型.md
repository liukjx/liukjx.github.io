# 第06课：商业模式——怎样掌握两种爆品增长模型

## 核心概念

### 爆品 = 商业模式（非简单产品）

爆品不是一个简单的产品，而是一个**商业模式的代称**：

> 通过有爆发式成长性的产品，极大地提升企业效率，让企业获得结构性的优势。

### 智米的企业价值观

| 价值观 | 含义 |
|--------|------|
| **极致** | 用做感动人心的产品的心态，不断追求更好的东西 |
| **创新** | 无创新不产品——不简单的重复做和别人一样的东西去内卷 |

## 阶段模型详解

### 爆品的四个关键词（雷军《小米创业思考》）

| 关键词 | 解释 | 案例说明 |
|--------|------|----------|
| **单款** | 产品越精简越好，最好是一款标准品 | iPhone全球一个SKU，包装盒只改不干胶标贴 |
| **精品** | 品质好，口碑好 | 产品不好无法形成爆款 |
| **海量** | 单款最大规模复制 | 双11小米空气净化器2一个单品卖40万台 |
| **长周期** | 产品生命周期长 | 产品卖3年/5年/10年，像印刷品一样持续复制 |

**长周期的两种形态**：

```
形态一：经典不迭代
  └── 产品达成经典状态，长时间不迭代
  └── 例：福特的T型车（只有黑色）
  └── 规模效应随时间持续放大

形态二：小改款迭代
  └── 基于经典结构做局部改进
  └── 核心供应链结构不变
  └── 底层效率依然最大化
```

### 两种爆品增长模型

#### 模型一：规模效应型爆品

| 特征 | 说明 |
|------|------|
| 产生前提 | 产品的基本功能/标准品在社会上供给不充足 |
| 核心策略 | 以价格为第一性原理，极致控制价格 |
| 竞争壁垒 | 规模优势→成本优势→全方位壁垒 |
| 典型案例 | 福特T型车、小米空气净化器 |

**空气净化器的规模效应路径**：
```
钢需没被满足
    ↓
精简到最刚需状态
    ↓
最大化工业生产规模
    ↓
定价699元
    ↓
风暴式席卷刚需市场
    ↓
市场占有率第一 + 规模化第一
    ↓
对手难以在成本端竞争
```

#### 模型二：差异化创新型爆品

| 特征 | 说明 |
|------|------|
| 产生前提 | 基本需求已被满足，用户产生差异化需求 |
| 核心策略 | 发现规模产品忽视的用户需求，反其道而行 |
| 竞争壁垒 | 创新力+稀缺性 |
| 典型案例 | 通用汽车（凯迪拉克/别克）、智米电风扇/加湿器 |

### 规模效应 vs 差异化创新

```
规模效应               差异化创新
    │                     │
 价格第一性           用户需求第一性
    │                     │
 基本需求未饱和       基本需求已饱和
    │                     │
 成本优势为壁垒       创新力为壁垒
    │                     │
 历史性机遇           常态化机会
    │                     │
 例：T型车/净化器     例：通用/智米风扇
```

## 操作方法和步骤

### 如何识别两种爆品机会

**规模效应机会识别**：
- 产品的基本功能是否在市场上供给不足？
- 用户是否对价格高度敏感？
- 能否通过极致精简和规模效应大幅降低成本？

**差异化创新机会识别**：
- 规模产品忽视了什么用户需求？
- 用户在使用现有产品时有哪些"槽点"？
- 能否通过技术创新创造新使用场景？

### 差异化创新的具体方法

以用户"槽点"为创新原点：

| 产品 | 原有痛点 | 创新方案 |
|------|----------|----------|
| 电风扇 | 与空调配合不舒适 | 直流无刷电机+变频技术+智能控制+更柔和的风感 |
| 电风扇 | 场景受限 | 内置动力电池（充一次电运行16小时+），室内外通用 |
| 加湿器 | 注水困难（搬水箱） | 磁控法+水位传感器+霍尔开关，直接添水 |
| 加湿器 | 发臭/霉菌 | UV紫外线杀菌，保持无菌环境 |

## 案例参考

### 福特T型车 vs 通用汽车

| 维度 | 福特T型车（规模效应） | 通用汽车（差异化创新） |
|------|----------------------|----------------------|
| 策略 | 只有黑色，极致降本 | 凯迪拉克/别克等差异化品牌 |
| 用户需求 | 基本出行需求 | 更好的音响/更拉风的造型/更强劲的马力/家庭场景 |
| 竞争方式 | 价格第一性 | 体验第一性 |

### 智米电风扇的创新突破

**市场背景**：中国电风扇年销量5000-6000万台，全球2-3亿台，价格在百元左右

**发现机会**：
- 日本（空调大国）电风扇均价远高于中国
- 日本电风扇以"配合空调"为卖点（形成舒适微气流）
- 中国用户需要：更舒适、更节能、多场景

### 苹果iPhone的独特路径

苹果手机：

```
完全可以低价占领市场（以移动互联网工具建立垄断）
    ↓
但对创新能力有信心
    ↓
不向下卷价格
    ↓
靠产品创新+生态系统搭建能力
    ↓
建立超大规模（另一种方式）
```

## 金句摘录

> "爆品是一个商业模式的代称。它指的是通过有爆发式成长性的产品，极大地提升企业效率，让企业获得结构性的优势。"

> "单款、精品、海量、长周期——这是目前为止对爆款产品最精准的定义。"

> "商业成功并不只有唯一的路径——这就是商业生态的多样性。"

> "爆品不仅局限于所谓价格上——爱马仕的凯利包也是爆品。"

> "规模效应的机会不常有。但差异化创新同样可以出现爆品。"

> "只要你真正地留意、关心用户，真正地去体验、去挖掘，你发现你完全能找到新的成长点。"
