# 第07课：产品设计——怎样为产品构建爆品要素

## 核心概念

### 爆品的三大要素

```
爆品三要素
    ├── 通用（General Design）——降低用户使用难度
    ├── 极简——聚焦原点 + 效率最大化 + 用户体验提升
    └── 超预期——让用户愿意主动分享传播
```

## 阶段模型详解

### 要素一：通用（General Design）

**来源**：美国北卡罗莱纳大学的产品研究项目

**原始定义**：为残障/特殊人群做设计——让产品对所有人友好

**核心洞察**：为特殊人群设计的产品，普通人用起来**更好用**

**经典案例：按键开关的演变**

```
小按键开关（力矩大、手指不便的人按不动）
    ↓
大按键开关（专为残障人士设计）
    ↓
大按键开关迅速取代小按键开关（普通人用起来更好用）
```

**经典案例：iPad**
- 一两岁小孩也能用得非常好
- 一键回Home的能力——不知道怎么操作时按一下就能回来
- 最简化产品使用逻辑的设计

**智米的应用**：
- 产品无需说明书（买回来打开即可用）
- 只有一个按键开关（不需要任何指引，用户就知道怎么操作）
- 设计理念：用户着急地打开包装箱、迫切希望产品马上发挥作用——这时候让他看说明书，他会痛苦和愤怒

### 要素二：极简

**极简的核心价值（三层递进）**：

```
1. 战略层：使企业原点聚焦
2. 资源层：使所有资源投入效率最大化
3. 体验层：极大地提升用户体验
```

**空气净化器案例**：
- 此前：一大片按键、一大片中英文说明、一大堆功能
- 智米：三个指示灯 + 一个按键
- 用户面对产品不会产生"不知所措的茫然感"

### 要素三：超预期

**核心在"超"**：
- 性价比不好 → 抱怨（负效率）
- 性价比还好 → 接受（中性）
- 性价比**超好** → 主动分享传播（裂变）

**为什么超预期能带来主动传播？**

> 每个人都愿意把自己获得的好的东西、有优势的东西，主动向外扩散。

**类比**：朋友圈转发 = 都是自己认为好的、超出预期的东西

**空气净化器的超预期点**：
- 699元 vs 别人3000-4000元
- 开箱体验：精致触感、无说明书即时可用
- 实际性能：快速降低PM2.5
- 用户反应：再买几台→给父母买→发朋友圈→裂变传播

## 操作方法和步骤

### 如何构建"通用"设计

1. **换位思考到极限状态**：设想用户在最急迫、最不方便的情况下使用产品
2. **面向所有人群**：不仅是正常成年人，还包括老人、小孩、残障人士
3. **简化交互路径**：减少用户的操作步骤和学习成本
4. **全链条考量**：从开箱到使用全过程，不让用户有"卡住"的时刻

### 如何做到"极简"

1. **控制贪念**：只聚焦核心功能，砍掉非核心功能
2. **从原点简化**：产品定义端就做减法，后面所有环节自然跟随
3. **用户视角**：不是"我能做什么"，而是"用户需要什么"
4. **持续追问**：每多一个功能，就问"用户真的需要这个吗？"

### 如何创造"超预期"

1. **性价比锚点**：设定一个参照系（竞争对手的价格/体验）
2. **关键触点的惊喜**：开箱、第一眼、第一次使用、第一次见效
3. **超越心理预期**：价格比预想的低/品质比预想的高/体验比预想的简单
4. **创造"可传播的点"**：用户愿意发朋友圈的"亮点"是什么？

## 案例参考

### 通用设计：从特殊到普遍的扩散

```
设计出发点         使用效果           商业结果
    │                 │                 │
为残障人士           普通人更好用       取代旧设计
（大按键开关）       （更省力）          （小按键消失）
    │                 │                 │
一键回Home          老人/小孩都好用     人人都觉得好用
（iPad）             （降低认知门槛）    （行业标准）
```

### 智米产品的通用设计表现

| 触点 | 传统产品 | 智米产品 |
|------|----------|----------|
| 开箱 | 需要看说明书 | 无说明书，即时可用 |
| 操作 | 多个按键/多种模式 | 一个按键/三个指示灯 |
| 反馈 | 不明显 | 实时显示PM2.5数值变化 |
| 使用 | 复杂设置 | 开机即用 |

## 金句摘录

> "通用设计实际上是降低用户的使用难度的设计——它在一个极限值的条件下考虑用户的使用，进而对于普通人来说更好用。"

> "对残障人士友好的产品，普通人用起来更好用。"

> "大家希望到手即可用。"

> "当有一个按键的时候，不需要任何的指引，用户就知道怎么去做。"

> "极简的产品能极大的提升用户体验。"

> "只有性价比超好，用户才愿意主动地去分享和传播。"

> "每个人都愿意把自己获得的好的东西、有优势的东西，主动地向外扩散。"

## 自检问题

<details>
<summary>点击展开自检问题</summary>

1. **通用设计自检**：你的产品是否考虑到了最极端的使用场景？老人、小孩、残障人士能用吗？用户打开包装后需要看说明书吗？
2. **极简评估**：你的产品功能能否砍掉一半？如果能，哪一半是用户最不关心的？
3. **超预期诊断**：用户拿到你的产品后，有没有一个"wow时刻"？这个时刻能让他主动发朋友圈吗？
4. **传播点设计**：你的产品是否有明确的"可传播点"？用一句话说清楚：用户为什么会推荐你的产品给朋友？
