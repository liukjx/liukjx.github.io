# 第08课：系统训练——怎样训练打造爆品的能力

## 核心概念

### 做爆品需要的基本素养（非技能）

| 素养 | 具体体现 |
|------|----------|
| **人-物关系** | 对人造物有天然的偏爱和兴趣，在人-物交流中能感受到快乐 |
| **生活热爱** | 能发现生活中有趣的东西，主动理解用户，产生同理心 |

**关键认知**：
- 素养 ≠ 技能（美术基础/绘画能力/CAD操作都不是最关键要素）
- 兴趣驱动才能克服枯燥、繁琐和各种困难
- 做产品时经常处在嘈杂环境中（模型制作、样机制作、工厂试制），但如果热爱产品本身，会自然忽略环境不适

## 阶段模型详解

### 三层训练法

```
    表层：天赋/能力圈识别
        ↓
    中间层：刻意训练
        ├── 观察（发现爆品、理解爆品）
        └── 换位思考/同理心
        ↓
    底层：哲学/基础学科积累
```

### 三层训练法详解

#### 表层——天赋与能力圈

**核心认知**：
1. 每个人都有对特定物品的特殊兴趣——需要识别、发现、训练、强化
2. 天赋 ≠ 专长：不做后天训练不会成为专长（如运动员需要科学系统训练）
3. 如果兴趣点+能力圈与产品事业吻合——成功的概率高
4. 如果兴趣点+能力圈与社会发展趋势一致——可能创造很大的社会价值

**能力圈与社会趋势的匹配**：

```
过去（基本需求未满足时）
    └── 规模化和基本需求优先
    └── 审美/设计素养不能发挥最大效用

今天（中国）
    └── 基本需求已满足
    └── 精致/审美/设计素养发挥效用的最佳时机
```

#### 中间层——刻意训练

**训练方向一：观察生活，发现爆品**

| 场景 | 看什么 | 思考什么 |
|------|--------|----------|
| 宜家（国民品牌） | 销量最大、最持久的产品（如比利书架，畅销40年，每4-5分钟卖一个） | 产品如何呈现？生产组织方式？供应链体系？ |
| 爱马仕（奢侈品） | 生命力持久的细节（线脚、金属工艺） | 经典是如何形成的？长周期销售的逻辑？ |
| 历史产品 | 索尼Walkman（几千万级大爆款） | 创始人在飞机上听音乐的需求→收录机+耳机→代替"随身听"名词 |

**训练方向二：换位思考（瞬间变小白）**

**方法**：
1. 快速抹掉自己对产品的前期理解
2. 快速降低感知力到用户层面
3. 设想自己是老人、婴儿、心烦意乱急需产品的购买者
4. 反复训练，形成能力

**关键认知**：
- 产品原点最好来源于自身生活——对生活最熟悉、看得最透
- 自身生活中的迫切需求 = 最好的产品出发点

#### 底层——哲学与基础学科积累

**哲学的价值**："无用之用，方为大用"

| 学科 | 对产品的指导 |
|------|-------------|
| 哲学 | 寻找第一性原理，理解底层规律 |
| 美学 | 理解极简的方向和程度 |
| 系统学 | 理解产品的系统化生成 |
| 混沌学 | 理解非线性的涌现和变化 |

**乔布斯的启示**：
- 乔布斯与Jonathan（设计VP）讨论问题
- 从产品入手 → 最终讨论到哲学问题
- 真正做得好产品的，从第一性原理、从哲学原点出发

## 操作方法和步骤

### 如何识别自己的天赋和能力圈

1. **自我观察**：你对什么类型的物品最有兴趣？什么物品让你愿意花时间研究？
2. **交叉验证**：你的兴趣点 + 能力点 + 要做的事业是否吻合？
3. **顺势而为**：这个吻合点是否与社会发展趋势一致？
4. **持续强化**：不做后天训练，天赋不会变成专长

### 刻意训练实操

**观察训练步骤**：
1. 选定一个消费场景（线上/线下）
2. 找出该场景中销量最大、销售最持久的产品
3. 思考：它为什么会爆？它的原点是什么？供应链如何组织？
4. 记录发现，形成自己的"爆品案例库"

**换位训练步骤**：
1. 拿出自己的产品（或竞品）
2. 强迫自己在5秒内变成"小白用户"
3. 完全不看说明书，尝试完成核心任务
4. 记录所有"卡住"的点
5. 循环3-5次，直到能快速切换视角

### 哲学积累路径

- 从产品实践出发，回溯到哲学层面思考
- 追问每一个设计决策背后的"第一性原理"
- 阅读哲学、美学、系统学基础著作
- 形成"从产品到哲学再回到产品"的思考闭环

## 案例参考

### 索尼Walkman的故事

```
创始人在飞机上听音乐的需求
    ↓
将收录机与耳机结合
    ↓
全球销量几千万级的大爆款
    ↓
"Walkman"一词代替"随身听"这一功能化名词
```

### 设计师创业的天然优势（苏峻自述）

| 维度 | 说明 |
|------|------|
| 学科架构 | 科学+工程+艺术的交叉 |
| 知识体系 | 综合性知识积累 |
| 核心优势 | 更懂人性、更懂人 |
| 角色定位 | 人与产品之间的连接点 |

**注意**：设计背景是**必要条件**，不是**充分条件**

## 自检问题

<details>
<summary>点击展开自检问题</summary>

1. **天赋识别**：你对什么类型的物品最有"天然的偏爱"？电子/服装/家居/美妆/汽车？你的能力圈和兴趣点是否吻合？
2. **观察练习**：最近一次去商场或逛网店，你有没有思考过"为什么这个产品卖得最好"？试着找出一款你身边的"爆品"，分析它的爆品逻辑。
3. **小白测试**：拿你的产品给一个完全不了解的人试用，观察他/她会在哪里卡住。你能不能做到"瞬间变小白"？
4. **哲学自问**：你产品的"第一性原理"是什么？能否用一句最简洁的话描述你产品存在的根本原因？
5. **素养评估**：你是因为热爱产品本身才做产品，还是因为它"看起来是个好生意"？两者之间有什么区别？
