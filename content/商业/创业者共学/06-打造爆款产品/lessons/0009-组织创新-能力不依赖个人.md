# 第09课：组织创新——怎样让做爆品的能力不依赖个人

## 核心概念

### 让创新能力沉淀在组织上

> 产品创新型组织的目标：让公司的创新力不再是创始人个人的事情，变成团队的系统能力、有传承、有梯队，真正沉淀在组织系统上。

**智米的定位**：在小米生态链中以产品能力为特点

## 阶段模型详解

### 产品创新组织建设的五大环节

```
1. 人才识别（眼里有光/心里有爱）
    ↓
2. 组织方式（In-house团队，长期专注）
    ↓
3. 创造空间（自由度 + 明确方向指引）
    ↓
4. 正反馈进化（小成功→正向反馈→强化→更大成功）
    ↓
5. 能力沉淀（从个人→组织系统）
```

## 操作方法和步骤

### 第一步：人才识别——"眼里有光，心里有爱"

**判断标准**：当和你聊产品的时候，你看他的眼神里有没有光彩

**为什么重要**：
- 做产品是"苦逼"的事情——需要耐得住寂寞、耗得起时间
- 没有兴趣和热爱的支撑，很难坚持下去
- 产品能力需要持续迭代——没有真正的乐趣，能力提升有限

**案例：索尼的内部人才招聘制度**

| 制度特点 | 说明 |
|----------|------|
| 岗位不固定 | 进入公司后，岗位角色不固定 |
| 主动应聘 | 员工对某产品线感兴趣可主动去应聘 |
| 跨行业/跨专业 | 可跨行业、跨专业进入产品部门 |
| 创始理念 | "让索尼成为工程师的乐园"——工作=游戏=乐趣 |

**索尼的人才识别案例：大贺典雄**
- 第二任领导人，毕业于东京音乐学院，真正的指挥家、音乐家
- 两位创始人发现他对硬件有浓厚兴趣和独特理解
- 最终成为接班人，做出了CD等改变音乐行业的产品

### 第二步：组织方式——In-house团队（长期专注）

**In-house vs 外包**：

| 对比项 | In-house团队 | 外包服务 |
|--------|-------------|----------|
| 专注度 | 长期聚焦一个领域 | 项目制，跨度大 |
| 专家培养 | 可培养专家型人才 | 难形成深度积累 |
| 产品一致性 | 从内到外系统化 | 风格和品质可能不统一 |
| 案例 | 苹果In-house设计团队 | 苹果早期与Frog/IDEO合作 |

**关键认知**：
- 专家 = 在特定领域长期聚焦积累
- 产品不仅是外观设计，要与技术、内核结合
- 必须对行业有足够深的沉淀和理解，才能打造出超预期产品

### 第三步：创造空间与方向指引的平衡

**核心矛盾**：

```
系统驱动（效率）     vs     产品创新（灰度/自由度）
    │                            │
  数字化管理               需要自由空间
  高咬合节奏               需要静默期
  输入输出量化           可能爆发式涌现
```

**解决方案**：
- 自由度 ≠ 天马行空（企业有自己的战略和商业目标）
- 必须有**明确的方向指引**（由创始人/管理者提供）
- 如果没有方向指引 → 各自做各自工作 → 无合力 → 效率损耗

**案例：索尼Walkman小型化**
- 方向指引："便携式音乐播放器，轻量化和小型化就是用户价值的体现"
- 自由发挥：具体如何小型化 → 设计师自由发挥 → 综合解决方案
- 经典细节：研发负责人把产品扔入水中测试——"还有没有气泡冒出来？还有就还有小型化空间"

**案例：苹果iMac的进化**

```
从第一代iMac → 到今天
    ↓
方向非常清楚：桌面算力工具
    ↓
最好的方式：一块悬浮在桌面的屏幕
    ↓
其他部分：越小越好、越少越好
    ↓
最终达到：类艺术品一般，优雅且强大的算力工具
```

**案例：苹果MacBook的进化**
- 方向指引：移动算力工具，减少束缚
- 路径：多接口 → 极少接口 → 单一接口 → 可能无接口
- 朝向：无线化、全无线化、尽量轻薄化

### 第四步：正反馈进化

#### 正反馈逻辑（生物学比喻）

```
简单需求 + 基本供给 = 生存（原地闭环）
    ↓
当变化涌现 + 环境正向反馈 = 变化被强化
    ↓
持续向前和向上的进化逻辑
```

#### 正反馈 vs 负反馈

| 状态 | 正向团队 | 负向团队 |
|------|----------|----------|
| 方向 | 管理者给出明确方向并共识 | 管理者不清楚，让团队出30个方案 |
| 行动 | 聚焦做正确的事 | 漫无目的尝试 |
| 第一版方案 | 可能直接找到最终原型 | 需要从大量方案中不确定地选择 |
| 市场反馈 | 正反馈→团队信心和激励 | 负反馈（销量不佳/评价不好） |
| 下一轮 | 更加聚焦、力出一孔 | 更加迷失，下次出60个方案 |

**极致案例：苹果工业设计团队**
- 仅用20多名工业设计师
- 在In-house团队工作20-25年
- 有带头人的明确方向指引
- 持续呈现令人赏心悦目的产品

| 特点 | 细节 |
|------|------|

| 工作年限 | 20-25年 |

## 金句摘录

> "当你跟他聊产品的时候，你看他的眼神里有没有光彩——眼里有光，实际上就是心里有爱。"

> "让索尼成为工程师的乐园——工作就是游戏，游戏就是乐趣。"

> "专家一定不是在各个领域中今天做一下、明天做一下成长出来的——他一定需要在某一个领域长期聚焦的积累。"

> "系统驱动跟创新本身是有着天然矛盾的。产品创新本身就是需要灰度、需要自由度的。"

> "自由度的创造过程并不是天马行空——企业有自己的战略和商业目标。"

> "真正的好团队是越战越勇的团队，真正的好团队是越做越强的团队。"

> "如果管理者也不清楚方向，让团队出30个方案——大概率市场会给一个负反馈，团队会越来越迷失。"

## 自检问题

<details>
<summary>点击展开自检问题</summary>

1. **人才识别**：你的团队成员在聊产品时，眼里有光吗？你能否分辨"真正热爱"和"只是会做"的人？
2. **组织方式**：你们的产品/设计团队是In-house还是外包/兼职？成员是否长期专注在同一个领域？
3. **方向 vs 自由**：你的团队是有明确的方向指引，还是"先出30个方案看看"？团队成员是否清楚产品最终要达成什么？
4. **正反馈循环**：你的团队最近一次获得市场正向反馈是什么时候？这个反馈是否被用来强化团队的信心和方向？
