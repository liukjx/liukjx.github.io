# 夏日冰粉

## 学习目标
- 了解手工冰粉的核心设备和材料
- 掌握标准配比和前期准备
- 学会手工搓冰粉技法
- 掌握石灰水点冰粉成型技术
- 了解火龙果冰粉和红糖冰粉做法

## 核心设备与材料

| 材料 | 用途 |
|------|------|
| 冰粉籽 | 浆液来源 |
| 食品级熟石灰 | 凝固剂 |
| 细孔布袋 | 装籽搓粉 |
| 圆形容器 | 搓粉用 |
| 大量杯 | 量取3000ml白开水 |
| 小量杯 | 称量冰粉籽和石灰 |

## 前期准备与标准配比

> [!WARNING] 关键配比
> **标准比例**：100g 冰粉籽 + 10g 食品级熟石灰 + 500ml 自来水（兑石灰水）

**准备步骤**：

1. 熟石灰加500ml自来水——**会放热，勿用手搅拌**
2. 静置10分钟
3. 冰粉籽装袋后清水冲洗1分钟
4. 扎紧袋口
5. 在3000ml白开水中**浸泡5分钟**再搓（更易出浆）

## 手工搓冰粉技法

```mermaid
flowchart LR
    A[浸泡5分钟] --> B[双手挤压揉搓<br/>冰粉籽出浆]
    B --> C[溶液渐浑浊]
    C --> D[大量白色气泡出现]
    D --> E[用力挤压只能挤出泡沫<br/>→ 停止]
```

> [!TIP] 判断标准
> 当用力挤压也只能挤出泡沫状浆液时，说明冰粉籽几乎完全出浆，可以停止了。此演示为**有气泡冰粉**做法。

## 石灰水点冰粉成型

这是最关键的一步，也是新手最容易失败的地方：

1. 静置后的石灰水——**只取上层澄清部分**（浑浊和沉淀不用）
2. 澄清石灰水缓慢倒入冰粉浆液
3. **朝一个方向**不断搅拌
4. 少量多次加入
5. 搅拌中手感受到**明显阻力**时立即停止
6. 常温静置30分钟，或冰箱冷藏5分钟

> [!DANGER] 失败预防
> - 必须使用**食品级**熟石灰
> - 石灰水溶解放热——勿用手搅拌
> - 石灰水只取上层澄清液
> - 少量多次点入，有阻力即停
> - 严格按配比降低失败率

## 彩色火龙果冰粉做法

1. 浸泡过的冰粉籽袋中加入**红心火龙果**
2. 扎紧袋口压碎
3. 搓粉时果肉和冰粉浆一起挤出（溶液变粉红）
4. 后续石灰水点粉流程相同
5. 冰箱冷藏10分钟即可凝固

## 红糖冰粉装配流程

```mermaid
flowchart LR
    A[碗底铺碎冰] --> B[盛入适量冰粉]
    B --> C[加花生碎+脆枣片<br/>+山楂碎+葡萄干+桂花酱]
    C --> D[沿碗周围倒入红糖浆]
```

> [!NOTE] 装配要点
> - 冰粉用量不宜过多，适量即可
> - 红糖均匀浇在碗周围——方便顾客搅拌
> - 配料按喜好添加

## 技术总结

| 关键步骤 | 要点 |
|---------|------|
| 配比 | 100g籽 + 10g石灰 + 3000ml水 + 500ml兑石灰水 |
| 搓前浸泡 | 5分钟，更易出浆 |
| 停搓标准 | 出现大量白泡、只能挤出泡沫 |
| 石灰水 | 只取上层澄清，少量多次点入 |
| 阻力判断 | 有明显阻力立即停止 |
| 凝固时间 | 常温30分钟 / 冷藏5分钟 |

## 自测

> [!QUESTION] 自测题
> 石灰水点冰粉时，手感受到明显阻力说明什么？应该怎么做？

<details>
<summary>参考答案</summary>

说明石灰水中的钙离子已经和冰粉浆液中的果胶充分结合，冰粉即将凝固。应该**立即停止加入石灰水**，否则会变苦或过硬。然后静置等待凝固即可。
</details>
