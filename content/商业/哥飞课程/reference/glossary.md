# 出海AI工具站术语表

## 网站类型

| 术语 | 英文 | 说明 |
|---|---|---|
| 独立站 | DTC Site | 独立于平台（如亚马逊）的电商站，通常用 Shopify |
| 内容站 | Content Site | 通过博客/评测文章获取流量，靠广告或联盟佣金变现 |
| 工具站 | Tool Site | 提供在线功能服务（压缩、转换、生成等），靠付费或广告变现 |
| AI工具站 | AI Tool Site | 基于AI模型的工具站，利用API或自部署模型提供服务 |
| 导航站 | Directory Site | 收录和推荐其他产品的列表站，借别人产品获取流量 |

## SEO 相关

| 术语 | 英文 | 说明 |
|---|---|---|
| GSC | Google Search Console | 谷歌站长后台，提交网站、查看搜索数据 |
| 内链 | Internal Link | 自己网站页面之间的链接，用于传递权重 |
| 外链 | Backlink | 其他网站指向你网站的链接，提升网站权重 |
| 锚文本 | Anchor Text | 链接上显示的文字，告诉谷歌页面主题 |
| nofollow | nofollow | 链接属性，告诉谷歌不要传递权重（但现在谷歌不完全遵守） |
| dofollow | dofollow | 链接属性，允许多少传递权重 |
| 权重 | Authority/Domain Authority | 搜索引擎对网站的信任度和排名能力 |
| 收录 | Indexing | 网站页面被谷歌加入搜索索引 |
| 排名 | Ranking | 搜索关键词时的展示位置 |
| 网页供应量 | Webpage Supply | 搜索某个词时出现的网页数量，越少越容易竞争 |
| On-Page SEO | 站内优化 | 页面内容、结构、关键词布局等内部优化 |
| Off-Page SEO | 站外优化 | 外链建设、社交媒体推广等站外工作 |

## 六字真言

> **分门别类罗列**

哥飞最核心的SEO心法，每次做页面都要记住：
- 首页列出二级分类
- 二级页面列出三级分类
- 每级做一段介绍
- 用内链串联起来
