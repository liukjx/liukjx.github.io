# 第04课：产品倒做深度拆解：思考 × 开发 × 交易

> "我进入任何一个新的行业，都不是技术出身，不是因为拥有某一项核心技术才去创业。我们大量选择是跨界过来，首先是看到了需求，然后才去做产品。"
> —— 杜国楹

## 一、为什么"倒做"？

大多数产品经理的思维是正向的：**"我有什么技术/资源 → 我能做什么产品 → 卖给谁"**

杜国楹的方法正好反过来：**"谁在哪里有什么需求没被满足 → 需要什么产品 → 我们需要具备什么能力"**

> [!ABSTRACT] 产品倒做 = 强用户思维 × 强需求思维
> 不是"我有什么所以给你什么"，而是"你要什么所以我去做什么"。

## 二、三条逻辑全拆解

### 逻辑一：思考的逻辑（原点问题）

> "谁，在哪里，有什么需求没被满足——这是你创业的原点。"

| 步骤 | 问题 | 小罐茶案例 |
|------|------|-----------|
| 1. 人群+场景 | 谁？在哪里？ | 商务人士，在社交/送礼场景 |
| 2. 核心需求 | 什么需求没被满足？ | 送茶不知道价格，买茶怕踩坑 |
| 3. 需求性质 | 偏物质还是偏情感？ | 偏情感（社交货币+体面送礼） |
| 4. 自身能力 | 为什么是我们？ | 多年消费品经验、品牌能力 |

### 逻辑二：开发的逻辑（从需求到壁垒）

> "基于对用户的洞察、需求的洞察，进入设计、进入开发、进入供应链，最后沉淀下来成为核心能力、核心技术、核心壁垒。"

**开发路径**：核心需求点 → 产品设计 → 技术/供应链 → 核心壁垒

杜国楹的关键动作分解：
1. **识别核心需求点**（只抓一个最重要的，不是所有需求）
2. **围绕核心需求做设计**
3. **通过供应链/技术实现**
4. **沉淀为护城河**（别人抄不走的能力）

**小罐茶的开发链条**：
- 核心需求点 → 标准化（统一价格、统一品质）
- 设计 → 统一小罐、统一重量
- 供应链 → 8+1工厂布局（因为找不到代工，只能自己做工业化）
- 壁垒 → 黄山中央工厂的智能化设备、全产业链能力

> [!TIP] 互联网/软件映射
> **核心需求点**：你的App要解决的那个"最痛的点"是什么？不是功能列表，是**一个**用户非用不可的理由。
>
> **开发路径对比**：
> - 消费品：需求点 → 设计 → 工厂/供应链 → 品牌壁垒
> - 互联网：需求点 → MVP → 技术架构 → 网络效应/数据壁垒
>
> **案例**：Dropbox的核心需求点是"文件在不同电脑间自动同步"，壁垒是"用的人越多越好用"（网络效应）。

### 逻辑三：交易的逻辑（产品到渠道）

> "产品一旦做出来，它适合在哪里卖？过去大家在哪里卖？今天我们希望在哪里卖？"

大多数创业者先做产品再想怎么卖。杜国楹是在**做产品之前**就想好了怎么卖。

| 维度 | 传统茶的做法 | 小罐茶的做法 |
|------|-------------|-------------|
| 渠道选择 | 茶城、街边茶叶店 | 购物中心专卖店 + 线上旗舰店 |
| 原因 | 需要品鉴、讲茶的故事 | 标品，不必试饮 |
| 推广方式 | 口碑+老客 | 品牌广告+购物中心流量+线上种草 |

**关键洞察**：产品形态决定了渠道模式，渠道模式决定了推广方式——这些都是**在设计产品之前就应该想清楚的**。

## 三、产品倒做的完整工作流

```
思考逻辑                         开发逻辑                         交易逻辑
┌──────────────┐               ┌──────────────┐               ┌──────────────┐
│ 谁？         │    →          │ 核心需求点   │    →          │ 在哪卖？     │
│ 在哪里？     │               │ ↓            │               │ ↓            │
│ 什么需求？   │               │ 产品设计     │               │ 怎么卖？     │
│ 为什么是我？ │               │ ↓            │               │ ↓            │
└──────────────┘               │ 供应链/技术  │               │ 怎么推广？   │
                               │ ↓            │               └──────────────┘
                               │ 核心壁垒     │
                               └──────────────┘
```

## 四、创业者最常见的错误

- **技术迷恋**："我有个牛逼的技术，一定能做出好产品" → 倒做的反面
- **功能堆砌**：想满足所有用户的所有需求 → 没有核心需求点
- **产品做完才想怎么卖** → 可能发现渠道根本不匹配
- **忽略自身能力评估**：看到一个好机会但团队做不了

> [!WARNING] 注意
> 产品倒做不是万能公式。如果你是**跨界创业者**（没有深厚技术背景），倒做是你最可靠的路径。

## 五、本课总结

- **核心框架**：产品倒做 = 思考逻辑 × 开发逻辑 × 交易逻辑
- **核心原则**：需求在前，产品在后；用户在前，技术在后
- **核心能力**：找到"一个核心需求点"并围绕它做透的能力
