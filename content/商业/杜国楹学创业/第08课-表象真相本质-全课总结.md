# 第08课：表象·真相·本质

> "我们去看一个咖啡果——它的皮、它的肉、它的核。把它分成三层的话，就像认知一个问题一样：表象、真相、本质。"
> —— 杜国楹

## 一、三层洞察模型

```
                ┌──────────────┐
                │   表象       │
                │  (what)      │
                │  肉眼所见    │
                ├──────────────┤
                │   真相       │
                │  (why)       │
                │  背后的原因  │
                ├──────────────┤
                │   本质       │
                │  (core)      │
                │  底层规律    │
                └──────────────┘
```

- **表象**：事件/现象肉眼可见的样子（"会看的看门道，不会看的看热闹"）
- **真相**：背后的原因、逻辑、驱动因素
- **本质**：最深层的规律、人性底层需求、价值内核

## 二、钻石案例：三层洞察

| 层次 | 钻石 | 解读 |
|------|------|------|
| **表象** | 一块石头 | 碳元素结晶体 |
| **真相** | 钻石=爱情 | "钻石恒久远，一颗永流传" |
| **本质** | 社交货币（唯一性承诺） | DR钻戒"一人一生只能定一枚"——洞察到爱情唯一性的本质需求 |

## 三、茶叶案例：三层洞察

| 层次 | 茶叶（以高端茶为例） |
|------|---------------------|
| **表象** | 一片树叶子 |
| **真相** | 礼品——高端茶的主要流通方式是"送礼"，不是自用 |
| **本质** | 社交货币——需要形成价值共识 |

> "这是我在进入茶行业第一个阶段、前三年都没识别到的真相——高端茶是以礼品的形态在流通。本质上它要成为社交货币。"

这个洞察决定了小罐茶的整套策略：统一价格（形成价值共识）、精美包装（适合送礼）、购物中心店（提升品牌调性）。

## 四、用三层模型分析互联网产品

> [!ABSTRACT] 微信
> - **表象**：一个聊天App
> - **真相**：移动时代的"身份ID" + "社交关系链"
> - **本质**：人的连接需求（随时随地与重要的人保持联系）

> [!ABSTRACT] 小红书
> - **表象**：一个种草/分享平台
> - **真相**："别人的真实生活参考"——决策辅助工具
> - **本质**：人对"更好的生活"的向往 + 从众/参考心理

> [!ABSTRACT] 抖音
> - **表象**：短视频App
> - **真相**：算法驱动的注意力黑洞
> - **本质**：人对"新鲜有趣内容"的无限渴求（多巴胺驱动）

## 五、三层模型在工作中的应用

> "在公司内部，我们拿这个模型诊断一切问题——一次质量事故，表象是某个批次有质量问题，真相可能是制度不完善，本质可能是企业缺少对品质的敬畏之心。"

可以用三层模型分析：
- **用户反馈**：他说"界面不好看"（表象）→ 其实是"找不到想要的功能"（真相）→ 本质是"信息架构不清晰"
- **竞品动作**：竞品降价了（表象）→ 可能在清库存或抢份额（真相）→ 本质是"行业进入价格战阶段"
- **数据变化**：DAU下降了（表象）→ 可能是某渠道量下降（真相）→ 本质可能是"核心价值被稀释"
