# 术语表

## A

| 术语 | 解释 |
|------|------|
| All in | 全力投入，集中所有资源做一件事 |
| MVP | Minimum Viable Product，最小可行产品，快速试错的核心理念 |

## C

| 术语 | 解释 |
|------|------|
| CPS | Cost Per Sale，按销售付费的推广模式 |
| CRM | Customer Relationship Management，客户关系管理系统 |
| 私域流量 | 品牌或个人可直接触达的用户池，如微信好友、社群 |

## F

| 术语 | 解释 |
|------|------|
| FOMO | Fear Of Missing Out，错失恐惧症，担心错过机会的焦虑心态 |
| 复利 | 时间带来的指数级积累效应，利滚利 |

## H

| 术语 | 解释 |
|------|------|
| 港股打新 | 在香港证券市场认购新上市的股票赚取首日溢价 |

## I

| 术语 | 解释 |
|------|------|
| IAA | In-App Advertisement，应用内广告变现 |
| IAP | In-App Purchase，应用内购买变现 |
| IP | Intellectual Property，知识产权，泛指个人品牌或内容品牌 |

## K

| 术语 | 解释 |
|------|------|
| KOL | Key Opinion Leader，关键意见领袖/网红 |

## M

| 术语 | 解释 |
|------|------|
| MCN | Multi-Channel Network，多频道网络，网红经纪机构 |

## R

| 术语 | 解释 |
|------|------|
| ROI | Return On Investment，投资回报率 |
| RCEP | 区域全面经济伙伴关系协定 |

## S

| 术语 | 解释 |
|------|------|
| SOP | Standard Operating Procedure，标准作业流程 |
| SEO | Search Engine Optimization，搜索引擎优化 |

## 其他常用概念

| 术语 | 解释 |
|------|------|
| 信息差 | 你知道而别人不知道的信息，是赚钱的重要来源 |
| 认知变现 | 将个人的认知和判断力转化为实际收益 |
| 降维打击 | 用更高级的思维或技术手段在低维度市场竞争 |
| 杠杆 | 用有限资源撬动更大收益的手段（人力、资金、技术） |
| 破圈 | 突破现有圈层进入更高或不同的社交圈层 |
| 利他思维 | 先帮助他人创造价值，顺带获得回报的思维方式 |
| 长期主义 | 以长期价值为导向的做事方式，不追求短期利益 |
| 冷钱包 | 不连接网络的加密货币存储设备，安全性最高 |
| 守破离 | 学习三阶段：守（模仿）、破（创新）、离（自成一派） |
| 空杯心态 | 放下已有认知，以开放心态学习新事物 |
| 正反馈 | 积极的结果反馈，能激励持续行动的动力 |
| 流量洼地 | 用户量大但竞争少的平台或渠道领域 |
| 龙珠 | 生财有术社区内的最高级别荣誉积分 |
| 大航海 | 生财有术组织的团队实战项目活动 |
