# 第1课：闪卡的起源与 Anki 的价值

## 🎯 本课目标

- 理解闪卡的核心机制——主动回忆

- 明确 Anki 的核心优势与适用场景
- 认识选材的重要性与时间预期
- 完成 Anki 的安装和首次配置

## 一、什么是闪卡？

闪卡（Flash Card）是间隔复习最基础的单元。

| 维度 | 核心 | 例子 |
|------|------|------|
| **形式** | 正面问题 / 背面答案，或文字 / 图片 | 正面写 "apple"，背面写 "苹果" |
| **机制** | 主动回忆（Active Recall） | 看正面 → 合上书 → 强迫自己回忆 → 再看背面验证 |
| **粒度** | 极小，一张卡一个知识点 | 一张卡只问"工作记忆容量为几？"，不混入其他问题 |

> [!NOTE] 关键区分
> **主动回忆 ≠ 被动浏览**。前者是"看问题→想答案→验证"，后者是"看问题→直接看答案"。很多人用了 Anki 却还在被动浏览，效果大打折扣。

### 没有纸质卡也能用出"闪卡效果"

| 工具 | 方法 |
|------|------|
| **大纲笔记**（幕布、Workflowy） | 折叠子节点，看上级回忆下级，一条笔记一个知识点 |
| **思维导图**（XMind、MindNode） | 前面写问题，后一级写答案，折叠后看问题回忆 |
| **书边笔记** | 书右侧记关键词，复习时看关键词回忆整段内容 |

## 二、闪卡的三代演进

### ① 莱特纳盒子（1970s）——实体时代

- 5个实体盒子，新卡片放入盒子1
- 复习正确 → 移到下一盒；错误 → 移回前一盒
- 盒号越大，间隔越长
- 本质与 Anki 的4个评估按钮同理

> [!WARNING] 局限
> 少量短期还行，卡片一多周期一长，管理复杂度就失控了。

### ② Supermemo（1987）——软件化与算法奠基

| 贡献 | 说明 |
|------|------|
| **软件化** | 从实体盒子到软件，管理大量卡片成为可能 |
| **SM-2 算法** | 被 Anki 沿用至今的间隔复习算法 |
| **增量学习** | 内容很难？每次只学一点，下次再学一点 |
| **渐进阅读** | 学不下去换内容，保留笔记带着复习，回头再看不难 |

> [!WARNING] Supermemo 的局限
> 易用性差（手动链接笔记操作繁琐）、稳定性差（卡死/崩溃）、生态封闭（缺乏第三方工具）。

### ③ Anki（2006）——大众化与生态繁荣

两大基本原理（都是经过反复验证的常识）：

1. **主动回忆**：看问题想答案
2. **间隔复习**：把集中突击复习前置并分散

> "那些从过去流传下来的常识，却意外的正确。"——《考试脑科学》

## 三、Anki 的四大优势

| 优势 | 为什么重要 |
|------|-----------|
| **自定义内容** | 笔记是你自己思考成果的固化。新人觉得麻烦，长期用户认为这是最大优点 |
| **多平台同步** | 手机/电脑/平板同步，带来**分散学习**的好处：早中晚各复习一点，效果更好 |
| **本地化（离线可用）** | 同步后离线可用，稳定不丢数据 |
| **插件生态** | 开源社区不断扩展功能，满足各种需求 |

---

## 四、Anki 解决什么问题？

> [!ABSTRACT] 一句话
> Anki 解决的是学习成果的**保存**和**进度衔接**问题。

| 痛点 | Anki 的解法 |
|------|------------|
| 学习难（新知无法联系旧知） | 间隔复习把理解转入常识记忆 → 以熟带新 |
| 信息多（学了这个忘那个） | 成果固化 + 不间断的间隔复习 |
| 周期长（第一轮学完像没学） | 间隔复习让长周期学习变得可持续 |
| 竞争强（短期能力无法改变） | 善假于物，用工具提升效果 |
| 应用难（学完用不上） | 把所学变成随时能调用的理解 |

## 五、选材决定成败

> [!WARNING] 新同学最容易犯的错误
> 上来就抄别人的牌组，或者拿单词表入门。

| ❌ 错误的选材 | ✅ 正确的选材 |
|-------------|-------------|
| 网上复制粘贴的内容 | 自己思考加工过的内容 |
| 单词表（缺乏实际使用价值） | 专业课知识（有理论价值和实用价值） |
| 孤立的知识点 | 与已有知识能建立联系的内容 |

你不可能从无意义的内容里，通过间隔复习感受到意义。

## 六、时间预期

> [!NOTE]
> 用了 Anki ≠ 学习时间大幅减少。学习的实质没变，该花的时间还是要花。初期可能会更多（适应变化、解决问题）。

- 学得快的人 → 花了时间解决问题 → 提升空间大
- 一味求快 → 没时间解决问题 → 提升空间从哪来？
- **一分辛苦一分财，在 Anki 上也适用**

## 📝 自我检测

> [!QUESTION] Q1：闪卡的核心机制是什么？它和被动浏览有什么区别？

<details>
<summary>查看答案</summary>

核心机制是**主动回忆**（Active Recall）。区别：主动回忆是"看问题→合上→自己回忆→再验证"，被动浏览是"看问题→直接看答案"。后者虽然用了 Anki，但效果与传统学习无异。

</details>

> [!QUESTION] Q2：Supermemo 提出的"渐进阅读"核心是什么？

<details>
<summary>查看答案</summary>

三大核心：**成果巩固**（笔记记下来并复习）、**任务切换**（学不下去换内容）、**进度保留**（换内容时保留之前笔记）。"东边不亮西边亮"——这条路走不通先去走另一条，过段时间再回头。

</details>

> [!QUESTION] Q3：Anki 最大的优点是什么？很多新人为何把它当成缺点？

<details>
<summary>查看答案</summary>

**自定义内容**。新人觉得要自己做卡很麻烦，不如用别人的省事。但长期用户知道——笔记是你自己思考成果的固化，别人的笔记无法替代你大脑中的理解过程。当然，单词翻译等通用内容也可以用别人的。

</details>

> [!QUESTION] Q4：每天用 Anki 应该做哪两类任务？

<details>
<summary>查看答案</summary>

每天两种任务：① **新学**（自己添加适当数量的新内容）② **复习**（之前学过的卡片到期后自动出现）。两者同时进行，才能一边推进一边巩固。

</details>

## ⚡ 今日行动

1. **安装 Anki**（如果还没有）：
   - 访问 `apps.ankyweb.net` 下载桌面版
   - 官网 `ankyweb.net` 注册账号
   - 手机安装对应版本
2. **体验完整流程**：
   - 创建一个牌组
   - 添加 3 张问答题卡片（用你正在学的知识）
   - 点击牌组开始复习
   - 体验 4 个评估按钮
3. **选材检查**：想想你打算用 Anki 学什么？选一个**有意义的、自己加工过的**内容方向。
