# 第9课：插件系统

## 🎯 本课目标

- 了解插件的安装、备份和卸载方法
- 掌握5个核心插件的用法
- 学会插件故障处理

---

## 一、插件常识

### 安装方法

- **在线安装**：工具→插件→获取插件→粘贴代码→确定→重启
- **离线安装**：将插件文件夹复制到 `addons21` 目录

### 选择建议

- **首选**：提升学习质量的插件（算法、牌组转换）
- **其次**：提升效率的插件（编辑、标签）
- **最后**：外观样式类插件
- **避开**：不支持新版本、差评多、长期未更新的插件

### 备份与卸载

- 卸载前先备份插件文件夹（创建压缩包）
- 在插件窗口选中→右下角删除
- 或删除 `addons21` 中的对应文件夹

> 插件仅限于电脑版使用，手机版Anki没有插件。手机上的策略：有想法先标记→同步到电脑→批量处理。

## 二、核心插件详解

### 1. FSRS4Anki Helper `759844606`

与FSRS算法配套，手动/半自动安排复习间隔的插件。

**三大功能分类：**

| 功能分类 | 说明 |
|---------|------|
| **重设进度（Reschedule）** | 更新参数后批量重设间隔，让复习间隔更精确 |
| **分散关联卡片（Disperse）** | 避免关联卡片连续出现造成提示 |
| **减轻负担** | 提前复习（考前）、推迟复习（积压时）、均衡任务量 |

**特殊功能**：节假日设置（如每周日不复习）、通过DSR参数搜索难点

### 2. Edit Field During Review `1020366288`

在复习界面直接编辑笔记，无需进入编辑窗口。

**使用方法**：在模板中，字段名前加 `edit:`，如 `{{edit:正面}}`

- 直接点击字段即可编辑
- 可用加粗/斜体快捷键（Ctrl+B、Ctrl+I）
- 点击别处或按ESC自动保存
- 复习时有新思考→立即修改→固化下来

### 3. Convert Subdecks to Tag Hierarchy `1172858842`

将多级牌组转换成多级标签，并将下级笔记合并到上级牌组。

**使用场景**：复习后期（冲刺阶段）将从"单元测验"模式切换到"期末考试"模式。

> [!WARNING] 易错点
> 执行前先选中最上级牌组；默认不合并牌组，需进设置改为 `true`。

### 4. Quick Tagging `304770511`

在复习界面一键添加/编辑标签。

- **默认快捷键**：Q键添加标签，W键编辑标签
- **高级用法**：设置自定义快捷键一键添加特定标签（如Shift+D添加todo标签）

### 5. Automatic Basic to Cloze `800723229`

在问答题模板界面直接记填空题，无需频繁切换模板。

**前提**：账户里需要有默认名称的"问答题"和"填空题"模板。
**效果**：安装后问答题界面也有挖空按钮→选中文字→点击挖空→添加完成。

## 三、故障处理

| 情况 | 处理 |
|------|------|
| **能打开Anki但报错** | 工具→检查数据库（执行几次）→禁用可疑插件 |
| **打不开Anki** | 启动时按住 Shift 键→绕过有问题的插件→成功后检查数据库+禁用可疑插件 |
| **插件安装失败** | 通常是网络原因→科学上网→重试 |

> [!NOTE] 预防
> 使用主流插件、保持插件更新、只安装需要的插件。
