# 记录方法体系参考

> 涵盖：课程 04-1 至 04-8

## 一、Anki 笔记类型总览

| 类型 | 适用场景 | 核心特点 |
|------|---------|---------|
| **问答题（Basic）** | 有明确问题和答案的知识点 | 问题→答案，一对一，最常用 |
| **填空题（Cloze）** | 术语定义、固定表达、关键概念 | 隐藏关键词，通过上下文回忆 |
| **图片遮盖（Image Occlusion）** | 解剖图、地图、流程图 | 在图片上遮挡关键区域 |
| **问答翻转（Basic + Reversed）** | 双向记忆（汉译英+英译汉） | 一次添加生成两张卡片 |
| **可选翻转（Basic + Optional Reversed）** | 部分需要双向 | 通过开关字段控制 |

### 问答题补充变体

| 类型 | 特点 | 适用场景 |
|------|------|---------|
| 简单答案 | 答案简短，直接记忆 | 基本知识点 |
| 多要点答案 | 答案分点，用关键词组块化 | 复杂概念 |
| 含图片答案 | 图文结合 | 增强理解 |
| 输入问答题（Type-in） | 需手动输入答案核对 | 拼写要求高、术语记忆 |

## 二、填空题的挖空方式

| 方式 | 语法 | 效果 |
|------|------|------|
| **单空挖空** | `{{c1::答案}}` | 一张卡片，一个空 |
| **连续挖空** | `{{c1::答案1}} {{c2::答案2}}` | 多张独立卡片，每次只出现一个空 |
| **同时挖空** | `{{c1::答案1}} {{c1::答案2}}` | 一张卡片，多处同时被隐藏 |
| **混合挖空** | `{{c1::A}} {{c2::B}}` | 不同批次用连续，批次内用同时 |
| **嵌套挖空** | 先挖最小再选更大范围 | 由易到难，逐层叠加 |
| **提示词** | `{{c1::答案::提示方向}}` | 给方向不给答案 |
| **输入型填空** | `{{type:cloze:Text}}` | 需打字输入验证 |

### 易错点

- **挖空过碎**：一句话切成5-6空，语义断裂
- **难度低于考试**：只背关键词不会论述
- **提示过度**：提示直接把答案泄露
- **问答题不能使用 `{{c1::}}` 语法**

## 三、分类方式

### 按牌组（默认方式）

每个牌组对应一个学科或教材，简单直观适合新手。

### 按标签（推荐用于知识管理）

- 单级标签：`重要`、`难点`、`todo`
- 多级标签：`心理学::记忆::工作记忆`（用 `::` 分隔层级）

| 维度 | 牌组 | 标签 |
|------|------|------|
| 一个笔记可属于 | 一个牌组 | 多个标签 |
| 灵活性 | 低 | 高 |
| 复习混合 | 按牌组独立 | 可用筛选牌组混合 |
| 适合阶段 | 初学 | 中后期知识管理 |

## 四、碎片化输入与结构化输出

### 为什么需要碎片化

降低难度、明确价值、提升兴趣、自由组合

### 结构化输出的7种方法

1. 源头保持专注
2. 结合大纲笔记
3. 先分后总
4. 相同前缀
5. 多级标签
6. 搜索筛选为专题
7. 经常翻书看目录

## 五、记录的心法与字段设计

### 记录的心法

- **质量优先**：质量 = 1，速度 = 0
- **克制囤积欲**：不能完成闭环的新知识，宁可不学
- **以终为始**：能复习多少 → 就记多少
- **不要重复记录**：选一个工具记好
- **记录即思考**：用自己的话记（生成效应）

### 字段设计建议

| 字段 | 用途 | 示例 |
|------|------|------|
| **问题（正面）** | 触发回忆的提示 | 什么是工作记忆？ |
| **答案（背面）** | 要回忆的内容 | 容量约4项，临时存储和处理信息 |
| **引用** | 书中原话（点击显示） | 引用的原文 |
| **例子** | 具体应用场景 | 记电话号码时暂时默念 |
| **补充** | 额外说明 | 相关概念的延伸 |

> 提示字段：`{{hint:字段名}}` 默认隐藏，点击后才显示。
