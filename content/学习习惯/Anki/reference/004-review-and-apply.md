# 复习与致用体系参考

> 涵盖：课程 05-1 至 06

## 一、复习的四维评估

| 维度 | 含义 | 对应评估 |
|------|------|---------|
| **流畅度** | 回忆的顺畅程度 | Again→Hard→Good→Easy |
| **准确度** | 答案是否正确 | 答对 vs 答错 |
| **完整度** | 是否遗漏要点 | 部分正确？需要补充？ |
| **状态** | 卡片当前所处阶段 | 未学习→学习中→复习中→已掌握 |

### 四个按钮的深层逻辑

| 按钮 | 含义 | 下次间隔 | 适用场景 |
|------|------|---------|---------|
| **Again** | 完全没记住/答错 | 马上重来（<10分钟） | 忘记、错误、不确定 |
| **Hard** | 想起来了但很困难 | 较短（原间隔×1.2） | 回忆吃力，模糊 |
| **Good** | 顺利回忆 | 标准间隔 | 正常情况 |
| **Easy** | 太简单 | 很长间隔 | 已烂熟于心 |

### 常见误区

- 用 Hard 代替 Again → 下次间隔过长
- 过度用 Easy → 以为自己会了
- 机械点击 → 相当于重新阅读

## 二、笔记的五种处置

| 处置方式 | 操作 | 适用场景 |
|---------|------|---------|
| **删除** | 彻底移除 | 确定不需要、记错了 |
| **暂停** | 暂时隐藏，不参与复习 | 还没学到 |
| **搁置** | 关联卡片自动推迟到次日 | 避免连续出现 |
| **标记** | 添加标记便于批量处理 | 存疑内容 |
| **修改** | 编辑笔记内容 | 表达不清、需要补充 |

### 标记的五种颜色

| 颜色 | 含义 |
|------|------|
| 🔴 红色 | 完全没理解/错误 |
| 🟠 橙色 | 理解但记忆不牢 |
| 🟢 绿色 | 需要补充内容 |
| 🔵 蓝色 | 需要查证/存疑 |
| 🩷 粉色 | 自定义用途 |

## 三、记忆原理速查

### 阿特金森-谢夫林三阶段模型

感觉记忆（0.5-2秒）→ 工作记忆（容量约4项）→ 常识记忆（长期仓库）

### 艾宾浩斯遗忘曲线

- 遗忘在学习后立即开始，最初遗忘最快
- 间隔复习可以有效抵消遗忘趋势
- 每次成功提取，下一次遗忘速度减慢

### 干扰理论

- **前摄干扰**：旧知识干扰新知识的记忆
- **倒摄干扰**：新知识干扰旧知识的回忆

### 提取练习效应

- 主动回忆比被动重读效果好得多
- 每次提取都在强化神经回路
- 必要难度：回忆越费力，记忆效果越好

### 神经达尔文主义

神经回路遵循"用进废退"原则。

### 睡眠与记忆增强

- **睡眠巩固**：新知识→尽力复述→睡眠→第二天回忆率提升
- 策略：睡前复习当日难点，睡醒后再快速回顾一次

### 影响遗忘的7大因素

| 因素 | 对策 |
|------|------|
| 初始学习不足 | 合上书复述，能完整回忆再设间隔 |
| 主动学习不足 | 记"是什么-为什么-怎么用"三栏笔记 |
| 组织方式差 | 改写成顺口溜、逻辑树、图表 |
| 不复习不使用 | 设每日最低复习量，形成习惯 |
| 干扰 | 学50分钟后强制休息10分钟 |
| 缺觉 | 23:30前睡，睡前5分钟回顾 |
| 情绪/压力 | 运动+冥想降低皮质醇 |

## 四、背诵 vs 复习

| 对比 | 背诵 | 复习 |
|------|------|------|
| 定义 | 从未掌握→能完整复述 | 掌握后遗忘→拉回原有水平 |
| Anki间隔 | < 1天（学习阶段） | ≥ 1天（复习阶段） |

> **背不会不过夜**：当天必须能复述才允许设置>1天间隔。

## 五、处理难点

| 难点类型 | 表现 | 对策 |
|---------|------|------|
| **瓶颈卡片（Leech）** | 多次复习仍记不住 | ①暂停几周后重新学 ②拆分为更小笔记 ③换角度记 |
| **理解缺陷** | 不是记不住，是没理解 | 回到原文重新理解，改写笔记 |
| **上下文缺失** | 孤立卡片难以回忆 | 添加上下文提示/做专题复习 |
| **混淆相似内容** | 两个概念经常搞混 | 做对比笔记，放在一起对比复习 |

### 识别难点的定量方法

| 方法 | 搜索语法 | 操作 |
|------|---------|------|
| Leech阈值 | 牌组选项→Lapses→Leech threshold | 默认8次重来 |
| 今日重来 | `rated:1:1` | 1天内重复失败的卡片 |
| 近7天重来 | `rated:7:1` | 7天内重复失败 |
| Lapses列排序 | 浏览窗口添加Lapses列→降序排序 | 选前20张做强化 |

## 六、合理减负

| 方法 | 说明 |
|------|------|
| 调整上限 | 降低每日新卡和复习上限 |
| 暂停不重要的 | 用标签区分优先级 |
| 删除过剩笔记 | 删掉不重要的笔记 |
| 增加间隔倍数 | 在牌组选项中调整 |
| 启用 FSRS | 更精准地安排复习 |
| 设置到期日 | 将部分笔记推迟到将来 |

### 设置到期日的7大场景

| 场景 | 操作 |
|------|------|
| 区分轻重缓急 | 非重点→分散到7-15天后 |
| 平衡批量导入 | 1000张分散到100天 |
| 重新导入已学笔记 | 直接设较大间隔（90-365） |
| 假期/考试避让 | 提前复习或延后 |
| 处理拖延任务 | 70张分散到1-10天 |
| 按难度动态调整 | 简单卡长间隔，困难卡短间隔 |
| 考前突击 | 考后到期卡片提前到考前 |

## 七、致用——让知识产生价值

### 致用的三层含义

1. **用知识解释新知识**：以熟带新
2. **用知识解决现实问题**：理论联系实践
3. **重组知识创造新知识**：跨学科联系

### 致用的具体方法

| 方法 | 操作 | 频率 |
|------|------|------|
| 主题复习 | 通过标签筛选同主题卡片 | 学完一章/一本书后 |
| 结构整理 | 碎片笔记→整理大纲结构 | 定期 |
| 联系实践 | 添加"应用场景"字段 | 遇到相关场景时 |
| 专题笔记 | 用标签跟踪todo | 日常 |
| 跨书联系 | 不同书相同主题放一起复习 | 积累到一定量后 |

### todo 标签工作流

1. 看笔记时想"这个知识可以用在哪里？"
2. 添加标签 `todo` 或 `todo::待实践`
3. 设置筛选牌组只复习带 todo 标签的卡片
4. 实践中用到了 → 改标签为 `todo::已完成`
5. 定期复盘：哪些知识还没用过？为什么？

## 八、学习计划设置速查

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 每日新卡上限 | 10-30 | 少即是多 |
| 每日复习上限 | 100-200 | 超过可能导致积压 |
| 间隔倍数 | 1.0（默认） | 可适当调高 |
| 简单奖励 | 130%（默认） | 点Easy的额外加成 |
| 毕业间隔 | 21天 | 卡片进入"复习中"状态的最小间隔 |
| 搁置关联卡片 | 开启 | 避免连续出现 |
