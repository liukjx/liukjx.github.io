# 导入与联动方案参考

> 涵盖：课程 12-1 至 12-4

## 一、通用导入格式

### Anki 支持的格式

| 格式 | 扩展名 | 说明 |
|------|--------|------|
| Anki 牌组包 | .apkg | 单个牌组导出，导入不覆盖原有库 |
| Anki 集合包 | .colpkg | 整个库导出，导入会覆盖 |
| CSV / TSV | .csv / .tsv | 通用文本格式，可用 Excel 编辑 |
| 纯文本 | .txt | 一行一条笔记，最简单格式 |

### 导入窗口关键选项

| 选项 | 说明 |
|------|------|
| 模板 | 选择导入笔记使用的模板 |
| 牌组 | 导入到哪个牌组 |
| 现有笔记（重复处理） | 更新（新替旧）/ 保留（旧不变）/ 复制（新旧共存） |
| 匹配范围 | 仅模板 / 模板+牌组 |
| 字段匹配 | 导入文本与模板字段的对应关系 |

### 手机端导入

- **安卓**：右上角三点→导入牌组→选择文件
- **iPhone**：浏览器下载→点击文件→自动跳转Anki导入

## 二、任意笔记工具导入（通用方案）

### 一句话/一段话笔记

1. 在任意笔记工具中记一句话或一段话
2. 保存为 .txt 文件，或通过在线转换工具处理
3. 导入Anki→选择"浏览划线"模板→导入
4. 两种学习方式：纯浏览 / 选中文字挖空成填空题

### 问答笔记

- 格式：以"问"开头的问题 + 以"答"开头的答案，上下行相邻
- 支持特殊符号：双括号（高亮）、细方括号（标签+高亮）、粗方括号（填空）

### 在线转换工具

1. 粘贴笔记到在线转换工具
2. 点击处理→下载 .csv 文件
3. Anki→文件→导入

## 三、幕布笔记导入

### 幕布的特点

- 大纲式笔记工具，适合记录学科知识
- 支持一键切换思维导图模式
- 三个快捷键：回车（新节点）、Tab（降级）、Shift+Tab（升级）

### 层级规范

| 层级 | 内容 | 对应Anki |
|------|------|---------|
| 1级 | 书名 | 多级标签第一级 |
| 2级 | 章名 | 多级标签第二级 |
| 3级 | 节名 | 多级标签第三级 |
| 4级 | 问题 / 题干 | 问题字段 |
| 5级 | 答案 / 补充 | 答案字段 |
| 6级 | 补充说明 | 补充字段 |

### 两种笔记类型

| 类型 | 标记 | 4级 | 5级 |
|------|------|-----|-----|
| 问答题 | 4级末尾加两个问号（??） | 问题 | 答案 |
| 浏览划线题 | 无两个问号 | 一句话/一段话 | 可选补充 |

### 导入流程

1. 幕布笔记→导出 OPML 格式
2. 在线转换网站→上传 OPML 文件→处理→下载
3. Anki→文件→导入→选择下载的文件
4. 已导入部分可标记为"完成"，下次自动忽略

### 标签支持

- 幕布中：空格 + #标签名 + 空格 → Anki中变成标签
- 可用于标记重要性（高/低）、难度等维度

## 四、微信读书导入

### 支持的内容来源

- 微信读书 APP 内自营图书
- 微信公众号文章（在微信中→右上角→在微信读书中打开）
- 导入到微信读书的电子书

### 三种笔记类型

| 类型 | 操作 | 对应Anki牌组 | 难度 |
|------|------|-------------|------|
| **划线** | 选中内容→划线 | 了解 | 低 |
| **批注** | 选中内容→写想法→一句话批注 | 理解 | 中 |
| **问答笔记** | 通过批注记问答 | 掌握 | 高 |

### 特殊符号

- **细方括号[ ]**：关键词→转换为标签 + 高亮
- **粗方括号【 】**：填空内容→变为填空题

### 导入流程

1. APP内导出笔记（目前网页版导出有bug）
2. 在线转换工具→粘贴笔记→处理→下载
3. Anki→文件→导入→选择文件

### 专题学习

- 不同书的同主题笔记→通过标签聚合→筛选牌组专题复习
- 学完一章→选择该章标签→创建筛选牌组→结构化复习
- 学完一本书→创建全书的筛选牌组→整体回顾

## 五、强强联合的核心理念

> **各工具做自己最擅长的事**：幕布/微信读书负责记录和整理 → 定期导入Anki → Anki负责间隔复习

- 保留原有记笔记习惯，不改 workflows
- 发挥各工具特长
- 多一份归档打印的备份
- 笔记修改后不需要回改原始工具——最终目的是记住
