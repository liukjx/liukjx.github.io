# 前端快速课程地图

## 主线顺序

| 阶段 | 推荐顺序 | 目标产出 | 完成标准 |
|------|------|------|------|
| 01 | HTML + CSS | 响应式静态页面 | 能还原一个移动端和桌面端页面 |
| 02 | JavaScript 基础 + DOM/BOM | 原生交互页面 | 能独立完成表单、列表、筛选和分页 |
| 03 | JavaScript 核心与异步 | 可维护的业务逻辑 | 能解释闭包、原型、this、Promise，并处理 loading/error |
| 04 | Git / npm / Vite | 可协作的前端工程 | 能创建、分支开发、构建并部署一个 Vite 项目 |
| 05 | TypeScript | 类型安全的业务代码 | 能为 API、组件 props、状态和工具函数补全类型 |
| 06 | Vue3 或 React（二选一） | 框架应用 | 能完成路由、状态管理、表单和接口请求 |
| 07 | 完整项目 | 可展示作品 | 通过 [[PROJECT-PRACTICE\|项目验收清单]] |

## 分流规则

- 目标是国内 Vue 岗位：选择 Vue3，优先学习 Composition API、Vue Router、Pinia。
- 目标是 React 岗位或跨端生态：选择 React，优先学习 Hooks、React Router、Redux Toolkit。
- 不要在阶段 06 同时深入两个框架。完成一个项目后，再用专题笔记补第二个框架。

## 暂缓专题

以下内容不作为主线前置条件：jQuery、深度 Webpack、Gulp、Rollup、SSR、小程序、uni-app、Taro、Canvas/ECharts、Node 高级服务端。它们按岗位或项目需要进入 [[index\|按需专题]]。

## 每阶段循环

1. 阅读对应笔记的学习目标和核心概念。
2. 不看答案完成自测题，记录仍然解释不清的术语。
3. 完成该阶段的小项目，保留代码和运行截图。
4. 按验收清单逐项检查，再进入下一阶段。
