# 前端主线项目实践与验收清单

这些项目不要求一次做成商业产品，要求能运行、能解释、能复现。每个阶段完成后，把代码放在独立 Git 仓库，并记录运行命令和截图。

## 01：响应式内容页

使用 HTML/CSS 制作一个课程介绍页或个人作品集首页。

验收：

- [ ] 使用语义化标签，键盘可以访问主要链接和表单控件。
- [ ] 桌面端和移动端均无横向滚动，布局使用 Flex 或 Grid。
- [ ] 至少包含导航、内容区、卡片列表、表单和页脚。
- [ ] 使用媒体查询或流式单位适配至少两个屏幕宽度。
- [ ] 能解释盒模型、层叠优先级、定位上下文和响应式策略。

## 02：原生 JavaScript 任务板

使用原生 JavaScript 实现任务列表，支持新增、编辑、完成、删除、筛选和本地持久化。

验收：

- [ ] DOM 事件使用事件委托或清晰的监听生命周期。
- [ ] 输入校验、空状态、错误状态和重复提交都有处理。
- [ ] 刷新页面后数据仍然存在，数据格式可解释。
- [ ] 至少有一个异步请求，并显示 loading、成功和失败状态。
- [ ] 能解释事件冒泡、事件对象、Promise 链和 async/await。

## 03：异步数据看板

使用原生 JavaScript 或轻量 API 完成搜索、分页和并发请求看板。

验收：

- [ ] 将 API、状态转换、渲染和事件处理拆分为独立函数。
- [ ] 正确处理竞态、取消请求或过期响应。
- [ ] 能写出 Promise.all、Promise.allSettled 的适用场景。
- [ ] 至少有一个闭包或高阶函数，并能说明其用途。
- [ ] 为关键纯函数准备最少 5 个输入/边界案例。

## 04：Vite 工程化项目

把任务板迁移为 Vite 项目，加入环境变量、代码检查、构建和部署脚本。

验收：

- [ ] `npm install` 后可以用一条命令启动开发服务器。
- [ ] `npm run build` 成功生成生产文件。
- [ ] `.gitignore`、环境变量示例和 README 齐全，密钥未提交。
- [ ] 至少完成一次分支开发、合并和回滚演练。
- [ ] 能说明依赖、脚本、开发服务器和生产构建的关系。

## 05：TypeScript 类型安全改造

将项目中的 API 数据、表单、组件参数和工具函数迁移到 TypeScript。

验收：

- [ ] `strict: true` 下无类型错误，生产构建前执行类型检查。
- [ ] API 响应、错误结构、分页参数和表单状态都有明确类型。
- [ ] 至少使用一次泛型、联合类型、类型守卫和工具类型。
- [ ] 不用 `any` 掩盖业务类型问题；必要时说明 `unknown` 的收窄过程。
- [ ] README 记录类型设计取舍和仍未覆盖的边界。

## 06：Vue3 或 React 管理台

选择一个框架做一个小型管理台：登录页、列表页、详情页、表单页和权限状态。

验收：

- [ ] 路由切换、刷新、404 和鉴权跳转均可用。
- [ ] 状态管理只保存跨页面共享状态，局部状态留在组件内。
- [ ] 表单有校验、提交中、成功、失败和重置状态。
- [ ] 列表有 loading、empty、error、分页和重复请求处理。
- [ ] 至少有一个可复用组件和一个可复用业务 composable/hook。
- [ ] 能解释组件边界、响应式/状态更新机制和渲染触发原因。

## 结业验收：完整项目发布

- [ ] 从 README 的零环境步骤可以复现项目。
- [ ] 有线上地址或可离线运行的构建产物。
- [ ] 有 3 个以上用户流程的录屏或截图。
- [ ] 有基础测试或手工测试记录，覆盖成功、空、错误和权限场景。
- [ ] 能在 10 分钟内讲清项目架构、一个技术取舍和一个待改进点。
