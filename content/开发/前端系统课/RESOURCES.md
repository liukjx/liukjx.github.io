# 前端开发资源

## Knowledge

### HTML + CSS

- [MDN Web Docs: HTML](https://developer.mozilla.org/zh-CN/docs/Web/HTML) — HTML 标准参考，最权威的文档
- [MDN Web Docs: CSS](https://developer.mozilla.org/zh-CN/docs/Web/CSS) — CSS 标准参考，属性查询首选
- [Flexbox Froggy](https://flexboxfroggy.com/) — CSS Flexbox 交互式游戏学习
- [CSS Grid Garden](https://cssgridgarden.com/) — CSS Grid 交互式游戏学习

### JavaScript

- [MDN Web Docs: JavaScript](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript) — JS 语言标准文档
- [ECMAScript 规范](https://tc39.es/ecma262/) — JS 语言标准规范
- [JavaScript.info](https://javascript.info/) — 现代 JavaScript 教程，英文/中文
- [You Don't Know JS (YDKJS)](https://github.com/getify/You-Dont-Know-JS) — 深入理解 JS 核心机制

### Vue

- [Vue.js 官方文档](https://cn.vuejs.org/) — Vue3 官方中文文档
- [Pinia 状态管理](https://pinia.vuejs.org/zh/) — Vue 官方推荐状态管理库
- [Vue Router](https://router.vuejs.org/zh/) — Vue 官方路由

### React

- [React 官方文档](https://zh-hans.react.dev/) — React 官方中文文档
- [Redux 官方文档](https://redux.js.org/) — React 状态管理库
- [React Router 官方文档](https://reactrouter.com/) — React 路由

### TypeScript

- [TypeScript 官方文档](https://www.typescriptlang.org/zh/docs/) — TS 官方中文文档
- [TypeScript 类型体操](https://github.com/type-challenges/type-challenges) — TS 类型练习

### 工程化

- [Webpack 官方文档](https://webpack.docschina.org/) — 构建工具配置
- [Vite 官方文档](https://cn.vitejs.dev/) — 下一代前端构建工具
- [Node.js 官方文档](https://nodejs.org/zh-cn/docs/) — Node.js 文档
- [Git 官方文档](https://git-scm.com/book/zh/v2) — Git 版本控制

### 其他

- [微信小程序官方文档](https://developers.weixin.qq.com/miniprogram/dev/framework/) — 小程序开发文档
- [ECharts 官方文档](https://echarts.apache.org/zh/index.html) — 数据可视化图表库
- [Nuxt.js 官方文档](https://nuxt.com/) — Vue SSR 框架
- [Next.js 官方文档](https://nextjs.org/docs) — React SSR 框架
