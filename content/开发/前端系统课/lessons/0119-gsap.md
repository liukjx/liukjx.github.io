## GSAP 简介

GSAP（GreenSock Animation Platform）是一个高性能的 JavaScript 动画库，兼容所有主流浏览器。

### 安装

```bash
npm install gsap
# 或 CDN
# <script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.0/gsap.min.js"></script>
```

### 基本使用

```javascript
import { gsap } from 'gsap';

// 最简单的动画
gsap.to('.box', {
  x: 300,
  rotation: 360,
  duration: 2,
  ease: 'power2.out'
});
```

## 核心方法

### gsap.to()

```javascript
// 从当前状态到目标状态
gsap.to('.element', {
  x: 200,            // 水平移动 200px
  y: 100,            // 垂直移动 100px
  rotation: 360,     // 旋转 360 度
  scale: 1.5,        // 缩放 1.5 倍
  opacity: 0.5,      // 透明度
  backgroundColor: '#FF6B6B',  // 背景色
  borderRadius: '50%',         // 圆角
  duration: 1,                 // 持续时间（秒）
  delay: 0.5,                  // 延迟
  ease: 'power2.inOut',        // 缓动
  repeat: 2,                   // 重复次数（-1 无限）
  yoyo: true,                  // 往返效果
  stagger: 0.1,                // 逐个延迟（多个元素）
});
```

### gsap.from()

```javascript
// 从指定状态到当前状态
gsap.from('.element', {
  x: -200,
  opacity: 0,
  scale: 0,
  duration: 1
});

// 组合使用
const tl = gsap.timeline();
tl.from('.header', { y: -100, opacity: 0, duration: 0.5 })
  .from('.content', { x: -50, opacity: 0, duration: 0.5 })
  .from('.footer', { y: 100, opacity: 0, duration: 0.5 });
```

### gsap.fromTo()

```javascript
// 完全控制起始和结束状态
gsap.fromTo('.element',
  { x: -100, opacity: 0, scale: 0.5 },  // from
  { x: 100, opacity: 1, scale: 1.5, duration: 1.5 }  // to
);
```

### gsap.set()

```javascript
// 立即设置属性（无动画）
gsap.set('.element', {
  x: 100,
  y: 50,
  opacity: 0,
  visibility: 'visible'
});
```

## 缓动函数

```javascript
// 基础缓动
ease: 'power1.out'     // 缓出
ease: 'power2.in'      // 缓入
ease: 'power3.inOut'   // 缓入缓出
ease: 'none'           // 线性

// 弹性
ease: 'elastic.out(1, 0.3)'
ease: 'elastic.in'

// 弹跳
ease: 'bounce.out'
ease: 'bounce.in'

// 回退
ease: 'back.out(3)'
ease: 'back.in'

// 自定义缓动
ease: 'steps(12)'
ease: 'customEase'  // 需要 CustomEase 插件
```

## 时间线（Timeline）

### 创建和控制时间线

```javascript
const tl = gsap.timeline({
  paused: true,         // 初始暂停
  repeat: 2,            // 重复
  yoyo: true,           // 往返
  onComplete: () => console.log('动画完成')
});

// 添加动画
tl.to('.box1', { x: 200, duration: 1 })
  .to('.box2', { x: 200, duration: 1 }, '-=0.5')  // 提前 0.5s
  .to('.box3', { x: 200, duration: 1 }, 0)         // 从 0s 开始
  .to('.box4', { x: 200, duration: 1 }, '<');      // 与前一个同时

// 控制方法
tl.play();      // 播放
tl.pause();     // 暂停
tl.resume();    // 继续
tl.reverse();   // 反向
tl.seek(2);     // 跳到 2s
tl.progress(0.5); // 跳到 50%
tl.timeScale(2);  // 2 倍速
tl.kill();      // 杀死动画
```

### 标签和回调

```javascript
const tl = gsap.timeline();

tl.addLabel('intro', 0)
  .to('.title', { opacity: 1, y: 0, duration: 1 }, 'intro')
  .addLabel('content', 1.5)
  .to('.text', { opacity: 1, duration: 0.8 }, 'content')
  .to('.image', { scale: 1, duration: 0.8 }, '<')
  .addPause('content')
  .addLabel('end', 3)
  .to('.button', { opacity: 1, duration: 0.5 }, 'end');

tl.eventCallback('onComplete', () => {
  console.log('动画完成');
});
```

## 动画控制

```javascript
// 暂停所有 GSAP 动画
gsap.globalTimeline.pause();
gsap.globalTimeline.resume();

// 获取动画
const tween = gsap.to('.box', { x: 200, duration: 1 });
tween.kill(); // 停止动画

// 清除所有动画
gsap.killTweensOf('.box');

// 从特定值开始
gsap.to('.box', {
  x: 400,
  scrollTrigger: '.trigger',  // 需要 ScrollTrigger 插件
});
```

## 自测题

### 问题 1
GSAP 的 to()、from() 和 fromTo() 有什么区别？

<details>
<summary>查看答案</summary>
to()：从元素的当前属性值动画到指定的目标值，适合元素已在最终位置的逆动画；from()：从指定的起始值动画到元素的当前属性值，适合入场动画；fromTo()：同时指定起始值和结束值，提供最精确的控制。fromTo() 在需要精确定义动画两端状态时最常用，to() 是日常使用最多的方法。
</details>

### 问题 2
GSAP 时间线（Timeline）的优势是什么？

<details>
<summary>查看答案</summary>
时间线可以精确控制多个动画的顺序和重叠关系。优势：1）链式调用，代码更简洁；2）支持相对定位（'-=0.5' 提前、'<' 同时、'>' 结束后）；3）全局控制（play/pause/reverse/timeScale）；4）添加标签和回调函数；5）支持嵌套时间线。相比单独创建多个 Tween，时间线在管理复杂动画序列时效率更高。
</details>

### 问题 3
GSAP 中的 stagger 参数有什么作用？

<details>
<summary>查看答案</summary>
stagger 用于对多个元素的批量动画添加错开延迟。例如 gsap.to('.items', { x: 200, stagger: 0.1 }) 会让每个元素依次延迟 0.1 秒开始动画。stagger 还支持更复杂的配置：{ each: 0.2, from: 'end' }（从末尾开始）、{ from: 'center' }（从中间向两边）、{ grid: [3, 3], axis: 'x' }（网格错开）等。
</details>
