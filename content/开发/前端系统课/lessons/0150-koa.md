## 创建服务器

```javascript
const Koa = require('koa');
const app = new Koa();

app.listen(3000);
```

## 中间件洋葱模型

```javascript
app.use(async (ctx, next) => {
  console.log('中间件 1 开始');
  await next();
  console.log('中间件 1 结束');
});

app.use(async (ctx, next) => {
  console.log('中间件 2 开始');
  await next();
  console.log('中间件 2 结束');
});

app.use(async (ctx) => {
  ctx.body = 'Hello Koa';
  console.log('处理请求');
});

// 输出顺序：
// 中间件 1 开始
// 中间件 2 开始
// 处理请求
// 中间件 2 结束
// 中间件 1 结束
```

## 路由

```javascript
const Router = require('@koa/router');
const router = new Router();

router.get('/users', async (ctx) => {
  ctx.body = { data: [...] };
});

router.get('/users/:id', async (ctx) => {
  ctx.body = { id: ctx.params.id };
});

app.use(router.routes());
app.use(router.allowedMethods());
```

## Cookie 和 Session

```javascript
// Cookie
ctx.cookies.set('token', 'abc123', {
  maxAge: 24 * 60 * 60 * 1000, // 1天
  httpOnly: true,
  signed: true
});

const token = ctx.cookies.get('token');

// Session
const session = require('koa-session');
app.keys = ['secret-key'];
app.use(session(app));

app.use(async (ctx) => {
  if (!ctx.session.views) {
    ctx.session.views = 0;
  }
  ctx.session.views++;
});
```

## 自测题

### 问题 1
Koa 的洋葱模型与 Express 的中间件模型有什么不同？

<details>
<summary>查看答案</summary>
Express 的中间件是线性模型，中间件按顺序依次执行，next() 前执行代码后直接进入下一个中间件，没有"回归"过程。Koa 的洋葱模型基于 async/await，中间件在 next() 前后都可以执行代码，形成一层层进入再一层层退出的结构。洋葱模型适合请求预处理和响应后处理（如日志记录、响应时间计算、错误处理等）。
</details>

### 问题 2
Koa 的 ctx 对象封装了什么？

<details>
<summary>查看答案</summary>
ctx 是 Koa 的上下文对象，封装了 Node.js 的 req 和 res 对象，同时提供了 request 和 response 的别名方法。ctx.body（设置响应体）、ct.status（状态码）、ctx.query（查询参数）、ctx.params（路由参数）、ctx.cookies（Cookie 操作）等。ctx 对象贯穿整个请求生命周期，是 Koa 中访问请求和响应的主要途径。
</details>
