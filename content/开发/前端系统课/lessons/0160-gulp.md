## Gulp 基础

```javascript
const gulp = require('gulp');
const sass = require('gulp-sass')(require('sass'));
const babel = require('gulp-babel');
const uglify = require('gulp-uglify');
const concat = require('gulp-concat');

// 编译 SCSS
gulp.task('styles', () => {
  return gulp.src('src/scss/**/*.scss')
    .pipe(sass({ outputStyle: 'compressed' }))
    .pipe(gulp.dest('dist/css'));
});

// 编译 JS
gulp.task('scripts', () => {
  return gulp.src('src/js/**/*.js')
    .pipe(babel({ presets: ['@babel/env'] }))
    .pipe(concat('app.js'))
    .pipe(uglify())
    .pipe(gulp.dest('dist/js'));
});

// 监听
gulp.task('watch', () => {
  gulp.watch('src/scss/**/*.scss', gulp.series('styles'));
  gulp.watch('src/js/**/*.js', gulp.series('scripts'));
});

// 默认任务
gulp.task('default', gulp.parallel('styles', 'scripts', 'watch'));
```

## 自测题

### 问题 1
Gulp 的 pipe（管道）模式有什么优势？

<details>
<summary>查看答案</summary>
Gulp 使用流（Stream）和管道模式，文件在内存中流转，每个插件处理文件流的一个环节。相比于 Grunt 等工具在每个插件步骤都读写磁盘的方式，Gulp 的流式处理效率更高。pipe 模式使代码可读性好，每个 .pipe() 是一个独立的处理步骤，易于理解和调试。
</details>

### 问题 2
gulp.series 和 gulp.parallel 有什么区别？

<details>
<summary>查看答案</summary>
gulp.series 串行执行任务，一个任务完成后才执行下一个，适合有依赖关系的任务（如先编译再压缩）。gulp.parallel 并行执行任务，所有任务同时启动，适合无依赖关系的任务（如同时编译 CSS 和 JS）。根据需要组合使用两种模式。
</details>
