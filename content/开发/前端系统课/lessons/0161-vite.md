## Vite 原理

Vite 利用浏览器原生 ES Module 实现开发服务器，使用 Rollup 进行生产构建。

```javascript
// 开发模式
// 浏览器直接加载 ES Module
<script type="module">
  import { createApp } from 'vue'
</script>

// 生产模式
// Rollup 打包
```

## Vite 配置

```javascript
import { defineConfig } from 'vite';
import vue from '@vitejs/plugin-vue';
import path from 'path';

export default defineConfig({
  plugins: [vue()],
  resolve: {
    alias: {
      '@': path.resolve(__dirname, 'src')
    }
  },
  server: {
    port: 3000,
    proxy: {
      '/api': {
        target: 'http://localhost:8080',
        changeOrigin: true
      }
    }
  },
  build: {
    outDir: 'dist',
    sourcemap: false,
    chunkSizeWarningLimit: 500,
    rollupOptions: {
      output: {
        manualChunks: {
          'vue-vendor': ['vue', 'vue-router', 'pinia'],
          'element': ['element-plus']
        }
      }
    }
  }
});
```

## 插件开发

```javascript
function myPlugin() {
  return {
    name: 'vite-plugin-my',
    // 解析钩子
    resolveId(source) {
      if (source === 'virtual-module') {
        return '\0virtual-module';
      }
    },
    // 加载钩子
    load(id) {
      if (id === '\0virtual-module') {
        return 'export default "virtual module"';
      }
    },
    // 转换钩子
    transform(code, id) {
      if (id.endsWith('.custom')) {
        return { code: transformCustom(code), map: null };
      }
    },
    // 配置钩子
    config(config, { command }) {
      if (command === 'serve') {
        return { define: { __DEV__: true } };
      }
    }
  };
}
```

## 自测题

### 问题 1
Vite 开发环境为什么不打包比 Webpack 快？

<details>
<summary>查看答案</summary>
Vite 开发环境利用浏览器原生 ES Module 支持，不需要像 Webpack 那样先打包所有模块再启动服务器。Vite 只在浏览器请求模块时才编译该模块（按需编译），并使用 esbuild（Go 语言编写）进行预构建和编译，速度极快。项目越大，Vite 的优势越明显。
</details>

### 问题 2
Vite 插件和 Webpack 插件的开发模式有什么不同？

<details>
<summary>查看答案</summary>
Vite 插件基于 Rollup 插件接口（钩子函数），开发模式和生产模式共享一套插件 API。Vite 插件 API 扩展了 Rollup 的钩子，添加了 Vite 特有的钩子（config、configResolved、configureServer 等）。Webpack 插件基于 Tapable 的事件机制，在 compiler 和 compilation 的各阶段执行。
</details>
