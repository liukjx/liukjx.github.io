# 补充课19：怎么知道别人的产品用了什么API？

> 魔术=产品；戏法=API — 看穿产品背后的技术栈

## 学习目标

- 理解"魔术与戏法"的思维模型
- 掌握使用 Replicate.com 和 Toolify.ai 发现 API
- 学会拆解 AI 产品背后的 API 组合
- 培养产品嗅觉，每天记录需求

---

## 1. 魔术与戏法思维

AI 产品就像一场魔术表演：

| 概念 | 解释 | 比喻 |
|------|------|------|
| **魔术** | 你看到的完整产品 | 舞台上的精彩表演 |
| **戏法** | 背后调用的 API | 袖子里的隐藏机关 |

一个看起来"哇塞"的AI产品，拆开来看，90% 只是把几个公开 API 巧妙地组合在一起。

> [!TIP] 核心认知
> 大多数 AI 产品并不神秘。它们只是把已有的 API 用新的方式组合起来。**会拆解，你就会创造。**

### 为什么这对你重要？

- **不再被"技术壁垒"吓倒** — 看到新产品，你能一眼看穿它的底牌
- **快速复制与创新** — 知道它用了什么，你就能做出更好的
- **培养产品直觉** — 做多了拆解，你自然知道什么能做什么不能做

## 2. 发现 API 的核心工具

### Replicate.com：AI 模型/API 的淘宝

[Replicate](https://replicate.com) 是目前最大的开源 AI 模型市场：

- 提供数百个开源模型的 API 接口
- 每个模型都有在线体验（Playground）
- 直接给出 API 调用代码（Python、Node.js、curl）
- 按量计费，价格透明

**常见模型举例：**

| 模型 | 功能 | 价格 |
|------|------|------|
| Stable Diffusion | 文生图 | $0.002/张 |
| Whisper | 语音转文字 | $0.006/小时 |
| Llama 3 | 文本生成 | $0.0005/次 |
| MusicGen | AI 音乐生成 | $0.008/秒 |

### Toolify.ai：AI 产品目录

[Toolify.ai](https://toolify.ai) 是 AI 产品的"天眼查"：

- 收录 10000+ AI 产品
- 按品类分类（写作、设计、视频、编程...）
- 显示流量排名、增长趋势
- 可以直接看出竞品格局

> [!TIP] 使用技巧
> 看到一个新产品后，先去 Toolify.ai 搜索它的品类，看看有哪些竞品，对比它们的流量和功能，你就能快速理解这个市场的格局。

## 3. 拆解练习：看穿 API 组合

### 方法论：三步拆解法

1. **用一用** — 体验产品全部功能，记录所有能力点
2. **猜一猜** — 根据能力点猜测背后技术栈
3. **查一查** — 用工具验证猜想

### 实战案例

**产品：AI 头像生成器**

| 功能 | 猜测的 API | 验证方法 |
|------|-----------|----------|
| 上传照片 | 无，前端基础功能 | — |
| 人脸检测 | 调用 face-api.js 或 AWS Rekognition | 检查网络请求 |
| 生成不同风格头像 | Stable Diffusion + LoRA | 看生成速度与风格特征 |
| 支付收费 | Stripe / Lemon Squeezy | 看支付页面域名 |

**产品：AI 视频翻译**

| 功能 | 猜测的 API | 验证方法 |
|------|-----------|----------|
| 语音识别 | Whisper API | 看延迟与准确度 |
| 翻译 | GPT-4 / DeepL API | 检查翻译质量特征 |
| 语音合成 | ElevenLabs / Azure TTS | 听音色质量 |
| 视频处理 | FFmpeg / AWS Elemental | 技术特征 |

### 验证技巧

1. **打开浏览器开发者工具（F12）** → Network 标签 → 看发出的 API 请求
2. **看域名** — 如果是 `api.openai.com` 就一目了然
3. **看响应格式** — 不同 API 有不同特征（如 OpenAI 的 streaming 格式很独特）
4. **看错误信息** — 有时候报错会直接暴露后端技术栈

## 4. 培养"产品嗅觉"

产品嗅觉不是天生的，是练出来的。每天花 10 分钟做这件事：

### 每日三问

每天记录 3 个你看到的"需求信号"：

```
日期：2026-08-03

1. 我在小红书看到一个帖子：想要一个能把口播视频自动加上字幕的工具
   → 产品想法：AI 字幕生成器
   
2. 朋友圈有人问：有没有能一键把会议录音转成会议纪要的工具
   → 产品想法：AI 会议纪要助手
   
   
3. 同事抱怨：整理 Excel 数据太费时间了
   → 产品想法：AI 数据清洗工具
```

> [!NOTE] 为什么是 3 个？
> 数量不重要，重要的是**养成习惯**。每天 3 个，一年就是 1000+ 个需求洞察。其中哪怕只有 1% 能变成产品，你就有 10 个产品机会。

### 需求来源渠道

- 小红书/抖音评论区
- 知乎问题
- 微信聊天群里的抱怨
- 身边朋友的工作痛点
- 自己的日常不便

## 5. 实践任务

### 任务：拆解 3 个热门 AI 产品

选 3 个你常用的 AI 产品，尝试反推它们的 API 组合：

| 步骤 | 具体操作 |
|------|---------|
| 1. 选产品 | 从 Toolify.ai 热门榜选 3 个 |
| 2. 用功能 | 完整使用一遍所有功能 |
| 3. 抓网络 | 打开 DevTools 抓 API 请求 |
| 4. 猜技术 | 根据特征猜测使用的模型/API |
| 5. 写报告 | 记录你的拆解结果 |

**推荐拆解目标：**

- 任何 AI 写作工具 → 猜测用 GPT-4 / Claude / 自研模型
- 任何 AI 图片工具 → 猜测用 Stable Diffusion / DALL-E / Midjourney
- 任何 AI 视频工具 → 猜测用 Runway / Pika / 自研
