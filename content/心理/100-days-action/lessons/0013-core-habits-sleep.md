# 第13课：核心习惯 — 早起与睡眠

## Learning Objectives

- 理解早起为何是所有习惯中"最值得优先养成的核心习惯"
- 掌握早起三大方法：光线法、双闹钟法、睡眠周期法
- 学会调整生物钟的三大策略，建立稳定的作息节律
- 掌握提高睡眠质量的五项实用技巧
- 学会布钦疗法应对失眠问题

---

## 1. 早起 — 所有核心习惯中最值得优先养成的一个

在习惯养成的世界里，有一个概念叫做 **"核心习惯"（Keystone Habit）** 。所谓核心习惯，是指那些一旦养成，会自然引发一系列积极连锁反应的习惯。而在所有核心习惯中，**早起是最值得优先养成的**。

### 多米诺骨牌效应

当你能在清晨 5:30 或 6:00 起床，你会发现：

| 早起引发的连锁反应 | 具体表现 |
|:---|:---|
| 获得安静的个人时间 | 无人打扰，可以专注阅读、写作、运动或冥想 |
| 提升全天效率 | 早起完成最重要任务后，一整天都带着成就感 |
| 改善饮食选择 | 有时间吃早餐，而非匆忙凑合或不吃 |
| 促进规律运动 | 早晨是运动习惯最容易坚持的时间段 |
| 改善情绪状态 | 有充裕时间准备，减少匆忙带来的焦虑 |
| 带动早睡 | 早起自然倒逼前一晚早睡，形成良性循环 |

> [!NOTE] 多米诺骨牌的起点
> 早起就像多米诺骨牌的第一张牌——一旦推倒，它会依次触发运动、健康饮食、高效工作、良好情绪等一系列积极改变。这也是为什么几乎所有高效能人士都有早起的习惯。

## 2. 早起让你拥有"额外时间"实现一直想做的事

许多人常说"我没时间"。但真相是：**每个人每天都有相同的 24 小时，区别在于你如何利用清晨的时间**。

### 每日时间对比

假设你平时 7:30 起床匆忙出门，与 5:30 起床对比：

```
平时起床：7:30 → 洗漱→ 出门 → 到公司 9:00
                                     [匆忙的1.5小时]

早起后：  5:30 → 阅读/运动/写作 → 早餐 → 出门 → 到公司 9:00
                                     [充实的3.5小时]
```

每天多出 **2 小时**，一年就是 **730 小时**——相当于 **30 个完整日子**。这多出来的时间可以用来：

- 读 30+ 本书（按每本 20 小时计）
- 学会一项新技能（语言、编程、乐器）
- 完成个人项目或副业
- 建立稳定的晨间运动习惯

> [!TIP] Key Insight
> 早起不是为了"少睡"，而是为了把最优质的精力分配给最重要的事。清晨的 2 小时，是全天注意力最集中的时间段，没有任何会议、消息和干扰。

## 3. 早起三大方法

### 方法一：光线法

人类进化了几百万年，我们的身体天生就是被光线唤醒的。光线是最自然的闹钟。

#### 科学原理

| 光线类型 | 生理作用 | 最佳时间 |
|:---|:---|:---|
| **清晨阳光（自然光）** | 抑制褪黑素分泌，唤醒大脑 | 日出前后 |
| **蓝光（早晨）** | 激活血清素，提升警觉性和情绪 | 起床后 30 分钟内 |
| **红光/暖光（傍晚）** | 促进褪黑素分泌，为睡眠做准备 | 睡前 1-2 小时 |

**具体做法：**

1. **睡觉不拉严窗帘**，留一条缝让清晨自然光透入
2. **起床第一件事拉开窗帘**，让阳光照射到眼睛（无需直视太阳）
3. 如果房间采光不好，使用**模拟日出闹钟**（Sunrise Alarm Clock），在预定起床时间前 30 分钟逐渐增强光照
4. 冬季或阴雨天，可以使用 **光照治疗灯**（10,000 lux）照射 15-30 分钟

#### 褪黑素与血清素的关系

```
          白天日照充足
               ↓
        血清素分泌增加  ← 提升情绪和清醒度
               ↓
          晚上光线变暗
               ↓
        血清素转化为褪黑素
               ↓
            进入睡眠
```

> [!WARNING] 关键要点
> 白天晒太阳越充分，晚上的褪黑素分泌就越好。这就像一个蓄水的过程——白天"蓄"血清素，晚上"释放"褪黑素。如果白天整天待在室内不见阳光，晚上的睡眠质量一定会受影响。

### 方法二：双闹钟法

这是日本早起研究专家**中岛孝志**提出的方法，核心思路是：**用两个闹钟制造"不得不起床"的局面**。

#### 双闹钟设置方案

```
┌─────────────────────────────────────────────────────────┐
│                   双闹钟布局示意图                        │
│                                                         │
│  ┌─────────────────────┐     ┌──────────────────────┐   │
│  │   闹钟 A（温柔型）    │     │   闹钟 B（粗暴型）    │   │
│  │                      │     │                      │   │
│  │  位置：床头柜         │     │  位置：房间另一侧      │   │
│  │  时间：目标时间       │     │  时间：目标时间+3分钟  │   │
│  │  音量：轻柔           │     │  音量：最大           │   │
│  │  用途：轻度唤醒       │     │    必须下床才能关闭   │   │
│  └─────────────────────┘     └──────────────────────┘   │
│                                                         │
│             闹钟 A 唤醒 → 闹钟 B 强迫下床                │
└─────────────────────────────────────────────────────────┘
```

**操作步骤：**

1. **设定两个闹钟**，间隔 3 分钟（如目标 6:00，则 A=6:00，B=6:03）
2. **把闹钟 B 放在房间另一侧**——必须下床走几步才能关掉
3. **闹钟 A 设置在床头**，音量设置为"刚好能唤醒你"的轻柔水平
4. 当闹钟 A 响起，你知道 3 分钟后闹钟 B 会巨响，这迫使你主动下床去关 B

> [!TIP] 进阶技巧
> 把闹钟 B 放在**卫生间**，旁边放一杯水。你下床 → 走过去关闹钟 → 顺便开灯 → 喝水 → 洗脸。这一系列动作完成后，大脑已经被充分唤醒，几乎不可能再回去睡。

### 方法三：睡眠周期法

睡眠不是一条连续的直线，而是由 **90 分钟** 左右的周期组成的。

#### 睡眠周期结构

```
睡眠阶段        ┌───────┐
                │ 快速  │
                │ 眼动  │
                │ 睡眠  │
                └───────┘
      ┌─────────┐ ┌───────┐
      │ 浅层睡眠 │ │ 深层  │
      │ 阶段 1-2 │ │ 睡眠  │
      └─────────┘ └───────┘
      ←——约 90 分钟——→

      一个完整周期 = 浅睡 + 深睡 + 快速眼动
```

**核心原则：在睡眠周期结束时（而非中间）醒来，你会感觉最清醒。**

#### 睡眠周期计算表

| 入睡时间 | 5个周期醒来 (7.5h) | 6个周期醒来 (9h) |
|:---|:---|:---|
| 21:00 | 04:30 | 06:00 |
| 21:30 | 05:00 | 06:30 |
| 22:00 | 05:30 | 07:00 |
| 22:30 | 06:00 | 07:30 |
| 23:00 | 06:30 | 08:00 |
| 23:30 | 07:00 | 08:30 |
| 00:00 | 07:30 | 09:00 |

**使用方法：**

1. 确定你的起床时间（固定不变）
2. 以 90 分钟为单位倒退计算入睡时间
3. 给自己留出 15 分钟入睡缓冲期

> [!EXAMPLE] 示例
> 如果你需要 6:00 起床：
> - 倒退 5 个周期（7.5 小时）→ 理想入睡时间 22:30
> - 倒退 4 个周期（6 小时）→ 可接受入睡时间 00:00
> - 建议 22:15-22:30 上床，留出缓冲
>
> **关键**：不要在周期中间（如 23:00 或 23:30）被闹钟叫醒，那时你可能正处于深睡阶段，醒来会极度疲惫。

## 4. 早睡是早起的前提

没有早睡，早起就是无源之水。很多人尝试早起失败，根本原因不是起不来，而是**睡得太晚**。

### 睡眠需求计算公式

```
早起时间 − 睡眠需求周期数 × 90分钟 = 最佳上床时间
```

### 早睡的四个技巧

| 技巧 | 具体做法 | 原理 |
|:---|:---|:---|
| 设置"睡眠提醒"闹钟 | 睡前 1 小时设置提醒闹钟 | 提前告知大脑准备 |
| 建立"睡前仪式" | 刷牙 → 调暗灯光 → 阅读纸质书 | 条件反射暗示身体 |
| 把手机请出卧室 | 卧室只用来睡觉，不带电子设备 | 减少蓝光和多巴胺刺激 |
| 固定上床时间 | 每天同一时间上床，包括周末 | 稳定生物钟 |

> [!QUOTE]
> "早起的秘诀不是意志力，而是早睡。如果你不能早睡，就不要谈早起。"

## 5. 调整生物钟的三个建议

人体的生物钟（昼夜节律）位于下丘脑的视交叉上核（SCN）。它控制着褪黑素、皮质醇、体温等生理指标的日周期波动。

### 建议一：白天多晒太阳

| 时间 | 光照建议 | 生理机制 |
|:---|:---|:---|
| 起床后 0-1 小时 | 户外自然光 10-30 分钟 | 抑制褪黑素，设定生物钟的"早上"信号 |
| 上午 10:00-15:00 | 尽可能在窗边或户外 | 维持血清素水平，提升情绪 |
| 傍晚/黄昏 | 调暗室内灯光 | 让生物钟感知"夜晚来临" |

> [!WARNING]
> 阴天室外的光照度仍有 1,000-5,000 lux，远高于室内灯光（通常 100-300 lux）。所以在**窗边坐一整天**比不上**出门走 10 分钟**。

### 建议二：晚上远离手机和电脑

蓝光（尤其是 450-480nm 波长的蓝光）对褪黑素的抑制作用最为显著。

| 设备类型 | 蓝光强度 | 建议使用时间 | 替代方案 |
|:---|:---|:---|:---|
| 手机 | 高（近距离、高亮屏） | 睡前 1 小时不用 | 纸质书、Kindle |
| 电脑/平板 | 中高 | 睡前 1 小时降低亮度 | 听播客、音频节目 |
| 电视 | 中（距离较远） | 睡前 30 分钟关闭 | — |
| 纸质书/电子墨水 | 无蓝光 | 随时可用 | — |

### 建议三：固定时间睡觉和起床（包括周末）

这是调整生物钟**最重要**的一条原则。

```
工作日：23:00 睡 → 6:00 起
周末：  23:00 睡 → 6:30 起（最多晚起30分钟）

                    ❌ 错误示范
周六：  01:00 睡 → 10:00 起  ← "社交时差"
周日：  00:00 睡 → 09:00 起
周一：  23:00 睡 → 06:00 起  ← 极度痛苦（时差反应）
```

> [!CAUTION] 社交时差
> 周末补觉到中午，相当于每周五飞往美国西海岸，周日又飞回来。这种"社交时差"（Social Jet Lag）对健康的危害不亚于真正的时差。

## 6. 提高睡眠质量的 5 个技巧

### 技巧 1：睡前降低体温

核心体温下降是入睡的重要信号。

- **睡前 1 小时洗热水澡**：热水使体表血管扩张，散热加速，出浴后体温迅速下降，产生强烈的困意
- **降低卧室温度**：理想的睡眠室温是 **18-22℃**
- **选择合适的被子**：不要盖得过厚，保持身体微微凉爽

### 技巧 2：白天运动 + 睡前放松

| 时间 | 活动类型 | 建议时长 | 作用 |
|:---|:---|:---|:---|
| 早晨/下午 | 有氧运动（跑步、游泳） | 30-60 分钟 | 提高深睡比例 |
| 傍晚 | 瑜伽、拉伸 | 10-20 分钟 | 放松肌肉 |
| 睡前 10 分钟 | 冥想、腹式呼吸、渐进放松 | 5-10 分钟 | 降低心率，平复思绪 |

### 技巧 3：把握"睡眠点"——困了立刻睡

"睡眠点"就是身体发出困意信号的时刻。**错过这个窗口，困意会消失，进入"第二春"状态**，之后更难入睡。

**常见困意信号：**
- 打哈欠
- 眼皮沉重
- 注意力难以集中
- 身体微微发冷

> [!TIP] 关键技巧
> 一旦出现上述信号，**立刻上床**，不要想着"看完这一章"或"刷完这个视频"。睡眠窗口通常只持续 10-20 分钟，错过就要等下一个周期。

### 技巧 4：睡前 4 小时不进食、不喝咖啡浓茶

| 物质 | 作用时长 | 建议最后摄入时间 |
|:---|:---|:---|
| 咖啡因 | 半衰期约 5-6 小时 | 下午 14:00 前 |
| 浓茶 | 半衰期约 4-5 小时 | 下午 15:00 前 |
| 大量食物 | 消化 3-4 小时 | 睡前 3-4 小时停止进食 |
| 酒精 | 代谢 1-2 小时/杯 | 见下方详细说明 |

**关于晚餐：**
- 晚餐应清淡，避免高油脂、高蛋白食物
- 如果感到饥饿，可以吃少量香蕉、温牛奶等助眠食物
- 不要大量饮水，以免夜起打断睡眠

### 技巧 5：不依赖酒精入睡

这是一个常见的误区。酒精确实可以让你**更快入睡**，但会严重破坏**睡眠质量**。

```
酒精对睡眠的影响：

┌─────┐                  ┌─────┐
│ 入睡 │                  │ 入睡 │
│ 速度 │    饮酒后         │ 速度 │    无酒精
│  ↑   │                  │ 正常 │
└─────┘                  └─────┘

┌──────────────┐          ┌──────────────┐
│   深睡  ↓    │          │   深睡  ↑    │
│  夜间觉醒 ↑  │          │  睡眠连续   │
│  快速眼动 ↓  │          │  快速眼动正常 │
│  后半夜质量差│          │  整夜质量好  │
└──────────────┘          └──────────────┘
```

> [!WARNING] 酒精与睡眠
> 酒精会抑制快速眼动睡眠（REM），导致记忆巩固受损、第二天注意力下降。酒精代谢后还会引起"反弹性觉醒"——后半夜频繁醒来。**用酒精助眠，是用睡眠质量换入睡速度，得不偿失。**

## 7. 应对失眠的布钦疗法

**布钦疗法**（Bootzin's Stimulus Control Therapy，刺激控制疗法）是被美国睡眠医学会认证的认知行为疗法核心组成部分，对慢性失眠效果显著。

### 核心原理

失眠者的典型问题：**床 = 焦虑 + 清醒**（条件反射）。布钦疗法的目标是将条件反射重新改为：**床 = 睡觉**。

### 六步操作指南

| 步骤 | 操作 | 说明 |
|:---|:---|:---|
| **第 1 步** | 困了才上床 | 不要因为"到点了"就上床，只有真正困了再进卧室 |
| **第 2 步** | 床只用来睡觉 | 不在床上玩手机、看书、看电视、工作或思考问题 |
| **第 3 步** | 睡不着就起床 | 如果躺下 20 分钟仍睡不着（凭感觉，不要看钟），**立刻起床**去另一个房间 |
| **第 4 步** | 在另一个房间做无聊的事 | 读枯燥的书、听白噪音，直到再次感到困意再回床 |
| **第 5 步** | 重复第 3-4 步 | 如果回去后还是睡不着，再次起床，循环直到快速入睡 |
| **第 6 步** | 每天固定时间起床 | 无论前一夜睡了多久，每天同一时间起床，白天不小睡 |

### 预期效果与注意事项

| 阶段 | 预期体验 | 应对心态 |
|:---|:---|:---|
| 第 1-2 周 | 可能睡眠更少，感觉疲惫 | 这是"重塑期"，坚持住 |
| 第 3-4 周 | 躺在床上开始感到困意 | 条件反射正在重建 |
| 第 5-6 周 | 上床后 10-15 分钟即可入睡 | 新习惯基本巩固 |
| 第 7 周+ | 稳定睡眠，不再恐惧"睡不着" | 完全建立床=睡觉的条件反射 |

> [!CAUTION] 布钦疗法注意事项
> - 执行期间避免白天小睡（包括午睡），否则会削弱夜间睡眠驱动力
> - 起床后不要看时间，看时间会增加焦虑
> - 如果坚持 6 周无改善，建议就医评估是否有其他睡眠障碍
> - 布钦疗法在短期内可能让睡眠时间更少，但长期效果远优于安眠药

---

**睡前不该做的三件事**：剧烈运动（让体温和心率升高）、大量进食（消化系统持续工作影响睡眠）、饮酒（虽然帮助入睡但破坏后半夜的深睡质量）。

## 本周行动清单

1. **选一个方法**：从光线法、双闹钟法、睡眠周期法中选一个尝试
2. **固定起床时间**：确定一个起床时间，接下来 7 天每天坚持（包括周末）
3. **设置双闹钟**：准备双闹钟，闹钟 B 放在房间另一侧
4. **建立睡前仪式**：睡前 1 小时关闭电子设备，做一件放松的事
5. **执行布钦疗法**：如果经常失眠，从今晚开始执行 6 步法
6. **记录睡眠日志**：每天记录上床时间、入睡耗时、起床时间、睡眠质量评分（1-10）

> [!TIP] Key Insight
> 早起不是目的，而是手段。早起的目的不是少睡，而是让你拥有高质量的生活。早起 + 高质量睡眠，是高效能人生的双引擎。

## Practice

> [!QUESTION] Self-check
> 1. 什么是"核心习惯"？为什么早起被认为是核心习惯中最值得优先养成的？
> 2. 请用自己的话解释双闹钟法的设计原理，以及它为什么有效。
> 3. 如果你需要在 6:00 起床，使用睡眠周期法，你应该在什么时间入睡？
> 4. 布钦疗法的六步分别是什么？为什么说短期可能让睡眠更少，但长期效果更好？
> 5. 请列出三个帮助调整生物钟的具体建议。

<details>
<summary>参考答案</summary>

1. **核心习惯**是指一旦养成会引发一系列积极连锁反应的习惯。早起被视为最值得优先养成的核心习惯，因为它会带动运动、健康饮食、高效工作、良好情绪等多方面的正面改变——这就是"多米诺骨牌效应"。

2. **双闹钟法**的原理是利用两个闹钟制造"不得不下床"的局面。闹钟 A（温柔型）放在床头，在目标时间轻柔唤醒；闹钟 B（粗暴型）放在房间另一侧，3 分钟后响起且音量最大。你为了不让 B 打扰家人或邻居，必须在 3 分钟内下床去关掉它——这个下床的动作本身就是有效的"唤醒仪式"。

3. 使用 5 个周期（7.5 小时），入睡时间应为 **22:30**；如果使用 6 个周期（9 小时），入睡时间应为 **21:00**。加上 15 分钟入睡缓冲，分别对应 22:15 上床或 20:45 上床。

4. 六步：困了才上床→床只用来睡觉→睡不着就起床→去另一个房间做无聊的事→重复→每天固定时间起床。**短期睡眠更少**是因为打破了过去"床=焦虑"的条件反射，需要时间重建"床=睡觉"的新条件反射，但长期效果优于安眠药。

5. ① 白天多晒自然光（尤其是早晨），抑制褪黑素、设定生物钟 ② 晚上远离手机/电脑的蓝光，睡前 1 小时不用电子设备 ③ 固定时间睡觉和起床，包括周末，不制造"社交时差"。

</details>
