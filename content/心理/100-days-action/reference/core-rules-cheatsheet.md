# 核心规则速查

> [!NOTE] 一句话总结
> 100天行动 = 选定**一个**习惯 → 设定**SMART+WOOP**目标 → **记录与可视化**打卡 → 运用**辅助规则**克服阻力 → 坚持**100天**形成自动化。

---

## 九大核心规则

| 规则 | 名称 | 核心思想 | 关键行动 |
|:----:|------|---------|---------|
| 1 | **一次一个习惯** | 意志力是有限资源，同时养成多个习惯必然失败 | 只选一个习惯，专注坚持100天，不贪多 |
| 2 | **SMART 目标** | 模糊目标无法执行，必须具体、可衡量、可达成、相关、有时限 | 将"我要运动"改为"每天晚饭后散步20分钟" |
| 3 | **WOOP 思维** | 愿望 + 结果 + 障碍 + 计划 = 可执行的行动预案 | 写下你的愿望、最好结果、最大障碍、如果-那么计划 |
| 4 | **记录与可视化** | 记录让进步可见，"别断链子"的视觉动力无可替代 | 每日在日历上打勾，保持链条不断 |
| 5 | **20 秒法则** | 增加坏习惯的启动阻力（+20秒），减少好习惯的启动阻力（-20秒） | 把想养成的习惯所需物品放在触手可及处 |
| 6 | **自我谅解** | 一次失败 ≠ 全盘放弃，自责只会加速放弃 | 犯错后对自己说"没关系，明天继续"，而不是"我完了" |
| 7 | **周总结与 ABC 策略** | 每周复盘 + 为困难情况准备三套方案 | 每周日回顾本周数据，为下周制定 A/B/C 三套计划 |
| 8 | **结构化日志** | 用"前提-行为-后果"模型分析行为，找到真正原因 | 每次坚持或放弃时写下：发生了什么、做了什么、结果如何 |
| 9 | **环境设计** | 环境对行为的影响远超意志力，设计环境而非对抗自己 | 清理诱惑源，布置提示物，让好习惯更容易 |

## 辅助规则

> [!TIP] 辅助规则是核心规则的补充，可根据个人情况自由组合使用。

| 辅助规则 | 说明 | 用法 |
|----------|------|------|
| **20 秒法则** | 减少好习惯的阻力（<20秒启动），增加坏习惯的阻力（>20秒才能拿到） | 吉他放在琴架上 vs 藏在琴盒里 |
| **仪式感** | 固定时间/地点/顺序的动作序列，形成条件反射 | 起床→喝水→铺床→冥想，形成固定晨间仪式 |
| **榜样人物** | 找到已经做到你想做的事的人，观察他们的方法和思维 | 关注一个你佩服的跑步达人，学习他的训练计划 |
| **ABC 策略** | A计划（理想情况）→ B计划（有干扰时）→ C计划（最差情况/底线策略） | A计划：晨跑5公里；B计划：午休快走30分钟；C计划：做10个俯卧撑 |
| **环境设计** | 清理诱惑、增加提示、利用默认效应 | 冰箱不放零食，水果放在最显眼的位置 |
| **拒绝技巧** | 四种方法拒绝干扰：破唱片法则、转移话题、缓冲话术、直接拒绝 | "谢谢邀请，但我正在坚持一个100天计划，这次就不去了" |
| **结构化日志** | A（前提）→ B（行为）→ C（后果）记录法 | 记录每次想吃甜食前的情绪、吃了多少、吃完的感受 |
| **群体打卡** | 利用社会压力和归属感提升坚持率 20-30% | 加入 100 天行动微信群，每日打卡 |

## 快速启动检查清单

### 第一步：准备（第1天）

- [ ] 选择一个最想养成的习惯（只选一个）
- [ ] 应用 SMART 原则写下具体目标
- [ ] 完成 WOOP 练习（写下来）
- [ ] 找到适合的记录工具（日历App/纸质日历/打卡应用）

### 第二步：环境布置（第1天）

- [ ] 应用 20 秒法则：减少好习惯的启动步骤
- [ ] 移除环境中坏习惯的触发物
- [ ] 设置视觉提示（便签、手机壁纸、待办清单置顶）

### 第三步：启动（第1-7天）

- [ ] 执行第一天行动，完成后立即记录
- [ ] 准备 3 套 ABC 方案
- [ ] 前 7 天只关注"做没做"，不关注"做得好不好"
- [ ] 每天在可视化工具上打勾

### 第四步：持续（第8-30天）

- [ ] 建立固定仪式（时间、地点、顺序）
- [ ] 每周日做一次周总结
- [ ] 遇到中断时运用自我谅解，第二天立即恢复
- [ ] 记录结构化日志，发现模式

### 第五步：巩固（第31-100天）

- [ ] 逐渐增加难度（渐进超载）
- [ ] 寻找伙伴或加入社群打卡
- [ ] 回顾前 30 天的记录，寻找改进点
- [ ] 第 100 天回顾整个旅程，规划下一个习惯

---

> [!WARNING] 黄金法则
> **完成比完美重要。** 在 100 天里，中断 1-2 天不影响最终结果，真正让你失败的是"中断后彻底放弃"。
