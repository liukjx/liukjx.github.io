# 心理学核心术语表

## 基础概念

| 术语 | 英文 | 简要解释 |
|------|------|----------|
| 亲密关系 | Intimate Relationship | 一段真实、安全的关系，双方可以做自己而不必伪装 |
| 正向意图 | Positive Intention | 在亲子互动中设立积极目标而非关注负面行为 |
| 正向催眠 | Positive Hypnosis | 吉利根提出的通过语言、画面、身体动作三重通道建立正向状态的沟通方式 |
| 创伤 | Trauma | 在发展过程中爱与恨失衡造成的心理损伤 |
| 固着 | Fixation | 心理发展停滞在某个早期阶段 |
| 退行 | Regression | 在压力下退回到早期发展阶段的防御机制 |
| 共情 | Empathy | 理解并感受他人情绪体验的能力 |
| 认知 | Cognition | 我们理解和组织经验的思维框架和假设 |
| 元认知 | Meta-cognition | 对认知的认知，即审视自己思维过程的能力 |
| 自我实现的预言 | Self-fulfilling Prophecy | 信念影响行为，最终使信念成为现实的心理现象 |

## 深度概念

| 术语 | 英文 | 简要解释 |
|------|------|----------|
| 真自我 | True Self | 以自身感觉为中心构建的自我，真实自体 |
| 假自我 | False Self | 以他人感觉为中心构建的自我，虚假自体 |
| 体验者 | Experiencer | 活在感觉和身体中，全情投入生命的人 |
| 观察者 | Observer | 用头脑评判、分析事物，与自身感受保持距离的人 |
| 共生 | Symbiosis | 两个人心理上未分化，彼此纠缠的依恋状态 |
| 分化 | Differentiation | 从共生状态中分离，建立独立自我的心理过程 |
| 死亡焦虑 | Death Anxiety | 对自我消亡的根本恐惧，常表现为过度控制 |
| 投射 | Projection | 将自己内心的感受和愿望归因于他人的心理机制 |
| 基石记忆 | Foundation Memory | 最早形成的核心创伤记忆，衍生出后续类似的痛苦体验 |
| 解离 | Dissociation | 精神与身体/感受分离的状态，如走神、麻木 |
