# 核心概念与术语表

## 核心概念

| 概念 | 英文 | 定义 | 关键要点 |
|------|------|------|----------|
| **5%改变** | 5% Change | 在不改变95%现状的前提下尝试5%的新可能 | 变化要小到不引起排异反应 |
| **扰动** | Perturbation | 恰到好处的刺激，让人更容易启动新行动 | 足够小、足够具体、有体验性 |
| **排异反应** | Rejection Response | 心理系统对变化产生的抵抗机制 | 新变化越大，排异越强 |
| **惯性** | Inertia | 维持现有状态的心理倾向 | 强大、狡猾、专注、有自我修复能力 |
| **向上螺旋** | Upward Spiral | 行动→状态好→更多行动的"正反馈循环" | 关键在迈出第一步 |
| **向下螺旋** | Downward Spiral | 状态差→不动→更差的"恶性循环" | 靠思考无法打破，只能靠行动 |
| **实验者心态** | Experimenter Mindset | 不对结果做预判，把建议变成实验 | 没有失败，只有结果 |
| **观察任务** | Observation Task | 不急于改变，先仔细记录问题细节 | 盯着问题看，问题就会"软化" |
| **防御性悲观** | Defensive Pessimism | 提前预设失败，为自己解压 | 释放压力后反而更能行动 |

## 五大工具箱

### 第一章：自我

| 术语 | 解释 |
|------|------|
| **外化的声音** | 把内心的冲突写成多个角色的对话 |
| **单双日作业** | 两种不同人生观各分配一半时间实现 |
| **黑色想象** | 假定最坏结果一定发生，然后思考应对 |
| **自律符号** | 用极小的象征性行为获得自律感 |
| **悖论干预** | 要求保持原状从而引出变化 |

### 第二章：原生家庭

| 术语 | 解释 |
|------|------|
| **课题分离** | 区分问题是谁的课题，谁的后果谁承担 |
| **目的论** | 一种行为持续存在是因为它达成了某种目的 |
| **互补关系** | 一方的行为由另一方的行为维持 |
| **重新解释** | 为同一件事换上不同的解释框架 |

### 第三章：工作与理想

| 术语 | 解释 |
|------|------|
| **去除评价** | 把"缺点"还原为"特点"，抛开对错判断 |
| **改写故事** | 换一个叙事角度来理解同一段经历 |
| **人与角色分离** | 区分"我是谁"和"我在这个场景下扮演什么角色" |
| **最小行动按钮** | 把大目标拆解成小到不可能失败的一步 |

### 第四章：亲密关系

| 术语 | 解释 |
|------|------|
| **新的沟通形式** | 改变沟通方式（写纸条、发语音等）而非内容 |
| **离开互补位置** | 停止维持对方问题的行为 |
| **家庭生命周期** | 家庭系统有不同发展阶段，每个阶段有不同的规则 |
| **去除三角化** | 不让第三方介入两人的直接关系 |

### 第五章：人际关系

| 术语 | 解释 |
|------|------|
| **接受不等于认同** | 承认事实不等于价值判断 |
| **可控与不可控** | 区分自己能控制的和不能控制的 |
| **身心链接** | 注意身体信号与人际压力的关系 |
