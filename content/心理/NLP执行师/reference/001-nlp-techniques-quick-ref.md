# NLP技巧速查

> 快速查找本课程中学到的NLP核心技巧。

## 情绪管理技巧

### 逐步抽离法
**用途**：将自己从负面情绪中分离出来

| 步骤 | 做法 |
|------|------|
| 1.定位 | 感受情绪在身体的哪个位置 |
| 2.具象化 | 给它颜色、形状、质地 |
| 3.封装 | 放进一个坚固容器中 |
| 4.远离 | 逐步把容器移远（1m → 5m → 10m） |
| 5.检查 | 感受身体变化，减轻了多少 |
| 6.学习 | 这份情绪想告诉我什么？ |

### 快速情绪调节（呼吸法）
- 深吸4秒 → 屏气2秒 → 慢呼6-8秒
- 重复3-5次
- 激活副交感神经，从压力状态恢复平静

### 打破状态
- 突然改变姿势、动作、话题
- 打断负面思维循环
- 重新定向注意力

## 沟通技巧

### 复述
重复对方的核心内容确认理解：
> "所以你的意思是……"
> "我听到你说的是……"

### 感性回应
在复述后表达对情绪的理解：
> "听起来这让你感到……"

### EQ型处理他人情绪四步法

| 步骤 | 做法 | 例句 |
|------|------|------|
| 1.肯定 | 承认对方情绪的存在 | "我看你很不开心" |
| 2.分享 | 倾听，不批判 | "愿意说说吗？" |
| 3.设范 | 在共情后建立边界 | "同时我们需要……" |
| 4.策划 | 一起面向未来想方案 | "你觉得接下来可以怎么做？" |

### 三不原则
- **不否定**对方的感受
- **不批判**对方的行为
- **不建议**（除非对方要求）

## 语言技巧

### 上堆下切
| 方向 | 问句 | 用途 |
|------|------|------|
| ↑ 上堆 | "这能给你带来什么？" | 探索意义和价值 |
| ↓ 下切 | "具体来说是什么？" | 找细节和证据 |
| → 平行 | "还有别的可能吗？" | 扩展思路 |

### 检定语言模式（Meta Model）

**三类语言漏洞**：
| 漏洞 | 例子 | 破解 |
|------|------|------|
| 删减 | "他不在乎我" | 具体他做了什么/没做什么？ |
| 扭曲 | "他让我生气" | 你如何解读他的行为？ |
| 一般化 | "没人理解我" | 真的没有人？有没有例外？ |

## 人际关系技巧

### 一分为二法
1. 区分一个人身上"不能接受的部分"和"有用的部分"
2. 放下不能接受的部分
3. 保留并使用有用的部分

### 接受批评法
1. 深呼吸保持平静
2. 把批评的内容和自己分开
3. 问：他说的是否有1%是真实的？
4. 有则改进，无则还给对方

## 目标与人生策划

### 有效目标六要素
1. **正面表述**（我要……，而非不要……）
2. **可验证**（有明确的完成标准）
3. **具体明确**（清晰无歧义）
4. **有起止点**（明确的时间范围）
5. **由己掌控**（不依赖他人）
6. **系统平衡**（三赢：我好你好系统好）

### 理解层次
| 层次 | 问题 | 应用 |
|------|------|------|
| 系统 | 为了谁？ | 使命与愿景 |
| 身份 | 我是谁？ | 角色定位 |
| 信念/价值 | 为什么重要？ | 驱动力 |
| 能力 | 怎么做？ | 技能策略 |
| 行为 | 做什么？ | 具体行动 |
| 环境 | 何时何地？ | 时空条件 |
