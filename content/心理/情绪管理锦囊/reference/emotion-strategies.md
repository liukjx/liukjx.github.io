# 情绪调节策略速查

## 消极情绪应对策略

### 愤怒控制4策略

| 策略 | 方法 | 适用场景 |
|------|------|----------|
| 认知重评 | 重新评估事件原因，改变思维方式 | 对事件原因有误解时 |
| 延迟反应 | 3分钟喘息，转移注意力 | 情绪即将爆发时 |
| 第三方帮助 | 找调停者客观分析 | 人际冲突中 |
| 转化为资源 | 用愤怒能量激发解决问题行动 | 需要行动力时 |

### 愤怒表达5部曲

1. **分散注意**：深呼吸，离开现场
2. **理清思绪**：复盘事件，找到真正原因
3. **表达不满**：描述行为+感受+原因
4. **提出方案**：用"当理...我觉得...我请你...是因为..."句式
5. **后悔药**：事后情境重评，吃一堑长一智

### 不正确的愤怒表达方式

- ❌ 责备和咒骂
- ❌ 向第三方抱怨（祥林嫂型）
- ❌ 冷战（冷暴力）

### 克服自卑4策略

1. **重新解读"不足"**：弱项可能是另一种优势
2. **设定合理目标**：不对自己过度苛求
3. **关注进步而非比较**：与自己赛跑
4. **培养自我慈悲**：接纳不完美

### 摆脱焦虑2工具

1. **认知行为工具**：识别并挑战灾难化思维
2. **正念呼吸工具**：专注当下呼吸，缓解杏仁核反应

### 走出抑郁方法

- 识别自动化消极思维
- 行为激活（逐步增加积极活动）
- 重建社会连接
- 寻求专业帮助

### 克服社恐方法

- 暴露疗法（逐步面对社交情境）
- 认知重建（挑战"被评判"恐惧）
- 降低完美主义标准
- 接纳不完美表现

## 积极情绪培育策略

### 启动4种快乐递质

| 神经递质 | 类型 | 激活方式 |
|----------|------|----------|
| 多巴胺 | 欲望 | 做热爱的事、唱歌、跳舞、旅游 |
| 内啡肽 | 减痛 | 运动、挑战困难、先苦后甜 |
| 催产素 | 爱的亲密 | 拥抱、陪伴、同理心对话 |
| 血清素 | 振奋 | 获得控制感、自主性、成就感 |

### 幸福感提升

- 区分快乐与幸福：快乐是即时的愉悦，幸福是有意义的快乐
- 创造幸福3秘诀
- 培养感恩之心

### 感叹培养

- 感恩日记
- 区分感恩 vs 报恩
- 关注已有而非缺失

### 平静3策略

1. **正念冥想**：关闭默认模式，获得深度安宁
2. **深呼吸**：缓慢吸气，激活副交感神经
3. **积极思维**：想愉悦放松的事

### 同理心提升

- 纳德拉同理心三原则
- 主动倾听
- 换位思考
- 情感共鸣

### 福流体验条件

- 明确目标
- 即时反馈
- 技能与挑战匹配
- 全神贯注
- 自我意识消失
- 时间扭曲感

## 通用情绪觉察方法

### 觉察愤怒的6个信号

| 信号 | 表现 |
|------|------|
| 被动攻击 | 冷嘲热讽、挖苦 |
| 开始反击 | 直面问题、开始说"不" |
| 公开责备 | 归咎于特定人 |
| 易激惹 | 小事也生气 |
| 环境不满 | 对团队/社会产生敌意 |
| 自我伤害 | 自责、抑郁、自毁倾向 |

## 常见情绪误区

| 误区 | 真相 |
|------|------|
| 情绪有好坏之分 | 情绪无好坏，是自然心理行为 |
| 控制情绪=压抑情绪 | 控制 ≠ 压抑，压抑导致更大问题 |
| 愤怒是坏事 | 适度愤怒激活生命力 |
| 优秀能克服自卑 | 追求优秀可能是自卑的过度补偿 |
| 快乐就是幸福 | 快乐是有意义的快乐
