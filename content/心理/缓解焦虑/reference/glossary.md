# 核心概念术语表

## 核心概念

| 术语 | 英文 | 定义 | 相关课程 |
|------|------|------|----------|
| 心理能量 | Psychological Energy | 荣格提出的人格动力系统，是一种普遍的生命力。能量高则人格独立稳定，能量低则依附他人 | 发刊词、全课程 |
| 内耗 | Internal Drain | 因内在冲突、自我攻击、过度思虑而导致的心理能量消耗 | 发刊词、第09课 |
| 快乐强迫症 | Happiness Compulsion | 强迫自己必须快乐的执念，无法接纳不快乐，反而加深焦虑 | 第02课 |
| 情绪拯救者 | Emotional Rescuer | 总是优先照顾他人情绪、背负他人情绪责任的人 | 第03课 |
| 心理边界 | Psychological Boundary | 区分自我与他人的心理界限，明确什么是自己的事、什么是别人的事 | 第16课 |
| 强迫性重复 | Repetition Compulsion | 无意识地重复童年创伤模式，在关系中不断复制熟悉的痛苦 | 第35课 |
| 反刍思维 | Ruminative Thinking | 反复思考同一负面事件或情绪，无法自拔的思维模式 | 第09课 |
| 认知融合 | Cognitive Fusion | 把想法等同于事实，被思维内容完全占据的心理状态 | 第09课 |
| 
| 内在小孩 | Inner Child | 人格中未被满足、未被疗愈的童年部分，常以情绪化方式呈现 | 第08课、第23课 |
| 攻击性 | Aggression | 人本能的驱力之一，健康的攻击性表现为自我主张和边界维护 | 第01课、第15课 |

## 情绪相关

| 术语 | 说明 | 相关课程 |
|------|------|----------|
| 负性情绪 | 即负面情绪，包括愤怒、悲伤、焦虑、自卑、抑郁等 | 全课程 |
| 情绪调节 | 对情绪的觉察、接纳与转化能力，而非压抑或逃避 | 第10课、第46课 |
| 哀悼 | 面对丧失时需要的心理过程，允许自己悲伤和低落 | 第05课 |
| 情绪价值 | 在关系中给予对方情感支持与理解的能力 | 第31课 |
| 情绪容纳 | 关系中一方能够承接另一方情绪的能力 | 第38课 |

## 关系相关

| 术语 | 说明 | 相关课程 |
|------|------|----------|
| 讨好型人格 | 通过满足他人来获得安全感和自我价值的人际模式 | 第01课、第14课 |
| 边界感 | 对自我与他人之间心理界限的觉察和坚持 | 第16课 |
| 课题分离 | 阿德勒心理学概念，区分"我的课题"和"他的课题" | 第16课 |
| 依恋模式 | 童年与主要照料者的关系模式，影响成年后的亲密关系 | 第33课 |
| 爱无能 | 无法建立真实情感连接、逃避亲密的心理状态 | 第32课 |
| 强迫性重复 | 在关系中无意识重复童年创伤的人际模式 | 第35课 |

## 自我成长相关

| 术语 | 说明 | 相关课程 |
|------|------|----------|
| 自我接纳 | 不加评判地接受自己的全部，包括缺点和负面情绪 | 第29课 |
| 自我慈悲 | 以善待自己的方式回应自己的痛苦和不足 | 第29课、第44课 |
| 自我价值感 | 对自身价值的感受和判断，不依附于外在成就 | 第25课、第40课 |
| 受害者认同 | 将自己固定在"被伤害者"角色中，放弃改变的主动权 | 第45课 |
| 内在标准 | 不依赖外界评价的、由自己确立的价值评判体系 | 第50课 |

## 心理学家与理论

| 人物/理论 | 贡献 | 相关课程 |
|-----------|------|----------|
| 荣格 (Carl Jung) | 提出"心理能量"概念 | 发刊词 |
| 弗洛伊德 (Freud) | 《哀悼与丧失》，阐述抑郁与丧失的关系 | 第02课、第05课 |
| 阿德勒 (Alfred Adler) | 自卑与超越理论、课题分离 | 第16课、第40课 |
| 温尼科特 (Winnicott) | "足够好的母亲"概念、抱持环境 | 第38课、第44课 |
| 约翰·鲍比 (John Bowlby) | 依恋理论 | 第33课 |
| 林清玄 | "人生不如意十之八九" | 第02课 |

## 日常用语对照

| 日常说法 | 心理学理解 |
|----------|------------|
| "我就是想太多" | 反刍思维 + 认知融合 |
| "我对TA那么好" | 过度付出，可能隐藏控制 |
| "我没办法拒绝" | 心理边界不清晰 + 讨好模式 |
| "我一定要快乐" | 快乐强迫症 + 情绪不接纳 |
| "我做错了"（反复自责） | 内疚感过度 + 自我攻击 |
| "我不够好" | 低自我价值感 + 内在批判者 |
|
