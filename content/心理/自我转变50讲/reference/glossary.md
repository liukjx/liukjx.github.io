# 核心术语表

| 术语 | 英文 | 定义 | 关键点 |
|------|------|------|--------|
| 自我转变 | Self-transformation | 新旧自我的更替，核心自我概念的变化 | 区别于日常改变，触及身份、关系、价值观等核心要素 |
| 响应召唤 | Responding to the Call | 转变的第一阶段，自我意志开始觉醒 | 包含缘起、冲突、容器、契机四个节点 |
| 脱离旧自我 | Letting Go of Old Self | 转变的第二阶段，与过去告别 | 包含失去、放逐、告别、迷茫四个节点 |
| 踏上新征程 | Embarking on New Journey | 转变的第三阶段，探索新的可能性 | 包含旧自我遗产、新守护者、实践探索三个节点 |
| 形成新自我 | Forming New Self | 转变的第四阶段，巩固新的自我 | 包含新指南针、现实炼金术、新信念、新故事四个节点 |
| "我想要" | "I Want" | 自我主导转变的关键力量，内心真实的愿望 | 经历了从模糊到清晰的过程 |
| 容器 | Container | 培育新自我的安全环境 | 可以是时间容器或关系容器 |
| 契机 | Turning Point | 推动选择的偶然生活事件 | 新旧自我无法共存时发生 |
| 保护性价值观 | Protected Values | 构成自我核心的、不可妥协的价值观 | 触及这些价值观的变化会引发强烈抵抗 |
| 思维窄化 | Narrowing of Thinking | 失去目标后，视野变得局限的心理状态 | 需要训练自己超越失去去看更大世界 |
| 中心自我 | Central Self | 当前主导身份认同的部分 | 转变涉及从中心到边缘的重组 |
| 边缘自我 | Peripheral Self | 尚未成为主导但可能发展的自我部分 | 爱好、兴趣经常是边缘自我的载体 |
| 新旧评价坐标 | Old/New Evaluation Framework | 从他人/社会评价切换到自我评价 | 这是形成新自我的关键一步 |
| 现实炼金术 | Reality Alchemy | 与现实的创造性互动方式 | 超越顺从和反抗的第三条道路 |
| 信念 | Belief | 从经验中长出的确定性认知 | 转变的最终产物之一 |
| 人生故事 | Life Story | 将转变经历整合成连贯的自我叙述 | 新自我的最终呈现形式 |

## 相关概念

- **自我三阶段**："我想要"经历的三个阶段——萌芽、冲突、清晰
- **关系的脱离四阶段**：从关系中断裂的四个心理阶段
- **小步子原理**：通过微小行动推进转变的方法
- **分界线**：区分旧自我和新自我的心理边界
- **求不得感**：想要却得不到的痛苦心理体验
- **被放逐感**：失去身份归属的心理体验
- **被抛弃感**：失去重要关系的心理体验
