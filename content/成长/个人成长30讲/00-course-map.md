# 课程地图

## 学习路径总览

本课程共30课，分为五大模块。建议按顺序学习，因为后面的概念（如课题分离、成长型思维）常在前面的基础上展开。

```mermaid
flowchart TD
    M0[导语] --> M1[模块一：接纳自己]
    M1 --> M2[模块二：做自己]
    M2 --> M3[模块三：经营关系]
    M2 --> M4[模块四：正确努力]
    M3 --> M5[模块五：实现改变]
    M4 --> M5
```

## 模块依赖说明

- **模块一（接纳自己）** 是基础，后续所有模块都建立在对自我的理解之上
- **模块二（做自己）** 和 **模块三（经营关系）** 互为补充，一个向内一个向外
- **模块四（正确努力）** 需要模块一的自我接纳做前提，否则努力会变成自我攻击
- **模块五（实现改变）** 是课程的集大成者，需要前面所有模块的认知积累
