# 时间管理核心术语表

## 核心模型

| 术语 | 含义 | 首次出现 |
|------|------|----------|
| **个人效能环** | 处理任何事情的四个环节：明确目标→制定计划→灵活执行→深度反思 | 发刊词/第21课 |
| **心静如水** | 时间管理的最佳状态——处理完事情后内心恢复平静 | 发刊词 |
| **螺旋上升** | 通过反思将过去经验升华，实现个人成长 | 第16课 |

## 目标模块

| 术语 | 含义 |
|------|------|
| **假大空全** | 目标无法实现的四个原因：假目标（一时激情）、大目标（超出能力）、空目标（无法落地）、全目标（啥都要）|
| **走脑** | 用理性分析制定目标，动力少、装备多、易放弃 |
| **走心** | 用内心感受制定目标，动力足、行动多、易坚持 |
| **五感写作法** | 用视觉/听觉/嗅觉/味觉/触觉写五年后的信，连接内心 |
| **GPS法** | 定义愿景→选择路径→阶段目标（把愿景落地成目标）|
| **快系统/慢系统** | 卡尼曼理论：快=无意识直觉，慢=有意识分析 |
| **三脑理论** | 原始脑（生存）、情绪脑（情感）、理智脑（认知）三层博弈 |
| **决策打分表** | 从热情、痛苦、时机三个维度给目标打分做取舍 |

## 计划模块

| 术语 | 含义 |
|------|------|
| **假计划** | 脑袋里做/备忘录式/过于严格/重要紧急四项线——四种没有行动力的计划 |
| **行动力四度理论** | 行动力 = 事情明确度 + 时间匹配度 + 精力充沛度 + 个人意愿度 |
| **衣柜整理法** | 收集（摊在床上）→ 明晰（分堆）→ 排程（搭配出门），每日计划方法 |
| **4D分类** | 立即去做/计划去做/授权去做/尽量别做 |
| **自然计划法** | 目标原则→展望结果→头脑风暴→组织梳理→下步行动（五步复杂任务分解）|
| **时间投资人** | 以投资视角使用时间：追求时间自由、配置时间资产、做时间定投 |
| **目标九宫格** | 八个方面分三层：根基层（健康/财富/人际）、平衡层（工作/家庭）、享受层（学习/体验/娱乐）|
| **顺流计划** | 用适合自己的方式做事，而不是强迫自己适应方法 |
| **碎片时间思考·大块时间执行** | 碎片时间构思、大块时间专注执行的节奏策略 |

## 执行模块

| 术语 | 含义 |
|------|------|
| **心理防御机制** | 面对压力时大脑自动启动的逃避机制，拖延的根源 |
| **拖延四因素** | 价值感不足、信心不足、分心冲动、反馈延迟 |
| **价值链法** | 把不想做的事和真正想要的目标关联，重新发现意义 |
| **优雅拒绝** | 说事实→谈感受→给建议（三明治拒绝法）|
| **番茄工作法** | 25分钟专注+5分钟休息，本质是增加反馈频率 |
| **任务化解三角形** | 搭梯子（降低难度）+ 找Keyman（找对的人）+ 去行动（行动中找到答案）|
| **加减乘除应变法** | 加法（记录）→减法（假设）→乘法（选择）→除法（反思）|
| **网事人书** | 四种快速学习新领域的方法：网络搜索→亲身实践→请教他人→阅读经典 |

## 反思模块

| 术语 | 含义 |
|------|------|
| **复盘** | 有推演地回顾，区别于总结（总结无推演）|
| **经验蓄水池** | 进水管（做事积累经验）出水管（未加工经验流走）的成长模型 |
| **4F复盘法** | Fact（事实）→ Feeling（感受）→ Finding（发现）→ Future（行动）|
| **周复盘六问** | 清空收集箱→浏览日程→梳理清单→回顾资料→Keyman交流→推进年目标 |
| **月复盘五步** | 目标核对→兴奋/沮丧→经验教训→满意度评分→新认识自己 |
| **移形换位法** | 站到六个不同角色位置（自己/同事/老板/父母/伴侣/孩子）看自己的一个月 |
| **标签vs封条** | 标签可撕掉（特点），封条永久（本性）。不要给自己贴封条 |
| **项目复盘四步法** | 回顾目标→评估结果→分析原因→总结经验 |
| **更新假设** | 复盘的终极目的：升级指导自己行为的底层假设 |

## 实战锦囊

| 术语 | 含义 |
|------|------|
| **效能卡点** | 卡在目标/计划/执行/反思四个环节之一，用对应问题突破 |
| **DO书法** | 以行动为导向的读书法（选行动页→记录行动→审视删除→画思维导图）|
| **功利性阅读** | 带着明确目的阅读（商业/方法论类书籍）|
| **非功利性阅读** | 享受阅读本身（小说/诗歌/散文）|
| **时间日志** | 记录时间实际花费，分析时间黑洞并修正行为 |
| **行为改变四阶段** | 事实→感受→分析→行动（缺一不可）|
| **SMART提问法** | 用SMART原则的五问与上级/同事建立共同目标 |
| **低头走路/抬头看路** | 专注执行 vs 全局审视，需要在两者间切换 |
| **习惯培养四阶段** | 新鲜感激情→方法技巧→渴求奖赏→习惯成自然 |
| **习惯培养卡片** | 定义成功+奖励/分段计划/if-then应对/签名（契约仪式）|
| **三条命法** | 每个月允许自己三次完不成计划，增加韧性 |
