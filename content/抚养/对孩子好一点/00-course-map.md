# 课程地图

## 学习路径

本课程分为四个模块，建议按顺序学习：

```mermaid

    M1[Module 1<br/>认识原生家庭] --> M2[Module 2<br/>养育的三根支柱]

    M2 --> M4[Module 4<br/>自我成长与家庭修复]
    M1 --> M4
    
    M1 --> L01[第01课：原生家庭是一切关系的投射]
    M1 --> L02[第02课：亲子关系如何投射到工作与婚姻]
    M1 --> L03[第03课：童年创伤的潜意识留存]
    M1 --> L04[第04课：潜意识、亲密关系与婚姻]
    M1 --> L05[第05课：简单体系 vs 复杂体系]
    
    M2 --> L06[第06课：无条件的爱]
    M2 --> L07[第07课：正确地爱孩子]

    M4 --> L14[第14课：改变三步法]
    M4 --> L15[第15课：感谢父母与家庭系统修复]
```

## 模块依赖关系

- **Module 1** 是所有模块的基础，必须先学
- **Module 2** 可以在 Module 1 之后学，是育儿的核心理念
- **Module 3** 需要 Module 2 的理解作为基础
- **Module 4** 可以从 Module 1 直接进入，也可以学完所有模块后再看
