# 第07课：正确地爱孩子——无条件的爱的实践

## 回忆上节课

[[0006-wu-tiao-jian-de-ai|第06课]]讲到：无条件的爱是三根支柱的**地基**，但生活中我们经常表达出的是**有条件的爱**。这节课我们进入实操——如何真正"正确地爱"。

## 用奖励交换的害处

很多父母习惯用交换来激励孩子："考到前三名，给你买自行车。"

但如果孩子没考好，你说："取消了，没有自行车了。"

> [!WARNING]
> 就这一刻，孩子立刻能感觉到——**你爱的是成绩，根本不是我**。

孩子心心念念一个学期，结果因为成绩没考好被取消奖励。伤害巨大——孩子会得出一个结论：**你并不爱我，你只是借助我去获得好的成绩，为了你的面子。**

### 交换的危害链条

```
用奖励交换 → 孩子失去内在动机 → 学习只为奖励，不是求知
→ 成绩好没奖励就没意义 → 成绩差被取消奖励 → 觉得父母不爱自己
→ 彻底放弃学习动力
```

## 孩子的逻辑：被奖励的才是好东西

心理学家做过一个测试：规定孩子**必须先吃完冰淇淋，才能吃芹菜**。结果孩子们抢着吃芹菜——因为他们认为"后来的那个、被用来当奖励的东西，一定是好东西"。

> [!TIP]
> 孩子对事物的价值判断，很大程度上来自**父母把它放在哪个位置**。
>
> 当你把"考第一名"和"买自行车"绑定，孩子自动得出逻辑：学习是糟糕的，自行车才是好东西。

樊登儿子的例子就是反面：家里从来不用交换。儿子成绩好不会额外奖励，成绩差也不会取消旅行。因为**"你是我的孩子，无论怎样我都爱你，这是无条件的。"**

结果是：孩子不需要拿学习来要挟父母，也不觉得学习是糟糕的事——**爸爸爱我，所以他给我的建议一定是对我好。**

## 不要附加条件

很多父母在不经意间把爱变成了"开玩笑"：

> 机场里，一个三岁孩子走路时踢了爸爸的脚。妈妈说："你再这样踢爸爸，**爸爸不爱你咯**。"

这句话在中国家庭里已经成为口头禅。孩子会记住：**"如果我好，他们就爱我；如果我不好，他们就不爱我。"**

> [!EXAMPLE]
> 樊登的家庭里，这种语言系统被彻底清除——不仅训练自己，还训练太太、岳父岳母、爷爷奶奶，甚至保姆。保姆离开时还会送手表表达感谢——"一家人"的感觉。

## 先表达爱 → 规范行为 → 重申爱

### 三步骤公式

```
第一步：先表达爱
"因为爸爸妈妈是爱你的，所以我们要规范你的行为。"
"因为爸爸妈妈是爱你的，所以爸爸要坚决反对你做这件事。"

第二步：规范行为
（明确告诉孩子哪里不对，为什么不对）

第三步：重申爱
"虽然爸爸今天批评了你，但是爸爸妈妈永远爱你。"
```

> [!TIP]
> 孩子不接受批评，是因为怕失去爱。如果你能确保每一次批评都**包裹在爱之中**，孩子就不会"一批评就炸"。

### 树的比喻

樊登有一次带着嘟嘟走在小区里，指着路边的树问：

"嘟嘟你看，有的树长得直，有的树长得弯。为什么？"

嘟嘟说："长得直的树，有人修剪吧？这个弯的树好像没人修剪。"

"那你知道了。你知道爸爸为什么有时候会向你提出要求和意见吗？"

"你在修剪我。"

"那你希望自己成为有修剪的、长得直直的树，还是没人修剪的、弯弯的树？"

"我希望长成一个直的树。"

> [!TIP]
> 用孩子能理解的语言沟通，"修剪"的比喻让孩子明白：**批评不是不爱，是为了让你长得更直。**

## 孩子不接受批评，因为怕失去爱

你见过"一批评就炸"的孩子吗？

孩子拼命捍卫自己没错，甚至用更叛逆的行为对抗——不是因为他倔强，而是因为他的潜意识在说：

> **"如果我错了，你就会不爱我。"**

孩子最不能承受的，就是失去父母的爱。所以他绝对不能认错。

### 如何判断你的孩子是否信任你？

| 健康的信号 | 危险的信号 |
|-----------|-----------|
| 被批评后能平静接受 | 被批评就炸、推卸责任 |
| 会说"爸爸我觉得老师说得不对" | 常说"这是老师说的，只能这样" |
| 会问"我这样处理，爸爸你觉得对吗" | 用老师的话来对抗父母 |
| 相信父母的判断 | 把父母当敌人 |

## 接受不完美

无条件的爱也包括接受孩子的**不完美**。

> 当你不断地让亮点变得越来越多，阴暗的地方会变得越来越少。但如果你整天盯着阴暗的部分，自己焦虑，爱的能量也表达不出来。

## 行动清单

1. **检查交换模式**：你在用哪些东西和孩子交换行为？（零食、玩具、iPad时间？）尝试一周不做任何交换。
2. **练习"三步骤批评"**：每次要批评孩子前，先走一遍"表达爱→规范行为→重申爱"。
3. **讲树的比喻**：带孩子看路边的树，让他自己得出"修剪才能长直"的结论。
4. **清除威胁式语言**：全家（包括老人和保姆）约定，绝不说"不爱你了""不要你了""不喜欢你了"。
5. **观察孩子被批评的反应**：如果你一批评他就炸，说明他怕失去你的爱——先从加强安全感开始。
