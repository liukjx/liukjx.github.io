## 从每件事中学习

成长型心态的最高境界是：**从生活的每一个事件中吸取养分，不断学习。**

这句话听起来简单，但大多数人的习惯模式是：

- 从失败中：自责、沮丧、放弃
- 从成功中：炫耀、满足、停下

成长型心态的人会：
- 从失败中：**"我从中学到了什么？"**
- 从成功中：**"还有什么可以做得更好？"**

> 比喻：同学聚会时，大家聊的是"买房了吗？多大？什么位置？几个孩子？"——在比较。但人生的维度是**完全不一样**的。

没有房子的人，依然可以活得很富足。比如香港那个收藏家，买了曾梵志早期所有的画，现在一幅值一个多亿，但他自己住在租房子里，把画捐给博物馆。他是真正热爱艺术的人，不是靠艺术赚钱的人。

> [!TIP]
> 不要用单一的维度（财富、排名、房子）来衡量人的价值。**终身成长的人，活在多个维度里。**

## 表扬过程和动机而非天赋

[[0010-cheng-zhang-xing-xin-tai|第10课]]提到表扬过程的重要性。这里再深入讲其**原理和操作**。

### 为什么不能表扬天赋？

当你对一个孩子说"你真聪明，你真有天赋"——

1. 孩子会觉得：**努力不重要**。努力恰恰说明我天赋不够（否则不需要努力）
2. 孩子会**回避挑战**——挑战可能暴露"我没天赋"
3. 孩子会把失败理解为"我没天赋"——归因固化，无法改变

### 正确的表扬方式

| 场景 | 错误的表扬 | 正确的表扬 |
|------|-----------|-----------|
| 钢琴弹得好 | "你真有音乐天赋" | "你今天练得很认真，我看到你反复练习了那段困难的节奏" |
| 考试考得好 | "你真聪明" | "你这次复习计划做得很好，坚持每天练习" |
| 画画画得好 | "你是小天才" | "你在配色上花了很多心思，这个尝试很有意思" |
| 比赛赢了 | "你天生是冠军" | "你的努力和坚持让你赢了这场比赛" |

### 樊登的亲身挑战

> 我也有虚荣心，希望大家觉得我有天赋。我讲课好，我一直告诉别人"我没准备"——这样显得更酷。
>
> 但事实上，我讲课的时间远超大量的人。我过去上台讲话紧张，腿发抖，把桌子都快踢翻了。**刻意练习，不断练，才是真相。**
>
> 所以我家嘟嘟弹钢琴时，我不表扬"你弹得好"，而是表扬"你今天练得真认真，你下了功夫，所以最近进步快"。

## 对挫折的反应

成长型心态最终的检验是**你对挫折的反应**。

### 父母的反应模式

| 孩子的挫折 | 固定型父母 | 成长型父母 |
|-----------|-----------|-----------|
| 考试只考了70分 | "怎么搞的！为什么别人能考好？" | "不错，从这次学到了什么？" |
| 忘做卷子背面 | "你这是什么态度！" | 笑一笑："以后怎么办？" |
| 比赛输了 | "你是不是不够努力" | "你从这个对手身上学到了什么？" |

### 嘟嘟的70分故事

> 嘟嘟回来告诉我考卷只考了70分。我问怎么考的。他说："背面还有题，没想到，光把正面的做完了。"
>
> 我笑了——你不觉得孩子犯错很萌吗？
>
> 然后我说："那么咱们要学什么？"
>
> 他说："以后把两面都看一下再交卷。"
>
> **很好。学会了。**

> [!TIP]
> 如果你能看到孩子犯错不再生气，而是觉得"萌萌的"——你的心态就调整好了。**你懂得珍惜孩子此刻可爱的瞬间。**

## 微软转型案例

微软的转型是成长型心态最经典的商业案例。

微软的CEO萨提亚·纳德拉上任后做的第一件事——向全公司推荐《终身成长》这本书。

> 微软之前是一个**天才性思维**的公司——"我必须证明我是这屋子里最聪明的人"。结果是大家互相推诿，有了问题互相责怪，"我不能错，都是你的错"。
>
> 纳德拉把微软变成了**成长型心态**的公司——"咱们能够学会什么？从这件事情中能吸取什么经验教训？"
>
> 结果：微软从落后多年回到市值第一。

> 这个案例说明：成长型心态不只用于教育孩子，它能用于**任何领域**——带团队、管公司、自己创业、学习进步。一通百通。

## 善待自己

> **你对自己之所以这么苛责，也是因为你小时候父母对你太过苛责。**

学习这件事，不只是如何当一个好的父母——**最重要的是更好地善待自己。**

| 固定型思维（苛责自己） | 成长型思维（善待自己）|
|----------------------|----------------------|
| "我怎么又没记住，我是不是脑子有病" | "我已经记住了一部分，继续积累" |
| "我学了好多次还是没学会，我太笨了" | "这次我比上次多理解了一点点" |
| 自责 → 难受 → 放弃 | 看到进步 → 开心 → 更愿意学 |

> 你把自己的心理调整好了，才能够有更多余力去管孩子。
>
> **你如果总是自责，心里难受，一定要找个人发泄——孩子就是那个发泄对象。**

## 良性循环 vs 恶性循环

### 恶性循环

```
苛责自己 → 心里难受 → 找孩子发泄
→ 伤害孩子自尊 → 孩子不配合
→ 更苛责自己 → 心里更难受 → 发泄更狠
```

### 良性循环

```
善待自己 → 看到自己的进步 → 心态轻松
→ 耐心对待孩子 → 看到孩子的亮点
→ 孩子的自尊水平上升 → 更自律 → 更轻松
```

> 选择权在你。**你可以选择做一个终身成长的人，也可以选择做一个固定型心态的人。**

## Module 2 核心原理总结

### 三条代码（复杂体系的原始动力）

1. **无条件的爱** → 归属感（第06-07课）
2. **价值感** → 自尊感（第08-09课）
3. **成长型心态** → 终身学习（第10-11课）

## 行动清单

1. **从今天起表扬过程**：每当孩子做出成绩，问自己"我是表扬了他的天赋还是过程？"
2. **把每一个挫折变成学习机会**：孩子遇到问题时，第一句话改成"我们从中学到了什么？"
3. **善待自己**：每天睡前回想一件自己做对的事，肯定自己的进步。
4. **检查你所在的循环**：良性还是恶性？意识到自己在哪个循环里，是改变的第一步。
5. **推荐阅读**：
   - 《终身成长》（卡罗尔·德韦克）
   - 《你就是孩子最好的玩具》（情感引导）
   - 《自卑与超越》（阿德勒）
