# 核心术语表

## A-C

| 术语 | 英文 | 解释 |
|---|---|---|
| 无条件的爱 | Unconditional Love | 不附带任何条件的爱，不是溺爱。先表达爱→规范行为→重申爱 |
| 归属感 | Belonging | 孩子知道"我属于这个家"，被无条件包容和接纳的感觉 |
| 成长型心态 | Growth Mindset | 相信能力可以通过努力和学习不断提升，每次挫折都是学习机会 |
| 固定型心态 | Fixed Mindset | 认为能力是天生的，做事是为了证明自己而不是学习 |
| 成瘾性人格 | Addictive Personality | 容易对烟酒、游戏、毒品等上瘾的人格特质，与父爱缺失相关 |
| 催产素 | Oxytocin | 让人感受到爱与亲密关系的激素 |

## D-J

| 术语 | 英文 | 解释 |
|---|---|---|
| 第一根支柱 | First Pillar | **无条件的爱**——家庭教育的地基 |
| 第二根支柱 | Second Pillar | **价值感**——让孩子感到自己有价值 |
| 第三根支柱 | Third Pillar | **成长型心态**——终身成长的能力 |
| 多巴胺 | Dopamine | 让人感到愉悦和满足的神经递质 |
| 反映情感 | Reflection of Feelings | 准确说出对方此刻的感受，帮助对方情绪平复 |
| 复杂体系 | Complex System | 因果关系不可追溯、非线性、进化论（如教育、养育） |
| 固定心态 | Fixed Mindset | 见"固定型心态" |

## M-Q

| 术语 | 英文 | 解释 |
|---|---|---|
| 秒变后妈 | - | 辅导作业时突然情绪失控，背后是童年创伤的触发 |
| 敏感度 | Sensitivity | 对周围评价/要求的敏感程度，顿感力低的表现 |
| 潜意识 | Subconscious/Unconscious | 未被意识到的心理内容，决定我们的行为模式 |
| 情感引导 | Emotion Coaching | 帮助孩子识别、理解和管理情绪的方法 |
| 资格感缺失 | - | "我没有幸福的资格"的心理状态，源于童年被抛弃/否定的经历 |

## R-Z

| 术语 | 英文 | 解释 |
|---|---|---|
| 肾上腺素 | Adrenaline | 让人处于应激状态的激素，打孩子导致孩子在体内积累过多肾上腺素 |
| 神经性背痛 | Psychogenic Back Pain | 心理问题导致的身体疼痛，通过心理治疗可缓解 |
| 斯德哥尔摩综合症 | Stockholm Syndrome | 人质爱上绑匪的心理现象，在家庭中表现为孩子对虐待自己的父母更加依恋 |
| 三根支柱 | Three Pillars | 无条件的爱 + 价值感 + 成长型心态 |
| 三千万词汇差距 | 30 Million Word Gap | 不同家庭背景的孩子在三岁前听到的词汇量差距 |
| 生活秩序 | Family Order | 父父子子、君君臣臣——家庭中的角色定位和秩序 |
| 价值感 | Self-Worth /Sense of Worth | 觉得自己有价值、有能力的感受 |
| 自尊水平 | Self-Esteem | 自律性来自自尊水平，自尊水平越高自律性越高 |
