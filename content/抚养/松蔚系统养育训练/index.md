# 李松蔚21天系统养育训练营

## 课程简介

本课程由李松蔚博士讲授，核心目标是帮助父母建立**系统养育**的思维方式——走出"孩子有问题需要修理"的单向思维，转向"亲子互动模式可以调整"的系统视角，让孩子在安全的亲子关系中逐步学会**自我负责**。

## 适合谁

- 3-16岁孩子的父母
- 希望改善亲子沟通、减少家庭冲突的父母
- 觉得"道理都懂但做不到"的父母
- 希望培养孩子独立性和责任感的父母

## 课程收获

课程结束后你将能够：

- 用 **共情式沟通** 走进孩子的内心世界
- 用 **激发式沟通** 唤醒孩子的内在动力
- 用 **约定式沟通** 和孩子一起制定并遵守规则
- 用 **视角转换式沟通** 化解亲子冲突
- 用 **赋能式沟通** 帮孩子在挫折中成长
- 用 **自我肯定式沟通** 管理好自己的情绪
