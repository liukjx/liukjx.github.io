# 第15课：儿童安全

## 学习目标

- 理解不同发育阶段孩子的受伤模式与预防策略
- 掌握家庭各房间（婴儿房、厨房、卫生间、车库、地下室）的安全要点
- 了解婴儿床、高脚餐椅、婴儿座椅、玩具等儿童用品的安全标准
- 学会正确选择、安装和使用汽车安全座椅
- 掌握外出时（背带、手推车、购物车、自行车、三轮车）的安全注意事项
- 了解游戏场地、水安全、动物相处、社区邻里的安全原则

---

## 一、孩子为什么会受伤（发育阶段与受伤模式）

### 受伤的三个因素

孩子受伤一般涉及三个因素：**孩子自身**、**导致伤害的事物**和**伤害发生的环境**。确保孩子安全必须同时重视这三个因素。

### 不同年龄段的受伤风险

| 年龄段 | 发育特点 | 主要受伤类型 | 预防要点 |
|--------|----------|--------------|----------|
| 0-6个月 | 无法自主移动 | 从高处坠落（床、尿布更换台） | 不单独留在高处 |
| 6-18个月 | 开始爬行、行走 | 触碰危险物品、从家具上坠落 | 创造安全环境，不以训诫代替看护 |
| 18个月-2岁 | 行动能力远超判断能力 | 误吞小物件、爬上高处、模仿大人 | 保管好药物和危险品，时刻监督 |
| 2-4岁 | 奇幻思维、自我中心 | 冲到马路上、玩火、向他人扔东西 | 定规矩并重复执行，严密看护 |

### 关键认知

> [!WARNING] 孩子不是故意不听话
> 6-18个月的孩子根本不会从训诫中吸取教训——他的记忆力还没有发育成熟。当你转身后，他还是会去触碰那些被禁止的东西。这并非顽皮，而是这个阶段正常的学习方式。

2-4岁的孩子往往相信自己的愿望可以控制事情的发生（**奇幻思维**），例如他划火柴只想到了电视中的篝火，而想不到火势会失控。

### 最容易发生伤害的紧张时期

- 孩子饥饿或疲劳时
- 母亲处于妊娠期
- 家中有人生病或去世
- 保姆更换
- 父母关系紧张
- 环境突然改变（搬新家、度假）

## 二、家庭安全总则与各房间安全要点

### 适用于所有房间的安全规则

- **烟雾探测器**：每层楼和每个卧室安装，每月检查
- **一氧化碳探测器**：家中必备
- **插座保护**：安装防窒息插座盖
- **楼梯防护**：楼梯顶部和底部安装儿童安全防护门
- **家具稳定**：书柜、梳妆台、电视柜靠墙固定；电视机安装在墙上
- **尖锐边角**：安装防撞脚和防撞条
- **窗帘绳索**：使用无绳窗帘，或将拉绳固定在高处
- **窗户安全**：安装护栏，纱窗不能防坠落；不在窗边摆放家具
- **纽扣电池**：存放在孩子够不到的地方，吞入为急症
- **塑料袋**：不要随意放置，打结后再丢弃

> [!IMPORTANT] 纽扣电池是致命危险
> 纽扣电池如果被孩子吞下，会造成严重的食道或胃肠道损伤，甚至可能导致死亡。如果怀疑孩子吞入或吸入了纽扣电池，必须马上送到医院急诊室。

### 厨房安全

厨房对孩子来说是最危险的房间之一。当与孩子一起在厨房时，应将其放在高脚餐椅或婴儿围栏中，并确保在视线范围内。

| 危险源 | 安全措施 |
|--------|----------|
| 洗涤剂/化学品 | 放在高处柜子并锁住；不用食物容器装危险品 |
| 刀具/剪刀 | 放在带锁的抽屉中 |
| 厨房电器 | 用后拔插头，电线不让孩子够到 |
| 锅具 | 把手转向炉子后方 |
| 燃气灶 | 关闭燃气阀门，使用防儿童遮盖物 |
| 微波炉 | 不加热婴儿奶（受热不均会烫伤） |
| 火柴/打火机 | 放在孩子看不到够不着的地方 |

### 洗衣房安全

- 洗衣凝珠色彩鲜艳如糖果，对幼儿有致命毒性，至少6岁前应避免使用
- 将洗涤剂放在高处带锁的柜子中
- 每次洗衣后清理洗衣垃圾盒以防火灾

### 卫生间安全

- **永远不要将孩子单独留在卫生间**，即使一分钟也不行
- 浴缸底部放防滑垫，水龙头加罩子
- 热水器最高温度不超过49°C
- 马桶盖养成盖上习惯，防止幼儿探身溺水
- 药物和化妆品锁在孩子够不到的柜子里
- 卫生间安装带接地故障断路器的安全插座

### 车库与地下室安全

- 门应自动关闭并上锁
- 涂料、油漆、杀虫剂、肥料放在带锁柜子里
- 工具（尤其是电动工具）锁好
- **不让孩子在车库和车道上玩耍**——倒车盲区致死事故频发
- 自动车库门确保反向功能正常
- 不在封闭车库中启动汽车（一氧化碳迅速聚集）
- 废弃冰箱/冰柜必须卸掉门

> [!WARNING] 车库前的悲剧
> 许多孩子是在车道上玩耍时被倒车的车辆无意撞死的。车辆有盲区，倒车摄像头也拍不到快速移动的小孩。切勿让孩子在车道或车库附近玩耍。

## 三、婴儿房安全

### 婴儿床安全标准

强烈推荐使用 **2011年6月以后生产** 的婴儿床（执行了更严格的安全标准）。旧式一边护栏可放下的婴儿床需要更换。

| 检查项目 | 安全要求 |
|----------|----------|
| 护栏栏杆间距 | < 6厘米，防止头部卡住 |
| 床头板/床尾板 | 无镂空设计 |
| 床角柱 | 与床头板等高或非常高 |
| 五金件 | 必须是原装，拧紧无松动 |
| 床垫大小 | 与床沿空隙＜两指 |
| 床板高度 | 会坐起前调低，会站立前调到最低 |

> [!WARNING] 婴儿床内不应放置的物品
> - 防撞护垫：可能导致窒息、被勒住、被困住
> - 枕头、被子、垫子、毛毯、毛绒玩具
> - 婴儿健身架（可能摔倒或砸到）
>
> 以上物品都有导致婴儿窒息的潜在风险。

### 尿布更换台安全

- 选购有四边5厘米高护栏、表面凹陷的结实台面
- 扣上安全带，但**不要完全依靠它**
- **永远不要将孩子独自留在更换台上**，即使被安全带扣住
- 用护臀膏代替爽身粉（爽身粉被吸入会伤害肺部）

### 双层床安全

> [!CAUTION] 不建议6岁以下儿童使用双层床上层
> 6岁以下孩子还没有完全具备安全爬上去和防止摔下来所需的动作协调性。

注意事项：
- 上层床垫大小合适，不超出床板边缘
- 上层安装护栏，护栏与床侧挡间距≤9厘米
- 床放在房间一角，两边有墙壁支撑
- 禁止孩子在双层床上跳跃、嬉戏、打闹

## 四、儿童用品安全

### 高脚餐椅

| 安全要点 | 说明 |
|----------|------|
| 底座 | 选择宽大的，不易翻倒 |
| 安全带 | 每次使用都扣好肩部、腰部和腿部安全带 |
| 位置 | 远离柜台、桌子和热源 |
| 监督 | 孩子坐餐椅时不要单独留下 |
| 可折叠式 | 确保所有固定装置锁死 |

### 婴儿座椅和摇椅

- 应有正规商标并符合安全标准
- **不要把婴儿座椅放在高于地面的地方**（桌子、工作台等）
- 不要用婴儿座椅代替汽车安全座椅
- 不要让孩子在座椅中无人看护

### 婴儿围栏

- 选择符合 ASTM F406 安全标准的产品
- 不要额外添加地垫（可能造成窒息）
- 网状围栏不能处于松弛状态
- 孩子会站立后移开所有盒子和大型玩具

### 学步车

> [!IMPORTANT] 美国儿科学会不推荐使用学步车
> 学步车会导致婴儿从楼梯上摔落并头部受伤，撞向家具可能导致家具倾倒砸伤婴儿。学步车不能帮助学习走路，反而会阻碍正常的运动发育。固定不动的学步装置或游戏架是更好的选择。

### 安抚奶嘴

| 要求 | 说明 |
|------|------|
| 奶嘴类型 | 买不会破裂的安抚奶嘴，不要用奶瓶奶嘴代替 |
| 挡板直径 | ≥3.8厘米，有通气口 |
| 安全 | 不要系在婴儿床上或孩子的脖子/手臂上 |
| 更换 | 变色或破裂立即更换 |

### 玩具安全

2017年美国急诊室收治了约25.1万名因玩具受伤的儿童，其中35%是5岁以下儿童。

**核心原则**：
- 根据年龄和能力选择合适的玩具
- 摇铃宽度至少4厘米，无可拆卸部件
- 小磁铁玩具对6岁以下儿童尤其危险（吞入后可能在体内互相吸引，造成肠道穿孔）
- 10岁以下儿童不要玩需要连电源的玩具
- 噪声超过100分贝的玩具可能损伤听力
- 弹射类玩具（飞镖枪、弹弓）不适合孩子玩

**玩具箱**：
- 最好选择没有盖子的玩具箱
- 有铰链盖子的需配有支撑支架
- 确保有通气口

## 五、汽车安全座椅

### 为什么必须使用汽车安全座椅

车祸是每年造成 **19岁以下儿童和青少年死亡人数最多** 的因素。坐在父母腿上实际上是最危险的——即使最身强力壮的成年人也无法在强烈碰撞中抱住孩子。

> [!WARNING] 不要被"短途"迷惑
> 最知名的车祸大多发生在离家8000米以内的范围，且汽车时速低于40千米。每次乘车都必须使用安全座椅，绝无例外。

### 汽车安全座椅的四大类型

| 类型 | 适用对象 | 关键说明 |
|------|----------|----------|
| 后向式 | 所有婴儿和幼儿 | 体重/身高未超过上限前，尽量延长后向使用时间 |
| 前向式（5点式安全带） | 幼儿和学龄前儿童 | 超过后向式上限后使用 |
| 增高型安全座椅 | 学龄儿童 | 身高/体重超过前向式上限后使用，直到能正常使用车载安全带 |
| 车载安全带 | 8-12岁以上 | 身高≥145cm，腿部可在座椅边缘弯曲 |

所有 **13岁以下** 的孩子都应该坐在 **汽车后排**。

### 选择汽车安全座椅的原则

1. 没有"最安全"的座椅——最适合孩子的身高体重、正确安装、每次都使用的就是最好的
2. 价格高不等于更安全
3. 不建议使用二手安全座椅（除非确认从未经历过碰撞、未被召回、所有标签和说明书齐全）
4. 生产商建议最多使用6年
5. 发生中等程度或严重车祸后应更换

### 安装要点

- 使用车载安全带或 **LATCH系统** 固定
- 安装后座椅前后左右摇晃幅度不应超过 **1英寸（2.54厘米）**
- 后向式安全座椅倾斜角度应正确，婴儿头向前倾说明角度不够
- 前向式安全座椅应使用**栓带**（顶部固定带）

### 使用注意事项

- 安全带应紧贴身体，不能用手捏起多余部分
- 冬季给孩子穿**多件薄衣**而非厚外套，安全带调紧后盖上毯子
- **永远不要将孩子单独留在车里**——炎热天气中10分钟即可致死
- 不要在车外让婴儿在汽车安全座椅中睡觉

> [!WARNING] 安全气囊与孩子不相容
> - 对13岁以下的孩子，汽车最安全的位置是后排
> - **永远不要**将后向式安全座椅放在有安全气囊的前排
> - 侧面安全气囊也需要正确安装安全座椅

### 防止遗忘孩子在车内的措施

- 把目的地需要用到的东西放在后座上（打开后门才能拿到）
- 孩子不在车里时，在安全座椅上放一个大型毛绒玩具；孩子上车时把玩具放到前排
- 让托儿机构在孩子未按时到达时打电话通知你

## 六、外出安全（背带、手推车、购物车、自行车）

### 婴儿背带

| 要求 | 说明 |
|------|------|
| 早产儿/呼吸疾病 | 不应使用垂直状态背带 |
| C形蜷曲 | 确保脖子伸直，下巴不压胸口 |
| 通气检查 | 确保口鼻不被布料或你的身体堵住 |
| 捡东西 | 屈膝不弯腰，防止孩子滑落 |
| 5个月以上 | 必须用固定带扣住 |

> [!WARNING] 婴儿背巾窒息风险
> 美国消费者产品安全委员会发出警示：用婴儿背巾背婴儿可能使其窒息。一定要确保头部在背巾外面，口鼻没有被堵住，始终能看到孩子的脸。

### 婴儿手推车

- 底座宽、不易翻倒
- 必须有容易操作的刹车和5点式安全带
- **不要在把手上悬挂包袋**——会使手推车向后倾倒
- 不要在打开或收起手推车时让孩子靠近（夹手指风险）
- 永远不要将孩子单独留在手推车中

### 购物车安全

> [!WARNING] 每年2万名以上儿童因购物车受伤送医
> 购物车极不稳定，将7.3kg的物品挂到把手上即可使其翻倒。应尽可能避免将孩子放在购物车座位上，可以用婴儿手推车或背带代替。

- 如果必须使用，确保孩子始终系着安全带
- 不允许孩子在购物车中站立、进入篮筐或骑在侧边上
- 不要将婴儿汽车安全座椅放在购物车上

### 自行车和三轮车

- 孩子至少到3岁左右才适合骑三轮车
- 选择车身低、轮子大的三轮车
- **每次骑车必须戴安全头盔**
- 穿包头鞋保护脚趾
- 不允许在机动车旁、车道或游泳池旁骑车
- 不要在孩子1岁前用自行车载他
- 大人骑自行车时不要用背带携带孩子

## 七、游戏场地与户外安全

### 游戏器械安全

| 要点 | 说明 |
|------|------|
| 年龄分离 | 5岁以下孩子远离大孩子玩耍区域 |
| 地面防护 | 秋千、攀爬架下方铺沙子/木屑/橡胶垫，厚度适宜 |
| 金属器械 | 夏季先检查温度，避免烫伤 |
| 秋千 | 柔韧材料座位，每次一个孩子，不从前后经过 |
| 滑梯 | 从梯子上爬，滑到底部迅速离开，先检查温度 |
| 攀爬架 | 4岁以下需密切监督 |
| 翘翘板 | 3-5岁需与年龄体重相仿的孩子一起 |

### 蹦蹦床安全

> [!WARNING] 美国儿科学会强烈反对年幼儿童玩蹦蹦床
> 美国每年约10万人次因玩蹦蹦床受伤，包括骨折、头部受伤、颈部或脊神经受伤。父母监督并不能完全避免伤害。

如果仍决定使用：
- 每次仅允许一个孩子
- 禁止翻筋斗
- 放在平地上，定期检查防护垫和弹跳网

### 院子安全

- 检查有毒植物（学龄前期植物是儿童中毒的首要因素）
- 使用环保除草剂/杀虫剂，施药后至少48小时内不让孩子在草坪上玩耍
- 除草时让孩子待在室内
- 烧烤架遮挡好，用完收起

## 八、水与动物安全

### 水安全

水是孩子遇到的最大的危险源之一——即使只有很少的水也可能溺水。

| 安全措施 | 说明 |
|----------|------|
| 成人看护 | 孩子在水中或水边时，成年人在**一臂距离内**进行接触式看护 |
| 游泳池围栏 | 至少1.2米高，有自动锁门，栏杆间距≤10厘米 |
| 小型水体 | 鱼塘、水桶、喷泉同样危险，用后倒空 |
| 救生衣 | 坐船或游泳时始终穿着，5岁以下使用带浮领的 |
| 心肺复苏 | 看护者应懂得心肺复苏术 |

> [!WARNING] 绝不可分心
> 孩子在水中的时候，看护者**不可使用手机、电脑或做其他事情**。一定要等孩子从水中出来再去做。

### 游泳课程

- 1岁以下不建议参加游泳活动
- 1-4岁可学习水中自救技能以降低溺水风险
- 4岁起可开始正式学习游泳
- 即使学会了游泳，孩子仍需要全程看护

### 动物安全

- 新生儿被带回家时，密切观察家中宠物的反应
- **千万不要让孩子单独与宠物待在一起**
- 5-6岁以下孩子还没有能力区分宠物和玩具
- 告诉孩子：遇到陌生狗时静静站着不动，不要跑、不要对视
- 选择性格温顺的宠物，年老宠物通常比幼小动物更安全
- 确保宠物接种狂犬疫苗
- 远离野生动物，发现异常动物通知卫生部门

## 九、社区与邻里安全

### 防止走失和被拐

| 措施 | 说明 |
|------|------|
| 外出时 | 始终留意孩子，约定每次出门要抓紧你的手 |
| 看护机构 | 确认只允许父母或委派人接走孩子 |
| 安全教育 | 教孩子不跟陌生人走、不上陌生人的车 |
| 求救 | 遇到危险大声叫喊，找到可信任的成年人 |

> [!TIP] 儿童拐卖的事实
> 儿童被陌生人拐卖的案件每年确实会发生，但在大多数儿童拐卖案件中，儿童多被监护人**以外的看护者**拐卖，而非陌生人。

### 祖父母/孙辈安全特别提醒

- 使用新婴儿床（2011年6月前生产的老式婴儿床不符合现行安全标准）
- 检查家中所有安全设备（烟雾探测器、灭火器、儿童防护门）
- 药物放在孩子看不到够不着的地方
- 购物时选择有低座儿童专用座的购物车
- 准备好安全头盔（让孩子选择喜欢的颜色和款式）

## 课程小结

儿童安全的核心原则是：**了解孩子的发育阶段、识别每个阶段的危险、创造安全的环境、时刻保持适当的监督**。大多数伤害不是随机的，而是可以预测和避免的。随着孩子不断成长，保护措施也需要随之调整。

> [!TIP] 关键理念
> 你不能改变孩子的年龄，对孩子天生的性格也影响甚微。因此，请把注意力集中在可能导致伤害的**物体和环境**上——通过创造一个安全的环境，让孩子尽情探索他想要的自由。

### 安全防护清单

- [ ] 家中安装烟雾探测器和一氧化碳探测器（每月检查）
- [ ] 家具（书柜、电视柜、梳妆台）已固定在墙上
- [ ] 婴儿床符合2011年6月后安全标准，床内无柔软物品
- [ ] 厨房危险品放在高处带锁柜中
- [ ] 卫生间热水温度不超过49°C
- [ ] 药物和化学品锁好
- [ ] 汽车安全座椅正确安装在后排
- [ ] 游泳池有1.2米以上围栏和自动锁门
- [ ] 家中无枪支，或已分处上锁存放
- [ ] 制定并演练了火灾逃生计划

## Worked Example

**情景**：小明1岁半，刚学会走路。妈妈在厨房做饭，把小明放在客厅玩玩具。突然电话响了，妈妈去接电话约2分钟。回到客厅发现小明已经爬上了书柜旁的椅子上，伸手去够书柜上的遥控器。

**分析**：
1. **发育阶段**：小明18个月，正处于"行动能力远超判断能力"的阶段，他对危险没有认知。
2. **环境危险**：书柜未固定、椅子靠近书柜使孩子能够攀爬、遥控器里有纽扣电池。
3. **建议措施**：
   - 将书柜固定在墙上
   - 不在窗边或书柜旁放置椅子等可攀爬的家具
   - 将含有纽扣电池的物品放在孩子够不到的高处
   - 接电话时带上孩子一起去，或将孩子放在安全围栏中
   - 所有危险品（包括遥控器）不放在孩子可接触的低矮处

## Practice

> [!QUESTION] 自测题
> 1. 孩子最容易发生伤害的紧张时期包括哪些？
> 2. 婴儿床内可以放置防撞护垫吗？为什么？
> 3. 13岁以下的孩子在汽车中最安全的位置是哪里？为什么？
> 4. 如果家中必须使用蹦蹦床，至少应遵守哪三项安全规则？
> 5. 纽扣电池被孩子吞入应该怎么办？

<details>
<summary>参考答案</summary>

1. 孩子饥饿或疲劳、母亲妊娠期、家人生病或去世、保姆更换、父母关系紧张、环境突然改变（搬新家/度假）。
2. **不可以**。防撞护垫没有证据表明能防撞伤，反而有导致婴儿窒息、被勒住或被困住的潜在风险。
3. **汽车后排**。前排安全气囊在爆开时会伤害孩子的头部和脊柱。后向式安全座椅绝对不能放在有安全气囊的前排。
4. ①每次仅允许一个孩子；②禁止翻筋斗；③大人从旁监督并让孩子遵守规则。
5. 必须**马上送到医院急诊室**。纽扣电池被吞入会严重损伤食道或胃肠道，甚至导致死亡，属于紧急事故。

</details>
