# 第20课：慢性健康问题

## 学习目标

- 理解慢性健康问题对家庭的情感、现实和生活影响
- 掌握如何与孩子坦诚沟通其慢性疾病
- 掌握缺铁性贫血的预防、症状和处理方法
- 了解囊性纤维化的遗传特点、症状和治疗原则
- 掌握1型儿童糖尿病的症状识别和日常管理
- 了解儿童HIV感染的传播途径和预防措施
- 了解镰状细胞病的症状、并发症和治疗

---

## 一、慢性健康问题概述

### 什么是慢性健康问题

慢性健康问题一般会迁延一年以上，需要持续的医疗护理。与急性健康问题（如伤口愈合、骨折、感染性疾病等可在短时间内恢复）不同，慢性健康问题需要长期管理。

> [!TIP] 慢性病的范围
> - 哮喘患儿每天都需要吸入药物以防发作
> - 糖尿病患者需要每日监测血糖和注射胰岛素
> - 有些问题（如尿床、足内翻）可能随长大自行消失
> - 慢性健康问题可能较轻，也可能发展为严重障碍

### 接受诊断时的常见情绪反应

无论孩子什么时候被诊断，父母都会经历一系列正常的情绪反应：

- **伤心、担忧、内疚或痛苦**——对孩子的期待被未知的恐惧替代
- **情绪起伏不定**——激动中夹杂着片刻安宁，对未知的拒绝和恐惧
- **孤独感**——觉得自己是世界上唯一有特殊需求孩子的父母
- **不堪重负**——需要大量时间、精力、金钱和情感投入

> [!IMPORTANT] 你不是一个人在战斗
> 你的忧伤和沮丧都是正常的。你的路途可能崎岖不平，但你也会遇到其他有相同经历的家长，你也会取得很多胜利。记住：**你的孩子始终是你的孩子，他不应该因疾病被贴上任何标签**。

### 慢性疾病家庭的压力来源

| 压力源 | 具体内容 |
|--------|----------|
| 医疗决策 | 选择医疗团队、了解诊断和预后、做治疗决定 |
| 日常护理 | 喂药、使用医疗器械、进行特殊疗法 |
| 资源协调 | 与专科医生、药剂师、治疗师、保险公司打交道 |
| 家庭平衡 | 不忽略其他家庭成员的需求 |
| 经济负担 | 医疗费用、保险、特殊教育支出 |

### 合理利用医疗资源

- 充分了解孩子的情况——多读资料、多向医生提问、多和其他患儿父母交流
- **记下你的问题**，确保都得到答案——不要等到下次见医生再问
- 记录和管理孩子在家的情况，确保遵从医疗护理建议
- 加入**父母互助小组**——获取资料、情感支持和其他治疗方法的信息

### 如何与孩子谈论慢性疾病

- **坦诚沟通**：如果不跟孩子说实话，他会觉得你在撒谎，产生被孤立和被排斥的感觉，而且往往会把事情想得更糟
- 使用明确和易于理解的语言
- 注意听孩子的回应，确认他的理解是否正确
- 请求亲人和朋友支持，不要一个人承担全部压力

### 与学校沟通

| 需要告知的信息 | 说明 |
|---------------|------|
| 健康问题 | 详细说明孩子的病情 |
| 治疗方案 | 白天需要哪些药和什么治疗 |
| 紧急联系 | 出现什么情况要打电话 |
| 急救培训 | 教工作人员识别和处理紧急情况 |

## 二、贫血

### 什么是贫血

贫血时，红细胞中的血红蛋白数量减少或红细胞数量减少，血液不能有效运输足够的氧气到全身，从而影响机体功能和发育。

### 缺铁性贫血——最常见的儿童贫血

> [!WARNING] 婴儿过早喝牛奶会导致缺铁性贫血
> 牛奶中铁元素非常少且不易吸收，还会干扰机体从其他食物中吸收铁。另外，牛奶可能刺激婴儿肠道引起少量出血。建议1岁前不喝牛奶，保证从辅食中摄入足量铁。

### 缺铁性贫血的原因

| 原因 | 说明 |
|------|------|
| 饮食缺铁 | 最常见原因，未摄入足够的含铁食物 |
| 过早喝牛奶 | 1岁前以牛奶代替母乳/配方奶 |
| 慢性失血 | 通过大便缓慢流失血液 |
| 吸收障碍 | 铁元素吸收不良 |

### 症状和体征

| 严重程度 | 症状 |
|----------|------|
| 轻度 | 可能无症状，或皮肤和黏膜轻度苍白（嘴唇、结膜、甲床粉红色变浅）|
| 中到重度 | 易怒、轻度虚弱、容易疲乏、气短、心率快、手足肿胀 |
| 持续贫血 | 影响正常生长发育 |
| 缺铁（未贫血） | 食欲下降、易怒、烦躁、注意力不集中、异食癖（吃冰块/尘土/黏土）|

### 诊断

大多数情况下，一次**血常规检查**即可确诊。

### 治疗

| 方法 | 说明 |
|------|------|
| 补铁剂 | 低龄婴儿用滴剂，大孩子用口服液或片剂 |
| 维生素C助攻 | 补铁后喝橙汁或吃新鲜水果促进吸收 |
| 避免与奶同服 | 牛奶妨碍铁元素吸收 |
| 疗程 | 遵医嘱定期检查，不可擅自停药 |

> [!CAUTION] 补铁剂过量会中毒
> 补铁剂摄入过量会引起中毒，必须放在孩子够不到的地方。补铁剂导致大便变深褐色或黑色是正常现象，不必担心。

### 预防

- 保证婴儿从辅食中摄入足量铁
- 1岁前不喝牛奶
- 含铁丰富的食物：红肉、肝脏、强化铁米粉、豆类、深绿色蔬菜

## 三、囊性纤维化

### 概述

囊性纤维化是影响寿命的美国常见儿童遗传性疾病，新生儿患病率约 **1/3500**。目前没有治愈方法，治疗方面已取得相当大的进展。

### 遗传特点

- 孩子必须从**父母双方**都继承致病基因才会患病
- 父母双方都携带致病基因时可以进行**基因筛查和遗传咨询**
- 孕妇可做产前检查判断胎儿是否携带基因

### 症状和体征

绝大多数囊性纤维化在出生后两年内诊断，超过一半的病例是因为**肺部反复感染**而被确诊。

| 系统 | 症状与表现 |
|------|-----------|
| 呼吸系统 | 呼吸道粘液比正常粘稠，难以咳出；持续性咳嗽；反复肺炎或支气管炎 |
| 消化系统 | 缺乏消化酶，难以消化脂肪和蛋白质；大便量多、体积大、有酸臭味 |
| 全身 | 体重减轻、发育迟缓 |

### 诊断方法

| 方法 | 说明 |
|------|------|
| 汗液试验 | 测量出汗时流失盐分的量——患儿汗液含盐量远多于健康孩子 |
| 基因检测 | 确认致病基因缺陷 |

### 治疗

囊性纤维化的治疗是终生的，需要多学科专家团队参与。

| 治疗方向 | 方法 |
|----------|------|
| 肺部感染 | 多种技术和药物帮助清除肺部浓稠分泌物；使用抗生素治疗肺炎 |
| 消化问题 | 每次吃饭和吃零食时服用含消化酶的胶囊；剂量取决于饮食成分和体重 |
| 整体管理 | 专科医院定期随访、监测治疗反应 |

> [!IMPORTANT] 像没有患病一样养育
> 绝大多数患儿在接受持续治疗后可以长大成人，过上充实的成年生活。除了极少数情况外，没有理由限制孩子的教育和职业目标。鼓励孩子发展并检验自己的能力。

## 四、糖尿病

### 1型糖尿病

胰腺不能分泌足够的胰岛素时引起1型糖尿病。胰岛素负责将葡萄糖从血液中运输到细胞里，为细胞提供能量。

#### 发病机制

| 步骤 | 说明 |
|------|------|
| 病因 | 免疫系统误攻击分泌胰岛素的细胞 |
| 遗传 | 仅约30%的患儿有近亲患糖尿病 |
| 不可预防 | 目前无法预防1型糖尿病 |
| 高发年龄 | 最常发生于学龄儿童 |

### 1型糖尿病 vs 2型糖尿病

| 特征 | 1型糖尿病 | 2型糖尿病 |
|------|-----------|-----------|
| 病因 | 免疫系统破坏胰岛细胞，胰岛素严重不足 | 身体不能恰当利用胰岛素，也无法产生足够胰岛素 |
| 患病年龄 | 各年龄段，常发于学龄儿童 | 年龄较大的儿童和青少年 |
| 与肥胖关系 | 无直接关系 | 85%的患儿为肥胖儿童 |
| 治疗 | 必须注射胰岛素 | 可口服药物或胰岛素 |

#### 警示症状（出现以下任何情况立即就医）

> [!WARNING] 糖尿病紧急症状
> - 排尿增多或频繁（如厕训练后的孩子可能开始尿床）
> - 口渴加剧
> - 食欲增加但体重减轻（或食欲持续降低）
> - 脱水
> - 无法解释的疲劳或乏力
> - 持续呕吐（尤其伴有虚弱或疲倦）
> - 视力模糊

#### 日常管理

| 管理项目 | 内容 |
|----------|------|
| 血糖监测 | 学会扎手指取血测量血糖 |
| 胰岛素注射 | 学会注射胰岛素；可转为便携式胰岛素泵 |
| 饮食管理 | 安排每天的三餐和零食 |
| 运动管理 | 合理安排孩子所需的运动量 |
| 学校沟通 | 教职工需了解病情、学会识别和处理低血糖 |

> [!TIP] 让孩子参与管理
> 对3岁以下的孩子，可以让他自己选择从哪根手指上取血，或在身体的哪个部位注射胰岛素。随着年龄增长，逐步教会他自己测血糖和注射胰岛素。

## 五、艾滋病毒感染和艾滋病

### 传播途径

儿童感染HIV的主要途径：

| 传播途径 | 说明 |
|----------|------|
| 母婴传播 | 感染HIV的母亲在怀孕、分娩或母乳喂养期间传给婴儿 |
| 血液传播 | 输入受污染的血液或血液制品 |
| 性传播 | 青少年中通过性接触传播 |

> [!IMPORTANT] 母婴传播可以有效预防
> 感染HIV的孕妇如果接受规范的抗病毒治疗，并在分娩时采取适当措施、避免母乳喂养，可以将母婴传播的风险降低到1%以下。

### 儿童HIV感染的特点

- 儿童HIV感染的病程进展比成人更快
- 早期诊断和治疗可以显著改善预后
- 症状可能包括：生长发育迟缓、反复感染、慢性腹泻、淋巴结肿大

### 治疗

- **抗逆转录病毒治疗（ART）** 是标准治疗方案
- 需要终身服药
- 定期监测病毒载量和CD4细胞计数
- 及时接种所有推荐疫苗（避免活疫苗）

### 心理与社会支持

- HIV感染儿童面临比疾病本身更大的挑战是社会歧视
- 帮助孩子建立健康的自我认知，不被疾病定义
- 保护隐私的同时，让学校和必要的照顾者了解情况

## 六、镰状细胞病

### 概述

镰状细胞病是一组影响红细胞的慢性遗传性疾病。患者的红细胞变成**镰刀型**，影响向全身运输氧的功能。

在美国，每年约2000名新生儿患病，多见于有非洲血统的人群，也见于印度、沙特阿拉伯、意大利、希腊、土耳其血统的孩子。

### 病理机制

| 正常红细胞 | 镰状细胞 |
|-----------|----------|
| 两面凹的圆盘形，可变形 | 镰刀型，形状异常 |
| 轻松在血管间穿行 | 具有粘性，聚集在一起 |
| 存活约120天 | 只存活几天 |

### 症状和体征

大多数患镰状细胞病的婴儿出生时看起来很健康，几个月大后症状开始显现。

| 症状 | 说明 |
|------|------|
| 手足发炎肿胀 | 通常是首先出现的症状 |
| 贫血 | 持续贫血 |
| 疼痛 | 骨骼、关节或腹部发作性疼痛（**镰状细胞危象**） |
| 皮肤苍白 | 血红蛋白减少 |
| 黄疸 | 红细胞破坏过多 |
| 易感染 | 感染风险增加 |
| 发育迟缓 | 长期影响 |

### 镰状细胞危象

孩子突然出现发作性疼痛（骨头、关节或腹部），可能持续数小时到数周。严重并发症包括：

- 肺炎
- 中风
- 器官损伤

### 治疗

| 方法 | 说明 |
|------|------|
| 预防性抗生素 | 从2个月大起服用至少到5岁，减少严重细菌感染 |
| 按时接种疫苗 | 接种所有推荐疫苗 |
| 羟基脲 | 9个月起服用，减少疼痛发作、肺炎和输血次数 |
| 经颅多普勒检查 | 2岁起每年一次，筛查中风风险 |
| 止痛 | 轻度疼痛用对乙酰氨基酚或非甾体抗炎药；热敷减轻疼痛 |
| 充分补水 | 非常重要 |
| 住院治疗 | 疼痛加重或出现并发症时：静脉止痛、抗生素、输血、吸氧 |

> [!WARNING] 发热是紧急信号
> 如果孩子出现发热，立即联系医生——这意味着孩子有可能出现了严重感染。患镰状细胞病的孩子，轻微症状可能很快发展为严重疾病。

### 生活方式建议

- 获得足够的休息和睡眠
- 喝足量的水
- 避免身体过热或过冷
- 医生可能推荐补充叶酸（帮助制造更多红细胞）

## 各慢性疾病概览对比

| 疾病 | 病因 | 主要症状 | 核心治疗 | 预后 |
|------|------|----------|----------|------|
| 缺铁性贫血 | 饮食铁摄入不足 | 苍白、疲乏、易怒 | 补铁剂+调整饮食 | 可治愈 |
| 囊性纤维化 | 遗传（父母双方携带基因） | 反复肺部感染、消化不良 | 清除分泌物+消化酶 | 可长大成人，无治愈方法 |
| 1型糖尿病 | 自身免疫破坏胰岛细胞 | 多饮多尿、体重减轻 | 胰岛素注射+血糖监测 | 需终身管理 |
| 镰状细胞病 | 遗传（血红蛋白结构异常） | 贫血、疼痛危象、易感染 | 预防性抗生素+止痛+羟基脲 | 需长期医疗护理 |

## 课程小结

慢性健康问题对家庭的影响是长期的、全方位的。关键在于：**接受诊断结果、积极获取知识、与医疗团队紧密合作、坦诚与孩子沟通、平衡家庭中各成员的需求**。每一种慢性疾病都有其特点和对应的管理策略，但共同的核心是——孩子始终是孩子，不应被疾病定义。

> [!TIP] 核心原则
> 孩子的治疗最终应该成为日常生活的一部分，而不是焦点。越是长期把他当成病人而不是正在成长的孩子来看待，他长大后就越有可能在社交和心理方面出问题。相对于保护来说，生病的孩子更需要你的鼓励。

### 家庭应对慢性病清单

- [ ] 接受诊断结果，允许自己感受正常的情绪反应
- [ ] 建立与医疗团队的沟通渠道，有问题及时联系医生
- [ ] 用笔记本记录所有问题和医生的回答
- [ ] 加入父母互助小组，与其他家庭交流经验
- [ ] 坦诚地与孩子谈论病情，使用明确易懂的语言
- [ ] 让孩子尽可能参与自己的疾病管理
- [ ] 与学校沟通，让老师了解孩子的医疗需求
- [ ] 平衡家中所有孩子的关注度
- [ ] 安排特别的活动，不让疾病阻止正常生活
- [ ] 照顾好自己——父母的身心健康直接影响孩子的照顾质量

## Worked Example

**情景**：3岁的莉莉最近变得容易疲劳、不爱玩耍，脸色苍白。妈妈带她去看儿科医生，血常规检查显示血红蛋白偏低，确诊为**缺铁性贫血**。

**分析**：
1. **原因排查**：莉莉1岁后开始喝牛奶，每天喝很多，但对含铁丰富的食物（红肉、肝脏、强化铁米粉）兴趣不大。
2. **治疗方案**：
   - 医生开具了儿童补铁剂（口服液），每天一次
   - 建议补铁后喝少量橙汁帮助吸收
   - 避免与牛奶同时服用
3. **家庭调整**：
   - 逐渐减少牛奶量至每天不超过500ml
   - 增加含铁丰富的食物：将碎牛肉加入粥中、用猪肝做成泥
   - 每日饮食中加入富含维生素C的水果
4. **随访**：治疗一个月后复查血常规，评估血红蛋白恢复情况

## Practice

> [!QUESTION] 自测题
> 1. 为什么婴儿过早喝牛奶会引发缺铁性贫血？
> 2. 囊性纤维化患者的肺部为什么容易反复感染？
> 3. 1型糖尿病和2型糖尿病的主要区别是什么？
> 4. 镰状细胞病患儿出现什么症状时必须立即联系医生？
> 5. 在孩子诊断慢性病后，父母应该如何与孩子谈论病情？

<details>
<summary>参考答案</summary>

1. 牛奶中铁元素非常少且不易被吸收，还会干扰机体从其他食物中吸收铁。牛奶也会刺激婴儿肠道引起少量出血导致血液流失，而且喝太多牛奶会使孩子对其他富含铁的食物缺乏兴趣。
2. 因为呼吸道中的粘液比正常情况下更稠，难以咳出，导致持续性咳嗽，容易引起肺炎或支气管炎。
3. 1型糖尿病是免疫系统破坏胰岛细胞导致胰岛素严重不足，与肥胖无关，各年龄段均可发病，必须注射胰岛素；2型糖尿病是身体不能恰当利用胰岛素，与肥胖密切相关，常见于较大儿童和青少年，可口服药物。
4. 出现**发热**时必须立即联系医生——意味着可能出现了严重感染。另外，突然出现骨骼、关节或腹部发作性疼痛也是需要警惕的镰状细胞危象信号。
5. 坦诚地告知孩子实际情况，使用明确和易于理解的语言。如果不跟孩子说实话，他会觉得你在撒谎，产生被孤立和被排斥的感觉。注意听他的回应，确认他的理解是否客观和正确。

</details>
