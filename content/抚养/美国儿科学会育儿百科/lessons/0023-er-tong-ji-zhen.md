# 第23课：儿童急诊

## 学习目标
- 识别真正的儿童急症并掌握基本应对原则
- 学习动物/人咬伤的伤口处理与风险评估
- 掌握烧烫伤的分级与紧急处理方法
- 了解呼吸道异物阻塞的预防与急救
- 掌握切割伤、擦伤的规范处理流程
- 了解溺水、电击伤、指尖损伤的急救措施
- 识别骨折症状与现场处置原则
- 掌握头部损伤的观察要点与就医指征
- 了解中毒的急救原则与预防措施

## 核心概念

儿童急症是指那些可能威胁生命或引起永久性损伤的情况，需要立即获得紧急医疗护理。

---

### 一、急症识别与应对

**常见急症原因：**
- 与机动车辆相关的损伤
- 被倒下的家具砸伤、高处坠落
- 中毒、烧伤或吸入烟雾
- 呼吸道异物阻塞
- 溺水（游泳池、浴缸等）
- 头部严重受伤、电击伤

**需要紧急医疗救护的症状：**

| 症状类别 | 具体表现 |
|---------|---------|
| 意识状态 | 行为异常、反应迟钝、昏迷 |
| 呼吸 | 呼吸困难、皮肤/嘴唇发青 |
| 出血/外伤 | 大面积/深度切割伤或烧伤、流血不止 |
| 神经系统 | 规律抽搐伴意识丧失、头部损伤后意识改变/严重头痛/呕吐 |
| 疼痛 | 严重持续性疼痛或加重 |
| 中毒 | 吞下/接触可疑有毒物质（即使无症状也要去急诊） |

**急症应对原则：**
1. 保持镇定
2. 孩子无反应+无呼吸 → 立即实施CPR
3. 拨打急救电话
4. 流血 → 用干净布持续按压出血部位
5. 抽风 → 放地板或床上，头转向一侧，**不要往嘴里放任何东西**
6. 带上孩子正在服用的所有药物和疫苗接种记录

> [!IMPORTANT] 催吐禁忌
> 除非医生特别指示，否则任何时候都不应催吐！催吐可能进一步损伤身体。

---

### 二、咬伤

**动物咬伤：** 大多数咬伤来自熟悉的动物（包括家养宠物）。美国每年47万例狗咬伤，60%是儿童。

**伤口处理：**
1. 持续按压出血部位5分钟或直到止血
2. 用清水和肥皂清洗伤口
3. 及时就医

**狂犬病风险评估：**
- 被野生动物咬伤风险更高
- 健康猫狗可观察10天
- 高风险需接受免疫球蛋白+狂犬病疫苗
- 狂犬病虽罕见但致命

**感染迹象（需立即就医）：**
- 伤口流出脓液、周围肿胀触痛
- 红线从伤口向外延伸
- 伤口上方淋巴结肿大

**人咬伤：** 清水和肥皂仔细清洗后就医。医生评估伤口、检查破伤风和乙肝疫苗接种情况。

> [!TIP] 心理创伤
> 被狗咬伤的孩子可能在伤后数周至数月内有恐惧、焦虑、噩梦等表现，需家人关心和支持。

---

### 三、烧烫伤

**分级：**

| 程度 | 表现 |
|------|------|
| 一度 | 皮肤发红，可能轻微肿胀 |
| 二度 | 疼痛、水泡、较严重肿胀 |
| 三度 | 感觉缺失，皮肤发白或发焦，损伤深层组织 |

**紧急处理：**
1. 立即用凉水冲洗伤处（足够长时间冷却）
2. **不要用冰块**（导致愈合缓慢）
3. 轻轻移除粘在伤处的衣物（粘住的不要强行撕）
4. 无渗出处用无菌纱布覆盖；有渗出处轻盖后立即就医
5. **不要涂黄油、油脂、芥末等**

**就医指征：** 比表面烫伤更严重、红肿疼痛持续数小时、电击伤、手部/嘴部/生殖器烧烫伤、化学物质烧伤

**预防：**
- 安装烟雾探测器（每月检查）
- 热水器最高水温不超过49°C
- 火柴/打火机锁在孩子够不到的地方
- 教孩子衣服着火时"停下、躺下、翻滚"

---

### 四、呼吸道异物阻塞

对7岁以下儿童尤其危险。最常引起事故的是食物。

**危险食物（<4岁避免）：**
- 整颗花生/坚果、整颗葡萄、火腿肠
- 硬/软/有黏性的糖果、维生素片
- 棉花糖、水果软糖、口香糖、爆米花

**危险物品：** 气球碎片、弹珠、硬币、小球、笔帽、磁铁、纽扣电池、安全别针

**预防原则：**
- 4岁前不给硬而光滑需咀嚼的食物
- 食物纵切后切成小块
- 进食时保持坐姿，在大人看护下
- 咀嚼时不要说话或大笑
- 为<3岁儿童选购玩具时注意年龄标注

> [!WARNING]
> 气道阻塞超过2-3分钟可能导致永久性损伤。

---

### 五、切割伤和擦伤

**止血原则：**
- 用无菌纱布或干净棉布**直接按压**出血位置5-10分钟
- 不要在止血前揭开纱布查看
- 不要用止血带（除非受过培训）
- 抬高受伤部位减少出血

**就医指征：**
- 伤口深或长≥1厘米
- 面部、胸部、背部的切割伤
- 伤口内有异物、边缘不能合拢
- 周围红肿/流脓
- 伤口需在8-12小时内得到修补

**擦伤处理：** 清水冲洗 → 温水和肥皂轻轻清洗 → 涂抗生素药膏 → 包扎 → 每天更换检查

> [!IMPORTANT]
> 不要使用含碘消毒液或酒精。结痂并非最佳恢复方式，它会减慢愈合过程并留下疤痕。

---

### 六、溺水

溺水是婴幼儿及较大儿童死亡的主要原因之一。

**防护要点：**
- **接触式看护：** 孩子在水里或靠近水时，成年人应距离一臂之内，**不**做分心的事（打电话、阅读、聊天）
- 家中游泳池周围安装≥1.2米高的栅栏，门自动关闭和锁住
- 所有人应学会CPR和游泳

**急救：**
1. 在不危及自身的前提下将孩子从水中捞出
2. 检查呼吸，如无呼吸立即实施CPR
3. 不要浪费时间挤水——集中精力恢复呼吸
4. 所有溺水孩子应接受全面医学检查
5. 曾停止呼吸/吸入水/丧失意识者应监护至少24小时

> [!DANGER]
> 浴缸、马桶中即使很少的水也可能让孩子溺水。对5岁以下儿童，绝​​不能单独留孩子在水边。

---

### 七、电击伤与指尖损伤

**电击伤急救：**
1. 关闭电源
2. 用**不导电材料**（木棍、卷起报纸、绳子）移开电线
3. 不要直接用手接触孩子
4. 切断电源后立即检查呼吸、肤色和反应
5. 所有遭受电击的孩子都应就医（内脏损伤难以发现）

**预防：** 插座安装保护盖、电线绝缘且孩子接触不到

**指尖损伤：**
- 夹伤后清洗伤口、冷敷、包扎
- 肿胀严重、切割伤深、甲床出血或疑似骨折 → 立即就医
- 不要自行拉直被夹断的手指

---

### 八、骨折

儿童骨骼更柔韧、骨膜更厚、自我修复潜力大。

**儿童特有骨折类型：**

| 类型 | 描述 |
|------|------|
| 青枝骨折 | 像嫩树枝折而不断 |
| 隆凸骨折 | 骨头被压弯但未完全断裂 |
| 弯曲骨折 | 骨头弯曲但没有断裂 |
| 骺板损伤 | 生长板损伤，需跟踪12-18个月 |

**症状：** 肿胀、疼痛、不能/不愿移动患肢

**现场处理：**
- 用袋子或卷起的报纸做简易夹板
- 就医前不要吃东西（可能需要全麻）
- 腿部骨折不要移动，打120叫救护车
- 开放性骨折：按压止血、纱布包扎，**不要将突出的骨头按回皮肤**

---

### 九、头部损伤与脑震荡

**轻微损伤（可居家观察）：**
- 孩子保持警觉和清醒
- 哭闹不超过10分钟
- 冷敷减轻肿胀
- 观察24-48小时

**紧急就医指征：**

| 症状 | 说明 |
|------|------|
| 过度困倦/不能叫醒 | 头部损伤后疲乏应在几小时内好转 |
| 持续呕吐或头痛 | 伤后4-6小时后呕吐不常见 |
| 持续严重脾气暴躁 | 可能表示婴儿头痛严重 |
| 协调/感觉/力气改变 | 肢体无力、口齿不清、斜视 |
| 昏迷/抽搐 | 昏迷>2-3分钟立即打120 |

**昏迷时注意事项：**
- 尽量不移动孩子（怀疑颈部损伤时尤其重要）
- 检查呼吸（无呼吸则实施CPR）
- 严重出血时用干净布直接按压
- 等救护车，不要自行送医

### 十、中毒

**中毒方式与急救：**

| 类型 | 急救措施 |
|------|---------|
| 入眼 | 温水持续冲洗内眼角15分钟后就医 |
| 皮肤接触 | 脱掉衣物，温水冲洗至少15分钟 |
| 吸入 | 抱到空气新鲜处，呼吸停止则实施CPR |
| 吞下 | 移开毒物，收集证据交给医生 |

**关键禁忌：**
- **不要催吐！** 呕吐可能加重损伤
- 不要使用吐根糖浆
- 不要扣嗓子眼或喂盐水催吐

**预防核心原则：**
- 所有药品和有毒物品**锁起来**
- 不要在食品容器中存放有毒物品
- 不把药物说成"糖果"
- 不在孩子面前服药

---

### 十一、安全建议

**CPR培训：** 美国儿科学会强烈建议所有父母和看护者完成CPR基本培训。

**家庭急救包必备物品：**
- 退烧/止痛药（对乙酰氨基酚或布洛芬）
- 抗组胺药、抗生素药膏
- 各种形状大小的创可贴、纱布垫、医用胶带
- 剪刀、镊子、肥皂、凡士林、湿巾、体温计

**药品安全管理：**
- 药品放在带锁柜子里
- 每次服药时开灯核对（防夜间喂药出错）
- 洗衣凝珠锁好，<6岁家庭最好使用传统洗衣粉/液

> 2. 孩子疑似中毒，吞下了不明液体，应该催吐吗？
> 3. 溺水急救时，第一件要做的事是什么？
> 4. 头部损伤后，哪些情况需要立即就医？

<details>
<summary>参考答案</summary>

1. **凉水冲洗**伤处足够长时间。不要用冰块，不要涂黄油/油脂。
2. **绝对不要催吐！** 收集毒物证据立即就医。
3. 在不危及自身的前提下捞出孩子，检查呼吸。如无呼吸立即实施CPR。
4. 过度困倦不能叫醒、持续呕吐/头痛、脾气暴躁、肢体无力/口齿不清/斜视、昏迷/抽搐。
