# 第26课：家庭问题

## 学习目标

- 理解如何向孩子告知收养事实及支持策略
- 识别虐待儿童的类型、迹象及报告责任
- 掌握帮助孩子应对父母离婚的方法
- 理解儿童对死亡和悲伤的分龄反应及应对策略
- 学会处理兄弟姐妹之间的竞争
- 了解单亲家庭和再婚家庭的挑战与支持策略
- 掌握多胞胎养育的关键要点

---

## 一、收养

### 如何告诉孩子他是被收养的

在孩子能够理解的时候（通常在2-4岁），就应让他知道关于亲生家庭和收养家庭的事，但要根据孩子的成熟程度决定告知信息量。

> [!TIP] 告知原则
> **诚实、简单、符合年龄**——"你的生父母非常爱你，但他们知道无法照顾你，所以他们找到了很喜欢孩子的人来照顾你。"

### 各年龄阶段沟通策略

| 年龄 | 策略 |
|------|------|
| **2-4岁** | 简单解释，用正面语言描述被收养的故事 |
| **学龄期** | 诚实回答具体问题，孩子不感兴趣时不要强加信息 |
| **青少年期** | 尊重孩子对自己故事的所有权，支持他寻找亲生父母的决定 |

### 关于寻找亲生父母

现在很多收养具有一定程度的公开性。即使是非公开收养，和孩子谈论他的亲生父母可以让他知道你理解他。让孩子知道，等他长大时，如果他愿意，你将帮助他寻找亲生父母。

> [!NOTE] 关键认知
> 孩子考虑亲生父母是谁的问题，**丝毫不会影响他（她）对你的爱**。和孩子谈论他的亲生父母，可以让他与你分享他的想法和情感。

### 来自美国儿科学会的建议

越来越多的孩子被同性恋的个人或家庭收养。科学文献表明，与一个或两个同性恋父母生活在一起的孩子，在情感发育、认知发育、社交能力发育和性发育上与异性恋父母的孩子成长得一样好。**父母的关爱和培养比性取向重要得多。**

## 二、虐待儿童

### 虐待的类型

| 类型 | 定义 | 特点 |
|------|------|------|
| **身体虐待** | 踢打、摇晃、烧烫或施加其他暴力 | 约每20个孩子中就有一个遭受过身体虐待 |
| **性虐待** | 孩子遭受不能理解或不同意的性行为 | 约1/5女孩和1/5男孩在18岁前遭受过 |
| **忽视** | 基本需求未能充分满足，造成实际或潜在伤害 | 包括生理、情感、医疗、教育忽视 |
| **情感虐待** | 言语虐待伤害孩子的自我价值感和情感健康 | 常与上述类型同时存在 |

> [!WARNING] 重要警示
> 超过**90%**的儿童性虐待受害者知道施虐者是谁，而且大多数性虐待发生在家庭中。教导孩子：如果他不愿意或感到不舒服，那么成年人接触他的身体就是不对的。

### 虐待迹象识别

**身体迹象：**
- 还不会翻身的婴儿出现任何损伤
- 4岁以下儿童躯干、耳朵或脖子有瘀青
- 与受伤方式描述不一致的损伤
- 体重未能增加或突然间显著增加
- 非医学原因的头痛或腹痛
- 外生殖器疼痛、出血或有分泌物
- 感染性传播疾病

**行为变化：**
- 恐惧行为、突然尿床或上厕所能力退化
- 离家出走、与年龄不相符的性行为
- 自信心突然改变、学校表现变差
- 极端消极或富有攻击性
- 胃口大增、偷食物

### 预防与报告

> [!IMPORTANT] 报告责任
> 如果你怀疑孩子被虐待了，**立即向当地儿童保护组织寻求帮助**。医生依法应向政府报告所有虐待儿童的疑似案例。

**预防措施：**
- 亲自监督孩子并参与孩子的活动
- 选择允许家长随时探望的看护机构
- 教导孩子基本安全法则：对违背意愿的事说"不"
- 保持与孩子的开放双向交流

## 三、离婚

### 不同年龄孩子的反应

| 年龄 | 典型反应 |
|------|----------|
| **2岁以下** | 变得异常黏人、依赖或沮丧；拒绝上床睡觉或夜间突然醒来 |
| **3岁以下** | 表现出悲伤和怕人；可能发脾气、食欲不振、如厕训练障碍 |
| **3-5岁** | 可能觉得自己造成了父母离婚；表现出攻击性，对父母一方不友好 |
| **学龄期** | 总是想着过去，长时间感到失落，节日和生日尤其痛苦 |

> [!TIP] 核心安慰
> 反复强调：**即使现在要在两个家庭生活，孩子还是被父母双方像原来一样疼爱，他仍然很安全。** 离婚不是孩子的错。

### 如何帮助孩子适应

1. **坦诚沟通**：用简单的话语回答孩子的问题，包括"爸爸为什么搬走了""我多久能见一次爸爸"
2. **不责备对方**：不要在孩子面前责备配偶或表达愤怒
3. **保持日常安排**：固定的活动、吃饭、睡觉时间能给孩子稳定感
4. **让孩子放心**：父母双方仍然爱他，不会抛弃他
5. **共同合作**：双方都积极参与孩子的生活，把分歧放在一边

### 监护安排注意事项

| 监护类型 | 优点 | 缺点 |
|----------|------|------|
| **单方监护** | 孩子有一个稳定的家 | 另一方可能从孩子生活中退出 |
| **共同监护** | 父母双方完全参与孩子生活 | 10岁以下孩子可能感到分裂在两个家庭 |

> [!WARNING]
> 为孩子应该看多少电视或吃什么食物而争吵，对孩子造成的伤害远远超过看电视和吃零食本身。如有需要，**在孩子不在的时候讨论这些问题**。

## 四、悲伤的反应

### 儿童对死亡理解的分龄特点

| 年龄 | 理解程度 | 行为表现 |
|------|----------|----------|
| **婴儿** | 无法理解 | 哭闹、食欲不振、难以被安抚 |
| **幼儿** | 不能理解死亡是永远的 | 哭闹、易激动、不配合、出现婴儿行为 |
| **学龄前** | 可能认为自己造成了死亡 | 脸上有悲伤神情，玩耍创造力和热情下降 |
| **学龄期** | 能理解死亡但可能感到内疚 | 可能变得沉闷、反复思考 |

### 帮助悲伤的孩子

- 尽量保持孩子熟悉的生活安排
- 用简单、真实的语言解释，不要编造童话故事
- 让孩子明白不是他做或想了什么导致亲人死亡
- 向爱你的人寻求帮助
- 在随后的数月和数年中，不要忌讳讨论失去的亲人

### 是否让孩子参加葬礼

| 条件 | 建议 |
|------|------|
| 孩子害怕、焦虑、不能理解葬礼目的 | 不应参加 |
| 孩子能理解情况且希望做最后道别 | 参加可能带来慰藉 |
| 决定参加 | 提前做好准备，安排专人带孩子提前离开 |

> [!NOTE]
> 一般来说，孩子会逐渐表现出恢复的迹象——一开始可能表现正常几个小时，然后是几天，最后是几周。如果4-6周内都没有正常阶段，应咨询儿科医生。

## 五、兄弟姐妹的竞争

### 竞争的特点

孩子之间的竞争是自然的，所有孩子都想要父母全部的爱和关心。当年龄差异在**1.5-3岁**时竞争最让人头疼，但即使差异9岁以上，大孩子仍然需要父母的爱。

| 年龄阶段 | 表现 |
|----------|------|
| **新生儿回家前** | 大孩子也要礼物，要求穿纸尿裤或从奶瓶喝水 |
| **新生儿回家后** | 爱哭、缠人、有更多需求，或变得沉默 |
| **小学阶段** | 对婴儿感兴趣但也通过攻击性行为获得关注 |
| **年龄渐长** | 较多接纳和保护，但也会有嫉妒 |

### 应对策略

- 不要对嫉妒反应过度，怨恨和沮丧是可以理解的
- 当大孩子模仿婴儿时，不要嘲笑或惩罚——告诉他不需要表现得像个婴儿也能获得爱
- 把私有物品和共享物品分开，减少空间争执
- **不要在孩子面前比较孩子**——"你姐姐总是比你干净"会使孩子讨厌你和姐姐
- 孩子争吵时最好不参与，让他们自己解决问题
- 使用暴力时必须干预，保护较小的孩子

> [!TIP]
> 与每个孩子单独相处很重要。即使每天只花**10-15分钟**与孩子进行他选择的活动，也会产生很大不同。

## 六、单亲家庭

### 单亲家庭的挑战与优势

| 挑战 | 优势 |
|------|------|
| 难以找到或承担儿童看护费用 | 可按照自己的信仰和规矩养育孩子 |
| 缺少分担日常照顾的人 | 与孩子之间的关系更亲密 |
| 容易劳累、心烦意乱 | 孩子可能更独立和成熟 |

### 给单亲父母的建议

- **好好照顾自己**：保证休息、锻炼和睡眠，定期离开孩子放松一下
- **不要感到内疚**：很多孩子在单亲家庭中成长得很好
- **设定严格但合理的规矩**：规矩明确一致时孩子感到安全
- **每天花时间与孩子在一起**：玩耍、聊天、阅读
- **建立支持网络**：与亲戚、朋友和社区保持积极联系

## 七、再婚家庭

### 再婚家庭的挑战

- 孩子可能因对亲生父母的忠诚而抵制继父母
- 继父母和孩子之间有嫉妒和争夺关注
- 双方都有孩子时情况更复杂

> [!TIP] 关键认知
> 继父母和继子女之间的关系是**慢慢发展的**，通常需要**一年或几年**，而不是几周或几个月。

### 融合建议

- 在住在一起前给孩子时间了解继父母
- 继父母和亲生父母共同决定规矩和期望
- 不要让再婚改变前任伴侣在孩子生活中的角色
- 所有大人（包括前任伴侣）参与影响孩子的重大决策
- 尊重孩子的意愿，如让他决定何时开始称呼继父母

### 成功的关键因素

| 因素 | 作用 |
|------|------|
| **亲生父母的支持** | 减少孩子的内疚感 |
| **所有成年人的良好交流** | 减少孩子适应不同价值观的困惑 |
| **共同的管教标准** | 帮助继父母建立权威角色 |
| **大人的耐心和努力** | 时间和磨合是关键 |

## 八、多胞胎

### 多胞胎养育要点

| 方面 | 建议 |
|------|------|
| **个体化** | 从一开始就把他们当成独立的个体，支持他们的不同点 |
| **分工发展** | 双胞胎可能各有所长，应定期分开让他们接触其他玩伴 |
| **与其他孩子** | 双胞胎会激起更强烈的兄弟姐妹竞争，每天与大孩子单独相处 |
| **上学安排** | 上小学后通常分在不同班 |
| **健康** | 多胞胎通常早产、体型小，注意汽车安全座椅的选择 |

### 双重身份

多胞胎既有作为个体的身份，也有作为双胞胎的身份。帮助他们理解和接受这两种身份之间的平衡，是父母面临的最有挑战的任务之一。

### 照顾好自己

> [!NOTE]
> 抚养双胞胎会比抚养一个孩子身体上更累，情感压力更大。**任何可以的时候赶紧补充睡眠**。可以与伴侣轮流喂夜奶，也可以请家庭成员和朋友帮忙。

## 场景案例：Worked Example

### 案例1：如何告诉4岁的孩子他是被收养的

**背景**：小明4岁了，父母一直纠结如何告诉他收养的事实。

**处理方案**：
1. 选择一个安静的下午，用简单正面的话语："你出生的时候，你的生父母非常爱你，但他们有些困难，所以找到了我们——我们一直想要一个孩子，我们很开心能成为你的父母。"
2. 观察孩子的反应，如果他点头或问简单问题，继续回答；如果他不感兴趣或走开，不强迫。
3. 后续根据孩子的年龄增长逐步补充更多信息。
4. 允许孩子表达任何感受，告诉他谈论这些是安全的。

### 案例2：父母离婚后如何安抚5岁的女儿

**背景**：女儿5岁，父母刚离婚，她开始尿床、发脾气，说"是我不好所以爸爸走了"。

**处理方案**：
1. 蹲下来直视她的眼睛："爸爸妈妈分开是我们大人之间的事，跟你一点关系都没有。你是一个很好的孩子。"
2. 保持固定的作息时间不变，包括吃饭、睡觉和上幼儿园。
3. 爸爸每周固定时间视频通话和周末见面。
4. 父母不在孩子面前讨论分歧和矛盾。
5. 观察到孩子情绪持续低落4周以上，咨询儿科医生。

### 案例3：双胞胎的个性培养

**背景**：同卵双胞胎兄弟3岁，总是穿一样的衣服，玩一样的玩具。

**处理方案**：
1. 开始给兄弟俩选择不同颜色的衣服。
2. 带他们分别参加不同的活动——哥哥去画画班，弟弟去音乐班。
3. 安排轮流和每个孩子单独相处15分钟。
4. 鼓励他们各自交朋友，而不是只和对方玩耍。

## 课程小结

家庭问题涵盖收养、虐待、离婚、悲伤、兄弟姐妹竞争、单亲、再婚和多胞胎等多个方面。处理这些问题的**核心原则是：坦诚沟通、尊重孩子的感受、保持稳定的生活安排、寻求专业帮助**。收养需要适龄告知，虐待必须及时识别和报告，离婚要减少对孩子的伤害，悲伤反应要分龄处理。了解这些家庭问题的应对策略，能帮助父母为孩子创造安全、健康的成长环境。

> [!TIP] 核心原则
> 无论家庭结构如何变化，**孩子最需要的是稳定、爱和安全感**。父母之间的合作、坦诚的沟通以及对孩子感受的尊重，是帮助孩子度过家庭变化的关键。
