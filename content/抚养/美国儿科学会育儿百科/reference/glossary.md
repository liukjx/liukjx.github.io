# 育儿百科术语表

> 本术语表收录课程中出现的关键医学及育儿术语，按拼音首字母排序，方便快速查阅。

## 新生儿反射

新生儿一出生就具备多种原始反射（primitive reflexes），这些反射是神经系统发育正常的重要标志。

| 术语 | 英文 | 解释 |
|------|------|------|
| 觅食反射 | Rooting Reflex | 轻触新生儿嘴角或脸颊，宝宝会转头朝向刺激方向并张开嘴。帮助宝宝找到乳头/奶嘴，约4个月时消失。详见 [[lessons/0005-liao-jie-ni-de-xin-sheng-er\|第05课：了解你的新生儿]] |
| 吮吸反射 | Sucking Reflex | 乳头或奶嘴放入宝宝口中时，宝宝会自动开始吮吸。与觅食反射配合完成喂养动作。 |
| 惊跳反射 | Moro Reflex / Startle Reflex | 突然的声音或头部位置变化使宝宝双臂向外伸展、手指张开，然后收回抱胸。约2个月时消失。 |
| 强直性颈部反射 | Tonic Neck Reflex / Fencing Reflex | 宝宝头部转向一侧时，同侧手臂伸直、对侧手臂弯曲，呈击剑姿势。约5-7个月时消失。 |
| 踏步反射 | Stepping Reflex | 扶住宝宝腋下使其脚底接触平面，宝宝会做出类似踏步的动作。约2个月时消失。 |
| 抓握反射 | Palmar Grasp Reflex | 刺激宝宝手掌时，宝宝会紧紧握住刺激物。约5-6个月时消失。 |
| 巴宾斯基反射 | Babinski Reflex | 轻划宝宝脚底外侧，宝宝的大脚趾会向上翘起、其他脚趾呈扇形展开。约1-2岁时消失。 |

## A-D

| 术语 | 英文 | 解释 |
|------|------|------|
| ADHD | Attention Deficit Hyperactivity Disorder | 注意力缺陷多动障碍，表现为注意力不集中、多动、冲动行为。详见 [[lessons/0018-xing-wei-wen-ti\|第18课：儿童行为问题]] |
| Apgar评分 | Apgar Score | 新生儿出生后1分钟和5分钟进行的快速健康评估，从心率、呼吸、肌张力、反射反应和肤色5个方面评分（每项0-2分，总分10分）。详见 [[lessons/0005-liao-jie-ni-de-xin-sheng-er\|第05课：了解你的新生儿]] |
| 百白破疫苗 | DTaP / DTP | 预防百日咳、白喉、破伤风的联合疫苗。详见 [[lessons/0031-yi-miao-jie-zhong\|第31课：疫苗接种]] |
| 扁平足 | Flat Feet / Pes Planus | 足弓塌陷，脚底几乎完全接触地面。多数儿童扁平足无需治疗，随发育自行改善。详见 [[lessons/0032-ji-rou-gu-ge-wen-ti\|第32课：肌肉和骨骼问题]] |
| 肠套叠 | Intussusception | 一段肠管套入相邻肠管，引起肠梗阻。典型症状为间歇性剧烈腹痛伴果酱样血便，需紧急就医。详见 [[lessons/0016-fu-bu-xiao-hua-wen-ti\|第16课：腹部与消化道问题]] |
| 川崎病 | Kawasaki Disease | 一种急性全身性血管炎，典型症状包括持续高热>5天、结膜充血、草莓舌、皮疹、手足肿胀。可累及冠状动脉，需及时治疗。详见 [[lessons/0030-xin-zang-wen-ti\|第30课：心脏问题]] |

## F-J

| 术语 | 英文 | 解释 |
|------|------|------|
| 发育里程碑 | Developmental Milestones | 儿童在特定年龄阶段应达到的能力标准，包括大运动、精细运动、语言、社交情感等方面。详见 [[lessons/0007-1-3-yue-ling\|第07课]] 至 [[lessons/0013-4-5-sui\|第13课]] |
| 分离焦虑 | Separation Anxiety | 婴幼儿在与主要照护者分离时表现出的焦虑、哭闹和抗拒行为。通常在6-8个月开始出现，1岁半左右达到高峰，随后逐渐减轻。详见 [[lessons/0009-8-12-yue-ling\|第09课：8-12月龄]] |
| 辅食 | Complementary Feeding / Solids | 除母乳或配方奶外，为满足婴儿生长发育需要而添加的其他食物。通常在6个月左右开始添加。详见 [[lessons/0008-4-7-yue-ling\|第08课：4-7月龄]] |
| 囟门 | Fontanelle / Soft Spot | 婴儿头骨之间的软组织间隙。前囟（头顶）通常在12-18个月闭合，后囟（脑后）在2-3个月闭合。详见 [[lessons/0005-liao-jie-ni-de-xin-sheng-er\|第05课：了解你的新生儿]] |
| 黄疸 | Jaundice | 新生儿皮肤和眼白发黄，由体内胆红素水平过高引起。生理性黄疸通常无需治疗，病理性黄疸需光疗等干预。详见 [[lessons/0004-xin-sheng-er-ri-chang-hu-li\|第04课：新生儿日常护理]] |
| 脐疝 | Umbilical Hernia | 脐部周围腹壁肌肉未完全闭合导致腹腔内容物膨出。大多数脐疝在1-2岁内自行愈合。详见 [[lessons/0006-di-1-ge-yue\|第06课：第1个月]] |
| 急性中耳炎 | Acute Otitis Media | 中耳的急性感染，常见于婴幼儿，表现为耳痛、发热、烦躁不安。详见 [[lessons/0022-er-bi-yan-hou-wen-ti\|第22课：耳鼻咽喉问题]] |
| 脊髓灰质炎疫苗 | IPV / Polio Vaccine | 预防脊髓灰质炎（小儿麻痹症）的疫苗。详见 [[lessons/0031-yi-miao-jie-zhong\|第31课：疫苗接种]] |
| 惊厥 | Convulsion / Seizure | 大脑异常电活动引起的肌肉抽搐、意识改变等症状。热性惊厥在儿童中较常见，通常预后良好。详见 [[lessons/0027-fa-re\|第27课：发热]] |

## K-R

| 术语 | 英文 | 解释 |
|------|------|------|
| 髋关节发育不良 | Developmental Dysplasia of the Hip (DDH) | 髋关节发育异常导致髋臼对股骨头的覆盖不足，可能影响行走。新生儿筛查可早期发现和治疗。详见 [[lessons/0032-ji-rou-gu-ge-wen-ti\|第32课：肌肉和骨骼问题]] |
| 麻腮风疫苗 | MMR Vaccine | 预防麻疹、腮腺炎和风疹的联合疫苗。通常在12-15个月和4-6岁时各接种一剂。详见 [[lessons/0031-yi-miao-jie-zhong\|第31课：疫苗接种]] |
| 脑膜炎 | Meningitis | 脑膜（包裹脑和脊髓的保护膜）的炎症，可由细菌或病毒感染引起。细菌性脑膜炎是儿科急症。详见 [[lessons/0029-tou-jing-shen-jing-wen-ti\|第29课：头颈和神经系统问题]] |
| 诺如病毒 | Norovirus | 引起急性胃肠炎的常见病毒，表现为呕吐、腹泻、腹痛。具高度传染性。详见 [[lessons/0016-fu-bu-xiao-hua-wen-ti\|第16课：腹部与消化道问题]] |
| 热性惊厥 | Febrile Seizure | 发热引起的惊厥发作，常见于6个月至5岁儿童。多数为单纯性热性惊厥，不造成脑损伤。详见 [[lessons/0027-fa-re\|第27课：发热]] |
| 如厕训练 | Toilet Training / Potty Training | 教会儿童使用马桶排便排尿的过程。多数儿童在2-3岁间准备好开始训练。详见 [[lessons/0010-1-sui-bao-bao\|第10课：1岁宝宝]] |
| 乳牙 | Primary Teeth / Baby Teeth | 儿童的第一副牙齿，共20颗，通常在6个月左右开始萌出，2-3岁出齐。详见 [[lessons/0008-4-7-yue-ling\|第08课：4-7月龄]] |
| 生长曲线 | Growth Chart / Growth Curve | 用于追踪和评估儿童身高、体重、头围等生长指标的标准化图表，帮助判断生长是否正常。详见 [[lessons/0006-di-1-ge-yue\|第06课：第1个月]] |

## S-Z

| 术语 | 英文 | 解释 |
|------|------|------|
| 水痘疫苗 | Varicella Vaccine | 预防水痘-带状疱疹病毒的疫苗。详见 [[lessons/0031-yi-miao-jie-zhong\|第31课：疫苗接种]] |
| 睡眠呼吸暂停 | Sleep Apnea | 睡眠中反复出现呼吸暂停的现象。儿童中常见原因为扁桃体/腺样体肥大。详见 [[lessons/0034-shui-mian-wen-ti\|第34课：睡眠问题]] |
| 陌生人焦虑 | Stranger Anxiety | 婴幼儿对陌生人的警惕和恐惧反应，通常在6-12个月间出现，是正常的发育阶段。详见 [[lessons/0009-8-12-yue-ling\|第09课：8-12月龄]] |
| 胎记 | Birthmark | 出生时或出生后不久出现的皮肤色素异常或血管异常。常见类型包括蒙古斑、草莓状血管瘤、葡萄酒色斑等。详见 [[lessons/0033-pi-fu-wen-ti\|第33课：皮肤问题]] |
| 脱水 | Dehydration | 体内水分和电解质不足的状态。婴幼儿脱水风险较高，表现为口干、尿少、哭时无泪、眼窝凹陷等。详见 [[lessons/0016-fu-bu-xiao-hua-wen-ti\|第16课：腹部与消化道问题]] |
| 哮喘 | Asthma | 一种慢性气道炎症性疾病，表现为反复发作的喘息、气促、胸闷和咳嗽。详见 [[lessons/0017-xiao-chuan-guo-min\|第17课：哮喘与过敏]] |
| 斜颈 | Torticollis | 颈部肌肉紧张导致头部向一侧倾斜，是婴儿期常见问题。早期物理治疗多数可纠正。 |
| 斜视 | Strabismus | 双眼不能同时注视同一目标，一只眼注视时另一只眼偏斜。需早期诊断和治疗以预防弱视。详见 [[lessons/0025-yan-bu-wen-ti\|第25课：眼部问题]] |
| 新生儿筛查 | Newborn Screening | 出生后对新生儿进行的遗传代谢病、听力、先天性心脏病等疾病的早期筛查。详见 [[lessons/0004-xin-sheng-er-ri-chang-hu-li\|第04课：新生儿日常护理]] |
| 猩红热 | Scarlet Fever | A族链球菌感染引起的疾病，表现为发热、草莓舌、咽喉痛和全身弥漫性红色皮疹。详见 [[lessons/0033-pi-fu-wen-ti\|第33课：皮肤问题]] |
| 胸外按压 | CPR / Chest Compression | 心肺复苏中的胸外按压技术，用于紧急情况下维持血液循环。详见 [[lessons/0023-er-tong-ji-zhen\|第23课：儿童急诊]] |
| 婴儿猝死综合征 | SIDS (Sudden Infant Death Syndrome) | 1岁以下婴儿在睡眠中意外死亡，原因不明。仰卧睡眠、安全睡眠环境可显著降低风险。详见 [[lessons/0006-di-1-ge-yue\|第06课：第1个月]] |
| 隐睾 | Undescended Testicle / Cryptorchidism | 睾丸未下降至阴囊内。多数在1岁内自行下降，持续未降需手术治疗。详见 [[lessons/0028-mi-niao-sheng-zhi-wen-ti\|第28课：泌尿生殖系统问题]] |
| 婴儿肠痉挛 | Infantile Colic | 健康的婴儿出现持续数小时无法安抚的哭闹，通常每天在同一时间发作，多于3-4个月后自行缓解。详见 [[lessons/0004-xin-sheng-er-ri-chang-hu-li\|第04课：新生儿日常护理]] |
| 预防接种 | Vaccination / Immunization | 通过接种疫苗使机体获得对特定传染病的免疫力。详见 [[lessons/0031-yi-miao-jie-zhong\|第31课：疫苗接种]] |
| 湿疹 | Eczema / Atopic Dermatitis | 一种慢性皮肤炎症，表现为皮肤干燥、红斑、瘙痒。与过敏体质相关。详见 [[lessons/0033-pi-fu-wen-ti\|第33课：皮肤问题]] |
| 自闭症谱系障碍 | Autism Spectrum Disorder (ASD) | 一种神经发育障碍，核心特征包括社交沟通障碍和重复刻板行为。早期干预至关重要。详见 [[lessons/0021-fa-yu-zhang-ai\|第21课：发育障碍]] |
| 足月儿 | Full-term Infant | 胎龄在37周至42周之间出生的新生儿。 |
