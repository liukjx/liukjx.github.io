# 各年龄段沟通指南

## 按年龄分类

```mermaid
flowchart LR
    A[3-6岁<br/>学龄前] -->|行为示范| B[7-11岁<br/>小学阶段]
    B -->|概念引入| C[12-15岁<br/>初中阶段]
    C -->|独立实践| D[15岁以上<br/>高中+]
```

## 3-6 岁（学龄前）

| 方面 | 建议 |
|------|------|
| **主要方法** | 行为示范，非语言沟通 |
| **最佳实践** | 使用现金交易，让孩子看到钱与物的交换过程 |
| **关键原则** | 观察力和模仿力最强，家长做好榜样 |
| **实操建议** | 带孩子用现金购物、让孩子拿出存钱罐的钱参与日常采购 |
| **注意** | 使用现金而非电子支付，让孩子有直观认识 |

> [!TIP]
> 对于这个年龄段，"做"比"说"重要一万倍。你如何使用钱，比你对钱说什么，更能影响孩子。

## 7-15 岁（小学到初中）

| 方面 | 建议 |
|------|------|
| **主要方法** | 概念引入 + 规则建立 |
| **关键概念** | 机会成本、需要与想要、预算 |
| **最佳实践** | 发放零花钱（少量 + 定期）、设立24小时冷静期 |
| **常见问题** | 冲动消费、同伴攀比、广告诱惑 |
| **应对策略** | 鼓励用自己零花钱购买、给决策权但不给超出认知的决策权 |

### 机会成本对话示例

> 孩子：妈妈我要买这双鞋！
> 家长：可以，但这学期的购物预算就超标了，买了这双鞋就不能买那个运动表了。你想清楚再决定。

> 孩子：我想周末跟同学看电影。
> 家长：可以，但你的功课时间要先保证。如果去看电影，下周的踢球时间就要取消。你自己安排。

## 通用原则

### 谈钱如谈性，越早越安全

- 你不教孩子钱，就会有别人（商家、广告）来教孩子
- 回避谈钱只会让孩子对钱产生过分敏感的心态
- 财商教育是一个长期工程，跟孩子一起成长才是正道

### 民主是建立在理性基础上的

- 当孩子没有足够的知识储备和决策经验时，让他们独自做重大决定是"愚蠢的"
- 尊重民主意志 ≠ 允许任性而为
- 给孩子适合其年龄的选择权，而不是把所有决定权都交给孩子
