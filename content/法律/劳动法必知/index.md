# 劳动法必知60讲

> 主讲人：胡高崇律师（北京市中伦文德律师事务所高级合伙人）

一门给所有职场人的劳动法通识课，按照"入职→在职→离职"的自然顺序，讲解劳动者在劳动关系中可能遇到的 60 个核心法律问题及应对方案。

## 课程受众

- 所有职场人（打工人、自由职业者、兼职者）
- 企业管理者、HR、人事主管
- 希望系统了解劳动法知识的学生和求职者

## 学习成果

学完本课程，你将能够：

- 识别求职、在职、离职各阶段的常见法律风险
- 在遭遇就业歧视、欠薪、违法辞退等情形时知道如何维权
- 理解 N、N+1、2N 等离职补偿计算规则
- 掌握劳动仲裁和诉讼的基本流程

## 课程结构

课程分为 **9 大模块**，共 **60 讲 + 1 篇发刊词**：

| 模块 | 涵盖课次 | 主题 |
|------|----------|------|
| 发刊词 | 第00课 | 职场安全感从何而来 |
| 模块一 | 第01-04课 | 求职入职 |
| 模块二 | 第05-07课 | 试用期 |
| 模块三 | 第08-16课 | 劳动合同 |
| 模块四 | 第17-26课 | 工时与休假 |
| 模块五 | 第27-35课 | 薪酬福利 |
| 模块六 | 第36-38课 | 竞业限制与服务期 |
| 模块七 | 第39-51课 | 离职与解除 |
| 模块八 | 第52-54课 | 特殊群体保护 |
| 模块九 | 第55-60课 | 争议解决 |
