# 第57课：仲裁调解——案件可能败诉，怎样判断该不该接受调解？

## 本节导读

调解是劳动争议处理的重要方式之一，可以贯穿案件处理全过程。本课讲解仲裁立案前和立案后两种调解的区别，以及劳动者何时应该接受调解、何时应该坚持仲裁。

## 两种调解方式

### 仲裁立案前的调解

由调解组织主持（企业调解委员会、基层人民调解组织等），达成的协议称为**调解协议书**。

- 可书面或口头申请调解
- 调解组织需在**15日内**达成协议
- **调解协议书具有合同效力**，但不具有强制执行力
- 一方不履行时，另一方仍需通过仲裁或诉讼维权

### 仲裁立案后的调解

由仲裁委员会主持，达成的协议称为**调解书**。

- 仲裁委员会处理争议应"**先行调解**"（《劳动人事争议仲裁办案规则》第3条）
- **调解书具有强制执行力**——用人单位不履行，劳动者可直接申请强制执行
- 调解金额一般低于仲裁请求金额

> [!TIP] 调解书 vs 调解协议书
> 立案前→调解组织主持→"调解协议书"→合同效力，无强制执行力
> 立案后→仲裁委主持→"调解书"→具有强制执行力

## 是否接受调解的判断策略

### 适合调解的情况

| 因素 | 说明 |
|------|------|
| 证据不充分 | 仲裁请求可能无法得到支持时，调解更适合 |
| 公司经营困难 | 即使胜诉也可能拿不到钱，不如调解落袋为安 |
| 时间成本高 | 想快速结案，不想长期耗在仲裁诉讼中 |
| 灵活方案 | 可以协商金钱之外的其他解决方案 |

### 适合坚持仲裁的情况

| 因素 | 说明 |
|------|------|
| 事实清楚、证据充分 | 仲裁请求有很大可能获得支持 |
| 金额差距大 | 调解方案与应得金额差距过大 |

### 判断步骤

1. 明确自己最核心的诉求是什么
2. 冷静评估掌握的证据是否充分
3. 判断仲裁请求得到支持的可能性
4. 权衡调解与仲裁的风险与收益
5. 必要时咨询律师意见

## 核心要点

- 调解可发生在仲裁立案前（调解协议书，无强制执行力）或立案后（调解书，有强制执行力）
- 调解省时省力，但金额通常低于仲裁请求
- 证据不充分或公司经营困难时，调解是更稳妥的选择
- 事实清楚、证据充分时，坚持仲裁可能获得更高赔偿
