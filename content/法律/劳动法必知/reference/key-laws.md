## 赔偿计算速查

| 情形 | 赔偿标准 | 公式 |
|------|----------|------|
| 协商解除（企业提出） | N | 工作年限 × 月平均工资 |
| 合同到期不续签（企业不愿续） | N | 工作年限 × 月平均工资 |
| 不能胜任工作解除 | N+1 | 工作年限 × 月平均工资 + 1个月工资 |
| 医疗期满解除 | N+1 | 工作年限 × 月平均工资 + 1个月工资 |
| 客观情况重大变化解除 | N+1 | 工作年限 × 月平均工资 + 1个月工资 |
| 经济性裁员 | N | 工作年限 × 月平均工资 |
| 违法解除 | 2N | 工作年限 × 月平均工资 × 2 |
| 未签劳动合同 | 双倍工资 | 用工第2个月起至满1年止，每月支付双倍工资 |
