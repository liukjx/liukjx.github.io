# 第44课：婚姻存续期间，另一半欠债需要我共同偿还吗？

## Learning Objectives

- 理解夫妻共同债务的**共债共签**基本原则
- 掌握家事代理制度在债务认定中的作用
- 学会区分家庭日常生活所需债务与超出日常所需的债务
- 了解债权人和债务人各自的举证责任与风险防范方法

---

## 一、回顾上期思考题

> 小王和小李是约定财产制（AA制），小王向同学小张借了100万。小张找小李要钱，小李不同意。小李的主张能得到法官支持吗？

**答案：具体问题具体分析。**

关键在于**第三人（小张）是否知道**夫妻之间的财产约定：

- 如果小张**知道**夫妻是分别财产制 → 属小王个人债务，**小李不用还**
- 如果小张**不知道**这个约定 → 应当共同对外承担，然后小李可向小王追偿

```mermaid

    A[夫妻约定财产制<br>AA制] --> B[夫妻一方对外借款]
    B --> C{第三方是否知道<br>财产约定}
    C -->|知道| D[借款为个人债务<br>另一方不承担]
    C -->|不知道| E[借款为共同债务<br>共同对外承担]
    E --> F[承担后，可向<br>借款方追偿]```

## 二、民法典对夫妻共同债务的规定

### 核心法条

> **《民法典》第1064条**：
> 1. 夫妻双方共同签名或者夫妻一方事后追认等共同意思表示所负的债务，属于夫妻共同债务
> 2. 夫妻一方在婚姻关系存续期间以个人名义为**家庭日常生活需要**所负的债务，属于夫妻共同债务
> 3. 夫妻一方在婚姻关系存续期间以个人名义**超出家庭日常生活需要**所负的债务，**不属于夫妻共同债务**，但债权人能够证明该债务用于夫妻共同生活、共同生产经营或者基于夫妻双方共同意思表示的除外

### 基本原则

```mermaid
graph TD
    A[夫妻共同债务认定原则] --> B[**共债共签**<br>基本原则]
    A --> C[**家事代理**<br>补充原则]
    
    B --> B1[双方共同签名]
    B --> B2[一方签名+另一方事后追认]
    
    C --> C1[为家庭日常生活需要<br>一方签字即可]
    C1 --> C2[推定为共同债务]
    
    subgraph 超出日常生活需要
        D[一方以个人名义<br>超出日常所需] --> E[原则上为个人债务]
        E --> F[例外：债权人证明<br>用于共同生活/经营]
    end
```

## 三、案例分析

### 案情

一对90后小夫妻，婚后丈夫向老刘借款20万。数年后离婚，对这笔债务是个人债务还是共同债务产生争议。

### 分析

#### 情形一：借条上有夫妻二人签名

> **共同债务**，由二人共同偿还。

#### 情形二：只有丈夫签名，但妻子事后表示愿意一起还

> 属于**事后追认**，认定为**夫妻共同债务**。

#### 情形三：丈夫借20万购买小汽车供家庭使用

> 即使妻子不知情、没签字，但钱用于**家庭日常生活所需**，妻子也实际使用了小汽车 → **夫妻共同债务**

#### 情形四：丈夫瞒着妻子借20万用于自己挥霍或赌博

> 妻子始终不知情，钱未用于家庭生活 → **丈夫个人债务**

```mermaid
flowchart TD
    A[丈夫向老刘借20万] --> B{借条上谁签了名}
    B -->|夫妻双方签名| C[共同债务]
    B -->|只有丈夫签名| D{妻子事后态度}
    
    D -->|追认同意| C
    D -->|不知情/不同意| E{借款用途}
    
    E -->|用于家庭日常生活<br>如买车供家庭使用| C
    E -->|用于个人挥霍/赌博| F[丈夫个人债务]
    
    C --> G[夫妻共同偿还]
    F --> H[丈夫个人偿还]

## 四、如何界定"家庭日常生活需要"

根据国家统计局的调查，城镇居民家庭消费种类主要包括**八大类**：

| 类别 | 说明 |
|------|------|
| 食品 | 日常饮食支出 |
| 衣着 | 服装鞋帽 |
| 家庭设备用品 | 家电、家具等 |
| 医疗保健 | 就医、药品支出 |
| 交通通信 | 出行、通信费用 |
| 教育文化娱乐 | 子女教育、文化消费 |
| 居住 | 房租、物业、水电 |
| 其他 | 杂项支出 |

> ���家庭日常生活需要��，应综合考量夫妻职业、身份、资产、收入、家庭人数、当地生活习惯等因素认定。

## 五、实务建议

### 给债权人的建议

1. **让夫妻共同签字**是最稳妥的方案
2. 若一方未签字，事后通过**微信、录音等方式追认**
3. 若借款进入**夫妻共同账户或妻子名下账户**，可视为共同意思表示
4. 出借时考察债务人婚姻状况和家庭经济状况

### 给夫妻一方的建议

若债务已形成，为避免被认定为共同债务：

- **明确告知债权人**自己的反对意见
- 收集证据证明借款**未用于夫妻共同生活、共同经营**
- 避免通过电话录音、短信、微信等方式**被固定追认证据**

> [!warning] 
> 债权人应让债务人夫妻在借条上**共同签字**；夫妻一方应避免在不知情的情况下被认定追认。

## 总结

| 原则 | 内容 |
|------|------|
| **共债共签** | 双方共同签名或一方签名另一方事后追认的债务为共同债务 |
| **家事代理** | 为家庭日常生活需要所负债务，即使一方签字也属共同债务 |
| **超出日常需要** | 原则上为个人债务，但债权人能证明用于共同生活/经营的除外 |
| **家庭日常生活** | 参照八大类消费，结合家庭具体情况认定 |
| **风险防范** | 债权人要求共同签字，债务人注意不被认定追认 |
