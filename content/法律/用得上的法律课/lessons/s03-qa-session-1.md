# 补充课03：评论区用户提问汇总答疑（一）

## Learning Objectives

- 解决借贷纠纷中无借条但有转账记录的取证问题
- 理清租房设备损坏的责任划分
- 了解民事判决后执行难的应对策略
- 掌握社保缴纳不合规的维权途径

---

## 一、个人篇问题

### Q1：老赖跑了，找不到人了怎么办？

> 已起诉到法院但找不到债务人。

**答**：
- 法院可采用**公告送达**（在被告所在地粘贴送达公告，60天后视为送达完成）
- 债务人不出庭 → **缺席判决**
- 债权人胜诉后 → **强制执行**
- 拒不执行情节严重 → 可追究**拒不执行判决、裁定罪**

### Q2：没写借条，但有转账记录和微信答应还款的记录，能起诉吗？

**答**：可以。

> [!tip] 操作步骤
> 1. 将微信答应还款的信息和转账记录拿到**公证处**做**证据保全公证**
> 2. **不要删除原始记录**
> 3. 凭公证书向法院起诉

### Q3：帮同学借款近100万，他只写了欠款合同，不还怎么办？

**答**：关键看以**谁的名义**借的。

| 情形 | 责任 |
|------|------|
| **以使用人名义**借，款直接打入使用人账户 | 你只是中间人，责任较小 |
| **以你名义**借，经你账户转入使用人账户 | 债权人可**连带你一起起诉** |

> 建议：将欠款合同、转款记录等做**证据保全公证**，起诉时同时申请**财产保全**。

### Q4：只有借条有手印，没有转账记录，借款人联系不上，能起诉吗？

**答**：可以起诉，但**有风险**。

- 法院可用**公告送达**
- 但对方可能以"签了借条但未实际收款"抗辩
- 建议寻找**其他证人**或**物证**

### Q5：被骗5万元，罪犯已落网，需单独起诉他还款吗？

**答**：
- 依据**先刑后民**原则，应在刑事案件中**提起附带民事诉讼**
- 如果未提起，可**另行起诉**要求还款

### Q6：租房后发现东西不好使，房东说"谁租谁修"，应该谁修？

**答**：先看协议约定。

| 情形 | 处理 |
|------|------|
| 协议有约定 | 按约定 |
| 协议无约定 | 房东保障**基本设施**完好；租客**使用不当**造成损坏的由租客承担 |
| 建议 | 重新协商签订**补充协议** |

### Q7：买房六年没给房产证，怎么办？

**答**：
- 因开发商原因不能办产权证 → 开发商应承担**违约责任**
- 维权路径：与开发商沟通 → 沟通不成**起诉**（要求解除合同+赔偿损失，或继续履行+赔偿违约金）

### Q8：弟弟租房充电起火，烧了房东家具，房东没配灭火器也没备案，谁的责任？

**答**：
- **租客**：因自身原因引起火灾导致损失 → 应承担**赔偿责任**
- **房东**：消防合规问题是**行政处罚**，与民事赔偿不同
- 房东说"不赔就告你弟弟纵火" → 不构成刑事犯罪（未达失火罪标准）
- 建议：赔偿协商解决，恢复原状或赔2万元均可

### Q9：边缘地区无房屋产权，只有协议交易的风险在哪？

**答**：
- 合法商品房必须有**产权证**
- 农村房屋/小产权房：买卖只对**本集体成员**有效
- 城镇户口或其他集体人购买农村房屋 → **无效**
- 无产权交易**不受法律保护**，风险极高

### Q10：B被A经济诈骗后，A的弟弟写了欠条替哥哥还钱，之后一拖再拖，B能追回吗？

**答**：
- 弟弟自愿替哥哥还钱并签欠条 → **有效**
- B可凭欠条起诉**弟弟**，也可以将**哥哥和弟弟列为共同被告**

### Q11：官司赢了，申请强制执行了，但老赖名下的财产已转移，怎么办？

**答**：
- 积极向法院提供**隐形资产线索**：手机号（如1390开头的值钱号）、抖音号、微信账号等（均可拍卖）
- 协助法院查找其他可执行财产

## 二、职场篇问题

### Q1：员工在其他单位买了社保，本单位买不了，怎么办？

**答**：一个人只能有一个社保关系。建议尽快将社保关系**转到现单位**。

### Q2：单位不按工资全额缴五险一金，可以随时辞职并要求赔偿金吗？

**答**：
- 可以以"未依法缴纳社保"为由解除劳动关系并主张**补偿金**
- 但"未全额缴纳"标准不明确，各地法院判决不一，有一定风险
- 建议先向**劳动监察部门**反映

### Q3：单位没买一金（住房公积金），合法吗？

**答**：**不合法**。法律已明确规定**五险一金必须办**。

### Q4：单位缴社保但全部从工资扣，单位未出一分钱，怎么办？

**答**：如果单位应缴部分也从你工资扣 → **违法**。建议：
1. 先与单位协商
2. 协商不成 → 向**社保监察大队**投诉
3. 或向**劳动仲裁机构**申请仲裁
4. 仲裁后可起诉

### Q5：老板把货款卷走几百万找不到人，怎么办？

**答**：收集证据报警。构成犯罪则追究刑事责任；不构成犯罪可向法院起诉追回。

### Q6：离职一年了，公司还押着一万块钱，新单位工作一年未签合同，原承诺提成7万拿不到，怎么办？

**答**：
- 离职一年无证据证明主张过权利 → 可能已过**诉讼时效**
- 新单位不签合同 → 可要求签**无固定期限劳动合同**

### Q7：公司欠工资，劳动仲裁后到了执行局还拿不到，怎么办？

**答**：配合执行局**提供线索**，督促执行。

### Q8：装修公司倒闭，项目经理的工资没着落，怎么办？

**答**：
1. 申请**破产程序**，申报债权（工资属于破产清算优先项）
2. 查公司其他财产（厂房、车、库存、应收债权）
3. 如公司为**自然人独资**，可追加为连带责任人
4. 查公司注册资本是否实缴，未实缴的在差额内要求股东担责

### Q9：工伤后如何保证拿到赔偿金，且不影响再找工作？

**答**：
- 单位缴了工伤保险 → 由**社保基金**赔付，不用担心
- 单位未缴 → 由单位支付，可先**财产保全**
- 工伤不影响找工作（如影响劳动能力，找与能力相当的工作即可）

### Q10：公司先通知不续签合同，办理解除时又要求回去培训继续工作，能坚持当初决定吗？

**答**：
- 愿意签 → 回去继续工作
- 不愿意签 → 明确终止合同（但不能再要求经济补偿金）
- 建议：如对单位有感情，可抓住机会参加培训留下

## 三、婚姻篇问题

### Q：婚前男方给女方20万彩礼，结婚两年后离婚，男方无过错，彩礼能要回吗？

**答**：**一般不能**。已登记结婚并同居生活的，彩礼**不需要返还**。

**例外（可以要回）**：
1. 领证但**未同居生活**
2. 因彩礼导致男方**生活困难**（婚后财产不足以清还债务，生活水平显著下降）

## 四、社会篇问题

### Q：网上贷款平台收了高利息，还需要还吗？

**答**：
- 当前法律保护利率上限：**LPR的4倍**（目前约**15.4%**）
- 超过15.4%的部分，法院**不支持**
- 已支付的超过部分，不能要求返还

### Q：弟弟与公司签订合同从事"帮助失信人找回信誉"，支付20万后感觉被骗，怎么办？

**答**：
- 收集造假证据并做**公证**
- 向法院起诉**违约**
- 情节严重的可**报警诈骗**

### Q：普通人如何找律师？

**答**：
1. 联系一家律师事务所
2. 找专业对口的**代理律师**
3. 签约、缴费（费用交律所，由律所开发票）
4. 律师根据材料代理案件

> [!summary] 本课小结
> - 借款纠纷：**有转款记录+聊天记录**可公证后起诉
> - 执行难：积极提供**隐性资产线索**
> - 社保不缴：向**劳动监察部门**投诉或**劳动仲裁**
> - 彩礼返还：已登记同居的**一般不退**
> - 高利贷：超过**LPR4倍**的利息法院不支持
