# 游戏设计完整学习路线

> **目标**：从零基础 → 能够独立完成游戏设计全流程 → 开发属于自己的游戏
> **素材**：9门专业游戏设计课程，348节中文字幕课
> **时长**：预计 8-12 周（每天学习）

```mermaid
flowchart LR
    M1[Module 1<br/>游戏设计基础] --> M2[Module 2<br/>以玩家为中心]
    M2 --> M3[Module 3<br/>游戏系统设计]
    M1 --> M3
    M3 --> M4[Module 4<br/>游戏化与动机]
    M3 --> M5[Module 5<br/>关卡设计]
    M2 --> M6[Module 6<br/>游戏设计文档]
    M4 --> M6

```

## 学习建议

- **每个模块学完后**，尝试用所学知识分析和拆解你喜欢的游戏
- **Module 3 学完后**，尝试为一个简单游戏构思设计核心玩法
- **Module 6 学完后**，尝试为一个完整的游戏构思撰写GDD
- **保持实践**：每节课后完成自测练习，再做一个小型设计练习
