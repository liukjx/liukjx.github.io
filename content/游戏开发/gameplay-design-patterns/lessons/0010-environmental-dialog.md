# 第10课：环境叙事与对话系统

## Learning Objectives

- 区分世界内叙事（diegetic）与非世界内叙事（non-diegetic）及其设计影响
- 分析环境叙事的核心原理——"让世界自己说话"
- 理解对话树的设计模式和分支对话的管理策略
- 认识碎片化叙事在现代游戏中的应用价值

## Core Idea

叙事不必通过对话框或过场动画来传递。**环境叙事**让场景本身成为故事的载体——一面烧焦的墙、一张被翻倒的桌子、一封未寄出的信，都在无声地讲述着什么。而**对话系统**则是玩家主动参与叙事的工具，玩家通过选择说什么来"选择成为谁"。


> [!TIP] Key Insight
> "展示，而非告知"（Show, Don't Tell）在游戏中的最好实现是环境叙事。但环境叙事有一个隐形成本：**不是所有玩家都会主动解读环境中的叙事信号**。设计师需要确保：核心故事信息通过玩家一定会经过的方式传递（如对话树），而环境叙事服务于世界构建和沉浸感的"额外信息层"——即"锦上添花"而非"缺了就不行"。

### Diegetic vs Non-Diegetic 叙事

| 特性 | Diegetic（世界内） | Non-Diegetic（非世界内） |
|------|-------------------|------------------------|
| 信息位置 | 存在于游戏世界中 | 来自游戏世界之外 |
| 举例 | 墙上的字条、NPC 对话、收音机 | HUD 文字、过场动画字幕、菜单描述 |
| 沉浸感 | 高（角色也能"看到"） | 低（只有玩家能看到） |
| 控制权 | 玩家可以选择是否关注 | 强制呈现 |
| 常见应用 | 环境叙事、对话系统 | 教程提示、成就通知、菜单介绍 |

一个有趣的设计策略是**将 non-diegetic 转化为 diegetic**——《生化危机》中将生命值显示为角色的心跳声，《死亡空间》中将生命条集成在角色脊椎上的灯光条。

## Patterns in This Cluster

| 模式 | 英文名 | 简短定义 |
|------|--------|----------|
| 环境叙事 | Environmental Storytelling | 通过场景中的物品布局、空间状态和细节来传递叙事信息 |
| 对话树 | Dialog Trees | 分支结构的对话系统，玩家通过选择回复来推进或改变对话走向 |
| 世界内叙事 | Diegetic Narration | 存在于游戏世界内部、角色也能感知到的叙事信息 |
| 非世界内叙事 | Non-Diegetic Narration | 仅对玩家可见、游戏角色无法感知的外部叙事信息 |
| 可收集叙事碎片 | Collectible Story Fragments | 散落在地图中的碎片化故事信息，玩家收集后拼凑出完整叙事 |
| 风味文本 | Flavor Text | 增加世界氛围但通常不改变游戏玩法的描述性文本 |
| 背景故事 | Backstory | 游戏主要事件发生之前的历史，用来深化世界观和角色动机 |

## Worked Example：《极乐迪斯科》的对话系统与内心独白

《极乐迪斯科》（ZA/UM, 2019）的叙事系统是游戏设计历史上最独特的之一。它几乎没有传统意义上的"战斗"，核心玩法就是**对话**。

### 对话树的结构

《极乐迪斯科》的对话树不同于传统 RPG 的"选 A 说好话/选 B 说坏话"二元结构。它的核心创新是**技能作为对话参与者**：

```mermaid
flowchart LR
    NPC[”NPC 说：<br/>'你昨晚在哪儿？'”] --> P1[”选择 1:<br/>'我不记得了'”]
    NPC --> P2[”选择 2:<br/>'你管得着吗？'”]
    NPC --> P3[”选择 3:<br/>'你为什么要问？'”]

    P1 --> SKILL1[”[逻辑] 检定成功：<br/>'我喝醉了，<br/>但应该没离开过酒吧'”]
    P1 --> SKILL1F[”[逻辑] 检定失败：<br/>沉默不语”]
    P2 --> SKILL2[”[争强好胜] 主动触发：<br/>'你是不是想打架？'”]
    P3 --> SKILL3[”[同理心] 被动技能：<br/>'他看起来很紧张——<br/>他在隐瞒什么'”]
    P3 --> SKILL3C[”[循循善诱] 检定：<br/>'你看起来压力很大，<br/>出什么事了？'”]

    SKILL1 --> OUT1[”线索：昨晚的片段记忆”]
    SKILL2 --> OUT2[”线索：NPC 的敌意升级”]
    SKILL3C --> OUT3[”线索：NPC 的信任”]
```

**技能对话机制**：游戏中的 24 种技能不仅是战斗/检定的属性值，它们实际上是有"人格"的——每个技能都有自己在对话中的"声音"。

- **争强好胜**（Electrochemistry）："再喝一杯，你现在想喝"
- **通情达理**（Empathy）："他很难过，他在掩饰什么"
- **逻辑思维**（Logic）："这不符合时间线，注意矛盾"

这种设计实现了**"内部对话"的可玩化**——玩家不是在扮演一个角色和 NPC 聊天，而是在扮演这个角色的**多个内心声音**之间的协调者。

### 碎片化叙事的智慧

玩家在《极乐迪斯科》中拼凑自己的身份（失忆的主角）和世界发生了什么，全靠碎片化信息：

1. **内心的技能对话**（diegetic）：你的技能告诉你一些信息，但这些信息可能准确也可能不准确
2. **环境中的物品**（diegetic）：翻垃圾桶、读墙上的涂鸦、检查尸体——每一件事都透露片段信息
3. **对话中的线索**（diegetic）：NPC 说的每句话都可能包含真假混杂的信息
4. **思维内阁**（Thought Cabinet）：独特的"装备"系统，玩家可以主动"思考"某些想法，这些想法会改变技能和对话选项

> [!WARNING]
> 《极乐迪斯科》的叙事设计对玩家有较高要求。它要求玩家**主动地做信息拼图**，而不是被动接收故事。这对不习惯阅读和推理的玩家来说可能产生挫败感。这个案例说明：叙事设计风格本身就在"选择"目标受众——一个高度依赖环境叙事和碎片化叙事的游戏，天然筛选了愿意投入解读努力的玩家群体。

> [!QUESTION] 自我检测
> 以下哪一项是"diegetic（世界内）叙事"的例子？

> A. 屏幕左上角显示任务目标："找到草药 X 3"
> B. 游戏主角在日记中写下："今天找到了三株草药"
> C. 玩家解锁"草药专家"成就，弹出通知条
> D. 暂停菜单中显示角色背景故事

<details>
<summary>查看答案</summary>
B。在游戏世界中，主角确实写了日记——其他角色也可以读到这本日记。A 和 C 是典型的 non-diegetic HUD 元素（只有玩家能看到，角色不知道"任务目标"的存在）。D 中的暂停菜单也是 non-diegetic（角色不会打开一个叫"暂停菜单"的东西）。将必要信息转化为 diegetic 形式（如角色日记本、环境中的留言板）是提升沉浸感的重要设计手法。
</details>

## 总结

环境叙事和对话系统是游戏叙事中最具"游戏性"的两个工具。环境叙事让世界自己说话，对话系统则让玩家参与对话。二者的共同挑战在于：**在不打断玩家主动性的前提下传递叙事信息**。当玩家从一面斑驳的墙上"读出"一个悲伤的故事，或从一个对话选项中"活出"角色的性格时，游戏叙事就完成了它最独特的任务——让叙事成为一种**体验**而非**接收**。
