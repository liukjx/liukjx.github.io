# 第12课：经济系统与关卡设计

## Learning Objectives

- 理解游戏经济系统的基本构成（生产-消费-存储-交换循环）
- 分析通胀控制的设计手段及其必要性
- 认识关卡布局中的引导原理和节奏控制
- 评估检查点、安全区和秘密区域在关卡设计中的功能

## Core Idea

经济系统和关卡设计看似分属不同领域（抽象系统 vs 空间构建），但它们在游戏设计中承担着相同的核心功能：**为玩家行为提供结构和节奏**。经济系统通过资源稀缺性引导玩家的行为选择，关卡设计通过空间排列引导玩家的路径和注意力。


> [!TIP] Key Insight
> 游戏经济可以视为一种**"受控的资本主义模拟"**。与真实经济不同，游戏设计者可以并且应该主动干预市场——通过货币回收机制、绑定装备、手续费等手段来防止通胀失控。**玩家感觉"在赚"，但实际上设计者在精确计算他们能"赚多少、花多少"。** 关卡设计同理：玩家感觉"自由探索"，但实际路径和体验节奏是设计者精心编排的。这就是"受控的自由"——游戏设计的根本悖论和最高艺术。

### 经济系统的核心循环

```
生产源 (打怪掉落/采集/任务奖励)
    ↓
    ↓ 回收手段 (修理/购买/手续费/税收)
    ↓
玩家库存 (货币/材料/装备)
    ↓
玩家交易 (玩家间的资源再分配)
    ↓
    ↓ 经济调控 (绑定/BOP/每日限制/等级锁定)
    ↓
市场平衡
```

## Patterns in This Cluster

| 模式 | 英文名 | 简短定义 |
|------|--------|----------|
| 游戏经济 | Game Economy | 游戏内资源的生产、分配、消费和交换体系的整体系统 |
| 货币 | Currency | 游戏内交易和流通的媒介，通常分多种层级 |
| 交易 | Trading | 玩家之间直接或通过市场进行的资源交换行为 |
| 通胀控制 | Inflation Control | 防止货币贬值和经济失衡的设计手段和调控机制 |
| 关卡设计 | Level Design | 游戏空间的布局、编排和体验节奏设计 |
| 关卡布局 | Level Layout | 空间结构的组织和路径的规划，是玩家体验的物理框架 |
| 检查点 | Checkpoints | 保存游戏进度或提供复活的节点位置 |
| 安全区 | Safe Havens | 没有敌对威胁的休息和补给区域 |
| 秘密区域 | Secret Areas | 隐藏的、需通过探索发现的奖励性空间 |

## Worked Example：《魔兽世界》的拍卖行经济与副本关卡设计

### 拍卖行：玩家经济的微观宇宙

《魔兽世界》（Blizzard, 2004）的拍卖行（Auction House）是游戏史上最复杂的玩家经济运行系统之一。它的设计体现了游戏经济的核心原理。

#### 货币体系架构

```mermaid
graph LR
    subgraph ”货币层级”
        C1[铜币 Copper] --> C2[银币 Silver<br/>100 铜币 = 1 银币]
        C2 --> C3[金币 Gold<br/>100 银币 = 1 金币]
    end

    subgraph ”货币获取”
        S1[打怪掉落] --> C3
        S2[任务奖励] --> C3
        S3[专业采集/制造] --> C3
        S4[拍卖行交易] --> C3
    end

    subgraph ”货币回收（通胀控制）”
        R1[修理装备] --> DRAIN[货币消耗]
        R2[飞行路线] --> DRAIN
        R3[拍卖行手续费] --> DRAIN
        R4[专业技能训练] --> DRAIN
        R5[附魔/宝石材料] --> DRAIN
    end
```

#### 通胀控制的四大手段

1. **货币分层**：铜→银→金的百进制不是装饰——它本身就是通胀缓释手段。金币成为高端交易的单位，低级货币自然沉淀
2. **绑定机制（Soulbound/Bind on Pickup）**：关键装备绑定后不可交易，防止极品装备无限流通和囤积
3. **手续费（Auction House Cut）**：每次拍卖成交抽取约 5% 手续费，是持续的货币回收泵
4. **修理费**：死亡/磨损的修理费是最稳定的"货币下沉"（money sink）——随着版本推进修理费上涨，匹配玩家收入增长

#### 通胀的阶段性设计

有意思的是，《魔兽世界》的设计并非完全避免通胀。它的通胀节奏是**有意设计的**：

> [!NOTE]
> **版本初期的紧缩 vs 版本末期的宽松**。每个资料片初期（如 9.0 暗影国度发布时），由于新货币刚引入且玩家都在升级专业，市场上供不应求，经济紧缩。版本末期（如 9.2），玩家装备饱和、材料积累充足，市场走向宽松甚至轻微通胀。这种**周期性的经济波动**本身是设计的一部分——它为玩家创造"经济游戏"的起伏感，避免经济成为静态系统。

### 副本关卡设计：空间叙事的教科书

《魔兽世界》的副本（Dungeon/Raid）设计体现了关卡设计的核心原则：

#### 经典的"三幕式"关卡节奏

| 阶段 | 空间特征 | 内容节奏 | 设计目标 |
|------|---------|---------|---------|
| 开场 | 宽阔入口、少量小怪 | 低压力 | 团队集合、Buff 准备 |
| 中段A | 走廊 + 房间交替 | 压力周期性上升 | 资源消耗、团队磨合 |
| 安全区 | BOSS 战前的小型休整点 | 无威胁 | 恢复、战术讨论 |
| 中段B | 更复杂的机关/路径 | 高压力 | 终极考验前的热身 |
| BOSS 战 | 特殊竞技场 | 最高压力 | 团队合作的终极检测 |
| 战后出口 | 宝箱 + 捷径 | 奖励与释放 | 成就感、便利 |

#### 秘密区域的引导设计

《魔兽世界》副本中的隐藏内容遵循**"信号-行动-奖励"**的引导模式：

- **信号**：一个奇怪的墙壁、一个无法到达的平台、一个有特殊名称的 NPC
- **行动**：寻找触发条件（特定顺序击杀/特殊物品/隐藏开关）
- **奖励**：额外 BOSS/装备/成就/幻化外观

> [!QUESTION] 自我检测
> 《魔兽世界》中，将关键装备设计为"拾取绑定"（Bind on Pickup）的主要目的是什么？

> A. 防止玩家不小心把装备卖掉
> B. 限制装备在玩家经济中流通，防止金钱购买最强装备破坏游戏体验
> C. 方便开发者追踪装备流向
> D. 减少服务器数据库存储量

<details>
<summary>查看答案</summary>
B。拾取绑定（BoP）是最重要的经济调控设计之一。如果没有 BoP，高难度副本产出的极品装备就会在拍卖行流通——那么最有钱的玩家不需要通过高难度挑战就能获得最佳装备，"花金币买装备"取代了"花精力打副本"成为装备获取方式，这会从根本上破坏游戏的核心循环。BoP 确保了装备获取与游戏行为直接挂钩、不可转移。另一种绑定类型"装备绑定"（Bind on Equip, BoE）则允许装备在首次装备前流通一次，是折中设计——让专业制造装备可以交易，但一穿即绑定。
</details>

## 总结

经济系统和关卡设计虽然分工不同，但都在做同一件事：**为玩家的游戏行为创造结构和意义**。经济系统通过资源和价格的抽象层来引导玩家的行为选择，关卡设计通过空间排列来塑造玩家的体验路径。两者的核心设计原则也相通：**给玩家自由感的精确控制**。一个好的拍卖行让玩家感觉自己在做市场决策，实际上所有经济参数都在可控范围内；一个好的关卡让玩家感觉自己在探索未知，实际路径和节奏经过精密编排。
