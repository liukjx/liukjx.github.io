# 时间与动画 — 让着色器动起来

静态的着色器只能看到一成不变的颜色，而一旦引入**时间变量**，你的着色器就有了"生命"。本课将学习 Unity 的内置时间变量，以及如何利用它们驱动各种动态效果。

> [!info] **本课目标**
>   - 理解 _Time、_SinTime、_CosTime 四种通道的含义
>   - 掌握时间驱动动画的基本模式
>   - 结合内置函数实现闪烁、脉动、流动、波动四种动画

## 1. _Time 变量详解

Unity 提供了三个内置的时间变量，它们都是 **float4** 类型，每个分量代表不同的速度：

### 1.1 _Time

| 通道 | 计算方式 | 速度 | 用途建议 |
| --- | --- | --- | --- |
| `_Time.x` | t / 20 | 慢速（1/20） | 缓慢变化的动画 |
| `_Time.y` | t | 正常速度（×1） | **最常用**，等价于 Time.timeSinceLevelLoad |
| `_Time.z` | t × 2 | 双倍速度（×2） | 快速动画 |
| `_Time.w` | t × 3 | 三倍速度（×3） | 更快动画 |

### 1.2 _SinTime / _CosTime

这两个变量是 `_Time` 的三角函数简化版本：

| 通道 | _SinTime | _CosTime |
| --- | --- | --- |
| `.x` | sin(t / 8) | cos(t / 8) |
| `.y` | sin(t / 4) | cos(t / 4) |
| `.z` | sin(t / 3) | cos(t / 3) |
| `.w` | **sin(t)** — 等于 sin(_Time.y) | **cos(t)** — 等于 cos(_Time.y) |

> [!tip] **最常用的组合** 绝大多数情况下你只需要`_Time.y` 作为时间输入，然后用`sin(_Time.y)` 或`cos(_Time.y)` 生成循环动画。`_SinTime.w` 和`_CosTime.w` 只是这两个运算的预计算版本。

## 3. 四种常用动画模式

结合第 7 课的内置函数和 _Time 变量，我们可以归纳出四种最常用的动画模式。

#### 闪烁 (Blink)

abs(sin(_Time.y * _Speed))

颜色在 0-1 之间来回切换，适合"警报灯"效果

#### 脉动 (Pulse)

sin(_Time.y * _Speed) * 0.5 + 0.5

将 sin 的 [-1,1] 映射到 [0,1]，平滑呼吸效果

#### 流动 (Flow)

UV.x += _Time.y * _Speed

UV 持续偏移，适合水流、传送带

#### 波动 (Wave)

sin(UV.x * _Freq + _Time.y * _Speed)

基于位置 + 时间的波动，适合旗帜、水面

### 3.1 闪烁 (Blink) — 完整示例

**为什么用 abs(sin)？**

`sin(_Time.y)` 的返回值在 [-1, 1] 之间循环。取绝对值后，变为 [0, 1] 之间循环，且每秒有两个周期（从 0 到 1 再到 0 算一个周期）。如果你想控制闪烁频率，调整 _Speed 即可。

### 3.2 脉动 (Pulse) — 完整示例

**Blink vs. Pulse 的区别**

| 模式 | 公式 | 效果 |
| --- | --- | --- |
| Blink | `abs(sin(t))` | 快速开/关，有"尖角"突变 |
| Pulse | `sin(t) * 0.5 + 0.5` | 平滑呼吸，正弦波形状 |

### 3.3 流动 (Flow) — 完整示例

> [!warning] **纹理 Wrap Mode 的选择** 做流动动画时，纹理的 Wrap Mode 应设置为**Repeat** （默认），这样 UV 超出 [0,1] 范围时纹理会自动平铺。如果设置为 Clamp，边缘会出现拉伸。

### 3.4 波动 (Wave) — 完整示例

**波动公式拆解**

- `i.uv.x * _Frequency` — 频率：控制波的数量（值越大波纹越密）
- `_Time.y * _Speed` — 速度：控制波动的快慢
- `sin(...)` — 波形：在 [-1, 1] 之间振荡
- `* _Amplitude` — 振幅：控制波动幅度（建议 0.01 ~ 0.1）

## 7. 本课总结

| 概念 | 要点 |
| --- | --- |
| _Time | float4，4 种速度：慢/正常/2x/3x。最常用 _Time.y |
| _SinTime / _CosTime | sin(_Time) 和 cos(_Time) 的预计算版本 |
| 闪烁 (Blink) | `abs(sin(_Time.y * speed))`，快速开/关 |
| 脉动 (Pulse) | `sin(_Time.y * speed) * 0.5 + 0.5`，平滑呼吸 |
| 流动 (Flow) | `UV.x += _Time.y * speed`，纹理滚动 |
| 波动 (Wave) | `sin(UV.x * freq + _Time.y * speed)`，旗帜/水面 |
| 顶点动画 | 在 vert 函数中修改顶点位置，产生几何形变 |
