# 速查表

## 六阶段情节结构（Michael Hauge）

| 阶段 | 时间位置 | 关键事件 | 描述 |
|---|---|---|---|
| **设定** Setup | 0%-10% | 建立认同感 | 介绍英雄，展示日常生活，让观众关心角色 |
| **新情境** New Situation | 10%-25% | 机会降临 | 英雄遇到机会，进入新环境（常为地理变化） |
| **进展** Progress | 25%-50% | 计划似乎奏效 | 英雄追逐可见目标，障碍可被克服/绕过 |
| **复杂化** Complications | 50%-75% | 不可回头 | 风险升级，难度加大，英雄全身心投入 |
| **重大挫折** Major Setback | 75% | 一切皆失 | 最大打击，英雄想逃回身份 |
| **结局** Resolution | 75%-高潮 | 全力一搏 | 英雄倾尽所有，达成或失败 |
| **后果** Aftermath | 高潮后 | 新生活 | 展示旅程带来的改变 |

### 五个关键转折点

```
0%        10%       25%        50%        75%       100%
|——设定——|——新情境——|——进展——|——复杂化——|——结局——|
          ↑         ↑          ↑          ↑         ↑
        机会     确立目标   不可回头   重大挫折   高潮
```

## 十二阶段英雄之旅（Joseph Campbell / Chris Vogler）

| 阶段 | 描述 | 对应情节阶段 |
|---|---|---|
| 1. 普通世界 | 英雄的日常生活，展示缺失 | 设定 |
| 2. 冒险召唤 | 打破日常的呼唤 | 10%机会 |
| 3. 拒绝召唤 | 恐惧，不想改变 | 新情境中 |
| 4. 遇见导师 | 获得智慧/工具/鼓励 | 新情境中 |
| 5. 跨越第一个门槛 | 正式进入特殊世界 | 25%确立目标 |
| 6. 考验、盟友、敌人 | 学习规则，结交/对抗 | 进展 |
| 7. 接近最深的洞穴 | 接近最危险的地方 | 复杂化 |
| 8. 磨难 | 核心死亡与重生 | 75%重大挫折 |
| 9. 奖励 | 获得宝物/知识 | 结局准备 |
| 10. 回归之路 | 试图带奖励回来 | 结局 |
| 11. 复活 | 最后一次纯粹考验 | 高潮 |
| 12. 携带灵药归来 | 分享旅程所学 | 后果 |

## 角色六阶段发展（对应六阶段情节）

| 情节阶段 | 角色状态 | 关键动态 |
|---|---|---|
| 设定 | 完全活在身份中 | 英雄展示面具，观众建立认同 |
| 新情境 | 瞥见本质的可能性 | 英雄看到'另一种生活'的样子 |
| 进展 | 一只脚踏入本质 | 进两步退一步，逐渐尝试 |
| 复杂化 | 全心全意投入本质 | 烧毁退路，无法回头 |
| 重大挫折 | 恐惧，逃回身份 | 最后一次退缩，几乎放弃 |
| 结局 | 完全活出本质 | 选择真实自我，获得奖赏 |

## 角色核心构成

```
创伤 (Wound) → 恐惧 (Fear) → 身份 (Identity / Mask)
                                        ↓
渴望 (Longing) ← 本质 (Essence / True Self)
```

英雄的旅程 = 从 **身份** 走向 **本质**

## 建立认同感的五种方式

1. **同情** — 让英雄成为不应得的不幸的受害者
2. **困境** — 让英雄陷于危险（身体/情感/职业）
3. **讨喜** — 善良、关心他人、被周围人喜欢
4. **幽默** — 让英雄有趣，观众喜欢和TA待在一起
5. **能力** — 英雄在自己的领域非常出色

> 必须在展示角色缺陷之前建立认同感。

## 四种基本可见目标

| 类型 | 例子 |
|---|---|
| 赢得 (Win) | 赢得比赛（《洛基》）、赢得爱情 |
| 逃脱 (Escape) | 逃离环境（《楚门的世界》） |
| 阻止 (Stop) | 阻止坏事发生（《沉默的羔羊》） |
| 取回 (Retrieve) | 寻宝、取回某物（《夺宝奇兵》） |

## 四种主要角色原型

| 角色 | 外在功能 | 内在功能 |
|---|---|---|
| **英雄** | 推动情节，观众认同 | 经历从身份到本质的转变 |
| **反映角色** | 帮助英雄达成目标 | 英雄的良知，提醒英雄"做真实的自己" |
| **对手** | 最大障碍 | 体现英雄的内心冲突 |
| **浪漫角色** | 追求对象 | 看到英雄的本质并爱上的奖赏 |

## 内心冲突公式

英雄愿意为了达成可见目标做任何事——**只要别让我** \_\_\_\_\_\_\_\_\_\_\_\_\_。

> 填空的内容 = 英雄的**身份**
