# 叙事技巧速查

## 叙事核心概念

| 概念 | 定义 | 关键区分 |
|---|---|---|
| **Story（故事）** | 按时间顺序发生的所有事件 | "国王死了，然后王后也死了" |
| **Plot（情节）** | 事件被讲述的因果排列 | "国王死了，然后王后因悲伤而死" — E.M. Forster |
| **Fabula（本事）** | 按时间顺序的原始故事素材 | 俄国形式主义术语 |
| **Syuzhet（述本）** | 故事被呈现的方式（顺序、视角） | 俄国形式主义术语 |
| **Diegesis（故事世界）** | 故事内部的世界，包括一切角色感知和未感知的 | 叙述世界 vs 现实世界 |

## 场景结构：Scene + Sequel

```mermaid
flowchart LR
    subgraph Scene[Scene 场景]
        G[Goal 目标] --> C[Conflict 冲突]
        C --> D[Disaster 灾难]
    end
    Scene -->|→| subgraph Sequel[Sequel 后续]
        R[Reaction 反应] --> Di[Dilemma 困境]
        Di --> De[Decision 决定]
    end
    Sequel -->|新目标| Scene
```

- **Scene**: 角色有明确目标 → 遇到冲突 → 以灾难/转折结束
- **Sequel**: 角色对灾难反应 → 陷入困境 → 做出新决定 → 新目标

## 七点结构 (Seven-Point Structure)

| # | 节点 | 说明 |
|---|---|---|
| 1 | Hook | 主角的日常世界 |
| 2 | Plot Turn 1 | 冒险召唤，故事正式开始 |
| 3 | Pinch 1 | 反派展示力量，施加压力 |
| 4 | Midpoint | 从反应到行动的转折，重大胜利或失败 |
| 5 | Pinch 2 | 最黑暗时刻，"万事皆休" |
| 6 | Plot Turn 2 | 找到最终方案，最后一搏 |
| 7 | Resolution | 结局，主角改变或世界改变 |

## 角色弧光类型

| 弧光类型 | 主角变化 | 示例 |
|---|---|---|
| Flat Arc（扁平弧） | 主角不变，改变世界 | 007、印第安纳琼斯、John Wick |
| Change Arc（变化弧） | 主角克服缺陷，成长 | 《肖申克》Andy、《星战》Luke |
| Fall Arc（堕落弧） | 主角堕入黑暗 | 《教父》Michael、《绝命毒师》Walter |

## 线性 vs 非线性叙事

| 线性叙事 | 非线性叙事 |
|---|---|
| 事件按时间顺序呈现 | 事件不按时间顺序呈现 |
| 观众被动接收 | 观众主动拼凑 |
| 易于理解，契合主流观众 | 需要更多认知投入 |
| 适合短篇、商业片 | 适合文学性、实验性、解谜式故事 |
| 三幕结构天然匹配 | 需要更强的控制力以免混乱 |

## 游戏叙事特性

| 维度 | 线性叙事（电影/小说） | 互动叙事（游戏） |
|---|---|---|
| 节奏控制 | 作者完全控制 | 玩家部分控制 |
| 角色认知 | 观众观察角色 | 玩家成为角色（化身认同） |
| 故事进展 | 固定路径 | 分支/可选择 |
| 失败处理 | 不可能失败 | 失败是叙事的一部分（Game Over） |
| 情感连接 | 共情 | 共情 + 能动性 (Agency) |
| 信息呈现 | 线性揭示 | 环境/可选/碎片化 |

## 三种叙事张力

| 类型 | 定义 | 示例 |
|---|---|---|
| **Mystery（谜团）** | 观众想知道"发生了什么" | 侦探小说、反转片 |
| **Suspense（悬念）** | 观众想知道"会发生什么" | 希区柯克式悬念 |
| **Dramatic Irony（戏剧反讽）** | 观众知道而角色不知 | 恐怖片中观众看到凶手在门后 |

## 环境叙事原则

- **Show, don't tell** — 用空间讲故事
- **The iceberg principle** — 只展示世界的 10%，暗示剩下的 90%
- **Internal consistency** — 世界规则在任何时候都保持一致
- **Structured revelation** — 不要一次性倾倒设定，而是逐步揭示
