# Pitch Page 模板

Pitch Page 是推销你的剧本创意的一页纸文档。按照此模板填写，确保包含所有关键信息。

---

## 使用说明

- 严格限制在 **一页以内**
- 使用清晰、专业的排版
- Logline 是最重要的部分 — 花最多时间打磨
- Synopsis 不要透露太多细节，保持悬念
- 用于 pitch meeting、比赛提交、写作小组分享

---

## 模板

```
------------------------------------------------------------------
                          [剧本标题]
                            (居中)

------------------------------------------------------------------

格式：[Short Film] / [Feature] / [TV Series]

编剧：[你的名字]

类型：[Genre / Genres]

目标观众：[Target Audience]

------------------------------------------------------------------

LOGLINE（一句话梗概）
——————————————————————————————————————————————————————————————————
[用 1-2 句话概括故事的核心：
谁（主角）+ 想要什么（目标）+ 但遇到了什么（冲突）+ 否则会怎样（stakes）]

提示：好的 Logline 应该让人听完就想知道更多。
避免使用"故事讲述的是..."这样的开头。

------------------------------------------------------------------

SYNOPSIS（故事大纲）
——————————————————————————————————————————————————————————————————
[用 1-2 段概述故事的主要情节线。
包含：主角的基本情况、Catalyst 事件、主要的冲突和发展、
故事的结局方向。

保持简洁 — 2-3 段足够。不要列出每一个情节转折，
而是从 30,000 英尺的高度俯瞰整个故事。

提示：第一段写开场和催化剂事件，第二段写中间的冲突和发展，
第三段（可选）暗示高潮和结局。

------------------------------------------------------------------

联系方式
——————————————————————————————————————————————————————————————————
[你的姓名]
[Email 地址]
[电话号码（可选）]
[个人网站/社交媒体（可选）]

------------------------------------------------------------------
```

## 填写示例

```
------------------------------------------------------------------
                        迷路的星星
                            (居中)

------------------------------------------------------------------

格式：Short Film

编剧：张三

类型：剧情 / 家庭

目标观众：12岁以上，对亲情题材有共鸣的观众

------------------------------------------------------------------

LOGLINE（一句话梗概）
——————————————————————————————————————————————————————————————————
一个 8 岁的女孩在超市走失后，她的母亲在寻找女儿的过程中，
发现这个"走失"其实是女儿精心策划的一次"逃跑"。

------------------------------------------------------------------

SYNOPSIS（故事大纲）
——————————————————————————————————————————————————————————————————
单亲妈妈林薇为了生计每天打两份工，8 岁的女儿小雨放学后
总是独自在家。一天，林薇带着小雨去超市，转身结账的功夫，
小雨不见了。监控显示小雨是主动离开的。

林薇焦急地寻找女儿的过程中，通过小雨藏在书包里的日记，
发现女儿是因为觉得"自己让妈妈太累了"才选择离开。她循着
日记里的线索，在城市里各处寻找女儿去过的角落。

最终，林薇在天文馆找到了小雨 — 那里是她和前夫（已故）
最喜欢带女儿去的地方。母女相拥而泣，林薇终于意识到女儿
需要的不是更多钱，而是更多时间。

------------------------------------------------------------------

联系方式
——————————————————————————————————————————————————————————————————
张三
zhangsan@email.com
weixin: zhangsan_writer

------------------------------------------------------------------
```

## 填写注意事项

### Logline 写作要点

- **含主角** — 谁的故事？
- **含目标** — 他/她想要什么？
- **含冲突** — 谁/什么在阻止他/她？
- **含 stakes** — 如果失败会怎样？
- 长度：1-2 句话，不超过 30 个英文单词或 60 个中文字

> [!TIP]
> Logline 模板："当 [Catalyst] 发生时，一个 [主角描述] 必须 [目标]，否则 [stakes]。"

### Synopsis 写作要点

- 不列出每一个情节，而是概括主要弧线
- 包含主角的成长/变化
- 不要写"然后...然后...然后..."，而是写"因此...但是...所以..."
- 保持悬念 — 不要揭示所有的 twist

> [!WARNING]
> 不要写太长！如果 Synopsis 超过 3 段，说明你还没有提炼好你的故事。一页纸的 Pitch Page 上，Synopsis 不应该喧宾夺主。
