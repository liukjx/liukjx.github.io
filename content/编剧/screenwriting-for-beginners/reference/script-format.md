# 剧本格式速查

本参考文档提供了标准 Hollywood 剧本格式的速查指南。所有专业剧本使用 **Courier New 12pt** 字体（等宽字体），确保 1 页约等于 1 分钟银幕时间。

---

## 页面基本规范

| 项目 | 规范 |
|---|---|
| 字体 | Courier New, 12pt |
| 页边距 | 左 1.5 inch（Scene Heading/Slugline 从 1.5 开始） |
| 右 | 1.0 inch |
| 上/下 | 1.0 inch |
| 行距 | 单倍行距 |
| 页数估算 | **1 page ≈ 1 minute** of screen time |

---

## 标题页 (Title Page)

标题页是剧本的名片。格式如下：

```
                        SCREENPLAY TITLE
                             (居中)

                        written by
                             (居中)

                        Your Name
                             (居中)

                Contact: your.email@example.com
                         (右下或居中)
```

> [!NOTE]
> - 标题不用斜体或引号，全部大写或首字母大写均可
> - "written by" 小写
> - 联系方式放在底部

---

## Slugline / Scene Heading (场景标题)

每个场景以 Slugline 开头，格式为：

```
INT./EXT. LOCATION - DAY/NIGHT
```

**规则：**
- 全部大写
- INT. = Interior（室内），EXT. = Exterior（室外）
- 如场景同时在室内外，用 `INT./EXT.`
- DAY/NIGHT 后不加句号
- Slugline 后的第一行是 **Action**（动作描写）

**示例：**
```
INT. COFFEE SHOP - DAY
```
```
EXT. RAINY STREET - NIGHT
```

---

## Action / Scene Description (动作描写/场景描述)

Slugline 之后紧接动作描写。

**规则：**
- 现在时态撰写
- 简洁、视觉化
- 使用 **Show Don't Tell** 原则
- 每个段落不超过 3-4 行
- 角色第一次出现时，名字用 **全部大写**

**示例：**
```
INT. COFFEE SHOP - DAY

Sunlight streams through the window. Steam rises from a mug on the counter.

ANNA (20s, tired eyes but a determined smile) sits alone at a corner table. She stares at a blank notebook.
```

---

## Character Introduction (角色引入)

角色初次登场时，名字用 **全部大写**，括号中可包含简要描述。

**格式：**
```
NAME (AGE, KEY TRAITS) does something or is somewhere.
```

**示例：**
```
LEO (30s, sharp suit, nervous hands) steps through the door.
```

之后再次出现时用正常大写（即 Dialogue 中的角色名正常大写格式）。

---

## Dialogue (对白)

角色说话的部分。

**规则：**
- 角色名居中，全部大写
- 对白居中对齐
- 对白框宽度约 3.5 inch

**示例：**
```
                    ANNA
           I don't know why I came here.
           Maybe I was hoping for a sign.

                    LEO
           Sometimes a coffee is just a
           coffee.
```

---

## Parentheticals (附加指示)

在角色名和对白之间的小括号指示，用来提示说话方式或动作。

**规则：**
- 少用 — 让演员和导演发挥
- 除非必要，不要说明显而易见的情感
- 仅在可能产生歧义时使用

**格式：**
```
                    ANNA
                     (whispering)
           I don't know why I came here.
```

---

## Transitions (转场标记)

场景之间的转场提示，右对齐。

**常见转场：**
```
FADE IN:              (剧本最开头)
FADE TO BLACK.        (场景结束)
CUT TO:               (标准转场)
SMASH CUT TO:         (突然的、冲击性的转场)
DISSOLVE TO:          (有时间流逝感的转场)
FADE OUT.             (剧本最后)
```

> [!TIP]
> 现代剧本中除了 FADE IN 和 FADE OUT，通常只需要使用 CUT TO 或直接省略转场标记。

## 完整剧本片段示例

```
FADE IN:

INT. WRITER'S STUDIO - DAY

A messy desk covered in coffee cups, scribbled notes, and a single
laptop that glows with an empty document.

JAMIE (20s, pajamas, messy hair) stares at the screen. Has been
staring for a while.

The cursor blinks. Mocking her.

                    JAMIE
           Okay. Page one. Here we go.

Jamie's fingers hover over the keyboard. She takes a deep breath.

                    JAMIE (CONT'D)
                     (to herself)
           You can do this.

She types one sentence. Then deletes it. Types another. Deletes.

Jamie slumps back in her chair. This is going to be a long night.

FADE OUT.

THE END
```

## 页面计数参考

| 剧本类型 | 建议页数 | 大约银幕时间 |
|---|---|---|
| Short Film (短片) | 5 - 15 页 | 5 - 15 分钟 |
| TV Sitcom (情景喜剧) | 25 - 35 页 | 22 - 30 分钟 |
| TV Drama (一小时剧) | 45 - 60 页 | 42 - 48 分钟 |
| Feature Film (长片) | 90 - 120 页 | 90 - 120 分钟 |

## 快速检查清单

写完后检查你的格式：

- [ ] 使用了 Courier New 12pt 字体
- [ ] 每个场景以正确的 Slugline 开头
- [ ] 角色名在对白前全部大写
- [ ] 角色首次出现时名字全部大写
- [ ] Action 段落不超过 3-4 行
- [ ] 使用了现在时态
- [ ] 没有不必要的 Parentheticals
- [ ] 页数符合你的目标长度
- [ ] FADE IN 在开头，FADE OUT 在结尾
