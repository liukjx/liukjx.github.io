# 第11课：主角的塑造

## 学习目标

- 理解主角的核心特质
- 掌握主角缺陷的类型与运用
- 理解角色弧光（Character Arc）的概念
- 学会让主角始终保持主动

## 核心内容

### 主角的定义与特质

主角（Protagonist）是你故事的中心人物，观众通过ta的眼睛体验旅程，为ta加油。

**主角的基本信息：**
- **年龄与性别** —— 影响观众对角色的第一印象
- **名字** —— 在剧本中角色的名字对读者很重要
- **外形描写** —— 影响谁可以扮演这个角色以及观众如何与ta建立联系

> [!WARNING]
> 这个世界并不公平。你如何描写主角的外形会影响观众对ta的看法和假设。你有意识地选择利用它，或颠覆它。

### 主角最核心的要素：缺陷

> [!TIP]
> **缺陷是主角之所以成为主角的原因。** 缺陷阻碍目标达成，制造所有挣扎和冲突，驱动整个故事前进。

**缺陷的工作机制：**

```
主角有缺陷 → 缺陷阻碍目标 → 冲突和障碍出现
    ↓
观众为主角加油 → 希望主角认识到缺陷
    ↓
主角意识到缺陷 → 克服缺陷 → 实现目标
```

### 常见的主角缺陷类型

#### 讨喜类缺陷（观众容易共情）

| 缺陷类型 | 说明 | 典型例子 |
|---------|------|---------|
| 缺乏自信 | 不相信自己的能力 | 辛巴（《狮子王》）|
| 缺乏自我价值感 | 不觉得自己值得被爱/尊重 | —— |
| 低自尊 | 觉得自己做不好事情 | —— |
| 不安全感 | 对自己所处状态感到不安 | —— |
| 天真 | 需要成长来理解世界 | —— |
| 无法放下过去 | 沉溺于过去无法前行 | —— |
| 无法面对过去 | 逃避过去的创伤 | —— |
| 缺乏信任 | 不信任他人 | 常见于超级英雄电影 |
| 无法承诺 | 害怕做出承诺 | 浪漫喜剧经典缺陷 |

#### 不讨喜类缺陷（慎用）

| 缺陷类型 | 说明 |
|---------|------|
| 固执 | 需要付出更多努力让观众站在主角一边 |
| 冲动 | 可能导致观众反感 |
| 偏见 | 极其容易让观众失去耐心 |
| 傲慢/自负/骄傲 | 通常是反派的缺陷 |

> [!EXAMPLE]
> **如何处理不讨喜的缺陷？**
> 以《豪斯医生》为例：豪斯自私、刻薄，但每一集的编剧都精心设计一个场景，让他**做出看似无私的行为**，即使他事后辩解这是出于自私动机，观众心中也会留下疑问——"他真的那么坏吗？"

### 角色弧光（Character Arc）

角色弧光是指主角在整个故事中的**变化轨迹**：

```
故事开始时                     故事结束时
   ↓                             ↓
[有缺陷的主角] → 经历事件 → [克服缺陷的主角]
```

**弧光的三个阶段：**
1. **设定缺陷** —— 故事开始时，主角的缺陷已经存在
2. **缺陷被挑战** —— 故事中的冲突不断揭示和挑战这个缺陷
3. **缺陷被克服** —— 在高潮时刻，主角终于认识到并克服缺陷

### 主角必须主动

> [!WARNING]
> **主角必须是主动的，不能是被动的。**
>
> 如果主角只是被动地对事件做出反应，故事就会缺乏张力。主角必须做出选择、采取行动，推动故事向前发展。

**主动 vs 被动：**
- 主动主角：做出决定，采取行动，改变局势
- 被动主角：等待事情发生，被他人推动，随波逐流

### 主角的背景故事

虽然不是所有背景都需要展示给观众，但**你必须知道**：

- 是什么造就了今天的TA？
- 童年的关键事件是什么？
- 最大的恐惧和渴望是什么？
- 秘密的梦想是什么？

> [!NOTE]
> 在头脑风暴阶段，专注于**角色本身**而非情节。不要写"ta在故事中做了什么"，而是写"ta作为一个人是谁"。情节稍后再处理。

## 实践与反思

### 自测题

<details>
<summary>点击展开答案</summary>

1. **为什么主角必须有缺陷？**
   - 完美的主角无趣且无法制造冲突。缺陷是阻碍目标实现的障碍，也是整个故事张力的来源。
2. **"主角必须主动"是什么意思？**
   - 主角要主动做出选择、采取行动来推动故事，而不是被动等待事件发生。
3. **角色弧光的三阶段是什么？**
   - 设定缺陷 → 缺陷被挑战 → 缺陷被克服。
4. **如何处理不讨喜的主角缺陷？**
   - 让角色偶尔做出无私或善良的行为，即使ta事后为这些行为找自私的借口，也能在观众心中留下余韵。
</details>

### 练习任务

1. **缺陷清单**：使用补充材料中的角色缺陷清单，选择2-3个缺陷，尝试组合成一个复杂的主角。
2. **角色头脑风暴**：用角色头脑风暴问卷回答关于主角的20个问题（不要涉及情节）。
3. **弧光规划**：为你的主角设计一个三阶段的弧光：开始时的缺陷 → 中间的关键挑战 → 结束时的转变。
