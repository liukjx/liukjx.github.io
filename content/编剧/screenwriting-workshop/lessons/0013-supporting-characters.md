# 第13课：配角的塑造

## 学习目标

- 理解配角的分类和功能
- 掌握角色金字塔的结构
- 学会创造令人难忘的配角
- 避免工具人式的配角

## 核心内容

### 角色金字塔

```
         ╱\
        ╱  ╲           主角（最详细的背景信息）
       ╱    ╲          需要非常私密的细节，就像真实的朋友
      ╱ 主角  ╲
     ╱________╲
    ╱          ╲       反派（几乎与主角一样详细的背景）
   ╱   反派     ╲
  ╱______________╲
 ╱                ╲    帮手与对立者（频繁出镜，中度细节）
╱  帮手/对立者      ╲
╱____________________╲
╱                      ╲ 配角发言（1-2句台词，简短描述）
╱      配角角色          ╲
╱__________________________╲
╱                            ╲ 群演（无台词，布景装饰）
╱          群演               ╲
╱______________________________╲
```

> [!TIP]
> **金字塔原则：** 越往上，你对角色的了解应该越深入。主角，你需要了解ta像了解最好的朋友；群演，只需要一个宽泛的描述。

### 配角的主要类型

#### 1. 主角的伙伴（Allies）
主角的朋友和同伴，帮助主角完成旅程。

> [!EXAMPLE]
> 《指环王》中的山姆是弗罗多最忠实的伙伴。

#### 2. 反派的爪牙（Minions）
反派的低级手下，为主角设置障碍。

#### 3. 宿敌（Nemesis）
宿敌是一个特殊的角色——ta与主角对立，但**不是最终的Boss**。宿敌可以在结尾得到救赎。

> [!EXAMPLE]
> **《星球大战》中的达斯·维达：** 在整个三部曲中看起来像是反派，但最终揭示真正的反派是皇帝，达斯·维达只是一个宿敌——他在最后得到了救赎，为儿子牺牲自己。

**宿敌 vs 反派：**

| 特征 | 宿敌 | 反派 |
|------|------|------|
| 与主角对立 | 是 | 是 |
| 最终Boss | 否 | 是 |
| 可能被救赎 | 是 | 不一定 |
| 用于隐藏真凶 | 常用于悬疑故事 | —— |

#### 4. 背景角色（Background Characters）
日常生活中会遇到的各类人——收银员、咖啡师、路人。他们的重要性取决于在故事中的角色。

### 如何让配角令人印象深刻

#### 1. 给出色的开场介绍

> [!WARNING]
> 避免单调的介绍方式："角色名，30岁，站在咖啡店里。"
> 使用有辨识度的特征："角色名，30岁，紫色挑染，站在咖啡店里。"

**好的开场介绍公式：**
```
[名字], [年龄], [一个独特的视觉细节], [正在做什么]
```

#### 2. 赋予独特的说话风格

如果每个角色说话方式都一样，故事会很无聊。

> [!NOTE]
> 理想情况下，即使观众移开视线，仅凭说的话也能分辨出是谁在讲话。

**方法：**
- 不同的词汇选择
- 不同的语法结构
- 不同的说话节奏
- 地方方言或特定用语

#### 3. 避免刻板印象

> [!TIP]
> 刻板印象（Stereotype）的力量在于快速传达信息，但会限制角色深度。即使是配角，也要挑战自己去避免刻板印象。

**如何颠覆刻板印象：**
- 如果需要一个"安静的图书管理员"，给她一个秘密的爱好
- 如果需要一个"咖啡师"，让ta和主角聊聊感情问题
- 在刻板印象的基础上，加入意想不到的元素

#### 4. 每个配角都必须有意义

> [!WARNING]
> **如果主角根本不需要与此人交谈，就删掉ta。**

常见错误：主角去咖啡店一定要和咖啡师寒暄，因为现实生活中会这样。但如果这段寒暄**没有推动情节或故事**——删掉它。主角直接走进咖啡店，走出来时已经拿着拿铁，观众会自动脑补。

**检验标准：** 这个角色的每一句对话是否在某种程度上推动了情节发展？

### 经典配角案例分析

| 电影 | 配角 | 令人难忘的原因 |
|------|------|--------------|
| 《公主新娘》 | 维齐尼、伊尼戈、费兹克 | 说话风格迥异，外形差异巨大，在剧本中介绍方式独特 |
| 《狮子王》 | 丁满与彭彭 | 语言风格天差地别，与辛巴的关系各有不同功能 |
| 《狮子王》 | 鬣狗 | 出色的对立者范例——与主角作对但最终反转帮助了主角 |
| 《第五元素》 | 鲁比·罗德 | 通过言辞、反应和未说出的话展现丰富信息 |

## 实践与反思

### 自测题

<details>
<summary>点击展开答案</summary>

1. **角色金字塔的层级规则是什么？**
   - 越往上，角色的背景信息越详细。主角需要最完整的背景，群演只需要宽泛描述。
2. **宿敌和反派有什么区别？**
   - 宿敌与主角对立但不是最终Boss，可能在结尾得到救赎；反派是终极对手。
3. **如何检验一个配角是否应该被删掉？**
   - 如果主角不需要与此人交谈，ta的对话没有推动情节或故事，这个角色就应该被删掉。
4. **如何让配角令人印象深刻？**
   - ①独特的出场介绍 ②独特的说话风格 ③避免刻板印象 ④确保有意义。
</details>

### 练习任务

1. **配角清单**：为你的故事列出所有配角，按照角色金字塔分类。
2. **测试删减**：检查每个配角——你能否在不影响故事的前提下删掉ta？
3. **独白测试**：随机选一段配角的台词，遮住名字读——能否仅凭语言风格分辨出是谁在说话？
4. **颠覆练习**：选一个刻板印象的配角设定，加入一个出人意料的特征。
