# 第16课：Loglines 与 Pitches

## 学习目标

- 理解 Logline（剧情概要）的定义和作用
- 掌握写出好 Logline 的四大要素
- 学习 Pitch（推销/推介）的基本技巧
- 能够在60字以内浓缩你的故事核心

## 核心内容

### 什么是 Logline？

**Logline（剧情概要）** 是对你故事的一到两句话的描述，理想情况下控制在 **60个字** 以内。它是剧本推介和创意的基石——很多剧本比赛和线上提交都会要求你在60字以内说清你的故事。

> [!TIP]
> 一个好的 Logline 能够决定你的故事是否获得关注。它是你整个剧本的"电梯演讲"。

### Logline 的四大要素

写一个有效的 Logline，需要包含以下四个核心元素：

| 要素 | 说明 | 示例 |
|------|------|------|
| **主角 (Protagonist)** | 描述主角的身份和特质 | "一个渴望冒险的堪萨斯农场女孩" |
| **目标 (Goal)** | 主角必须完成的任务 | "她来到了一个只在梦中幻想过的世界" |
| **冲突 (Conflict)** | 阻碍主角达成目标的力量 | "她必须面对黑暗势力的威胁" |
| ** stakes (赌注/利害关系）** | 如果失败会失去什么 | "如果失败，她再也回不了家" |

### Pitch 的核心技巧

Pitch（推介）是在短时间内向他人推销你的故事。关键要点：

1. **简洁有力** —— 从 Logline 开始，逐步展开
2. **情感共鸣** —— 让对方感受到故事的情感内核
3. **明确独特性** —— 你的故事有什么与众不同之处
4. **自信表达** —— 你对故事的信心会感染对方

### Logline 写作公式

```
[主角描述] + [目标] + [冲突] + [风险/赌注]
```

**示例拼合：**

> 一个渴望冒险的堪萨斯农场女孩（主角）来到一个她只在梦中幻想过的世界（目标），但她必须明白有时候没有地方比得上家（冲突与主题）。

## 实践与反思

> [!WARNING]
> 写 Logline 时最常见的错误是试图塞入太多信息。记住：60字以内，聚焦核心冲突。

### 练习：写一个 Logline

选择一个你熟悉的故事（电影、小说或你自己的创意），用下面的模板写一个 Logline：

1. 主角是谁？
2. 他/她想要什么？
3. 什么在阻碍他/她？
4. 如果失败会怎样？

<details>
<summary>参考答案（以《哈利·波特与魔法石》为例）</summary>

> 一个发现自己其实是巫师的孤儿男孩，必须进入魔法学校学习，同时阻止一个邪恶巫师获得永生之石。

</details>
