# 第20课：三幕结构（Three Act Structure）

## 学习目标

- 理解三幕结构的整体框架
- 掌握九个故事结构检查点
- 分清"情节"与"故事"的区别
- 了解三幕结构与四幕结构的关系

## 核心内容

### 三幕结构概览

三幕结构是传统的小说和好莱坞电影结构方法，分为：**第一幕：建立**、**第二幕：对抗**、**第三幕：解决**。

```mermaid
flowchart TB
    subgraph ”第一幕：建立 (Setup)”
        O[开场] --> T1[转折点1]
    end
    subgraph ”第二幕：对抗 (Confrontation)”
        T1 --> T2[转折点2]
    end
    subgraph ”第三幕：解决 (Resolution)”
        T2 --> E[结局]
    end
```

### 实际的紧张感曲线

故事中的紧张感并非平稳上升，而是**起伏波动的**：

```mermaid
---
config:
  theme: neutral
---
line
    title 故事紧张感变化曲线
    x-axis [”开场”, ”激励事件”, ”中点”, ”黑暗时刻”, ”高潮”, ”结局”]
    y-axis ”紧张感”
    line [1, 2, 3, 1, 5, 0.5]
```

每个高潮后通常伴随短暂的释放，紧张感以阶梯式持续攀升。

### 九个检查点详解

```mermaid
flowchart LR
    subgraph ”第一幕”
        A1[1、吸引点] --> A2[2、背景故事] --> A3[3、触发事件]
    end
    subgraph ”第二幕”
        A3 --> B1[4、危机] --> B2[5、挣扎] --> B3[6、顿悟]
    end
    subgraph ”第三幕”
        B3 --> C1[7、计划] --> C2[8、高潮] --> C3[9、结局]
    end
```

| # | 检查点 | 幕 | 说明 |
|---|--------|----|------|
| 1 | **吸引点 (Hook)** | 第一幕 | 快速抓住读者，提出故事问题 |
| 2 | **背景故事 (Backstory)** | 第一幕 | 了解角色、世界规则 |
| 3 | **触发事件 (Trigger)** | 第一幕 | 推动主角踏上旅程的关键事件 |
| 4 | **危机 (Crisis)** | 第二幕 | "失败的领悟"——主角意识到缺陷但无法克服 |
| 5 | **挣扎 (Struggle)** | 第二幕 | 所有出错的事件，紧张感持续升级 |
| 6 | **顿悟 (Epiphany)** | 第二幕 | 主角意识到缺陷并决心改变 |
| 7 | **计划 (Plan)** | 第三幕 | 基于顿悟制定的新方案 |
| 8 | **高潮 (Climax)** | 第三幕 | 与反派的最终对决 |
| 9 | **结局 (Resolution)** | 第三幕 | 收尾悬念，留给观众最后画面 |

### 关键概念：情节 vs 故事

> [!TIP]
> **情节**解决的是"发生了什么"，而**故事**解决的是"主角经历了怎样的内心变化"。
>
> 九点检查点的核心价值在于：它们帮助你追踪**角色的情感旅程**，而不仅仅是情节的推进。

### 三幕结构与四幕结构的关系

- **四幕结构**更适合了解剧本的**篇幅和页码分布**
- **三幕结构**与电影的**情节发展和情感弧线**更紧密
- 实际写作中，可以将三幕结构作为主线，四幕结构作为页码参考

## 实践与反思

### 练习：用九点检查

找一个你熟悉的故事，尝试填写九个检查点各对应什么事件：

<details>
<summary>以《星球大战：新希望》为例</summary>

| 检查点 | 对应事件 |
|--------|----------|
| 吸引点 | "这次公主没有逃脱的机会" |
| 背景故事 | 卢克是孤儿，本是他的导师 |
| 触发事件 | 本告诉卢克必须面对达斯·维德 |
| 危机 | 卢克拒绝并离开本 |
| 挣扎 | 找汉·索罗、救莉亚、本牺牲 |
| 顿悟 | "我必须相信自己" |
| 计划 | 相信原力，摧毁死星 |
| 高潮 | 卢克拉动扳机摧毁死星 |
| 结局 | 卢克和伙伴们获得奖牌 |

</details>
