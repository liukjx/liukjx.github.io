# 第27课：编剧软件介绍

## 学习目标

- 了解主流编剧软件的特点与区别
- 根据自身需求选择合适的编剧工具
- 为后续的剧本写作做好工具准备

## 核心内容

### 为什么不能用 Word 写剧本？

剧本有严格的格式要求——不同的边距、标签设置、角色名位置、对白宽度等。如果用 Word 手动调整格式，会让人无比头痛。编剧软件可以**自动格式化**，让你专注于创作本身。

### 行业标准：Final Draft

| 特性 | 说明 |
|------|------|
| 价格 | $250 |
| 平台 | Mac / PC |
| 核心功能 | 自动格式化剧本 |
| 规划工具 | 虚拟索引卡（Virtual Index Cards）、大纲功能 |
| 批注系统 | 可在剧本中添加备注，不干扰正文 |
| 行业兼容 | 行业通用标准，文件交换无障碍 |

> [!TIP]
> Final Draft 是**好莱坞行业标准**，几乎所有专业编剧都在使用。如果你打算认真走编剧这条路，这是值得投资的选择。

### 免费替代：Celtx

| 特性 | 说明 |
|------|------|
| 价格 | **免费**（有付费升级版 Celtx Plus） |
| 平台 | Mac / PC |
| 核心功能 | 自动格式化剧本 |
| 导出格式 | 支持导出 PDF |
| 局限 | 免费版缺少批注功能（在剧本中直接添加备注） |

> [!NOTE]
> 讲师 Danny 在大学时使用的就是 Celtx 免费版，他认为对初学者来说完全够用。即使缺少批注功能，也不影响核心创作。

### 如何选择？

1. 访问 [finaldraft.com](https://finaldraft.com) 和 [celtx.com](https://celtx.com) 了解功能和用户评价
2. 如果只是试试水、预算有限：**选 Celtx**
3. 如果确定要长期投入：**选 Final Draft**

> [!TIP]
> 下一课将演示如何使用 Celtx，建议先下载免费版或试用版，以便跟上课程内容。

### 其他编剧软件（补充知识）

除了 Final Draft 和 Celtx，市面上还有：

- **Fade In** — 价格适中的专业级编剧软件，功能强大
- **WriterDuet** — 支持在线协作的编剧工具
- **Highland** — 简洁轻量的 Mac 端编剧软件
- **Trelby** — 开源免费的编剧软件

## 实践与反思

### 📝 本周任务
1. 访问 Final Draft 和 Celtx 官网，了解它们的界面和功能
2. 下载 Celtx（或你感兴趣的其他免费编剧软件）并试用
3. 思考：你更看重工具的哪个方面？价格？功能？还是行业兼容性？
