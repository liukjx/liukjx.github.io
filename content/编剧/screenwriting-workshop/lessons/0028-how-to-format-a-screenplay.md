# 第28课：剧本格式基础

## 学习目标

- 掌握剧本四大核心元素的格式规范
- 理解标题页的构成
- 了解为什么格式对剧本至关重要

## 核心内容

### 为什么格式重要？

> 推荐阅读：《好莱坞标准》（The Hollywood Standard）——剧本格式的权威指南。

虽然编剧软件会自动处理格式，但理解格式背后的逻辑仍然很重要。正确的格式让你的剧本看起来**专业、规范**，让读者（制片人、导演、演员）专注于故事本身。

### 页面基本设置

| 设置项 | 要求 |
|--------|------|
| 字体 | **12号 Courier 或 Courier New**（等宽字体） |
| 打印方式 | 业界发送：单面打印；个人使用：可双面打印 |
| 页时规则 | **一页剧本约等于一分钟银幕时间** |

> [!NOTE]
> Courier 是等宽字体（每个字符宽度相同），这使得每一页的内容量大致相等，从而有了 "一页一分钟" 的行业规则。这帮助编剧、导演和制片人评估剧本长度。

### 标题页（Title Page）

标题页包含三要素：

```
                          我的惊人剧本
                          
                           Danny Alcorn
                                      Danny Alcorn
                                      电话: 555-1234
                                      邮箱: danny@example.com
                                      地址: 123 好莱坞大道
```

| 要素 | 格式要求 |
|------|----------|
| **标题** | 页面顶部向下 4 英寸，居中，全大写，加下划线 |
| **作者名** | 标题下空两行，居中；合作编剧用 `&` 连接（如 John Doe & Sarah Smith） |
| **联系信息** | 页面右下角：电话、邮箱、邮寄地址 |

> [!TIP]
> 关于邮箱地址有不同的看法，但 Danny 认为在数字时代，邮箱是最便捷的联系方式，建议保留。

### 剧本四大核心元素

#### 1. 场景标题（Slugline / Scene Heading）

格式：**INT./EXT. 地点 — 时间**

| 组成 | 说明 | 示例 |
|------|------|------|
| 内景/外景 | `INT.`（室内）或 `EXT.`（室外），全大写加句点 | INT. |
| 地点 | 具体场景位置 | 编剧教室 |
| 时间 | DAY, NIGHT, SUNSET, DAWN, LATER, CONTINUOUS | DAY |

**完整示例：**
```
INT. 编剧教室 — 白天
EXT. 游乐场 — 晚上
INT. 约翰的车 — 日落时分
EXT. 麦当劳停车场 — 稍后
```

> [!WARNING]
> - 场景标题中**不要包含动作或冠词**（如"一个""这个"）
> - 错误：`INT. 博比睁开眼睛`
> - 正确：`INT. 博比的卧室 — 白天`，然后动作行写"博比睁开眼睛"

**什么时候需要新的场景标题？**
- 地点变化时
- 时间变化时
- 当不确定是否需要时——**为了清晰，添加它**

**边距设置：**
- 左边距：1.7 英寸
- 右边距：1.1 英寸

#### 2. 动作描述（Action / Description）

```
博比从床上坐起来，揉了揉眼睛。晨光透过窗帘的缝隙
洒在地板上。
```

| 要求 | 说明 |
|------|------|
| 时态 | **现在时**（如"邦德捡起枪"，而非"邦德捡起了枪"） |
| 标点 | 使用标准标点符号 |
| 大写规则 | 仅用于：角色**首次出场**的姓名、听到的声音（如"门铰链 **吱呀** 作响"） |
| 段落长度 | **尽量控制在四行以内**，避免大段黑字 |
| 边距 | 左 1.7 英寸，右 1.1 英寸 |

#### 3. 对白（Dialogue）

对白包含三个部分：

```
                    约翰
            妈，爸，我要入伍了。
            （停顿）
            你们这个时候应该要说点什么。
```

| 组成部分 | 边距设置 |
|----------|----------|
| **角色名**（全大写） | 左 4.1 英寸（不居中） |
| **对白内容** | 左 2.7 英寸，右 2.4 英寸 |
| **括号说明**（Parenthetical） | 左 3.4 英寸，右 3.1 英寸 |

**括号说明（Parenthetical）的使用原则：**
- 控制在 **1-2 行**以内
- 不需要大写或标点
- 不要用"他""她"（显然指发言者）
- **谨慎使用**，仅在必要时加入
- 常见用词：停顿、轻声、咳嗽、笑等

> [!TIP]
> 尽量避免过度"导演指示"。最佳的对白应该让读者从上下文中就能理解语气。

#### 4. 转场（Transition）

```
                    淡入：
```

| 转场类型 | 使用说明 |
|----------|----------|
| **淡入**（FADE IN） | **每个剧本开头** |
| **淡出**（FADE OUT） | **每个剧本结尾** |
| 切至（CUT TO） | 场景之间过渡，**谨慎使用** |
| 匹配剪辑（MATCH CUT） | 强调两个场景间视觉关联时使用 |

**边距：** 左 6 英寸

> [!IMPORTANT]
> - 切至（CUT TO）不需要在每个场景后都加，默认场景切换就是直接切换
> - 规范剧本（Spec Script）中不应出现摄像机指示，转场使用要适度

### 综合示例

```
INT. 客厅 — 晚上

罗杰和艾米·撒切尔坐在一张磨损的绿色沙发上。
他们的儿子约翰站在咖啡桌后，看着父母。

                    约翰
            妈，爸，我要入伍了。
            （停顿）
            你们这个时候应该要说点什么。
```

## 实践与反思

### 📝 写作练习

1. 打开你选择的编剧软件（Celtx 或 Final Draft）
2. 创建一个标题页，包含标题、你的名字和联系信息
3. 写一个简短场景：包含场景标题、动作描述和至少两段对白
4. 检查格式是否正确
