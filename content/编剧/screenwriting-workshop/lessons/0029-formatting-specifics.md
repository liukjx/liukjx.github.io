# 第29课：格式细节与特殊场景

## 学习目标

- 掌握闪回、梦境等特殊场景的格式
- 学会处理角色改名、双人对白等常见情况
- 了解蒙太奇和画外音的格式写法

## 核心内容

### 闪回（Flashback）与梦境（Dream Sequence）

#### 方式一：完整场景闪回

在场景标题中标注，并下划线：

```
INT. 儿童卧室 — 1917年7月 — 闪回（FLASHBACK）
```

> 如果需要更具体的时间，可以在场景标题中加入年份。

#### 方式二：快速闪现（越来越常用）

直接在动作描述中用全大写加下划线标注：

```
                    记忆闪现（FLASHBACK）

汽车在转角处失控，轮胎在柏油路上擦出火花。

                    闪回结束（END FLASHBACK）
```

**适用场景：** 梦境（DREAM SEQUENCE）、幻想（FANTASY SEQUENCE）同样适用。

#### 何时需要标注"闪回结束"？

- 如果闪回的结束点**清晰明确**，不需要特别标注
- 如果结束点**容易混淆**，在画面转场处用全大写添加 `END FLASHBACK`（左 6 英寸）

### 画面叠加文字（Superimpose）

格式：用大写写 `SUPERIMPOSE：` 后接要叠加的信息。

```
超级市场内，人来人往。

                    叠加文字（SUPERIMPOSE）：
                    "三个月后"

小林推着购物车穿过走廊。
```

### 角色改名（Character Name Change）

当角色在场景中先以匿名出现、后揭示身份时：

```
EXT. 赌场休息室 — 晚上

一位穿着讲究的男人走进休息区，在吧台坐下。

                        穿着讲究的男人
                马提尼，摇匀，不要搅拌。

他转向身旁坐着的美丽金发女郎。

                        詹姆斯·邦德（穿着讲究的男人）
                我叫邦德，詹姆斯·邦德。

                        金发女郎
        （笑）
                这是你惯用的开场白吗？

此后，他的所有对话标注为"詹姆斯·邦德"。
```

> [!TIP]
> 首次见面时，角色先以描述性名称出现；身份揭示后，在对话角色名旁用括号注明之前的代称，此后统一使用真实姓名。

### 双人对白（Dual Dialogue）

当两个角色同时说话时，将他们的对白**并排**排列：

```
艾米和杰克坐在公园的长椅上，玩着猜谜游戏。

一、二、三！

        艾米                                杰克
    红色。                              蓝色。
```

**多人同时说话的处理：**

```
                    记者1
            总统先生，这会影响战争
            吗？

                    记者2
            我们什么时候能看到结果？

                    记者3
            总统先生！总统先生！
```

如果要表现多人嘈杂的效果，也可以用正斜杠分隔角色名：

```
                    记者1/记者2/记者3
            总统先生！这会影响战争吗？
            我们什么时候能看到结果？
```

### 蒙太奇（Montage）

蒙太奇是多个快速场景的集合，用于讲述一段完整的故事。

**格式方式一（推荐）：** 作为一系列项目符号式描述列出，每个条目简洁（最多两行）：

```
蒙太奇（MONTAGE） — 准备出国

A. 她在图书馆查阅资料，书页翻飞。
B. 她在家中的行李箱前犹豫不决，衣服堆满床铺。
C. 机场航站楼，她在人群中回望。
```

**格式方式二：** 在开头加下划线标注"蒙太奇"，类似闪回的处理方式。

> 两种方式都可以，这在一定程度上取决于个人风格偏好。

### 画外音（Voice Over, VO）与画外音（Off Screen, OS）

- **V.O.** — 角色不在场景中，但声音叠加（如旁白）
- **O.S.** — 角色在场景中但不入画（如隔壁房间说话）

格式：在角色名后的括号中标注：

```
                        小林（V.O.）
            那时候我还不明白，这将
            改变一切。

                        隔壁传来声音：
                        老张（O.S.）
                谁在外面？
```

## 格式总结表

| 场景类型 | 关键格式要点 |
|----------|------------|
| 闪回 | 场景标题加 `— 闪回（FLASHBACK）` 或动作描述中标注 |
| 梦境/幻想 | 同闪回处理 |
| 闪回结束 | 仅在不清晰时加 `END FLASHBACK` |
| 叠加文字 | `叠加文字（SUPERIMPOSE）：` |
| 角色改名 | 新名（曾用名） |
| 双人对白 | 并排列出 |
| 多人同时说话 | 并排列出或用斜杠分隔 |
| 蒙太奇 | 项目符号式简洁列出 |
| V.O. / O.S. | 角色名后括号标注 |
