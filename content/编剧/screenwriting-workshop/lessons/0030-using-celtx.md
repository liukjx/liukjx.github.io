# 第30课：使用 Celtx 编写剧本

## 学习目标

- 掌握 Celtx 的基本界面和操作流程
- 学会在 Celtx 中设置标题页、编写场景
- 了解 Celtx 的高级功能（索引卡、主目录）

## 核心内容

### Celtx 界面概览

![Celtx 界面](https://via.placeholder.com/600x400?text=Celtx+界面示意图)

初次打开 Celtx，你会看到：

- **最近项目列表** — 快速访问你正在进行的项目
- **项目模板** — 可选择电影、话剧、音频剧等模板
- **我们选择：电影模板（Film）**

### 标题页设置

在标题页标签（Title Page）中填写：

| 字段 | 示例 |
|------|------|
| 剧本标题 | 我的伟大剧本 |
| 作者名 | Danny Alcorn |
| 联系信息 | 电话、邮箱、地址 |

### 基本写作流程

#### 步骤 1：场景标题

在 **下拉菜单** 中选择"场景标题（Scene Heading）"：

```
丹尼的客厅 — 白天
```

按下回车 → 自动跳转至"动作行（Action）"

#### 步骤 2：动作描述

```
丹尼和她的朋友们在客厅里坐着。
```

#### 步骤 3：对白

按下 **Tab 键** → 进入"角色名"模式：

```
                    丹尼
```

按下回车 → 进入"对白"模式：

```
                    丹尼
            谁准备好吃午餐了？
```

#### 步骤 4：创建新场景

完成一段动作或对白后，按两次回车 → 进入新的场景标题。

### 操作技巧

| 操作 | 说明 |
|------|------|
| Tab 键 | 切换到下一元素类型 |
| 回车键 | 进入当前元素的编辑 |
| 下拉菜单 | 手动选择元素类型（场景标题/动作/角色/对白/转场） |
| 角色记忆 | 输入首字母会自动提示之前用过的角色名 |

#### 自动格式化的便利

Celtx 智能识别：

```
丹尼的客厅 — 白天  →  自动格式化为完整场景标题
丹尼                →  自动格式化为大写角色名
```

### 双人对白功能

1. 选中两个角色的对白文本
2. 点击工具栏中的"双对话（Dual Dialogue）"按钮
3. 对白会自动并排显示

### 导出 PDF

1. 下滑到页面底部
2. 点击"类型设置 PDF（Typeset PDF）"标签
3. 选择格式选项：
   - 场景编号（Scene Numbers）：**规格剧本设为"无"**
   - Mores & Continues：建议开启（自动标注翻页处）

> [!WARNING]
> Celtx 的**实时拼写检查**不太可靠。每次导出前，记得手动点击"拼写检查（Spell Check）"按钮。

### 进阶功能

#### 索引卡（Index Cards）

每个场景自动生成一张索引卡：

- 可以添加场景备注
- 可以标记情节线（A/B 情节）
- 可以用颜色标记（如反派场景标蓝色）
- 可以拖拽调整场景顺序

#### 草稿本（Scratch Pad）

为场景添加灵感笔记的临时区域：

```
场景3备注：引入反派——他是服务员，
但丹尼并不知道。
```

#### 主目录（Master Catalog）

管理剧本中的所有角色信息：

| 功能 | 说明 |
|------|------|
| 角色列表 | 查看所有角色及其出现场景 |
| 角色描述 | 添加外貌、性格特征、动机 |
| 场景关联 | 查看角色在哪些场景中出现 |

> [!TIP]
> 讲师 Danny 坦言并不太使用主目录功能。她习惯在写作前用 Word 文档整理角色信息。你可以根据自己的习惯决定是否使用这些辅助功能。

## 实践与反思

### 📝 本周任务

1. 下载并安装 Celtx（免费）
2. 创建一个新项目，设置标题页
3. 写至少 3 个场景的小剧本片段
4. 尝试创建双人对白
5. 导出为 PDF，检查格式

> [!NOTE]
> 花 10-15 分钟熟悉 Tab 和回车的导航方式，你会迅速掌握 Celtx 的使用。

---

> 工具是手的延伸。当你熟悉了 Celtx 的操作后，格式问题将不再干扰你的创作流——你可以全心投入故事本身。
