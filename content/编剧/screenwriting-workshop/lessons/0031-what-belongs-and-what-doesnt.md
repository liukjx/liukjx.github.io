# 第31课：优秀剧本——该写什么与不该写什么

## 学习目标

- 理解规范剧本（Spec Script）与拍摄剧本（Shooting Script）的区别
- 掌握剧本中该写和不该写的内容
- 学会"展示而非告诉"（Show, Don't Tell）的核心原则

## 核心内容

### 规范剧本 vs. 拍摄剧本

| 对比项 | 规范剧本（Spec Script） | 拍摄剧本（Shooting Script） |
|--------|------------------------|----------------------------|
| 目的 | 展示创意，寻找买家 | 实际拍摄使用 |
| 摄像机指示 | **绝对禁止** | 可以有 |
| 场景编号 | **不应出现** | 必须有 |
| 作者 | 编剧独立完成 | 编剧+导演+摄影师协作 |

> [!IMPORTANT]
> 作为课程学员，你正在写的是**规范剧本**。规范剧本的第一条铁律就是：**绝对不要提到摄像机**。

### 剧本的黄金法则

```
✅ 剧本中只能写：  看得见的画面 + 听得见的声音
❌ 剧本中不能写：  看不见的东西（情感、内心想法、背景故事）
```

#### ❌ 错误示例（小说式写法，应避免）

```
她因为她的狗跑掉了而感到伤心。
```

**为什么错？** "感到伤心"——我们看不见情感。

#### ✅ 正确示例（电影式写法）

```
她凝视着空荡荡的狗窝。
她嗅了嗅，用袖子擦了擦鼻子。
```

**为什么对？** 这些动作是**可拍摄的**，观众通过视觉自然理解她在伤心。

### 如何巧妙实现"想要的镜头"？

虽然你不能直接写摄像机指示，但可以通过**描述方式**巧妙引导：

> [!TIP]
> **例：** 你想要一个从脚踝往上摇到头顶的镜头。
>
> **聪明写法（不提摄像机）：**
> 她的粉色高跟鞋带子缠绕在纤细的脚踝上，紧扣着结实的小腿。
> 她的粉色裙子在微风中轻轻摇曳。
> 她手中提着一个奢华的设计师包包。
> 她微笑着，优雅地甩动着她那完美的金色长发。
>
> **效果：** 除了从下往上拍摄，没有第二种拍法能呈现这些细节。你巧妙地"迫使"导演采用你想要的镜头。

### 剧本写作的核心原则

#### 1. 用现在时写作

```
✅ 邦德捡起枪。
❌ 邦德捡起了枪。
```

剧本是**此时此刻正在发生**的体验。

#### 2. 全面、形象、简洁

- **全面**：包含所有必要信息
- **形象**：创造生动的视觉画面
- **简洁**：用最少的词传达最多的信息

#### 3. 保持一致的语调

| 类型 | 动作描述的语调 |
|------|--------------|
| 喜剧 | 可以诙谐、讽刺、夸张 |
| 戏剧 | 应该庄重、克制 |

> 你的动作描述风格本身就在传达电影的氛围。

#### 4. 用视觉呈现背景故事

**技巧一：扫过照片**
```
镜头扫过墙上的照片——一座小镇的全家福。
```

**技巧二：融入对话**
```
                    老张
        （看着老照片）
        那是……1998年？我们刚结婚那会儿。
```

### 剧本中不应出现的内容

```
❌ 角色的内心想法（"她想……""他感到……"）
❌ 情感描述（"悲伤地""愤怒地"）
❌ 背景故事说明
❌ 摄像机指示（"镜头推近""特写"）
❌ 对演员的表演指导（"慢慢地""深情地"）
❌ 替代导演的工作
```

### 把剧本看作"印象派绘画"

编剧的工作是**建议轮廓、形状和形式**，给导演和演员留出空间来填充细节。

```
过于细致（微观管理）：
她走到橱柜前，打开柜门，拿出面包，关上柜门，
打开冰箱，取出花生酱和果酱，关上冰箱门……

适度描述（印象派）：
她做了一个花生酱果酱三明治。
```

> [!IMPORTANT]
> 唯一需要加入细节的时候是：**这些细节对故事或角色揭示至关重要**。例如，角色只吃草莓果酱——而这将成为破案的关键线索。

### 剧本的首要目标：**清晰（Clarity）**

> 绝不要让读者停下来思考："等等，这是怎么回事？"

读者应该**始终清楚**：
- **谁**在对谁做什么
- **何时**发生
- **何地**发生

如果这些信息丢失了，没人能想象出你的电影会是什么样子。

## 实践与反思

### 📝 本周练习：从电影到剧本

1. 挑选一部你喜欢的电影片段
2. 重温这个片段
3. **尝试写出它在剧本中的样子**
4. 专注于**你能看到和听到的内容**
5. 剔除所有无关的细节

<details>
<summary>📌 练习要点</summary>

这个练习帮助你思考"从纸面到银幕"的过程中，哪些内容可以呈现、哪些不能呈现。比如：

- 角色的情感 → 通过表情和动作呈现
- 背景故事 → 通过对话或环境细节暗示
- 氛围 → 通过声音和视觉描述创造

</details>

---

> 学会"展示而非告诉"，是小说家转型为编剧的最大跨越。当你开始用眼睛和耳朵而不是用内心独白讲故事时，你就真正成为了一个编剧。
