# 第32课：写好对白

## 学习目标

- 理解对白的核心目的：推动情节或揭示角色
- 掌握让对白听起来自然真实的技巧
- 学会赋予每个角色独特的声音
- 理解潜台词（Subtext）的重要性

## 核心内容

### 对白的两个核心目的

> 每段对白至少应该满足其中一个目的，**最好两个都满足**。

1. **推动情节（Advance the Plot）**
2. **揭示角色（Reveal Character）**

如果没有满足任何一个——**删掉它**。

#### 避免无意义的寒暄

你注意到电影里没有人会在电话中说"再见"吗？因为没有意义。

```
❌ 应该删掉的对话：
"你好吗？"
"我很好，你呢？"
"我也很好。"

✅ 直接切入重点：
"计划有变，今晚八点老地方见。"
```

> [!TIP]
> 尽快切入场景或对话的**重点**。省略日常对话中的客套部分，这对观众是一种尊重。

### 优秀对白的特征

#### 1. 听起来自然

**选词要符合角色身份：**
- **年龄**：老人和青少年的用词不同
- **教育程度**：大学教授和街头小贩的词汇量不同
- **地域背景**：南方人和北方人的俚语不同

```
例：健怡可乐
佛罗里达人称它为"苏打（Soda）"
中西部人称它为"汽水（Pop）"
——如果写一个芝加哥角色说"苏打"，就会显得不真实。
```

**时代感要注意：**
```
"第22条军规（Catch-22）"这个短语在1961年之后才进入日常用语。
如果你写发生在1950年代的角色说这个，会非常出戏。
```

**人们通常用缩写：**
```
✅ "我不会（I won't）"、"不能（I can't）"
✅ "我不会这样做（I will not do this）"——只在强调时用完整形式
```

**人们通常不说完整的句子：**
```
✅ "来不来？"（而非"你要不要来？"）
✅ "门口等你。"（而非"我会在门口等你。"）
```

> [!WARNING]
> 不要为了真实感而牺牲清晰度。你的目标是在真实与可理解之间找到平衡。

#### 2. 每个角色声音独特

理想情况下，即使没有上下文，读者也能从一句对白判断出是谁在说话。

**经典例子：**

| 角色 | 独特之处 |
|------|---------|
| 尤达（《星球大战》） | 倒装句语序 |
| 布朗博士（《回到未来》） | 夸张、充满激情 |
| 罗宾（《如果你相信》） | 从不说完整的句子 |

**为什么重要？**
如果每个角色说话方式都一样——电影会变得非常无聊。

**《第五元素》中的三个角色：**
- 科尔宾·达拉斯
- 鲁比·罗德
- 莉露

你不会把任何一个人的台词与其他人的混淆。

#### 3. 独特且有原创性

**避免陈词滥调（Cliché）：**
定期审视剧本，找出那些用滥了的表达，用全新的方式替换。

**谨慎引用经典台词：**
除非你的角色本身就有"爱引用别人话"的特点——否则观众会认出这是别人的台词，而不是你的原创。

### 潜台词（Subtext）

> 潜台词是角色**没说出口**的那部分意思——真正的意图藏在话语之下。

```
角色说："我很好。"
潜台词："我一点都不好，但我不想让你知道。"
```

优秀对白的美妙之处往往在于它**没有说出来的东西**。

### 实用的对白技巧

#### 打断与重叠

人们经常会打断对方、抢着说话。你可以在对白中体现这一点：

```
艾米
我从来没想过要……
杰克
（打断）
……你总是这样。

```

> 《月光（Moonlighting）》整部剧集都围绕角色互相打断、从不听对方说话展开。适度使用可以创造喜剧效果。

#### 对白密度

| 类型 | 对白密度 |
|------|---------|
| 快节奏喜剧 | 对白密集、语速快 |
| 悬疑惊悚 | 对白少、留白多 |
| 文艺剧情 | 对白适中、注重潜台词 |
