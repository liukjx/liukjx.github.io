# 第33课：写好动作/场景描述

## 学习目标

- 掌握动作描述的核心技巧：简洁、形象、现在时
- 学会用细节选择来塑造角色和氛围
- 理解"展示而非叙述"在动作描述中的具体运用

## 核心内容

### 动作描述的基本原则

> 剧本的大部分内容是动作描述，所以这一课很大程度上是对上一课的深化。

#### 1. 用现在时写作

```
✅ 邦德捡起枪。
❌ 邦德捡起了枪。
```

剧本是「此时此刻正在发生」的体验。

#### 2. 绝不要提到摄像机

虽然不能写摄影机指示，但可以通过**巧妙描述**引导拍摄方式：

<details>
<summary>📌 经典例子</summary>

**想要的镜头：** 从脚部向上摇到头顶的镜头

**聪明写法：**
她的粉色高跟鞋带子缠绕在细的脚踝上，紧扣着结实的小腿。
她的粉色裙子在微风中轻轻摇曳。
她微笑着，优雅地甩动着完美金色长发。

**效果：** 只有一种拍摄方式能捕捉这些细节——你巧妙地让导演「不得不」采用你的方案。

</details>

#### 3. 简洁第一

| 理想长度 | 说明 |
|---------|------|
| ✅ **一行** | 完美 |
| ✅ **两行** | 很好 |
| ✅ **四行以内** | 可接受 |
| ❌ **超过四行** | 太长了，会被拒绝 |

> [!WARNING]
> 剧本被拒绝的最常见原因之一就是**描述过多**——页面上有大片黑色文字，看起来很吓人。

#### 4. 使用正确的标点和语法

这让你看起来专业。不做的话会让读者怀疑你的严谨程度。

### 动作描应该写什么

```
✅ 可以写的内容：
- 角色看得见的动作（走路、说话、吃饭、哭泣）
- 听得见的声音（门响、玻璃碎、笑声）
- 环境的视觉细节（光线、颜色、空间布局）
- 角色的外貌特征

❌ 不可以写的内容：
- 角色的内心感受（"她感到悲伤"）
- 背景故事
- 摄像机指示
- 替代导演和演员的工作```

### 「展示而非叙述」在动作描述中的体现

**错误方式（小说式）：**

```
她因为男友和她分手了而感到难过。
```

**正确方式（电影式）：**

```
她拿起桌上的合影照片，看着它。
停顿。
她把照片翻了过去——面朝下扣在桌上。
然后继续做她的花生酱果酱三明治。
```

通过可视的动作，我们「看见」了她的难过。

### 细节的选择：什么该写，什么不该写

#### 不需要写的细节（太琐碎）

```
❌ 她从厨柜拿出面包，打开冰箱，取出花生酱，
拧开盖子，拿出刀，把花生酱涂在面包上……
```

> 每个人都知道怎么做花生酱果酱三明治。如果你写「她在做一个花生酱果酱三明治」，演员和导演自然会把它做好。

#### 需要写的细节（对故事有意义）

```
✅ 她从厨柜里拿出面包，又从冰箱取出草莓果酱——
    她只吃草莓味的。

如果这条线索后来在破案时出现（某人在草莓果酱罐上发现了指纹），
那么这个细节就值得写。
```

> [!TIP]
> 只加入那些**揭示角色**或**铺后续情节**的细节。如果一个细节没有叙事功能——删掉它。

### 用动作描写角色与空间

好的动作描述不只告诉读者「这个房间长什么样」，而是通过**角色的动作**来揭示环境。

**静态描述：**

```
INT. 简的客厅 — 白天
地板上满地是破旧的塑料儿童玩具。
```

**通过动作描述（更生动）：**

```
INT. 简的客厅 — 白天
简把脚边一个破烂的塑料玩具踢到一边。
```

信息相同，但后者有了角色在空间中的互动，更生动。

### 四个客厅·四种人物性格

仅仅通过几个词的描述，就能创造完全不同的环境和角色印象：

| 角色 | 客厅描述 | 推断出的性格 |
|-----|---------|------------|
| **简** | 地板上是破旧的塑料儿童玩具 | 年轻母亲，家庭生活忙乱 |
| **萨蔓莎** | 先烤的饼干放在闪亮的咖啡桌上 | 精致、好客、有条理 |
| **艾米** | 健身车停在大屏电视前 | 注重健康、现代生话 |
| **詹妮弗** | 窗帘柔和光线，风格不一但舒适的家具 | 有品味、温和、舒适 |

> [!NOTE]
> 选词和细节的不同，决定了读者对角色产生完全不同的印象。这就是精准描述的力量。

### 动作描述检查清单

在写每段动作描述时问自己：

- [✅] 这是现在时吗？
- [✅] 有没有提到摄像机？
- [✅] 能控制在四行以内吗？
- [✅] 每个细节都是看得见、听得见的吗？
- [✅] 这些细节对故事或角色有意吗？
- [✅] 读者知道谁在哪里、在做什么吗？

## 实践与反思

### 📎 本周练习

从本课「四个客厅」的例子中选择**萨蔓莎、艾米和詹妮弗**中的两位：

1. **第一步：** 用一段静态描述写出她们的客厅
2.**第二步：** 改为通过**角色动作**来描述同样的空间
3. **最终目标：** 浓缩成一句话，但仍然揭示静态描述中的所有细节

<details>
<summary>📌 示例参考</summary>
**萨蔓莎的客厅 — 动作版：**

萨蔓莎轻轻地将一盘刚出炉的饼干放在闪亮的咖啡桌上的小茶垫上，摆正位置后满意地退后一步。

→ 这句话既描述了房间的整洁精致，也暗示了主角的性情。

</details>

> 动作描述是剧本的骨架。用最少的词创造最生动的画面——这是编剧的艺术。
