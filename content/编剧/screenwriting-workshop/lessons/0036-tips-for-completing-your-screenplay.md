# 第36课：完成剧本的实用建议

## 学习目标

- 掌握克服写作障碍的方法
- 建立可持续的写作习惯
- 理解"完成比完美更重要"的核心理念

## 核心内容

### Danny 的六条实用建议

#### 1. 明确方向，制定计划

> **大纲**就是你的路线图和角色设计。

没有计划的情况：

```
写出精彩的第一幕
↓
迷失方向
↓
灵感缺失
↓
失去动力
↓
剧本搁置
```

> 在开始写剧本之前，确保你手边有大纲。它会带你安全通过情节的每一个转折。

#### 2. 写作——去做就对了!

> 每个人在开始写作时都会写出一些废话。

写作的真实体验：

```
坐下來 → 感觉毫无灵感 → 我不知道在写什么 → 我不想写了
↓（坚持10-15分钟）
扔掉第一页
↓
写出来的东西开始变好了
↓
你热身了，准备好了
```

> [!IMPORTANT]
> **最关健的一点**：腾出时间，坐下，開始写。

#### 3. 不要在30页后停下

| 阶段 | 感受 | 建议 |
|-----|------|------|
| **第一幕** | 蜜月期 — 兴奋、灵感涌现 | 尽情享受，但不要自满 |
| **第二幕** | 困难期 — 保持悬念、节奏、角色一致性 | **坚持下去**！有线路图在手就会容易很多 |
| **第三幕** | 收获期 — 角色已熟悉、声音已确立 | 第三幕会自然写出来 |

> 没有什么比打下"完"字并翻到最后一页更令人满足的事了。

**三个关键点（Beat）的结构力量：**
如果你在大纲中设置了九個检查点，你确切知道每个环节需要发生什么。

#### 4. 不要在写作时重写

> 在写作过程中停下来编辑——这是最具诱惑力的陷阱。

**行动规则：**

```
❌ 停在半路 → 回头编辑 → 反复修改 → 永远到不了终点

✅ 继续前行 → 保持势头 → 写完全稿 → 再来重写
```

> 你有的是时间来重写——我们会在后面的课程中专门讨论重写的技巧。

#### 5. 找出适合你的工作模式

**关键：** 了解自己何时最有创造力和生产力。

```
如果你不是早起的人：
  ❌ 早起一小时 → 你会又累又情绪不好

如果你是早起的人：
  ✅ 提前一小时起床写剧本

如果你是夜猫子：
  ✅ 晚上泡杯茶，舒舒服服地写
```

> 不管是什么模式——制定计划并**坚持执行**。

#### 6. 给自设置截至日期

**确保截期现实可行。**

专业人士的参考标准：

> 专业编剧被雇佣写一个剧本——大约需要 **10到12周**（全职）。

你可以在设定目标时参考这个基准。

> [!NOTE]
> Danny 的个人经验是：她在构思阶段花的时间比实际写作阶段多。一旦開始写作，她会变得有点强迫症——就想一口气把它写完。
>
> 你可能正好相反——快速确定创意，花更多时间在写作阶段细磨每个场景。无论哪种方式，只要**持续前進**，都是可以的。

### 写作心态的核心

#### 关于"完美初稿"的迷思

```
初稿（First Draft）= 把故事先倒出来
重写（Rewrite）= 从初稿中提炼精华
```

> 不要期待第一稿就是完美的。没有人的初稿是完美的。

#### 写作节奏的认知

写作不总是线性的。有时你会：

- 一天写10页
- 然后三天写不出一个字

> 这是正常的。关健是不要停止。

## 实践与反思

### 📎 开始行动清单

```
[] 确认你的大钢已经准备好
[] 设定每周写作时间（固定时段）
[] 设定一个现实的完成日期
[] 告诉一個朋友你的目标（增加责任）
[] 准备一个专用的写作空间
[] 打开编剧软件 → 开始写第一页
```
