# 第49课：编剧在线资源

## 学习目标

- 了解 Without a Box 等投稿平台的使用方法
- 掌握 InkTip 等推介平台的核心价值
- 学习如何评估和选择付费资源
- 学会利用在线工具追踪剧本的曝光情况

## 核心内容

### 在线资源的整体策略

在数字化时代，线上渠道已经成为剧本推广的重要途径。本课将介绍几个最实用的平台，但请记住：

> [!WARNING]
> 花钱时要谨慎。容易被各种"必赢"的噱头吸引，但一定要做好功课，查看网站外部的评论再做决定。

### 1. Without a Box

**网址**：withoutabox.com

- 大多数剧本比赛使用的**在线提交系统**
- 一次上传剧本，可同时向多个比赛提交
- 可查看提交状态
- 每周收到关于值得关注的比赛的邮件
- **用户界面评分**：3/5——功能实用，但体验一般

> [!TIP]
> Without a Box 的"比赛聚焦"邮件非常有用——经常会介绍一些你从未想过要去寻找的比赛。

### 2. Script Pipeline 编剧数据库

**性质**：需要年费的会员制平台

**功能：**
| 功能 | 说明 |
|------|------|
| **提交查询信** | 向平台提交 Logline、大纲等供审核 |
| **搜索需求** | 查看谁在寻找什么样的剧本 |
| **剧本评估折扣** | 行业专业人士给出反馈意见 |
| **曝光机会** | 高管可以浏览你的作品 |

**作者亲身体验**：参加了 Script Pipeline 的学生比赛后，获得了五年免费会员资格。投稿后收到了非常详细的个性化反馈——不是自动回复，而是一封长邮件，指出"你的对白需要改进"，并给出了具体建议。

> [!NOTE]
> 不保证每个人都能获得如此深入的关注，但这种可能性存在。对于认真寻求突破的编剧来说，值得考虑。

### 3. InkTip（最推荐的平台）

**网址**：inktip.com

**核心功能：**

1. **发布剧本** —— 约70美元，可在网站发布剧本六个月
2. **上传材料** —— PDF文件、Logline、一页概述（One-Pager）
3. **查看浏览记录** —— 谁查看了你的简介和概要
4. **优化简介** —— 六个月发布期内可以随时修改简介，测试不同版本的效果

**为什么推荐 InkTip？**

| 优势 | 说明 |
|------|------|
| **行业专业人士活跃** | 真正的制片公司和业内人士在使用这个平台 |
| **数据透明** | 你可以看到谁看了你的简介 |
| **A/B 测试** | 尝试不同版本的简介，看哪个更吸引人 |
| **性价比高** | 六个月约70美元，物有所值 |

> 如果你发现很多人点击了你的简介但没有人要求读完整剧本——这不代表故事有问题，说明你的简介需要改进。

#### InkTip 的 Newsletter

**价格**：约35-60美元（取决于优惠活动）
**时长**：四个月
**内容**：每周一封邮件，包含6-10个正在寻找特定剧本的制片公司线索

**推荐理由：**
- 即使你不投稿，也能了解当前市场在寻找什么类型的剧本
- 大部分公司会回复你的邮件（即使不符合需求也会礼貌回复）
- 偶尔还能获得创意灵感——看到有人寻找某个特定主题，可能会激发新想法

> [!TIP]
> "我觉得 InkTip 的 Newsletter 绝对值得购买。即使只是为了追踪市场风向——人们现在在寻找什么、什么类型很热门——就已经很有价值了。"

### 四个平台对比一览

| 平台 | 费用 | 适用场景 | 推荐度 |
|------|------|----------|--------|
| **Without a Box** | 投稿费另计 | 查找和提交比赛 | ★★★★ |
| **Script Pipeline** | 年费 | 获得行业反馈和曝光 | ★★★ |
| **InkTip 发布** | ~70美元/6个月 | 直接曝光给行业人士 | ★★★★★ |
| **InkTip Newsletter** | 35-60美元/4个月 | 追踪市场需求线索 | ★★★★★ |

### 如何最大化利用在线资源

1. **先做功课** —— 在付费前查阅外部评论
2. **准备充分** —— 确保 Logline 和概述已经打磨到位
3. **追踪数据** —— 关注哪些简介版本获得更多点击
4. **保持迭代** —— 根据数据反馈不断优化推介材料
5. **关注市场** —— 了解当前热门类型和需求

## 实践与反思

### 练习1：评估你的材料

在注册任何付费平台之前，先确保你的 Logline 和概述（One-Pager）已经打磨到位。重新审视第39课的内容，确保你的推介材料能达到"让人想看"的水平。

### 练习2：研究一个平台

选择一个本课提到的平台，去它的网站了解具体价格和服务条款。问问自己：这个平台适合我现在所处的阶段吗？

<details>
<summary>选择平台的参考思路</summary>

- **如果你刚刚完成第一稿**：先参赛积累资历（Without a Box）
- **如果你有多部完成稿**：考虑 InkTip 发布，直接推向市场
- **如果你需要反馈**：Script Pipeline 的评估服务可能有帮助
- **如果你想了解市场**：InkTip Newsletter 是最低成本的选项

</details>
