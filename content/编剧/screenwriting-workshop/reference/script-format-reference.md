# 剧本格式速查表

> [!TIP] 黄金法则
> 剧本是**蓝图**，不是文学作品。它只需要包含**可见的画面**和**可听见的声音**。

## 五大核心元素

| 元素 | 格式要求 | 用途 | 示例 |
|------|----------|------|------|
| **Slugline（场景标题）** | 大写 + 左对齐 | 标示场景开始，指定地点和时间 | `INT. 卧室 - 夜晚` |
| **Action（动作描述）** | 左对齐 + 现在时 | 描述可见的动作和画面 | `她打开门，愣住了。` |
| **Character（角色名）** | 居中 + 大写 | 标示即将说话的角色 | `张三` |
| **Dialogue（对白）** | 居中缩进 | 角色说的话 | `你来了。` |
| **Transition（转场）** | 右对齐 | 场景之间的过渡 | `CUT TO:` |

## Slugline 格式

```
INT. / EXT. 地点 - 时间
```

- **INT.** = Interior（内景）
- **EXT.** = Exterior（外景）
- **时间**: 白天/夜晚/黎明/黄昏（DAY/NIGHT/DAWN/DUSK）

> [!EXAMPLE]
> ```
> EXT. 曼哈顿街道 - 白天
> INT. 咖啡馆 - 夜晚
> EXT. 太空船 - 太空
> ```

## 角色介绍

首次介绍重要角色时，在动作描述中用大写标出角色名：

> [!EXAMPLE]
> 门开了，走进来一个中年男人——**张三（40岁）**，西装笔挺，手里拎着一个公文包。

## 对白扩展标记

| 标记 | 含义 | 使用场景 |
|------|------|----------|
| `(V.O.)` | Voice Over 旁白 | 角色以画外音叙述 |
| `(O.S.)` | Off-Screen 画外音 | 角色在同一场景但不在画面中 |
| `(CONT'D)` | Continued 继续 | 同一角色的对白被动作打断后继续 |
| `(beat)` | 节拍停顿 | 对白中的短暂停顿或情感转折 |

## 完整场景示例

```
INT. 书房 - 夜晚

台灯照亮了堆满书的书桌。张三盯着电脑屏幕，手指在键盘上悬空。

                    张三
            （自言自语）
            还得再改一遍。

手机震动。张三看了一眼来电显示——是李四。

                    张三
            （接起电话）
            喂？

                    李四（V.O.）
            你看到邮件没有？

张三站起身，走到窗边。窗外城市的灯火闪烁。

                    张三
            刚准备看。什么事？

CUT TO:
```

## 常见错误

> [!WARNING]
> - ❌ 写角色的内心活动（观众看不到）
> - ❌ 写摄像机指示（"镜头推近"）
> - ❌ 写导演指示（"切换到慢动作"）
> - ❌ 写冗长的环境描写（除非对故事重要）
