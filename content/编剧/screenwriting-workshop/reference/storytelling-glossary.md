# 编剧术语表

## 故事基础

| 术语 | 英文 | 定义 |
|------|------|------|
| 情节 | Plot | 故事中事件的有序排列 |
| 故事 | Story | 事件背后的原因和情感意义 |
| 主题 | Theme | 故事的核心思想或普世命题 |
| 前提 | Premise | 故事的基本设定 |
| 类型 | Genre | 故事所属的种类（剧情、喜剧、科幻等） |
| 惯例 | Convention | 特定类型的观众期待元素 |

## 结构术语

| 术语 | 英文 | 定义 |
|------|------|------|
| 三幕结构 | Three-Act Structure | 建立-对抗-解决的经典结构 |
| 四幕结构 | Four-Act Structure | 电视剧常用的四幕叙事 |
| 激励事件 | Inciting Incident | 打破平衡、启动故事的事件 |
| 转折点 | Plot Point | 故事方向发生改变的关键时刻 |
| 中点 | Midpoint | 故事中间的转折 |
| 高潮 | Climax | 冲突最激烈的时刻 |
| 结局 | Resolution | 高潮后的收尾 |
| 悬念 | Cliffhanger | 在关键时刻悬而未决的结尾 |
| 伏笔 | Foreshadowing | 为后续事件埋下的暗示 |
| 节奏 | Pacing | 故事展开的速度 |

## 角色术语

| 术语 | 英文 | 定义 |
|------|------|------|
| 主角 | Protagonist | 驱动故事的中心人物 |
| 反派 | Antagonist | 制造冲突的对立面 |
| 配角 | Supporting Character | 围绕主角的其他角色 |
| 角色弧光 | Character Arc | 角色的成长变化轨迹 |
| 原型 | Archetype | 普遍的角色模式 |
| 英雄之旅 | Hero's Journey | 12 阶段叙事模型 |
| 缺陷 | Flaw | 角色的内在弱点 |
| 欲望 | Desire | 角色想要的东西 |
| 需求 | Need | 角色真正需要的东西 |
| 潜台词 | Subtext | 对白之下的真实含义 |

## 写作工具

| 术语 | 英文 | 定义 |
|------|------|------|
| Logline | Logline | 一两句剧情概要 |
| Synopsis | Synopsis | 一页的故事摘要 |
| Treatment | Treatment | 详细的剧本大纲 |
| Outline | Outline | 场景列表式提纲 |
| 初稿 | First Draft | 剧本的第一个完整版本 |
| 重写 | Rewrite | 系统性修改过程 |
| Workshop | Workshop | 集体反馈的工作坊 |

## 剧本格式

| 术语 | 英文 | 格式 |
|------|------|------|
| 场景标题 | Slugline | INT./EXT. 地点 - 时间 |
| 动作描述 | Action | 左对齐，现在时 |
| 角色名 | Character | 居中大写 |
| 对白 | Dialogue | 居中缩进 |
| 转场 | Transition | 右对齐 |
| 旁白 | V.O. | Voice Over |
| 画外音 | O.S. | Off-Screen |
