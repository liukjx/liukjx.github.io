# 课程地图

## 推荐学习路径

```mermaid
flowchart TD
    M1[模块 1：故事引擎] --> M2[模块 2：核心理论]
    M2 --> M3[模块 3：作者的角色]
    M2 --> M4[模块 4：角色的角色]
    M3 --> M5[模块 5：接收者的角色]
    M4 --> M5
    M5 --> M6[模块 6：故事开发流程]
```

## 模块依赖关系

| 模块 | 前置要求 | 核心产出 |
|------|---------|---------|
| 模块 1 | 无 | 课程概览与故事引擎比喻 |
| 模块 2 | 模块 1 | 知识缺口理论体系 |
| 模块 3 | 模块 2 | 作者的框架工具集 |
| 模块 4 | 模块 2 | 角色行动的设计工具 |
| 模块 5 | 模块 2 + 3 + 4 | 接收者意义的创造 |
| 模块 6 | 全部前置 | 完整故事开发流程 |

```mermaid
flowchart LR

    C -.->|反馈循环| A
```
