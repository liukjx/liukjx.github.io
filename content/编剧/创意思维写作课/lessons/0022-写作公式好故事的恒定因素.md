# 第22课：写作公式——好故事的恒定因素

## 学习目标

- 记住并理解三大核心写作公式
- 掌握戏剧性渴望与戏剧性障碍的设置方法
- 学会通过"渴望-障碍-行动"循环推动情节
- 理解"行动就是性格"的创作原则

## 三大核心公式

故事写作有其恒定的基本规律，无论讲什么类型的故事，以下三个公式都是你反复修炼的基本功。请将它们抄在本子上，并牢牢记住。

### 公式一：没有冲突 = 没有故事

在故事的世界里，读者喜欢"不忠的肩负甚于忠贞的猎犬"。虚构文学是"肮脏的游戏"。一个完美的人物是无聊的。

严歌苓的小说《芳华》中，如果刘峰没有因为情欲而抱了林丁丁，刘峰的故事就没有办法继续讲下去。一个人见人爱的雷锋般的人物，有什么好看的呢？读者很快就会对他失去兴趣。但圣人也是有情感的——刘峰终于还是"犯了错误"，也正因如此，我们才开始在刘峰身上投入情感，关注他的故事。小说中的叙述者萧穗子坦言：早在刘峰抱林丁丁之前，她的内心就有了对刘峰犯错的期待，因为一个没有瑕疵的人，是那么的不真实。

> [!TIP] 核心启示
> 如果你要让冲突发生，故事里的主人公必然不可能是完美的。即使他以完美的形象出场，那也是为之后的剧情转折埋下的伏笔。

### 公式二：渴望 + 障碍 = 冲突

讲故事就是要制造麻烦。你要让人物始终麻烦缠身、冲突不断。但并非所有的麻烦事都是冲突——故事里的冲突应该是可以推动情节发展的**戏剧性冲突**。而要想让戏剧性冲突发生，你必须给人物两个要素：

| 要素 | 定义 | 关键要求 |
|------|------|----------|
| 戏剧性渴望 | 人物必须感觉到这个渴望的满足与否是**生死攸关**的大事 | 情感、身体、社会或经济层面事关存亡 |
| 戏剧性障碍 | 假如人物不理会这个障碍，也不采取行动，就要遭受严重危害或灭顶之灾 | 必须与渴望**旗鼓相当**，势均力敌 |

**经典案例对照：**

| 作品 | 渴望 | 障碍 |
|------|------|------|
| 《飘》 | 斯嘉丽希望得到阿希里的爱情 | 阿希里就要和梅勒尼结婚 |
| 《罗密欧与朱丽叶》 | 罗密欧和朱丽叶希望结合 | 两家是世仇 |
| 《白鲸》 | 亚哈想要杀掉鲸鱼 | 必须征服鲸鱼和大海 |

如果其中一方太弱，故事就没有冲突可言了。假如亚哈非常走运，碰到鲸鱼时它正在浅滩打盹，还没等鲸鱼回过神来就被钢叉扎了个透心凉——这里没有任何障碍，也没有任何冲突和情节可言。反之，假如亚哈变得"聪明"，意识到冒着生命危险追杀鲸鱼不划算——故事就没有渴望，没有冲突，也没有故事了。

> [!WARNING] 关键守则
> 故事的定势永远是：**渴望-障碍-行动，渴望-障碍-行动，反复再三，并且情况变得越来越糟**，一直持续到故事的结尾。最后，形势要么柳暗花明，要么急转直下，要么两种可能的结合。这不光是故事的定式，也是生活本身的定式。

### 公式三：冲突 + 行动 + 结局 = 故事

故事最为纯粹的形式包括三个要素：冲突、行动、结局。

- 有个人遇到了一个难题——**冲突**产生
- 他必须努力奋斗——开始**行动**
- 于是他成功了或者失败了——形成某种**结局**

从攀登珠穆朗玛峰到追求爱情，从罗密欧到亚哈再到斯嘉丽，形式上这些故事完全是一模一样的。

**冲突的作用**在于迫使人物行动起来，强迫人物利用自身条件，以一种揭示他们自身性格特征的方式采取某种行动。人物以什么方式对待他们的麻烦，是最能够彰显人物性格的东西。**行动就是性格。**

> [!NOTE] 行动即性格
> 无论人物是否愿意，他们对冲突的反应都道出了他们的真实情况。除非人物迫不得已或受到了挑战，否则人物不会采取行动——就像我们大家一样。人物不可能没有任何理由地把自己推到极限状态，他必须受到激励、刺激和挑战，这个挑战就是**冲突**。

## 回检清单：回到渴望、障碍、行动

当你在写作中遇到麻烦的时候，首先要回到这三个要素上来。永远如此。它们是让故事波澜起伏的一二三。

| 问题 | 检查要点 |
|------|----------|
| 什么人渴望什么？ | 在稿子上找到他，精确到第几行 |
| 这个渴望够强烈吗？ | 能够再强烈些吗？能够出现得更早一些吗？ |
| 障碍是什么？ | 第一次出现在第几行？能更早出现吗？人物能不理睬它却毫发无损吗？ |
| 行动是什么？ | 人物通过做什么来克服障碍？能更早出现吗？能更强烈或更直接吗？ |
| 结局是什么？ | 胜利、失败还是局部胜利？是场面结局还是最终结局？ |

## 实践练习

> [!QUESTION] 练习：用写作公式分析你最喜欢的故事
> 选择一个你喜欢的电影、小说或短篇故事，用今天学到的三个公式进行拆解：
> 1. 核心冲突是什么？
> 2. 主人公的戏剧性渴望和戏剧性障碍分别是什么？
> 3. 渴望-障碍-行动循环出现了几次？每次情况是否变得更糟？
> 4. 最终的结局是胜利、失败还是两者兼具？

<details>
<summary>参考示例：以《饥饿游戏》为例</summary>

**公式一：没有冲突 = 没有故事**
凯特尼斯活在极权压迫的施惠国，她的生活本身就是冲突的温床——妹妹被选中、自愿代妹出征。

**公式二：渴望 + 障碍 = 冲突**
- 渴望：凯特尼斯想要活下来，并保护皮塔和妹妹
- 障碍：24个贡品只能活1个（后来改为2个），游戏制造者不断制造新的致命威胁
- 渴望与障碍旗鼓相当：凯特尼斯有射箭和丛林生存技能，但对手更残忍、装备更精良、游戏规则随时改变

**公式三：冲突 + 行动 + 结局 = 故事**
- 冲突：凯特尼斯必须在生死游戏中生存
- 行动：她逃入丛林、寻找水源、结盟、攻击物资储藏处
- 结局：她和皮塔成为共同获胜者，但面临总统的报复威胁

**循环升级：** 被追杀 -> 逃生 -> 蜂巢反击 -> 受伤 -> 结盟露露 -> 露露被杀 -> 规则改变 -> 终极对决 -> 险胜。每次循环都比上一次更危险。

</details>

## 本课小结

- **没有冲突 = 没有故事**：完美人物是无聊的，要让主人公不完美
- **渴望 + 障碍 = 冲突**：渴望要生死攸关，障碍要旗鼓相当
- **冲突 + 行动 + 结局 = 故事**：行动就是性格
- 渴望-障碍-行动循环反复，情况越来越糟
- 写作遇到瓶颈时，永远先回到这三个要素
