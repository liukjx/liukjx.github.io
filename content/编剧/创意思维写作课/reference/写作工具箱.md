# 写作工具箱

> [!ABSTRACT] 使用说明
> 本表将"一个故事的诞生：22堂创意思维写作课"所有核心工具汇编为速查表格。写作遇到瓶颈时，翻到对应章节即可快速找回方法。

## 1. 九句大纲法（第8课）

任何一个故事都可以浓缩为九个句子，涵盖**四个部分**和**五个转折点**。

| 编号 | 节点 | 所属部分 | 说明 |
|------|------|----------|------|
| 句1 | 设置悬念 | 第一部分（布局）0-20% | 抛出核心问题，牢牢抓住读者 |
| 句2 | 开始布局 | 第一部分 | 展示主人公的日常生活和背景信息 |
| 句3 | **第一情节点** | 第一部分→第二部分 | 故事发生重大变化，节奏更紧张 |
| 句4 | 主人公做出反应 | 第二部分（反应）20-50% | 主人公开始对新局面做出反应 |
| 句5 | **中间点** | 第二部分→第三部分 | 主人公从被动转为主动，开始反击 |
| 句6 | 采取行动 | 第三部分（行动）50-75% | 主人公积极主动地采取一系列行动 |
| 句7 | **第二情节点** | 第三部分→第四部分 | 新信息改变一切，打开新的大门 |
| 句8 | 成为催化剂 | 第四部分（催化剂）75-100% | 主人公成为事件推动者，走向最终对决 |
| 句9 | **结尾** | 第四部分 | 问题得以解决，故事结束（或为续集铺垫） |

> [!TIP] 使用方法
> 在动笔之前，先在卡片上写下这九个句子。如果你无法将故事浓缩为九句话，说明故事的结构可能存在问题。这个方法同样适用于分析你喜欢的电影和小说。

## 2. 叙事弧线五阶段（第10课）

| 阶段 | 名称 | 占比（约） | 核心任务 |
|------|------|------------|----------|
| 1 | 阐述（Exposition） | ~10% | 只告诉读者必须知道的信息，预示即将发生的事件；在8分钟（标准电影）时让主人公陷入困境 |
| 2 | 上升动作（Rising Action） | ~70% | 创造戏剧张力，情节点密集出现，揭示-幻灭循环，悬念叠加，情况越来越糟 |
| 3 | 危机（Crisis） | ~10% | 情况变得不能再糟，主人公到达领悟点，必须做出关键决定 |
| 4 | 高潮（Climax） | ~5% | 解决危机的一系列事件，主人公完成蜕变 |
| 5 | 结局（Resolution/Denouement） | ~5% | 释放所有戏剧张力，故事放缓，尽快结束 |

## 3. LOCK冲突基础四要素（第15课）

| 要素 | 英文 | 说明 |
|------|------|------|
| L | Lead（值得追随的主角） | 有叛逆精神、好奇心和成长空间的角色 |
| O | Objective（生死攸关的目标） | 故事最大赌注是"死亡"——生理、心理或社会意义上的 |
| C | Confrontation（正面对抗） | 主角与对立面的冲突占据故事大部分篇幅，两者旗鼓相当 |
| K | Knockout（精彩结尾） | 引起共鸣的结尾，超出书中内容，留给读者想象空间 |

**冲突结构口诀：一个乱子，两个关口**
- **开篇乱子**：第一页制造麻烦，打破日常平衡
- **第一关口**（无回头路）：主人公被迫进入冲突的第二幕
- **第二关口**（决战之门）：主人公介入最后决战，问题彻底解决

## 4. 人物七大变量与三维空间（第12课）

### 七大变量

| 序号 | 变量 | 说明 |
|------|------|------|
| 1 | 形象与个性 | 外貌、习惯、怪癖、喜欢的事物 |
| 2 | 故事背景 | 人物从哪里来，过去经历了什么 |
| 3 | 人物弧线 | 从遭遇心魔到征服心魔的成长过程 |
| 4 | 心魔 | 阻止人物行动的内在障碍（自私、傲慢、自卑等） |
| 5 | 世界观 | 人物的信仰体系和道德指南 |
| 6 | 目标与动机 | 驱动人物做出决定和行动的力量 |
| 7 | 决定-行动-行为 | 其他六项变量的合力结果，最终的答案 |

### 三维空间人物塑造

```
三维空间 = 一维（外表行为）+ 二维（背景心魔）+ 三维（行动改变）
```

| 维度 | 对应变量 | 读者看到什么 |
|------|----------|--------------|
| 一维 | 形象和个性 | 人物如何看待自己，希望别人如何看待自己 |
| 二维 | 故事背景 + 心魔 | 人物为什么有这样的选择和行为，埋下共鸣的种子 |
| 三维 | 行动 + 行为 + 世界观 | 人物攻克心魔、战胜自己、发生改变——最终回答"人物到底是谁" |

**人物弧线** = 从塑造心魔开始 → 到主人公征服心魔为止的整个过程。弧线是次要情节，从属于主要情节，直接推动戏剧性张力发展。

## 5. 瞬间悬念七法（第16课）

| 方法 | 操作要点 | 举例 |
|------|----------|------|
| 1. 微观障碍 | 插入看似微不足道的事件/人物，带出巨大枝节 | 服务员怀疑主角只带了一把牙刷 |
| 2. 提高赌注 | 从情节、人物、社会三个维度提高风险 | 对手抓了主角的家人做人质 |
| 3. 滴答时钟 | 为任务设定时间限制 | "炸弹还剩3分钟" |
| 4. 打断 | 在关键时刻中断对话或行动 | 电话响起，但接起来没人说话 |
| 5. 拿掉能力 | 拿走人物必备的能力、工具或帮手 | 爆胎、手机没电、失忆 |
| 6. 增加反方 | 赋予对手更大的力量（盟友、武器、秘密） | 反方发现了主角不想透露的秘密 |
| 7. 情感与思想 | 利用人物内心活动拖延问题解决 | 主角陷入回忆，迟迟无法做出决定 |

**三种悬念层次：**

| 层次 | 范围 | 示例 |
|------|------|------|
| 宏观悬念 | 贯穿整个故事 | 《飘》：斯嘉丽能活下来吗？能找到真爱吗？ |
| 场景悬念 | 单个场景 | 《毕业生》：本杰明会不会暴露？ |
| 超级悬念 | 人物和读者都不知道对抗势力 | 《釜山行》：乘客们能否逃脱丧尸的追捕？ |

## 6. 对话四法（第19课）

| 方法 | 关键原则 | 示例 |
|------|----------|------|
| 1. 避免直接回应 | 用回避、反问、中断代替准确回应 | A："我们去商场吧。" B："你老公昨天给我打电话了。" |
| 2. 压缩 | 砍掉无意义的开头（"好吧""对了"），去掉多余的定语和副词 | 删掉"我不是故意的"中的"我不是" |
| 3. 家长-成人-孩子矩阵 | 判断每个人物在场景中扮演的角色，角色差异自动制造张力 | 家长制定规则，成人理性分析，孩子情绪化——三者碰撞必有冲突 |
| 4. 沉默 | 无言常常是最好的选择 | 海明威《白象似的群山》：女人沉默回应堕胎提议 |

**训练对话的四种日常方法：**
1. **训练耳朵**：大声朗读自己写的对话 + 在公共场合偷听并默记他人对话
2. **牲口日记**：以人物口吻自由写作，向人物提问并记录回答
3. **改写电影脚本**：提取电影精彩对白，改写成故事场景，对比差异
4. **即兴表演**：关掉电视声音，模拟人物说话（广告效果尤佳，节奏快）

## 7. ABCDEF六步写作法（第22课/练习）

极简小说公式，每步写3分钟，18分钟完成一篇微型小说。

| 步骤 | 英文 | 内容 | 时长 |
|------|------|------|------|
| A | Action | 以动作和语言开始故事，进入一个情景 | 3分钟 |
| B | Background | 解释第一个动作发生的背景（日常生活、过去经历、社会环境） | 3分钟 |
| C | Complication | 让第一步中的事情出现问题、产生冲突，不要解决 | 3分钟 |
| D | Development | 人物开始处理问题，但问题不一定要得到解决 | 3分钟 |
| E | Epiphany | 人物灵光一闪，突然意识到某个观点，改变原有想法 | 3分钟 |
| F | Finale | 展现人物的生活发生了什么变化（避免"从此过上幸福生活"） | 3分钟 |

## 8. 三大核心公式（第22课）

```
公式一：没有冲突 = 没有故事
公式二：渴望 + 障碍 = 冲突
公式三：冲突 + 行动 + 结局 = 故事
```

**渴望必须有戏剧性**：人物感觉到满足与否是生死攸关的大事。
**障碍必须与渴望旗鼓相当**：一方太弱就没有冲突。
**循环法则**：渴望-障碍-行动反复再三，情况越来越糟，直到结尾。

**回检四问（写作遇到瓶颈时回到这里）：**
1. 什么人渴望什么？渴望够强烈吗？能更早出现吗？
2. 障碍是什么？能更强烈吗？人物能不理睬却毫发无损吗？
3. 行动是什么？能更早出现吗？能更强烈/更直接吗？
4. 结局是胜利、失败还是局部胜利？

## 9. 修改清单10问（第23课）

| 维度 | 核心问题 |
|------|----------|
| 1. 人物 | 主人公值得追随吗？对比充分吗？读者为什么产生共鸣？ |
| 2. 情节 | 有没有让读者不满意的地方？节奏紧迫吗？动作和描写平衡吗？ |
| 3. 开篇 | 引擎全开了吗？还是预热太久？基调统一吗？矛盾冲突够吗？ |
| 4. 中间部分 | 人物关系深化了吗？为最后决战埋下伏笔了吗？有死亡氛围吗？ |
| 5. 结尾 | 所有线索都处理了吗？结尾能引起共鸣吗？超出书中所写了吗？ |
| 6. 场景 | 每个场景都有冲突或紧张吗？动作场景目的明确吗？反应场景情感到位吗？ |
| 7. 陈述 | 有没有大量信息堆积？陈述有双重功效吗？ |
| 8. 声音/风格/视角 | 视角一致吗？写的是人物能看到/感受到的吗？大声朗读找别扭处 |
| 9. 背景与描写 | 背景活灵活现吗？像塑造人物一样用心吗？描写有双重作用吗？ |
| 10. 对话与主题 | 对话偏离回答制造悬疑吗？将对话作为武器了吗？主题自然植入了吗？ |

**推荐修改流程：**

| 轮次 | 重点 | 方法 |
|------|------|------|
| 第一轮 | 宏观结构（人物/情节/开篇/结尾） | 通读后结构调整，不改细节 |
| 第二轮 | 中观层面（场景/陈述/视角/声音） | 逐章朗读，标记问题区域 |
| 第三轮 | 微观细节（对话/描写/背景/主题） | 逐句打磨，注意用词和节奏 |
| 最终轮 | 统一检查，前后矛盾 | 打印通读或请他人阅读反馈 |

## 10. 其他核心工具速查

### 种子想法编织法（第5课）
1. 选出三个种子想法（每句一句话，具体明确）
2. 选最感兴趣的，花15分钟写成情节草稿
3. 把第二个种子想法揉入第一个，让两者互相作用（再写15分钟）
4. 把第三个也揉进来（再写15分钟）

### 共鸣与替代性体验创造法（第21课）

```
创造深化体验 = 共鸣 + 替代性体验
共鸣 = 建立利害关系，让读者感受到利害关系
替代性体验 = "如果怎样，将会怎样？"
```

替代性体验的两种读者需求：
- 现实中无法拥有的经历（死后/历史/超自然）
- 令人兴奋充满刺激的经历（竞技场/探险/灾难/爱情）

### 主题构思法（第11课）
- **主题先行使**：主题体现在人物和架构中（如《老人与海》）
- **叙事先行使**：主题随故事展开慢慢浮现（如《一桩事先张扬的凶杀案》）
- 主题永远在人物角色的核心冲突中凸显
- 测测你的主题能量：当问"故事讲的是什么"时，你的第一反应是情节层面的还是主题层面的？

### 潜意识创作法（第23课）
1. 睡前提问：在记事本写下具体问题
2. 晨起记录：醒来后第一时间写下所有答案
3. 灵感往往就会这样浮现在头脑中

### 场景设置练习法（第20课）

```
视角递进练习：我（第一人称）→ 她看他在看房子（第三人称近）→ 油漆工看房子（第三人称远）
核心原则：不直接说"他很伤心"，而是通过描述景物来传达情感
```

> [!WARNING] 常用警示
> - **不要预告太久**：开篇引擎要全开，不要在背景介绍里耗费读者耐心
> - **完美人物是无聊的**：给主人公制造麻烦，他有缺点读者才会投入情感
> - **不要准确回应**：对话中偏离正轨的回答比准确回应更有张力
> - **别在结尾磨蹭**：高潮过后尽快结束，释放戏剧张力
> - **不要害怕初稿糟糕**：一切都会在修改中好起来

## 11. 课程五大模块总览

| 模块 | 涵盖课程 | 核心产出 |
|------|----------|----------|
| 故事创意（第1-7课） | 故事本能、生活素材、秘密写作、种子想法、立意、预设 | 找到并孵化一个好故事想法 |
| 故事立意（第6-7课） | 立意与预设 | 将想法升级为具有冲突性和戏剧性的故事蓝图 |
| 故事结构（第8-10课） | 九句大纲法、叙事弧线 | 搭建稳固的故事骨架 |
| 故事写作（第11-22课） | 主题、人物、情节、冲突、悬念、对话、视角、共鸣、展示vs叙述、公式、ABCDEF法 | 十大写作法宝填充故事血肉 |
| 故事修改（第23课） | 修改哲学、修改清单10问 | 系统修改，让故事脱胎换骨 |
