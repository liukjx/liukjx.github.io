# 创意写作术语表

> [!ABSTRACT] 使用说明
> 本表收录"一个故事的诞生：22堂创意思维写作课"全课程的核心术语。每一条目包含中文术语、英文对应词、简要定义和对应课程序号，按中文拼音首字母排序。

## 术语总表

| 中文术语 | English Term | 定义 | 对应课程 |
|----------|-------------|------|----------|
| 背景（故事） | Background / Backstory | 人物过去的生活经历和社会环境，解释人物为何成为现在的样子 | 第4、12课 |
| 背景与描写 | Setting & Description | 故事发生的时空环境及其文字呈现，优秀的背景设置应像塑造人物一样用心 | 第19、23课 |
| 补充型作者 | Additive Writer | 菲茨·杰拉德提出的作家类型：初稿精简，修改阶段大量添入描述和过渡文字 | 第23课 |
| 阐述 | Exposition | 叙事弧线第一阶段，告诉读者必须知道的信息（仅限最低必要量），并预示即将发生的戏剧性事件 | 第10课 |
| 冲突 | Conflict | 两个以上势不两立的方面之间的矛盾冲撞，其中一方必须是人；故事的引擎 | 第15课 |
| 冲突基础（LOCK） | LOCK | LEAD（值得追随的主角）+ OBJECTIVE（生死攸关的目标）+ CONFRONTATION（正面对抗）+ KNOCKOUT（精彩结尾） | 第15课 |
| 冲突结构 | Conflict Structure | 一个乱子（开篇麻烦）+ 两个关口（无回头路的关口 + 介入最后决战的事件） | 第15课 |
| 初稿 | First Draft / Rough Draft | 故事的第一版文字，多数作家承认初稿通常是糟糕的，但一切可以在修改中好起来 | 第23课 |
| 大纲 | Outline | 在正式动笔之前用九句话描述故事结构的方法，涵盖四个部分和五个转折点 | 第8课 |
| 第二情节点 | Second Plot Point | 九句大纲法的第七句：改变故事的信息出现，主人公打开新的大门、设定新战略 | 第8课 |
| 第一情节点 | First Plot Point | 九句大纲法的第三句：故事发生重大变化，节奏更加紧张，主人公命运转折 | 第8课 |
| 顿悟 | Epiphany | ABCDEF六步写作法的第五步（E）：人物灵光一闪，突然明白了一个道理或改变原有想法 | 第22课（练习） |
| 对话 | Dialogue | 人物之间的言语交流，本质上是"动作的压缩与延伸"，每个人物说话都有自己的议程 | 第19课 |
| 对话四法 | Four Dialogue Methods | 避免直接回应、压缩不真实对话、家长-成人-孩子角色矩阵、沉默 | 第19课 |
| 发展 | Development | ABCDEF六步写作法的第四步（D）：人物开始处理问题，但问题未必得到解决 | 第22课（练习） |
| 高潮 | Climax | 叙事弧线第四阶段：解决危机的系列事件，将故事带到顶峰 | 第10课 |
| 共鸣 | Resonance | 让读者对主人公的处境、困境、需要和探索产生感同身受的体验 | 第21课 |
| 故事结构 | Story Structure | 自亚里士多德《诗学》以来经典的开头-中间-结尾三段式，具象化为五阶段叙事弧线 | 第8、10课 |
| 故事背景 | Backstory | 人物从哪里来、身上发生过什么事情；人是社会关系的总和，通过想象人物经历来把人物立起来 | 第12课 |
| 渴望 | Desire | 故事中人物内心最强烈的欲求，必须有戏剧性——人物感觉到满足与否是生死攸关的大事 | 第24课（第22课） |
| 渴望-障碍-行动循环 | Desire-Obstacle-Action Cycle | 故事的定势：人物的渴望遇到障碍，人物采取行动，反复再三且情况越来越糟，直到结尾 | 第24课（第22课） |
| 灵感生成 | Idea Generation | 从生活出发寻找故事雏形的十个小练习，包括写下秘密埋在心里、植入种子想法等 | 第3、4、5课 |
| 累积性悬念 | Cumulative Suspense | 随着情节推进逐步积累的悬念，通过不断提高赌注和增加障碍来实现 | 第16课 |
| 利害关系 | Stakes | 读者对主人公命运的关切程度；制造共鸣的方式就是建立利害关系并让读者感受到 | 第21课 |
| 立意 | Premise | 一个戏剧性的问题或核心冲突的雏形；将想法提升为立意的关键在于引入利害关系和冲突 | 第6课 |
| 乱子（开篇） | Disturbance | 故事要从乱子开始讲起：在第一页就要设计事情让主人公平淡的日常生活发生不平常的情况 | 第15课 |
| 灵感（种子想法） | Seed Idea | 展开故事情节的技巧：将几个互不相关的种子想法像织毛衣一样编织成一个故事 | 第5课 |
| 情节 | Plot | 故事中事件的序列安排，经典故事模型包括追寻、复仇、成长、爱情等原型 | 第14课 |
| 情节点 | Plot Point | 上升动作阶段推动故事朝新方向发展的关键事件，大多数情节点会给主人公制造新的麻烦 | 第10课 |
| 人物 | Character | 故事的灵魂，需要像设计产品一样精心塑造 | 第12课 |
| 人物七大变量 | Seven Character Variables | 形象和个性、故事背景、人物弧线、心魔、世界观、目标和动机、决定-行动-行为 | 第12课 |
| 人物弧线 | Character Arc | 从塑造心魔到主人公最后征服心魔的整个过程；人物因经历而改变成长产生的情节点 | 第12课 |
| 三维空间人物塑造 | Three-Dimensional Character | 一维（外表行为）→ 二维（故事背景+心魔）→ 三维（行动+世界观+改变），层层深入 | 第12课 |
| 视角 | Point of View (POV) | 讲述故事时采用的角度和观察位置；改变视角可以改变情感距离和故事氛围 | 第20课 |
| 瞬间悬念 | Micro-Tension / Instant Suspense | 在一个场景中制造出来的小型悬念，让读者手不释卷 | 第16课 |
| 瞬间悬念七法 | Seven Micro-Tension Methods | 微观障碍/提高赌注/滴答时钟/打断/拿掉能力/增加反方/情感与思想 | 第16课 |
| 上升动作 | Rising Action | 叙事弧线第二阶段，篇幅最大（好莱坞电影约100分钟），创造戏剧张力，情节迂回曲折 | 第10课 |
| 深化体验 | Deepened Experience | 读者阅读结束后不忍抽离、闭目回味的沉浸感，通过共鸣和替代性体验实现 | 第21课 |
| 神秘 vs 悬念 | Mystery vs Suspense | 神秘问"谁做的"（把答案藏好），悬念问"它还会再发生吗"（把答案安全放好） | 第16课 |
| 世界观 | Worldview | 人物认可和接受的信仰体系和道德指南；人物看待世界的基本方式 | 第12课 |
| 死亡氛围 | Death Atmosphere | 故事中弥漫的死亡气息（心理上或生理上），让读者感受到赌注之高 | 第23课 |
| 替在性体验 | Vicarious Experience | 将读者带到另一个地点、时间或情境，让读者身临其境，成为故事的一部分 | 第21课 |
| 童年心魔 | Inner Demon / Ghost | 关键时刻阻止人物采取行动的根本原因；自私、傲慢、自卑等一切阻碍主人公成长的因素 | 第12课 |
| 微观障碍 | Micro-Obstacle | 瞬间悬念的一种：一个看似微不足道的事件或人物，进场时带着制造复杂枝节的巨大潜力 | 第16课 |
| 危机 | Crisis | 叙事弧线第三阶段：情况变得不能再糟，主人公必须采取新的行动，故事到达领悟点 | 第10课 |
| 尾声 | Finale | ABCDEF六步写作法的第六步（F）：人物的生活发生了什么变化，结尾最好听起来像新开头 | 第22课（练习） |
| 行动 | Action | ABCDEF六步写作法的第一步（A）：人物生活中发生某件事情，由此进入一个情景 | 第22课（练习） |
| 行动 | Action (in Formula) | 冲突三要素之一：人物为了克服障碍而做的努力；行动就是性格 | 第24课（第22课） |
| 心魔 | Inner Demon | 见"童年心魔" | 第12课 |
| 叙事弧线 | Narrative Arc | 用视觉图表展现故事结构的方法，经历五个阶段：阐述→上升动作→危机→高潮→结局 | 第10课 |
| 悬念 | Suspense | 不给出解决方案，持续吊住读者的期待和担忧；"把答案安全放好" | 第16课 |
| 修剪型作者 | Subtractive Writer | 菲茨·杰拉德提出的作家类型：初稿把能想到的全写进去，修改阶段只管删除 | 第23课 |
| 展示 vs 叙述 | Show vs Tell | 写作的核心原则：通过具体事件和细节来展现，而非直接告诉读者 | 第19课（23讲） |
| 主题 | Theme | 故事所讲的内容以及如何与现实生活相关联；故事的核心思想和原信息 | 第11课 |
| 主题先行 | Theme-First Story | 主题无处不在，体现在人物和整个故事架构中，如《老人与海》 | 第11课 |
| 叙事先行 | Narrative-First Story | 精心雕琢人物的生活经历，主题随着故事展开慢慢浮现，如《一桩事先张扬的凶杀案》 | 第11课 |
| 预设 | Premise (Advanced) | 发生在角色身上的事件叙述 + 核心冲突的结果；预设 = 角色 + 冲突 + 结论 | 第7课 |
| 预设 vs 立意 vs 想法 | Idea vs Premise vs Presupposition | 想法是最初的念头 → 立意是引入冲突的戏剧性问题 → 预设是角色+冲突+结论的完整表述 | 第6、7课 |
| 障碍 | Obstacle | 阻止人物实现渴望的力量或事物，必须与渴望旗鼓相当、势均力敌 | 第24课（第22课） |
| 结局 | Resolution / Ending | 叙事弧线第五阶段：释放所有戏剧张力，故事放缓接近尾声，尽快结束 | 第10课 |
| 结尾（修改） | Ending (Revision) | 线索是否处理完毕？结尾是否能引起共鸣？最好的结尾能超出书中所写 | 第23课 |
| 九句大纲法 | Nine-Sentence Outline | 九个句子描述故事的四个部分（布局、反应、行动、催化剂）和五个转折点（悬念、第一情节点、中间点、第二情节点、结尾） | 第8课 |
| 开篇 | Opening / Inciting Moment | 故事开始的方式，应做到"引擎全开"，避免预热太久 | 第23课 |
| 奖励机制 | Reward System | 修改哲学五：写作也要有乐趣，建立奖励来庆贺完成的每个阶段性成果 | 第23课 |
| 种子想法 | Seed Idea | 见"灵感（种子想法）" | 第5课 |
| 中间点 | Midpoint | 九句大纲法的第五句：主人公从被动反应转变为主动出击的转折点 | 第8课 |
| 终极赌注 | Ultimate Stakes | 故事成功的最大赌注就是"死亡"——生理上的、心理上的，或社会意义上的死亡 | 第15课 |
| 主角（值得追随的主人公） | Lead (Worthwhile Protagonist) | LOCK第一要素：一个值得读者追随的主角，有叛逆精神、好奇心和成长空间 | 第15课 |
| 主观时间 | Subjective Time | 非线性写作练习的核心概念：现实时间与故事时间的错位与重组 | 第17课（练习） |
| 场景设置练习法 | Scene-Setting Exercise | 通过改变视角和情感状态来练习场景描写的方法：从第一人称→第三人称他→更远视角 | 第20课 |
| 自我认知 | Self-Awareness | 修改哲学四：认清自己是补充型还是修剪型作者，为修改任务做好准备 | 第23课 |
| 潜意识创作 | Subconscious Writing | 斯蒂芬·金所称"地下室的男孩"；利用睡前提问+晨起记录来激发潜意识解决问题 | 第23课 |
| ABCD出差（六步）写作法 | ABCDEF Writing Method | 极简小说写作公式：Action（动作）→ Background（背景）→ Complication（复杂性）→ Development（发展）→ Epiphany（顿悟）→ Finale（尾声） | 第22课（练习） |
| 三大核心公式 | Three Core Formulas | 无冲突=无故事；渴望+障碍=冲突；冲突+行动+结局=故事 | 第24课（第22课） |
| 修改清单10问 | Ten Revision Questions | 人物/情节/开篇/中间/结尾/场景/陈述/声音与视角/背景与描写/对话与主题 | 第23课 |
| 一个乱子两个关口 | One Disturbance, Two Doorways | 冲突结构口诀：开篇乱子 + 第一个无回头路的关口 + 第二个介入决战关口 | 第15课 |
| 家长成人孩子矩阵 | Parent-Adult-Child Matrix | 对话创作方法：判断每个人物在场景中扮演的角色角色（权威的家长/理性的成人/情绪化的孩子），角色差异自动制造张力 | 第19课 |
| 滴答时钟 | Ticking Clock | 瞬间悬念的一种：为任务设定时间限制，增加紧迫感和压力 | 第16课 |
| 提高赌注 | Raising the Stakes | 瞬间悬念的一种：从情节、人物和社会三个维度提高赌注，增加戏剧性冲突 | 第16课 |
| 打破打断 | Interruption | 瞬间悬念的一种：简单的中断也可以制造悬念，悬念意味着不要给出解决方案 | 第16课 |
| 拿掉能力 | Disempowerment | 瞬间悬念的一种：拿掉人物做某件基础事情的能力，增加解决问题的难度 | 第16课 |
| 增加反方 | Strengthening the Antagonist | 瞬间悬念的一种：赋予对手更大的力量，使正反双方力量对比更加悬殊 | 第16课 |
| 情感与思想（悬念） | Emotion & Thought (Suspense) | 瞬间悬念的一种：人物内心活动延迟问题解决，是提升张力的内部工具 | 第16课 |
| 宏观悬念 | Macro-Suspense | 贯穿整个故事的总体悬念句，如《飘》的"斯嘉丽在美国内战之后还活着吗？" | 第16课 |
| 场景悬念 | Scene-Level Suspense | 人物每进入一场戏都抱着某种目标，遇到障碍后读者关心"他能成功克服障碍吗？" | 第16课 |
| 超级悬念 | Super Suspense | 人物和读者都不知道对抗势力是什么，读者与主人公一起成为故事的一部分 | 第16课 |
| 偷听训练 | Eavesdropping Practice | 训练对话能力的方法之一：去公共场合偷听别人对话，默默记下来 | 第19课 |
| 牲口日记 | Livestock Diary / Character Journal | 以故事人物口吻自由写作，或向人物提问并让他们讲话、记录 | 第19课 |
| 即兴表演 | Improvisation | 训练对话能力的方法：打开电视关掉声音，模拟电视里的人物说话 | 第19课 |
| 非线性写作 | Nonlinear Writing | 打破时间线性顺序的写作练习，训练对不同时间结构的掌控能力 | 第17课（练习） |
| 想象力热身 | Imagination Warm-up | 从生活出发找到故事雏形的十个小练习，激发创意灵感 | 第3课 |
| 秘密写作 | Secret Writing | 写下你的秘密开启创造力源泉，将个人经历转化为故事素材 | 第4课 |
| 三维编织法 | Three-Seed Weaving | 选择三个种子想法→选择一个发展成情节→将第二个揉入→将第三个揉入，形成故事雏形 | 第5课 |
| 人生叙事 | Life Narrative | 没有故事我们每个人都是碎片——故事是建构自我认同的基本方式 | 第2课 |
