# 好莱坞剧本创作大师班

> 好莱坞编剧教学大师·剧本创作大师班——电影剧本写作基础

本课程笔记基于新片场引进的好莱坞编剧大师班视频教程整理，系统梳理了从古典叙事理论到现代剧本写作的完整知识体系。

## 课程概览

| 模块 | 内容 | 课时 |
|------|------|------|
| **模块一：基础理论** | 剧本基本架构、叙述理论、三幕剧、经典九拍 | 第01-04课 |
| **模块二：符号学** | 符号学作为编剧的秘密武器、电影符号学分析 | 第05-06课 |
| **模块三：人物原型** | 人物原型体系、原型关系、当代原型与同理心 | 第07-09课 |
| **模块四：三幕式结构** | 第一幕开场、第二幕鲸鱼的肚子、第三幕结局 | 第10-12课 |
| **模块五：高级分析** | 《社交网络》案例拆解、故事弧光、符号学应用 | 第13-14课 |
| **模块六：实战技巧** | 场景绘制、对话编写、作品分析 | 第15-17课 |

## 适合读者

- 编剧初学者，希望建立系统的剧本写作认知框架
- 有创作经验但缺乏理论支撑的写作者
- 影视专业学生，需要补充好莱坞编剧方法论
- 任何对故事创作感兴趣的人

## 学习路径

建议按课程编号顺序学习。模块之间有一定递进关系：理论 → 符号学 → 人物 → 结构 → 分析 → 实战。
