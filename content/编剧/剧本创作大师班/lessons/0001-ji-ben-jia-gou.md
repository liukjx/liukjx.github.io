# 第01课：剧本的基本架构

## Learning Objectives

- 理解编剧在电影制作中的角色定位与核心职责
- 掌握剧本主旨（Theme）的定义与提炼方法
- 区分不同类型的剧本及其用途
- 学会撰写前期纲要（Treatment）
- 掌握故事大纲（Outline）的构建方法
- 熟悉行业标准剧本格式规范

## Core Idea

剧本是电影的蓝图。正如建筑需要施工图、软件需要架构文档，一部电影的诞生首先依赖于一份结构完整、格式规范的剧本。本节课程从编剧的角色定位出发，逐步深入到剧本的构成要素、类型、前期写作工具以及行业标准格式，为后续课程奠定基础。

## 编剧的角色定位与职责

编剧是电影叙事的第一创造者。在电影工业体系中，编剧承担以下核心职责：

- **故事构思**：从零开始构建故事的世界观、人物弧光和核心冲突。
- **主旨提炼**：明确故事想要表达的核心思想——即"为什么要讲这个故事"。
- **结构设计**：将故事素材组织成具有戏剧张力的叙事结构。
- **人物塑造**：赋予角色独特的性格、动机和成长轨迹。
- **对白写作**：撰写符合角色身份、推动情节发展的对白。
- **格式规范**：按照行业标准格式呈现剧本，确保导演、演员和摄制组能够准确理解。

编剧与导演的关系是电影制作中最关键的协作关系之一。优秀的编剧为导演提供坚实的叙事基石，而导演则通过视觉语言将文字转化为影像。二者不是上下级关系，而是共创伙伴。

> [!TIP] Key Insight
> 在好莱坞工业体系中，编剧往往不是孤军奋战。多数商业电影采用"编剧室"（Writers' Room）的协作模式，由主创编剧带领团队共同完成剧本。然而，无论协作规模如何，对叙事本质的理解始终是编剧的核心竞争力。

## 剧本主旨（Theme）的定义与提炼

### 什么是主旨？

主旨（Theme）是剧本的核心思想，是故事试图传达的关于人性和世界的深层洞见。它不是情节的概括，而是故事背后站立的"为什么"。

主旨与情节的区别：

- **情节**是"发生了什么"——主角遭遇困境、做出选择、面对后果。
- **主旨**是"这意味着什么"——通过这些事件，故事告诉我们关于生活的什么真理。

主旨通常以"**A是关于B的**"句式来表达：

- 《肖申克的救赎》：希望是关于自由的——即使在最黑暗的环境中，希望也能带来救赎。
- 《教父》：权力是关于家庭的代价——维护家族意味着牺牲个人的道德底线。
- 《星际穿越》：爱是关于超越时空维度的连接——爱是人类最深层、最不可解释的力量。

### 如何提炼主旨？

1. **从人物出发**：主角的内心缺陷是什么？故事结束时他学到了什么？这个转变的方向就是主旨的核心。
2. **从冲突出发**：故事中对立的力量分别代表什么价值观？冲突的本质往往是价值观的碰撞。
3. **从结局出发**：故事的结局暗示了什么样的世界观？主角获得或失去了什么？这告诉我们生活是怎样的？

> [!WARNING]
> 主旨不能是说教。好的主旨是自然地嵌入故事结构中的，而非通过角色之口直接宣告。观众通过体验故事来领悟主旨，而不是被告知主旨。

### 主旨的递进层次

- **表层主旨**：故事直接的道德教训（"诚实是好的"）
- **深层主旨**：故事对复杂人性的探索（"诚实有时会伤害你爱的人，但最终是值得的"）
- **悖论式主旨**：故事展现的看似矛盾的真相（"真正的自由来自承担责任"）

## 剧本的基本定义与类型

### 剧本的定义

剧本（Screenplay / Script）是以书面形式呈现的电影叙事蓝图，包含场景描述、角色动作和对白。它为电影的每一个部门——导演、演员、摄影、美术、剪辑——提供统一的创作依据。

剧本的三大功能：

1. **沟通工具**：让所有参与电影制作的人对故事有统一的理解
2. **估算依据**：制片人基于剧本估算预算、时间线和资源需求
3. **销售文件**：在电影尚未拍摄之前，剧本就是"产品"本身

### 剧本的主要类型

| 类型 | 英文 | 定义 | 主要用途 |
|------|------|------|----------|
| 规格剧本 | Spec Script | 编剧独立创作的待售剧本，无特定制片方委托 | 向制片公司和工作室展示创意，推销项目 |
| 拍摄剧本 | Shooting Script | 经过修改定稿、标注场景编号和镜头指示的剧本 | 用于实际拍摄，导演和摄影指导的工作文档 |
| 改编剧本 | Adaptation | 基于小说、游戏、真实事件或其他媒介改编的剧本 | 将已有的IP（知识产权）转化为电影叙事 |
| 投拍剧本 | Commissioned Script | 制片方委托编剧撰写的特定项目剧本 | 按制片方需求定制开发的项目 |

> [!EXAMPLE]
> 绝大多数编剧首先写的是**规格剧本**。一部高质量的规格剧本就是编剧的"求职简历"——它证明了编剧有能力完成一个完整、动人、格式规范的故事。著名的《逃离德黑兰》（Argo）剧本就是先以规格剧本形式在业内流传，最终被制片公司买下并拍成电影。

## 前期纲要（Treatment）的写作

Treatment 是剧本正式动笔之前的一份叙事摘要，通常长度为 **2-5页**。它在行业中的重要性常被初学者低估——许多资深编剧认为，写好 treatment 是写出好剧本的前提。

### Treatment 的核心要素

- **标题与署名**：剧本名称和编剧信息
- **故事主线**：以现在时态、散文式叙事讲述完整故事
- **人物简介**：主要角色的简要描述（年龄、性格、核心动机）
- **主旨提示**：故事的核心思想方向
- **独特卖点**：吸引制片人注意的核心创意——"这个故事有什么不同？"

### Treatment 的写作原则

1. **散文式叙事**：用流畅的散文风格讲述故事，而非干巴巴的条目列表
2. **现在时态**：始终使用现在时态，强调"此刻正在发生"
3. **控制长度**：2-5页为佳，过长则失去摘要意义，过短则无法传达故事全貌
4. **情绪传达**：不仅要表达"发生了什么"，还要传达"感觉如何"——这是 treatment 区别于简单概要的关键
5. **不写对白**：治疗书中通常不写入完整对白，用叙述替代

### Treatment 示例结构

```
标题：《故事名称》

核心概念：一句话概括故事。

第一幕：...
第二幕：...
第三幕：...

人物简介：
- 主角（姓名，年龄，核心动机）
- 反派（姓名，年龄，与主角的冲突来源）
- 关键配角（姓名，与故事的关系）
```

> [!QUESTION] Self-check
> 为什么 treatment 需要以"现在时态"写作？这与剧本本身的风格有什么关系？

<details>
<summary>Reveal answer</summary>
剧本本身也是以现在时态写作的——每一场戏都描述观众当下看到和听到的内容，而非过去发生的故事。Treatment 使用现在时态有助于保持叙事的即时感和紧迫感，让读者感觉故事正在眼前展开。这也是培养编剧"以视觉化方式思考"的重要训练。如果 treatment 用过去时态，就会变成"讲述一个已经发生的故事"，失去了电影"正在发生"的沉浸感。
</details>

## 故事大纲（Outline）的构建

如果说 treatment 是电影的建筑外观效果图，那么 outline 就是详细的施工图纸。Outlin 将治疗书中松散叙述的故事拆解为具体的场景和节拍，是动笔写剧本之前的最后一步。

### Beat Sheet 方法

Blake Snyder 在其著作 *Save the Cat* 中提出的 **Beat Sheet** 是最经典的大纲构建工具之一，将电影分解为15个关键节拍（beats）。以下是核心节拍的简化版本及其在标准120分钟电影中的大致时间位置：

1. **开场画面**（Opening Image, 第1分钟）：主角在故事开始时的状态，呈现主角的"问题"
2. **主题呈现**（Theme Stated, 第5分钟）：某角色（通常不是主角）说出故事的核心主题
3. **铺垫**（Set-Up, 1-10分钟）：介绍主角的生活世界、主要关系和缺失
4. **催化剂**（Catalyst, 第12分钟）：打破平衡的事件，迫使主角面对问题
5. **争论**（Debate, 12-25分钟）：主角犹豫是否采取行动，内心挣扎
6. **第二幕衔接点**（Break into Two, 第25分钟）：主角决定行动，进入新世界
7. **B故事**（B Story, 第30分钟）：副线故事开始，通常涉及爱情或导师关系
8. **娱乐游戏**（Fun and Games, 30-55分钟）：预告片中的"好戏"部分，展示故事的核心吸引力
9. **中点**（Midpoint, 第55分钟）：重大转折——主角取得虚假胜利或遭遇虚假失败
10. **坏蛋逼近**（Bad Guys Close In, 55-75分钟）：压力持续上升，内外对手同时发力
11. **一无所有**（All Is Lost, 第75分钟）：主角遭遇最惨重的失败
12. **灵魂黑夜**（Dark Night of the Soul, 75-85分钟）：主角陷入最低谷，质疑一切
13. **第三幕衔接点**（Break into Three, 第85分钟）：在B故事的启发下，解决方案浮现
14. **高潮**（Finale, 85-110分钟）：终极对抗，主角运用所学解决问题
15. **终场画面**（Final Image, 第110-120分钟）：与开场形成对比的主角新状态

### Outline 构建步骤

1. **自由创作阶段**：将所有故事想法记录下来，不做任何评判——这是发散思维阶段
2. **结构梳理阶段**：将想法填入 beat sheet 框架，检查因果链条是否完整
3. **场景列表阶段**：将每个 beat 扩展为具体的场景，标注每个场景的时空位置
4. **逻辑检查阶段**：逐场检查因果链条，确保"因为A所以B"的关系贯穿始终，没有逻辑漏洞

## 标准剧本格式

好莱坞工业标准剧本格式是读者对剧本的"第一印象"。格式不规范会被直接淘汰——制片人在阅读剧本的头30秒内就能判断这是否出自专业编剧之手。

### 核心规范

| 要素 | 规范 |
|------|------|
| 字体 | Courier 12pt（等宽字体，不可使用Times New Roman或Arial） |
| 页数规则 | 1页剧本约等于1分钟银幕时间（120页 = 120分钟电影） |
| 对白行距 | 单倍行距 |
| 动作描写行距 | 双倍行距 |
| 上边距 | 1英寸（2.54厘米） |
| 下边距 | 1英寸（2.54厘米） |
| 左边距 | 1.5英寸（3.81厘米，预留装订空间） |
| 右边距 | 1英寸（2.54厘米） |

### 剧本要素与格式

剧本由以下几种基本要素组成，每种要素有特定的缩进和格式：

- **场景标题（Slug Line）**：场景的时空定位，格式为 `内景/外景 + 地点 + - + 时间`
  - 示例：`内景/ 客厅 - 白天`
- **动作描写（Action）**：描述场景中可见、可听到的事件。使用现在时态、主动语态
- **角色名（Character）**：角色名出现在对白上方，居中，全部大写
- **对白（Dialogue）**：角色说的话，居中排版
- **括号提示（Parenthetical）**：对白的语气或方式说明，置于角色名和对白之间
- **转场（Transition）**：如 `切至：`、`淡入：`、`淡出：`，右对齐

> [!TIP] Key Insight
> 格式的重要性不仅在于"看起来专业"。标准化的格式确保**每页剧本对应一分钟银幕时间**，这是制片人估算影片长度、预算和拍摄日程的基本依据。格式错误的剧本会直接破坏这种估算，让制片人无法判断影片的实际长度。

格式的完整细节和每个要素的具体排版参数请参阅 [[reference/screenplay-format|剧本格式参考]]。

## 本课总结

本课覆盖了剧本写作的基础架构：

- 编剧是电影叙事的第一创造者，承担从构思到成稿的完整职责
- 主旨（Theme）是故事的核心思想，需要通过故事本身来传达而非说教
- 剧本分为规格剧本、拍摄剧本、改编剧本等多种类型，各有不同用途
- Treatment 是2-5页的叙事摘要，以现在时态散文式写作，是推销项目的重要工具
- Outline 和 Beat Sheet 是构建故事结构的系统方法，帮助编剧在动笔前夯实结构
- 标准剧本格式（Courier 12pt、特定的缩进和边距）是剧本进入行业的基本门槛
