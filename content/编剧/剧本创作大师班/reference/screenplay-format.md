# 标准剧本格式速查

## 基本规范

| 项目 | 规范 |
|------|------|
| 字体 | Courier 12pt（等宽字体，不可使用比例字体） |
| 页数规则 | 1页剧本约等于1分钟银幕时间 |
| 装订 | 三孔装订（three-hole punched） |
| 封面 | 仅包含标题、编剧姓名、联系方式 |

## 页面边距

| 位置 | 英寸 | 厘米 |
|------|------|------|
| 上边距 | 1.0 英寸 | 2.54 cm |
| 下边距 | 1.0 英寸 | 2.54 cm |
| 左边距 | 1.5 英寸 | 3.81 cm |
| 右边距 | 1.0 英寸 | 2.54 cm |

## 剧本要素与排版

| 要素 | 英文 | 左边距 | 右边距 | 宽度 | 备注 |
|------|------|--------|--------|------|------|
| 场景标题 | Slug Line | 1.5 英寸 | 1.0 英寸 | 全文 | 全部大写 |
| 动作描写 | Action | 1.5 英寸 | 1.0 英寸 | 全文 | 现在时态 |
| 角色名 | Character | 3.7 英寸 | — | 居中 | 全部大写，对白上方 |
| 对白 | Dialogue | 2.5 英寸 | 2.5 英寸 | — | 对话文本 |
| 括号提示 | Parenthetical | 3.1 英寸 | 4.0 英寸 | — | 角色名下，对白前 |
| 转场 | Transition | 4.5 英寸 | 1.0 英寸 | 右对齐 | 如"切至：" |

## 场景标题（Slug Line）格式

场景标题的规范格式为：

```
内景/外景 - 地点 - 时间
```

缩写规范：

- **内景** = 内 / INT.
- **外景** = 外 / EXT.
- **白天** = 日 / DAY
- **夜晚** = 夜 / NIGHT
- 黄昏 / DUSK
- 黎明 / DAWN

示例：

```
内景/ 办公室 - 白天
外景/ 中央公园 - 夜晚
内/ 汽车 - 黄昏
```

当场景从一个房间移动到同一栋建筑内的另一个房间时，使用"继续"（CONTINUOUS）来标注连续时间：

```
内景/ 走廊 - 继续
```

## 动作描写（Action）规范

- 使用**现在时态**
- 使用**主动语态**
- 只描述**可见和可听到的内容**（不要写角色的内心想法）
- 段落不宜过长（3-5行为佳）
- 首次出现在剧本中的角色名**全部大写**

示例：

```
外景/ 银行门口 - 白天

李大明（40岁，穿着廉价西装）站在银行门口，手里紧握着一个信封。他环顾四周，额头渗出汗水。

一辆黑色轿车停在路边。
```

## 对白（Dialogue）规范

角色名居中，对白居中对齐：

```
                   李大明
           （低声）
       我不会再退让了。这一次，
       我要告诉他们真相。
```

## 常用转场

| 中文 | 英文 | 用法 |
|------|------|------|
| 淡入： | FADE IN: | 剧本开头（左对齐） |
| 淡出： | FADE OUT. | 剧本结尾（右对齐） |
| 切至： | CUT TO: | 标准场景切换 |
| 溶解至： | DISSOLVE TO: | 表示时间流逝的柔和切换 |
| 跳切： | SMASH CUT TO: | 突然的、冲击性的切换 |

## 页码

- 从第二页开始编号
- 页码位于右上角
- 格式：`编剧名 剧本标题 - 页码`

## 特殊情况

### 蒙太奇（MONTAGE）

```
蒙太奇 - 李大明在准备面试：
A) 李大明对着镜子练习自我介绍
B) 李大明查阅公司资料
C) 李大明试穿不同的领带
D) 李大明在夜晚失眠
蒙太奇结束
```

### 画外音（Voice Over, V.O.）

```
                   李大明（V.O.）
       如果当时我知道结果会是这样，
       我绝对不会按下那个按钮。
```

### 画外对白（Off-Screen, O.S.）

当角色在同一场景中但不在画面中时使用：

```
                   王丽（O.S.）
       大明！你在哪儿？
```

## 常见错误

- 使用比例字体（Times New Roman、Arial）替代 Courier
- 动作描写过短或过长（理想单段落不超过3-5行）
- 在动作描写中写入角色的内心活动（不可拍摄）
- 场景标题格式不一致
- 对白过于冗长
