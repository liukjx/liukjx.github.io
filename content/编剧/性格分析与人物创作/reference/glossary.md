# 术语表与核心概念

## 核心框架

| 术语 | 英文 | 定义 |
|------|------|------|
| Y轴 | Y-Axis | 人格组织水平（心智成熟度）：从精神病性到超越神经症性的纵向坐标 |
| X轴 | X-Axis | 性格类型（横向分类）：A类古怪型、B类情绪不稳定型、C类焦虑型 |
| 人格组织水平 | Level of Personality Organization | 人格功能的分层：精神病性→边缘性→神经症性→超越神经症性 |
| 智性区间 | Elastic Range | 每个人格类型的功能水平可在一定范围内上下浮动 |

## 人格水平

| 术语 | 英文 | 核心特征 |
|------|------|----------|
| 精神病性 | Psychotic | 现实检验严重受损，使用原始防御，自我认同破碎 |
| 边缘性 | Borderline | 情绪极端不稳定，关系现实检验有问题，被抛弃焦虑 |
| 神经症性 | Neurotic | 轻度心理病理，主要跟自己过不去，有完整共情能力 |
| 超越神经症性 | Above Neurotic | 最成熟的约5%人群，具备深层客体爱能力 |

## 精神分析四大流派

| 流派 | 创始人/代表 | 核心关注 |
|------|------------|----------|
| 经典精神分析 | 弗洛伊德 | 本我、自我、超我的结构，俄狄浦斯情结 |
| 自我心理学 | 安娜·弗洛伊德、埃里克森 | 自我功能、防御机制、毕生发展 |
| 客体关系学派 | 克莱因、温尼科特、鲍比 | 早期关系、依恋理论、真/假自体 |
| 自体心理学 | 科胡特 | 自恋的发展、自体客体、共情 |

## 性格类型（按A/B/C分类）

### A类：古怪型 (Odd Cluster)

| 类型 | 核心特征 | 经典电影角色 |
|------|----------|-------------|
| 偏执型 (Paranoid) | 不安全、不信任、恨 | 《肖申克的救赎》安迪、《爆裂鼓手》主角 |
| 分裂型 (Schizotypal) | 无法理解的内在幻想、被疏离 | 《被嫌弃的松子》 |
| 分裂样 (Schizoid) | 无欲无求、孤独、冷漠 | 《少年派》派 |

### B类：情绪不稳定型 (Dramatic-Emotional Cluster)

| 类型 | 核心特征 | 经典电影角色 |
|------|----------|-------------|
| 反社会型 (Antisocial) | 残忍、缺乏共情、操控 | 汉尼拔、小丑（2007版） |
| 自恋型 (Narcissistic) | 自大自我+理想化父母两极 | 美国队长、超人 |
| 表演型 (Histrionic) | 需要关注、解离倾向、情感肤浅 | 《律政俏佳人》 |
| 边缘型 (Borderline) | 极端不稳定、害怕被抛弃 | 玉娇龙、《这个杀手不太冷》小女孩 |

### C类：焦虑型 (Anxious Cluster)

| 类型 | 核心特征 | 经典电影角色 |
|------|----------|-------------|
| 强迫型 (Compulsive) | 完美主义、超我强大、情感隔离 | 《尽善尽美》、《飞行家》 |
| 抑郁型 (Depressive) | 空心人、假自体、自体虚弱 | 《海上钢琴师》、《花样年华》 |
| 受虐型 (Masochistic) | 受虐的快感、道德的胜利 | 《爆裂鼓手》（组合型） |

## 防御机制

| 层级 | 机制 | 定义 | 使用人群 |
|------|------|------|----------|
| 原始 | 投射 (Projection) | 把自己的内心内容投射到他人身上 | 精神病性、边缘性 |
| 原始 | 投射性认同 | 投射-认定-收回的循环 | 边缘性 |
| 原始 | 分裂 (Splitting) | 非黑即白 | 边缘性 |
| 原始 | 见诸行动 (Acting Out) | 用行动代替言语表达 | 边缘性 |
| 神经症性 | 压抑 (Repression) | 把冲突内容压入无意识 | 神经症性 |
| 神经症性 | 隔离 (Isolation) | 把情感与认知分离 | 强迫型 |
| 神经症性 | 理智化 (Intellectualization) | 用理性控制生活 | 强迫型 |
| 成熟 | 升华 (Sublimation) | 把原始冲动转化为社会可接受行为 | 神经症以上 |
| 成熟 | 幽默 (Humor) | 用幽默表达攻击而不伤关系 | 神经症以上 |
| 成熟 | 利他 (Altruism) | 从帮助他人中获得满足 | 神经症以上 |

## 编剧评估维度

| 维度 | 说明 |
|------|------|
| 类型 (Genre) | 类型元素明确、满足观众期待、主次清晰 |
| 钩子 (Hook) | 核心事件+主题+人物+结构四统一 |
| 主题 (Theme) | 模糊→明确→复合→高级模糊 |
| 人物 (Character) | 人格组织+核心特质+次要特质 |
| 结构 (Structure) | 外在结构+内在结构（人物关系） |
| 情节 (Plot) | 情节贯穿道具、三场好戏 |
| 叙事 (Narrative) | 叙事视角、节奏 |
| 对白 (Dialogue) | 符合人物性格原型 |
| 道具 (Prop) | 夺宝类、表意类、故事切入口类 |
