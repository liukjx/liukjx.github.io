# 跟着李新学编剧

## 课程信息

- **讲师**：李新（毕业于美国南加州大学电影学院）
- **形式**：10节音频课，每节约10-12分钟
- **来源**：基于USC电影学院编剧课堂 + 好莱坞一线合作经验 + 十年实战创作经验

## 课程说明

这不是一门只教"怎么写"的课。这门课会帮你搞懂：

1. **怎么看戏** — 成为高级观众，读懂编剧埋藏在故事中的密码
2. **怎么写戏** — 从创意、角色、结构到台词，掌握完整编剧流程
3. **怎么给自己加戏** — 编剧的吸引力法则，完全可以应用到生活、工作和社交

## 课程受众

- 编剧入门者：获得系统的好莱坞编剧方法论
- 影视爱好者：成为能看懂门道的"高级观众"
- 职场人士：把编剧的吸引力法则用到沟通、汇报和故事讲述中
