# 编剧术语表

## 核心概念

| 术语 | 英文 | 定义 |
|------|------|------|
| 戏核 | Core Concept | 一句话概括剧本核心创意。包含困境、惊奇、反讽三要素 |
| 节拍 | Beat | 主角每一次克服障碍、实现目标的努力尝试 |
| 三幕剧 | Three-Act Structure | 第一幕提出问题、第二幕尝试解决、第三幕真正解决 |
| 潜台词 | Subtext | 台词表面意思之下的真实意图 |
| 戏核 | Logline | 能一句话说清剧本核心创意的简洁表述 |

## 角色塑造

| 术语 | 定义 |
|------|------|
| 混搭 | 给高手角色配备一个极不匹配的职业/外貌/处境 |
| 放大技巧 | 把角色的某个个性特征从五分放大到十分 |
| 高一厘米角色 | 具备普通人大多数缺点 + 一两个超凡优点的角色 |
| 主CP | 主角与跟班/对手组成的搭档关系 |

## 情节与结构

| 术语 | 定义 |
|------|------|
| 多米诺原则 | 情节间要有强烈的因果逻辑：A→B→C |
| 人设原则 | 情节要符合角色的人设，性格决定命运 |
| 不可预测原则 | 用奇葩解决方案和反转制造惊奇 |
| 反转 | 障眼法，分为"你以为的A其实是B"和"你以为的前提不存在"两种 |
| 过场戏 | 没有任何节拍、只交代信息的场景 |

## 悬念技巧

| 术语 | 定义 |
|------|------|
| 悬崖抓手 | Cliffhanger | 在关键时刻戛然而止，留下巨大悬念 |
| 拼图游戏 | 把信息切割碎片，逐步披露，让角色和观众一起拼凑真相 |
| 掺水 | 在信息中掺杂误导性内容，让观众误入歧途 |
| 限能 | 不让任何角色知道全貌，每个人只掌握部分碎片 |

## 共情机制

| 术语 | 定义 |
|------|------|
| 同情 | 通过打压主角（被羞辱、多重打击、高失败成本）让观众心疼 |
| 爱慕 | 通过拔高主角（比普通人高一厘米）让观众向往 |

## 台词技巧

| 术语 | 定义 |
|------|------|
| 话只说一半 | 另一半留给观众脑补 |
| 移花接木 | 用比喻/类比把两种事物嫁接置换 |
| 木马计 | 主要信息伴随干扰信息出现 |
| 金句改写 | 用"生活就像X，Y"句式改写经典金句 |
