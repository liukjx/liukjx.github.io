# 电影剪辑术语表（中英对照）

## 切法类（Cuts & Transitions）

| 中文术语 | 英文术语 | 简要定义 |
|---------|---------|---------|
| 切 | Cut | 最基本的剪辑方式，将两个镜头直接拼接，没有任何过渡效果 |
| 匹配剪辑 | Match Cut | 利用两个镜头在构图、动作或内容上的相似性进行衔接，制造视觉或意义上的连贯 |
| 跳切 | Jump Cut | 在同一主体、同一机位的两个镜头之间直接切换，制造时间跳跃感或打破连续性 |
| 交叉剪辑 | Cross-cutting | 在两个或多个发生在不同地点的场景之间交替切换，暗示同时性 |
| 平行剪辑 | Parallel Editing | 与交叉剪辑类似，强调不同故事线之间的平行关系而非同时性 |
| 切出 | Cutaway | 从主场景暂时切到相关但非核心的画面，用于提供补充信息或调节节奏 |
| 插入 | Insert | 切到主场景中的某个细节特写，用于强调关键信息 |
| 硬切 | Hard Cut | 无任何过渡的直接切换，与前一个镜头形成鲜明对比 |
| 突切 | Smash Cut | 从一个安静或平缓的场景突然切到一个激烈场景，制造震惊效果 |
| L-Cut | L-Cut | 画面先切，声音后切——下一镜头的声音在前一镜头的画面中提前进入 |
| J-Cut | J-Cut | 声音先切，画面后切——下一镜头的画面出现前，其声音已经先出现 |

## 剪辑类型类（Editing Types）

| 中文术语 | 英文术语 | 简要定义 |
|---------|---------|---------|
| 蒙太奇 | Montage | 通过快速排列多个镜头来压缩时间、传达概念或制造情感效果 |
| 长镜头 | Long Take / Plan-Sequence | 一个持续较长时间未经剪辑的连续镜头，通常用于展现完整的时空关系 |
| 连续性剪辑 | Continuity Editing | 经典好莱坞剪辑体系，以保持时空连续性和叙事清晰为目标 |
| 隐形剪辑 | Invisible Editing | 让观众感受不到剪辑存在的剪辑风格，剪口顺应叙事逻辑和视觉习惯 |
| 快速剪辑 | Fast Cutting | 镜头时长远低于平均水平的剪辑风格，常用于动作场景制造紧张感 |

## 镜头类型类（Shot Types）

| 中文术语 | 英文术语 | 简要定义 |
|---------|---------|---------|
| 建立镜头 | Establishing Shot | 广角镜头，用于展示场景的空间环境和角色之间的位置关系 |
| 反应镜头 | Reaction Shot | 切到角色面部表情的镜头，用于捕捉其对事件或对白的情绪反应 |
| 主镜头 | Master Shot | 覆盖整场戏的连续广角镜头，作为剪辑的安全备份和空间参照 |
| 过肩镜头 | Over-the-Shoulder Shot | 越过一名角色的肩膀拍摄另一名角色的视角，常用于对话场景 |
| 单人镜头 | Single Shot | 只包含一名角色的中景或特写镜头 |
| 双人镜头 | Two-Shot | 同时包含两名角色的中景或全景镜头 |
| 特写 | Close-up | 聚焦于角色面部或物体细节的镜头 |
| 全景 | Wide Shot / Long Shot | 展示完整环境和角色全貌的镜头 |
| 主观镜头 | Point-of-View Shot / POV | 模拟角色视角的镜头，让观众看到角色所看到的画面 |

## 剪辑规则类（Editing Rules）

| 中文术语 | 英文术语 | 简要定义 |
|---------|---------|---------|
| 180度规则 | 180-degree Rule | 摄影机必须在角色关系轴线的一侧拍摄，保持空间方向的一致性 |
| 30度规则 | 30-degree Rule | 同一主体的连续两个镜头之间，机位角度变化至少需要30度，以避免跳切 |
| 视线匹配 | Eye-line Match | 切至角色所看事物的镜头时，视线方向必须与角色视线方向一致 |
| 正反打 | Shot / Reverse Shot | 在对话双方之间交替切换的剪辑模式，通常配合过肩镜头使用 |
| 动作匹配 | Action Match / Match on Action | 在前一镜头动作的延续中切换视角，利用动作连贯性隐藏剪口 |
| 轴线 | Axis of Action / 180-degree Line | 对话或动作场景中角色关系所形成的一条虚拟直线，摄影机不应越轴 |

## 工作流与版本类（Workflow & Versions）

| 中文术语 | 英文术语 | 简要定义 |
|---------|---------|---------|
| 粗剪 | Rough Cut / Assembly Cut | 按剧本顺序初步排列所有可用素材的初版剪辑，侧重故事结构而非节奏 |
| 精剪 | Fine Cut | 在粗剪基础上精雕细琢的版本，优化节奏、过渡和镜头选择 |
| 定剪 | Final Cut / Picture Lock | 画面完全锁定、不再做任何修改的最终版本，可移交调色和混音 |
| 导演剪辑版 | Director's Cut | 由导演主导完成的版本，通常与最终上映版有所不同 |
| 剪辑师剪辑版 | Editor's Cut | 剪辑师在不受导演影响下独立完成的版本 |
| 试映剪辑版 | Test Screening Cut | 用于观众试映的特定版本，后续会根据反馈进行调整 |
| 代理文件 | Proxy | 低分辨率版本素材，用于提升剪辑效率，定剪后重新链接原始素材 |
| 时间线 | Timeline | 剪辑软件中排列镜头的横向时间轴 |
| 版本管理 | Versioning | 通过编号或命名记录不同剪辑版本的做法，便于回溯和比较 |
| 画面定剪 | Picture Lock | 画面不再修改的标志性节点，所有画面编辑决策已确定 |

## 其他相关术语（Other Terms）

| 中文术语 | 英文术语 | 简要定义 |
|---------|---------|---------|
| 样片 | Dailies / Rushes | 每日拍摄结束后交给剪辑部门的原始素材 |
| 磁片 | Trims | 在精剪过程中被裁剪掉但仍然保留的素材片段 |
| 临时音轨 | Temp Track | 在精剪阶段使用的临时背景音乐，用于辅助判断节奏 |
| 套底 | Conform / Online Edit | 将代理文件的剪辑决策应用到原始素材上的过程 |
| 数字中间片 | Digital Intermediate / DI | 将胶片扫描为数字文件后进行调色和特效制作的中间流程 |
| 画幅比 | Aspect Ratio | 画面宽度与高度的比例，如16:9、2.35:1 |
| 参考监视器 | Reference Monitor | 经过色彩校准的监视器，用于确保色彩精确性 |
| 场记板 | Clapperboard / Slate | 在每场戏开始时拍摄的打板画面，用于同步音频和视频 |
