# 编剧术语表

## 核心概念

| 术语 | 英文 | 定义 |
|------|------|------|
| 戏剧情境 | Dramatic Situation | 故事的基本单元，包含事件、物理空间、人物关系空间、欲望钩子四要素 |
| 激励事件 | Inciting Incident | 打破人物生存平衡的第一个事件，建制主人公的戏剧欲望 |
| 戏剧任务 | Dramatic Task | 人物想要达成的目标，是观众持续观影的驱动力 |
| 主控思想 | Controlling Idea | 故事想表达的核心价值观判断，即"什么比什么更重要" |
| 戏核 | Drama Core | 最核心的戏剧情境，在此解决故事的终极命题 |
| 戏眼 | Drama Eye | 驱动全剧的关键人物（可能不出现或很少出现） |
| 戏胆 | Drama Gallbladder | 作为悲欢离合见证的关键道具 |
| 节拍 | Beat | 最小的戏剧单位，一次"行动-反应"交换 |
| 情节点 | Plot Point | 戏剧任务发生转折的位置（PP1/中点/PP2） |

## 注意力与悬念

| 术语 | 英文 | 定义 |
|------|------|------|
| 无意注意 | Unconscious Attention | 观众和人物同时获知信息，事件突然发生 |
| 有意注意 | Conscious Attention | 观众比人物知道得多，产生期待和担忧 |
| 期待式悬念 | Expectation-based Suspense | 观众比人物知道得多，产生担忧和期待 |
| 揭秘式悬念 | Revelation-based Suspense | 观众比人物知道得少，产生好奇心 |
| 突发式悬念 | Burst Suspense | 观众和人物知道一样多，感同身受的震惊 |
| 戏剧反讽 | Dramatic Irony | 观众拥有上帝视角，后知后觉的人物产生喜剧效果 |
| 设计未来 | Design the Future | 预告招数+实际拆招，需要两套策略 |
| 心中一计 | Hidden Intentions | 不透露招数，只设计一套策略 |

## 事件类型

| 术语 | 英文 | 定义 |
|------|------|------|
| 偶然事件 | Contingent Event | 没有伏笔、突然发生的事件（全片只能用一次） |
| 必然事件 | Necessary Event | 有因果链条、经过伏笔铺垫的事件 |
| 事情 | Thing | 仅有时间顺序、无因果联系的事实 |
| 事件 | Event | 有因果联系和情感联系的情节单元 |

## 人物

| 术语 | 英文 | 定义 |
|------|------|------|
| 主体 | Subject | 主人公，故事围绕其展开 |
| 对立体 | Opponent | 价值观层面的对立者（必须有） |
| 反派人物 | Villain | 纯阻碍者，不与价值观挂钩（可选） |
| 盟友 | Ally | 帮助主人公实现愿望的辅助角色 |
| 客体 | Object | 主人公欲望指向的对象，情感驱动力来源 |
| 输出体 | Output Body | 向观众传达世界规则的角色 |
| 外部欲望 | External Desire | 驱动情节类型的有形戏剧任务 |
| 内部欲望 | Internal Desire | 深层心理需求或未解决的心结 |
| 三一律 | Three Unities | 时间统一、空间统一、人物关系统一 |

## 结构

| 术语 | 英文 | 定义 |
|------|------|------|
| 一波三折 | One Wave Three Turns | 任何戏剧片段内部应有三次转折 |
| 一唱三叹 | One Song Three Sighs | 关键时刻反复渲染、详细描写 |
| 总分分总 | Total-Part-Part-Total | 总任务→分任务→分任务→总任务解决 |
| 隔断 | Segmentation | 一场戏内用于制造节奏的分段手段（空间/人物关系/冲突/情绪） |
| 两难抉择 | Dilemma | 3/4处的核心抉择：两善择一或两恶取轻 |

## 伏笔

| 术语 | 英文 | 定义 |
|------|------|------|
| 伏笔 | Foreshadowing | 预先埋藏的信息，为后续事件提供合理性 |
| 分晓 | Payoff | 伏笔对应的结果 |
| 多伏一小 | Multiple to One | 多个线索指向一个结论 |
| 一伏多小 | One to Multiple | 一个细节有多层意义的揭示 |
