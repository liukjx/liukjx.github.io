# 光影与色彩

> Krenz（K大）主讲的系统化数字绘画课程，聚焦于色彩理论与光照逻辑，涵盖从底图到光影二分到塑造到长色的完整工作流。

## 适合谁

- 有素描基础但色彩控制薄弱的插画学习者
- 能够画结构线稿但不知如何上色/打光的创作者
- 想要系统化理解光照逻辑（而非凭感觉配色）的画师

## 学习建议

1. **先练习直射光**：直射光有清晰亮暗分界，容易理解和练习
2. **二分做对可得60分**：光影二分是最重要的基本功
3. **结构是一切的基础**：色彩的上限取决于结构理解深度
4. **从灰阶开始**：先掌握明度控制再进入色彩训练
5. **逐步拓展色系**：相似色→灰纯对比→冷暖对比→全色系
