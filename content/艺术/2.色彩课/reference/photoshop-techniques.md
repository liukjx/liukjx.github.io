# Photoshop技法速查

## 图层混合模式

### 正片叠底 (Multiply)

**用途**：加深颜色、模拟阴影、为线稿上色

**原理**：用公式 `结果色 = 基色 × 混合色 / 255`，结果总是比原来的暗。

**典型用法**：
1. 在线稿层上方新建图层，设置为**正片叠底**
2. 用肤色或环境色在图层上涂抹
3. 线稿会透出来，同时颜色叠加在线稿上

**适用范围**：
- 给线稿上固有色
- 加深暗部色调
- 模拟水彩透叠效果

> [!tip] 配合**剪裁遮色片**使用，可将上色范围限制在线稿区域内。正片叠底叠多次会越来越暗，注意控制层数。

### 加亮颜色 (Color Dodge)

**用途**：模拟发光、强光反射、高光强化

**原理**：用公式 `结果色 = 基色 + (混合色 × 基色) / (255 - 混合色)`，结果总是比原来的亮。

**典型用法**：
1. 新建图层，设置为**加亮颜色**
2. 用低透明度画笔涂抹暖色（橙/黄）
3. 制造发光或金属反射效果

**适用范围**：
- 逆光场景的边缘光
- 金属质感的高光
- 背光透明材质的透光

> [!warning] Color Dodge在颜色饱和度过高时容易"烧焦"（产生纯白死区）。建议配合**低不透明度**（20-40%）和**柔边笔刷**使用，或搭配图层遮罩控制范围。

### 柔光 (Soft Light)

**用途**：增加色彩氛围、统一色调、柔化对比

**原理**：类似叠加一层半透明的柔和光源，比 Color Dodge 更温和。

**典型用法**：
1. 在完成图上新建图层，填充50%灰，设置为**柔光**
2. 用黑/白色画笔涂抹来增加/减少亮度和对比
3. 用彩色涂抹来增加色调影响

**适用范围**：
- 统一画面的整体色调
- 柔化过硬的明暗交界线
- 增加环境光氛围

> [!tip] 柔光层配合**50%灰填充**是"灰箱法"的核心技法——用黑白色在灰箱上画，就可以单独控制光影而不影响底层颜色。

## 核心操作技法

### 1. 临界值 (Threshold) 操作

**用途**：检查画面的黑白构成是否清晰

**步骤**：
1. 在图层面板底部点击**调整图层**图标
2. 选择**临界值**
3. 拖动滑块，观察画面变成纯黑+纯白的效果
4. 如果黑白块面无法辨认物体形状，说明明度关系需要调整

> [!tip] 临界值检查是"素描关"的质检工具。如果临界值模式下形状依然是清晰的，说明画面的明度结构过关。

### 2. 色版通道去背

**用途**：从复杂背景中抠出主体（如头发、半透明物体）

**步骤**：
1. 打开**色版 (Channels)** 面板
2. 分别查看红/绿/蓝三个色版，选择**主体与背景对比最大**的那个
3. 复制该色版（右键 → 复制色版）
4. `Ctrl + L` 调整色阶（让主体更白，背景更黑）
5. 用黑/白画笔手动修正边缘
6. 载入选区（`Ctrl + 点击缩略图`）
7. 回到RGB图层，添加图层遮罩完成去背

### 3. 剪裁遮色片 (Clipping Mask)

**用途**：将上色限制在下方图层形状内

**步骤**：
1. 准备一个已画好形状的图层（如线稿或色块）
2. 在其上方新建图层
3. 右键新图层 → **建立剪裁遮色片**（或 `Ctrl + Alt + G`）
4. 此时在上层涂抹，颜色只显示在下层的形状区域内

> [!tip] 剪裁遮色片 + 正片叠底配合，是快速给线稿上色的标准组合。

### 4. 暴力套索 + 色彩平衡长色法

**用途**：大幅延长色块范围，形成"长色"风格

**步骤**：
1. 用**套索工具**大致圈出要上色的区域
2. 羽化选区（`Shift + F6`，羽化值20-50像素）
3. 新建图层，用大笔刷填充颜色
4. 添加**色彩平衡**调整图层，绑定剪裁遮色片到该图层
5. 拖动色彩平衡滑块（阴影/中间调/高光分别调整）
6. 用大号软边橡皮擦擦出渐变过渡

**效果**：颜色会超出物体边界、互相渗透，形成色彩丰富的长色风格。

### 5. 套索 + Ctrl+J + Ctrl+U 局部化妆法

**用途**：精确调整画面中某一局部的颜色

**步骤**：
1. 用**套索工具**圈出要修改的区域
2. `Ctrl + J` 将选区复制到新图层
3. `Ctrl + U` 打开**色相/饱和度**面板
4. 拖动色相/饱和度/明度滑块微调
5. 用图层遮罩（白色显示/黑色隐藏）控制效果范围

> [!tip] 这一技法常用于"画完以后发现某个局部颜色不对"的情况——无需重画，局部调整即可。

### 6. 智能模糊 (Smart Blur) 临摹法

**用途**：将照片或参考图转化为可临摹的色块参考

**步骤**：
1. 打开参考图
2. `滤镜 → 模糊 → 智能模糊`
3. 调整**半径**（决定色块大小）和**阈值**（决定边缘保留程度）
4. 半径推荐值：10-30（视图片尺寸而定）
5. 得到色块化的参考图，便于观察明度关系和色块分布

> [!tip] 临摹时不要用吸管"抄色"，而是先目测判断HSB坐标，再手动选色。用智能模糊是为了看**色块分区**而非抄颜色值。

## 图层遮罩与画笔技法

### 7. 图层遮罩控制亮暗面积

**用途**：精确控制光影的覆盖范围，非破坏性编辑

**步骤**：
1. 在需要控制范围的图层上添加**图层遮罩**
2. 用**黑色画笔**涂抹遮罩——隐藏光影效果
3. 用**白色画笔**涂抹遮罩——显示光影效果
4. 通过调整画笔的**不透明度**和**流量**控制过渡柔和度

**核心原则**：
| 遮罩颜色 | 效果 | 用途 |
|----------|------|------|
| 纯白 | 完全显示 | 亮部区域 |
| 纯黑 | 完全隐藏 | 阴影区域 |
| 灰色 | 半透明显示 | 过渡区域 |

### 8. 硬笔 + 软橡皮擦渐变技法

**用途**：快速画出硬边+渐变过渡的色彩块面

**步骤**：
1. 选用**硬边笔刷**（硬度100%），画出清晰的色块边缘
2. 切换到**橡皮擦工具**，选用**软边笔刷**（硬度0%）
3. 用软橡皮擦轻轻擦拭色块边缘，产生自然渐变
4. 控制橡皮擦的不透明度来制造不同软硬程度的过渡

**优势**：比直接使用软笔刷画渐变更可控，边缘更干净。

### 9. 光色调整图层模式组合

**用途**：快速调整画面的整体光照氛围

**推荐的组合搭配**：

| 目的 | 图层模式 | 配合调整 |
|------|----------|----------|
| 提亮暗部 | 滤色 (Screen) | 叠加蓝紫色或暖色 |
| 加深对比 | 正片叠底 + 加亮颜色 | 分别控制暗部和亮部 |
| 暖光氛围 | 柔光 + 色彩平衡 | 增加红黄通道 |
| 冷光氛围 | 柔光 + 色相/饱和度 | 偏移色相至蓝青 |

### 10. RGB滑块辅助选色

**用途**：精确理解颜色组成，纠正色偏

**步骤**：
1. 打开**拾色器**，切换到RGB模式
2. 观察颜色的RGB分量：

| 颜色 | R偏多 | G偏多 | B偏多 |
|------|-------|-------|-------|
| 红色系 | 高 | 低 | 低 |
| 橙色系 | 高 | 中 | 低 |
| 黄色系 | 高 | 高 | 低 |
| 绿色系 | 低 | 高 | 低 |
| 蓝色系 | 低 | 低 | 高 |
| 紫色系 | 中 | 低 | 高 |

3. 通过微调RGB分量来校正色相偏移

> [!tip] 理解RGB分量有助于理解**色光混色**原理。例如：黄色 = 红+绿（不含蓝），品红 = 红+蓝（不含绿）。这在数字绘画中处理光照颜色时非常实用。
