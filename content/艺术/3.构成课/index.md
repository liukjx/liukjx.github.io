# Krenz 动态与构成 第14期

> **思考方式比绘画技巧更重要** — 这是一门用绘画包装的思考课。

## 课程简介

本课程系统讲解插画构成的**核心框架与思考工具**。Krenz老师从"人物 + 舞台 + 飞行道具 + 亮点"的基本框架出发，逐步深入到动态线、图形概括、节奏韵律、鹰架搭建等高级主题，最终迈向综合创作。

课程贯穿一个核心理念：**构成是选择问题，不是对错问题**。通过提升认知、建立分类能力、进行AB test实验，逐步构建自己的思考工具箱。

## 适合人群

- 已掌握一定绘画基础，希望提升画面构成能力的插画师
- 感觉画面动态不足、布局散乱的学习者
- 想知道"高手为什么这样画"的研究型创作者

## 课程大纲

| 课次 | 主题 | 核心内容 |
|------|------|----------|
| 入学典礼 | 课程导论 | 课程规则、切西瓜理论、作业制度 |
| 第01课 | 飞行道具 | 核心框架、三的定理、趋势、CSI用笔、研究方法 |
| 第02课 | 双主角与概括 | 形的层级、死角、双主角概念、CSI进阶 |
| 第03课 | 动态线 | 趋势→图形→结构、AB test、分类能力、风格光谱 |
| 第04课 | 拆解分组再构筑 | D字型/知字型/风字型、直曲对比、拉伸挤压、布料研究 |
| 第05课 | 节奏和韵律 | 背景构成、重复/不重复图形、视觉关键字、基本形 |
| 第06课 | 鹰架 | 丰富的穿插、视觉导引、八字回游、设计练习 |
| 第07课 | 研讨 | 系列作规划、选品、角色气质、资料搜集方法论 |
| 第08课 | 整合练习 | 摸鱼vs习作vs创作、图形vs结构思维、复合咏唱 |

## 学习路径

1. **热身**：入学典礼 + 第01课（了解框架与基础概念）
2. **筑基**：第02课-第04课（掌握动态与概括的核心技能）
3. **进阶**：第05课-第06课（背景构成与整体编排）
4. **实战**：第07课-第08课（创作流程与练习方法论）
