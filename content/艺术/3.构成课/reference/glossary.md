# 术语表

> 构成课中所有核心术语的简短定义与说明。

---

## CSI 用笔

| 项目 | 内容 |
|------|------|
| **英文** | CSI Stroke / Curve-Straight-In-between |
| **解释** | 将线条分为三种基本类型：C 线（弧线）、S 线（S 形弧线）、I 线（直线）。Krenz 强调有意识地选择用笔的线型，而非无意识地"搓线"。CSI 用笔是构成课所有技巧的基础。 |
| **关联** | L2、用笔等级 |

---

## 趋势

| 项目 | 内容 |
|------|------|
| **英文** | Trend / Gesture |
| **解释** | 画面中线的方向感与流动感。趋势是构成的第一步——在画任何具体物件之前，先感知和标出主要的动线方向。趋势也是透视线的基础。 |
| **关联** | L1-L2、D 字型、抓形 |

---

## 一级形 / 二级形 / 三级形

| 项目 | 内容 |
|------|------|
| **英文** | Level 1 / Level 2 / Level 3 Shape |
| **解释** | 形的三个层级：一级形是最大的整体趋势与轮廓；二级形是中型的块面与结构；三级形是细节与装饰。绘画时应从一级形开始，逐级推进，不可跳级。 |
| **关联** | L1-L3、形的层级 |

---

## 切西瓜理论

| 项目 | 内容 |
|------|------|
| **英文** | Watermelon Cutting Theory |
| **解释** | 画具有弧度或透视感的物件（如圆柱体、人物手臂）时，用"切西瓜"的方式——先画出大的弧面轮廓，再切出内部的形状转折，而非从边缘开始描边。 |
| **关联** | L2、透视、圆柱体 |

---

## 三的定理

| 项目 | 内容 |
|------|------|
| **英文** | Rule of Three |
| **解释** | 视觉上最舒适的数量是"三"。在画面中寻找三个层级（大/中/小）、三个方向、三个节奏点。无论是动线、元素还是反差，三次重复是最自然的编排。 |
| **关联** | L5、大中小、画面编排 |

---

## D 字型

| 项目 | 内容 |
|------|------|
| **英文** | D-Shape |
| **解释** | 一个大弧线内含直线切角的形状，形如字母 D。用于表现主体动态线，如脊柱的主要弯曲。D 字型是构成课最基础的动态线模型。 |
| **关联** | L1、趋势、主动态 |

---

## 知字型

| 项目 | 内容 |
|------|------|
| **英文** | Knowledge-Shape / Zhi-Shape |
| **解释** | 与 D 字型方向相反的辅助曲线。用于制造对比与丰富动态层次——当主体是 D 字型时，肢体或服饰用知字型产生反向张力。 |
| **关联** | L3、动态对比、辅助动态 |

---

## 风字型

| 项目 | 内容 |
|------|------|
| **英文** | Wind-Shape / Feng-Shape |
| **解释** | S 形或多段扭转的弧线，形如汉字"风"的笔画走势。用于表现复杂的扭转动态，或连接多个方向的复合运动。 |
| **关联** | L3、扭转、复合动态 |

---

## 直曲对比

| 项目 | 内容 |
|------|------|
| **英文** | Straight vs Curve Contrast |
| **解释** | 画面中直线（刚硬、稳定）与曲线（柔美、动感）的对比配置。是制造视觉张力和层次感的核心手段。一条好的动态线往往是大曲线中插入直线切角。 |
| **关联** | L3-L5、对比、张力 |

---

## 拉伸与挤压

| 项目 | 内容 |
|------|------|
| **英文** | Stretch & Squash |
| **解释** | 物体在运动中产生的形变：受力时挤压（Squash），伸展时拉伸（Stretch）。这是赋予画面动态感和弹性的基本技巧，尤其在 Q 版与美式风格中广泛应用。 |
| **关联** | L2-L3、动态、弹性 |

---

## 枕头模型

| 项目 | 内容 |
|------|------|
| **英文** | Pillow Model / Cushion Model |
| **解释** | 一种用"枕头形"来理解人体体块（如胸部、臀部、头部）的简化方法。枕头形的弧度和转折可以帮助建立立体感和透视感。Krenz 在画人体时经常从枕头形开始。 |
| **关联** | L4、透视、体块 |

---

## AB test

| 项目 | 内容 |
|------|------|
| **英文** | A/B Test |
| **解释** | 核心研究方法：针对一个特定的变量（如一条线的位置、一个形状的宽窄），尝试不同的方案（A、B、C...）并对比效果。AB test 是将"感觉"转换为"可操作的判断"的关键工具。 |
| **关联** | L3、L8、研究方法论 |

---

## 鹰架

| 项目 | 内容 |
|------|------|
| **英文** | Scaffolding |
| **解释** | 画面的空间层次架构——前、中、后三层的布局。每一层承载不同的信息量，通过动态线连接。鹰架确保画面有深度感和空间层次。 |
| **关联** | L5-L6、空间层次、构图 |

---

## 八字回游

| 项目 | 内容 |
|------|------|
| **英文** | Figure-8 Flow / Ba-Zi Circulation |
| **解释** | 画面能量的循环流动路径。观众的视线从入口进入，经过主体，通过辅助元素回旋，再回到起点形成闭环。能量流动的路径形如数字"8"。 |
| **关联** | L6、能量流动、动线设计 |

---

## 鱼尾巴

| 项目 | 内容 |
|------|------|
| **英文** | Fish Tail |
| **解释** | 八字回游的一种具体表现形式——能量从主体延伸出去后，在画面边缘像鱼尾一样分叉摆动，形成优雅的收尾。Krenz 表示学会画鱼尾巴后画面动态感显著提升。 |
| **关联** | L6、八字回游、动态延伸 |

---

## 选品

| 项目 | 内容 |
|------|------|
| **英文** | Selection / Curation |
| **解释** | 从搜集的资料中筛选出适合画面的元素。不是所有参考图上的东西都要画进去——要选择与主题、动态、构成匹配的元素，舍弃不符合的部分。 |
| **关联** | L7-L8、创作流程、资料搜集 |

---

## 视觉关键字

| 项目 | 内容 |
|------|------|
| **英文** | Visual Keywords |
| **解释** | 用于描述画面或角色特征的几个核心关键词。例如"轻盈、飘逸、优雅"或"厚重、坚硬、力量"。所有画面元素都应服务于视觉关键字，避免信息混乱。 |
| **关联** | L7、画面设定、统一性 |

---

## 摸鱼 / 习作 / 创作

| 项目 | 内容 |
|------|------|
| **英文** | Mindless Drawing / Study / Creation |
| **解释** | 三种绘画行为模式：摸鱼是被动技能下的无意识涂鸦；习作是刻意针对特定知识点的 AB test 练习；创作是包含设定、研究、选品、构图的完整作品。三者需要在学习计划中明确区分。 |
| **关联** | L8、练习规划 |

---

## 复合咏唱

| 项目 | 内容 |
|------|------|
| **英文** | Compound Chanting / Multi-Casting |
| **解释** | 同时运用多种绘画技巧的能力——如"图形 + 透视"同时进行。只有将单项技能练到反射动作（被动技能）的程度，才能实现复合咏唱。第八课作业就是复合咏唱的综合挑战。 |
| **关联** | L8、综合应用、实战 |

---

## 反复横跳

| 项目 | 内容 |
|------|------|
| **英文** | Back-and-Forth Switching |
| **解释** | 在不同思维模式和技巧之间灵活切换的能力——从图形思维切到结构思维，从写实切到夸张。反复横跳的能力决定了你的"防守范围"有多宽。 |
| **关联** | L8、防守范围、图形vs结构 |

---

## 防守范围

| 项目 | 内容 |
|------|------|
| **英文** | Defense Range / Comfort Zone Expansion |
| **解释** | 你能够在写实-夸张光谱上自由调整的范围。只练结构思维的人防守范围很窄（15-25），而同时练图形思维的人可以扩展到 25-80。防守范围越宽，越容易达到目标风格。 |
| **关联** | L8、光谱、反复横跳 |

---

## 顿悟时刻

| 项目 | 内容 |
|------|------|
| **英文** | Eureka Moment / Insight Moment |
| **解释** | 经过长时间的研究和试错后，突然理解某个原理或技巧的瞬间。Krenz 认为这是绘画学习中最具驱动力的体验——从"知道"通往"做到"的桥梁。 |
| **关联** | L8、研究精神、学习动力 |
