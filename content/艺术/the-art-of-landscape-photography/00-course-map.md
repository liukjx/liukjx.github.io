# 课程地图

## 学习路径

```mermaid
flowchart LR
    A[第01章 装备选择] --> B[第02章 拍摄技术]
    B --> C[第03章 画面平衡]
    C --> D[第04章 深度与透视]
    D --> E[第05章 构图的几何学]
    E --> F[第06章 光线]
    F --> G[第07章 各类风光拍摄]
    G --> H[第08章 后期处理]
    H --> I[第09章 发展个人风格]
```

**推荐路径：** 按编号顺序学习前7章打好基础，第08章（后期）可结合实际需求同步学习，第09章（个人风格）是最终目标。

## 章节依赖关系

| 章节 | 前置依赖 | 独立程度 |
|---|---|---|
| 第01章 装备 | 无 | 可独立阅读 |
| 第02章 技术 | 装备概念 | 需理解传感器、镜头类型 |
| 第03章 平衡 | 技术基础 | 独立美学章节 |
| 第04章 深度与透视 | 镜头类型、景深概念 | 依赖第02章 |
| 第05章 几何构图 | 无严格依赖 | 可与第03章互换顺序 |
| 第06章 光线 | 曝光控制 | 依赖第02章 |
| 第07章 场景 | 前6章综合 | 综合运用章节 |
| 第08章 后期 | 无严格依赖 | 可随时学习 |
| 第09章 风格 | 全部章节 | 最终整合 |
