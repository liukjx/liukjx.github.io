# 风光摄影的艺术

> 从技术到艺术的完整进阶指南

## 适合谁
- 有一定摄影基础、希望提升风光摄影水平的学习者
- 对构图美学和视觉表达有追求的风光摄影爱好者
- 想要理解光线、色彩与后期处理全流程的摄影师

## 学习成果
完成本课程后，你将能够：
- 根据拍摄场景选择合适的相机、镜头与配件
- 掌握曝光、景深、超焦距等核心技术参数
- 运用三分法、黄金分割、视觉平衡等构图原则
- 利用线条、形状、层次引导观众视线
- 理解和利用不同方向与质量的光线
- 针对海岸、山地、森林、水域等不同场景调整拍摄策略
- 完成从Raw文件到成片的后期处理流程

## 课程结构

本课程共9章，涵盖风光摄影从装备到后期、从技术到艺术的完整知识体系。

| 章节 | 主题 | 内容 |
|---|---|---|
| 第01章 | [装备选择](lessons/0001-equipment.md) | 相机格式、镜头、三脚架、滤镜 |
| 第02章 | [拍摄技术](lessons/0002-shooting-technique.md) | 曝光、景深、超焦距、衍射、色彩理论 |
| 第03章 | [画面平衡](lessons/0003-balance.md) | 视觉平衡、三分法、黄金分割、对称 |
| 第04章 | [深度与透视](lessons/0004-depth-perspective.md) | 线性透视、消失点、前景兴趣、移轴 |
| 第05章 | [构图的几何学](lessons/0005-geometry-composition.md) | 线条、形状、层次、运动与流动 |
| 第06章 | [光线](lessons/0006-light.md) | 光的方向与质量、季节、弱光、黑白 |
| 第07章 | [各类风光拍摄](lessons/0007-landscape-types.md) | 海岸、山地、森林、水域、微缩景观 |
| 第08章 | [后期处理](lessons/0008-processing.md) | 裁剪、锐化、曝光合成、全景接片 |
| 第09章 | [发展个人风格](lessons/0009-personal-style.md) | 极简、印象、抽象、风格定义 |
