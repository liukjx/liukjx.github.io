# 风光摄影术语表

> **用途**：快速查阅风光摄影中涉及的关键术语，中英文对照，帮助消除概念盲区。

---

## 基础曝光类

| 术语 | 英文 | 简要定义 |
|------|------|----------|
| 光圈 | Aperture | 镜头内控制进光量的孔径大小，用 f/ 值表示，数值越小孔径越大。 |
| 快门速度 | Shutter Speed | 相机传感器暴露在光线下的时间长度，以秒或分数秒表示。 |
| ISO | ISO / Sensitivity | 传感器对光的敏感度，数值越高对光越敏感，但噪点也越多。 |
| 曝光量 | Exposure Value (EV) | 衡量总曝光量的综合指标，由光圈、快门、ISO 三者共同决定。 |
| 曝光补偿 | Exposure Compensation | 在自动测光基础上人为增减曝光量的调整，单位为 EV 档。 |
| 向右曝光 | ETTR (Expose To The Right) | 在不过曝的前提下让直方图尽量靠右，以获取更丰富的阴影细节和信噪比。 |
| 曝光合成 | Exposure Blending / HDR | 拍摄多张不同曝光量的照片后合成为一张，以保留高光和阴影细节。 |
| 测光模式 | Metering Mode | 相机测量光线的方式，包括评价测光、中央重点测光、点测光等。 |
| 区域曝光法 | Zone System | 安塞尔·亚当斯提出的将亮度分为 11 个区域的曝光控制方法。 |

## 对焦与景深类

| 术语 | 英文 | 简要定义 |
|------|------|----------|
| 景深 | Depth of Field (DoF) | 画面中看起来清晰的范围，受光圈、焦距、对焦距离共同影响。 |
| 超焦距 | Hyperfocal Distance | 当对焦在此距离时，从该距离的一半到无穷远都处于可接受的清晰范围内。 |
| 焦点合成 | Focus Stacking | 拍摄多张不同对焦位置的照片后合成，获得全景深清晰图像。 |
| 弥散圆 | Circle of Confusion (CoC) | 点光源经镜头成像后变成的光斑大小，用于定义"可接受的清晰度"。 |
| 衍射 | Diffraction | 光圈过小时光线发生弯曲导致分辨率下降的光学现象。 |
| 最佳光圈 | Sweet Spot / Optimal Aperture | 镜头解析力最高且衍射影响较小的光圈值，通常为 f/8–f/11。 |
| 沙姆弗卢格原理 | Scheimpflug Principle | 当镜头平面、对焦平面、成像平面交于一条线时，可获得倾斜的清晰平面，常用于移轴摄影。 |

## 滤镜类

| 术语 | 英文 | 简要定义 |
|------|------|----------|
| 中性密度滤镜 | ND Filter (Neutral Density) | 均匀减少进光量的中性灰滤镜，用于实现长时间曝光。 |
| 渐变中性密度滤镜 | GND Filter (Graduated ND) | 一半透明一半减光、中间渐变的滤镜，用于平衡天空与地面的光比。 |
| 反向渐变滤镜 | Reverse GND (RGND) | 中间最暗、向边缘渐亮的渐变滤镜，用于日出日落时太阳附近的压光。 |
| 偏振镜 | Polarizer (CPL/PL) | 通过偏振光原理消除非金属表面反光、增强色彩饱和度和对比度的滤镜。 |

## 色彩与白平衡类

| 术语 | 英文 | 简要定义 |
|------|------|----------|
| 色温 | Color Temperature | 光源颜色的量化指标，单位为开尔文 (K)，数值越低越暖（偏黄），越高越冷（偏蓝）。 |
| 白平衡 | White Balance (WB) | 相机在不同色温光源下校正色彩、使白色呈现为白色的设置。 |
| 黄金时刻 | Golden Hour | 日出后和日落前一小时左右的暖色调低角度光线时段。 |
| 蓝色时刻 | Blue Hour | 日出前和日落后天空呈现深蓝色的短暂时段。 |

## 构图与视觉设计类

| 术语 | 英文 | 简要定义 |
|------|------|----------|
| 三分法 | Rule of Thirds | 将画面横竖三等分，将主体放置在交叉点或分割线上的构图方法。 |
| 黄金比例 | Golden Ratio (Phi, φ ≈ 1.618) | 自然界中广泛存在的比例关系，用于构图可产生和谐的视觉美感。 |
| 黄金分割 | Golden Section | 将线段按黄金比例分割为长短两段，常用于画面区域划分。 |
| 黄金螺旋 | Golden Spiral / Fibonacci Spiral | 基于斐波那契数列生成的螺旋线，引导视线从外向内汇聚。 |
| 黄金三角 | Golden Triangle | 将画面对角线分割后，由垂线构成的三角形构图框架。 |
| 斐波那契数列 | Fibonacci Sequence | 每一项等于前两项之和的数列 (0,1,1,2,3,5,8,13…)，其比值趋近于黄金比例。 |
| 视觉重量 | Visual Weight | 画面中不同元素吸引观众注意力的能力，受色彩、对比度、大小、位置影响。 |
| 视觉平衡 | Visual Balance | 画面中不同元素的视觉重量分布均匀、整体协调的状态。 |
| 对称 | Symmetry | 画面沿中轴线左右或上下镜像对应，产生庄重、稳定的视觉效果。 |
| 奇数法则 | Rule of Odds | 画面中主体数量为奇数时比偶数更有视觉趣味和动感。 |
| 引导线 | Leading Lines | 画面中引导观众视线向主体或远处延伸的线条元素。 |
| 前景兴趣 | Foreground Interest | 在画面近景处放置有吸引力的元素，增加纵深感和层次感。 |
| 天然画框 | Natural Frame | 利用树枝、窗框、拱门等元素在画面边缘形成框架，突出主体。 |
| 线性透视 | Linear Perspective | 平行线在远处汇聚产生纵深感的视觉现象。 |
| 消失点 | Vanishing Point | 平行线在透视中汇聚于画面上的点。 |
| 空气透视 | Aerial Perspective | 因大气散射导致远处物体对比度降低、颜色变淡、细节模糊的透视现象。 |
| 负空间 | Negative Space | 主体周围留白或简洁的区域，用于突出主体、营造意境。 |
| 层次感 | Layering | 通过前景、中景、远景的层层递进构建画面深度。 |
| 质感 | Texture | 画面中物体表面的触感视觉表现，通过侧光可增强质感。 |
| 节奏与重复 | Rhythm & Repetition | 画面中相似元素有规律地重复出现，形成视觉韵律。 |

## 镜头与传感器类

| 术语 | 英文 | 简要定义 |
|------|------|----------|
| 焦距 | Focal Length | 镜头光学中心到传感器的距离，单位 mm，决定视角大小。 |
| 宽高比 | Aspect Ratio | 画面宽度与高度的比例，常见有 3:2、4:3、16:9 等。 |
| 裁切系数 | Crop Factor | 传感器尺寸相对于全画幅（36×24mm）的比例系数。 |
| 全画幅 | Full-Frame | 传感器尺寸为 36×24mm，与 35mm 胶片相同。 |
| APS-C | APS-C | 比全画幅小的传感器规格，裁切系数通常为 1.5×（尼康）或 1.6×（佳能）。 |
| 星芒效果 | Starburst Effect | 点光源在小光圈下呈现星状放射线条的光学现象。 |
| 莫列波纹 | Moiré Pattern | 拍摄密集纹理时因传感器采样与纹理重叠产生的干涉波纹。 |
| 像差 | Aberration | 镜头未能将光线汇聚到同一点导致成像缺陷，包括色差、球差、畸变等。 |

## 后期与输出类

| 术语 | 英文 | 简要定义 |
|------|------|----------|
| Raw 文件 | Raw File | 未经相机内处理的原始传感器数据文件，保留最大后期调整空间。 |
| 直方图 | Histogram | 显示画面亮度分布（0-255 级）的图表，帮助判断曝光是否准确。 |
| 全景接片 | Panoramic Stitching | 将多张重叠拍摄的照片拼接成一张宽幅全景图。 |
| 亮度蒙版 | Luminosity Mask | 基于画面亮度值生成的选区，用于精细调整特定亮度范围的区域。 |
| 色调映射 | Tone Mapping | 将 HDR 高动态范围数据映射到标准显示范围内、保留细节的过程。 |
| 渐晕 | Vignetting | 画面边缘亮度低于中心的现象，可能是镜头固有特性或后期添加的效果。 |
