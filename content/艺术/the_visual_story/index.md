# 视觉结构基础

> **以视觉讲故事 (Visual Storytelling)** 的核心原理与实践方法

本课程基于《The Visual Story: Creating the Visual Structure of Film, TV, and Digital Media》(第三版, 2021) 一书，系统讲解七大基本视觉组件（空间、线条、形状、影调、色彩、运动、节奏）以及**对比与亲和原则**，帮助影像创作者理解并控制画面的视觉结构。

## 适用人群

- 导演、摄影师、美术指导、剪辑师
- 动画师、游戏设计师、视觉特效师
- 任何希望提升视觉叙事能力的创作者

## 课程结构

| 模块 | 内容 | 课时 |
|---|---|---|
| 模块一：基础 | 七种基本视觉组件 + 对比与亲和原则 | 第01-02课 |
| 模块二：空间 | 深度线索 + 画面结构与构图 | 第03-04课 |
| 模块三：线条与形状 | 线的观察方式 + 基础形状情绪 | 第05-06课 |
| 模块四：影调 | 影调控制与叙事手法 | 第07课 |
| 模块五：色彩 | 色彩系统/属性 + 配色方案/交互 | 第08-09课 |
| 模块六：运动 | 运动类型与连续体 | 第10课 |
| 模块七：节奏 | 视觉韵律与剪辑节奏 | 第11课 |
| 模块八：综合 | 故事与视觉结构 + 实践方法 | 第12课 |

## 学习路径

建议按顺序学习，因为每个概念都建立在前面的基础之上。若时间有限，可以先看第01-02课（基础原理），再选择感兴趣的组件章节。

## 核心书籍

> Block, B. (2021). *The Visual Story: Creating the Visual Structure of Film, TV, and Digital Media* (3rd ed.). Routledge.
