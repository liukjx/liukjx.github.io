# 概念设计的秘密

> 游戏美术基础与设计方法 — OLDFISH

**本书定位**：一本全面解析游戏美术与绘画设计底层逻辑的应用指南，从最基础的点线面构成，到复杂的规划设计方法论，系统性地构建概念设计师的完整知识体系。

## 适用读者

- 游戏概念设计师、原画师
- 游戏美术专业学生
- 对游戏美术创作感兴趣的爱好者

## 前置知识

- 基础的绘画能力
- 对游戏美术有基本了解

## 课程结构

本课程覆盖全书 **14 个章节**，从设计基础到综合应用，循序渐进：

| 模块 | 章节 | 核心主题 |
|------|------|----------|
| 基础篇 | 第01-03章 | 点线面基础、排列节奏、节奏的作用 |
| 造型篇 | 第04-06章 | 轮廓剪影、平面切割、体积结构 |
| 色彩篇 | 第07章 | 色彩搭配 |
| 表现篇 | 第08-09章 | 表现力、画面构图 |
| 空间篇 | 第10-11章 | 空间关系、光影环境 |
| 应用篇 | 第12-14章 | 概念的传达、设计语言、规划设计 |
