# 概念设计速查表

## 点、线、面基础

### 制造视觉中心的五种方式
| 方式 | 原理 | 应用 |
|------|------|------|
| 造型刺激 | 造型差异对比 | 突出建筑、角色 |
| 动势刺激 | 动态/姿势差异 | 夸张动作、水车/旗帜 |
| 色彩刺激 | 色彩差异对比 | 广告牌、亮色元素 |
| 线/面交汇 | 方向性汇聚 | 枝干交汇、地砖拼花 |
| 生理刺激 | 本能反应 | 骷髅、美女、食物 |

### 点在不同位置的形式感
| 位置 | 心理感受 | 应用场景 |
|------|----------|----------|
| 画面中心 | 视线凝聚力强、空间开阔 | 广场、战斗平台 |
| 正上方 | 坠落感、不安定感 | 悬空建筑 |
| 侧上方 | 视线延伸、安定感 | 山峰、肩甲设计 |
| 正下方 | 存在感极弱 | 避免使用 |
| 边缘 | 几乎没有存在感 | 避免主体放边缘 |

### 不同形状线的形式感
| 线类型 | 特征 | 应用 |
|--------|------|------|
| 直线 | 男性化、力量、力度 | 军事、工程机械 |
| 曲线 | 女性化、优雅、柔美 | 宫廷、花园题材 |
| 粗线 | 厚重、敦实、历史感 | 古建筑、石柱 |
| 细线 | 尖锐、脆弱、渺小 | 藤蔓、枝干 |

### 不同形状面的形式感
| 面类型 | 形式感 |
|--------|--------|
| 直线形等边面 | 安定、有序、坚实 |
| 斜四边形面 | 失衡趋势、重心转动 |
| 正梯形面 | 安定感 |
| 倒梯形面 | 不安定感 |
| 曲线规则面 | 女性化、柔软、动感 |
| 偶然形态面 | 自由、奔放、随机性 |
| 自然形态面 | 生动、不规则 |

## 排列节奏

### 节奏形成的三要素
1. 元素之间的**对比**（外观形式、间隔、趋势方向）
2. 变化层次形成有规律的**重复组合关系**
3. 不同层次赋予**起伏变化**（韵律）

### 四种排列结构形式
| 类型 | 特征 | 应用 |
|------|------|------|
| 重复排列 | 相同/相近元素反复出现 | 弹链、纹饰、廊柱 |
| 特异排列 | 局部插入变异元素 | 视觉焦点、事件暗示 |
| 渐变排列 | 递进式逐渐变化 | 动感表现、变身效果 |
| 发射排列 | 中心向外扩散/向内聚拢 | 纹饰、生物造型 |

### 特异排列的四种形式
- **造型特异**：形状/大小变异
- **颜色特异**：颜色属性变异
- **间隔特异**：空间位置变异
- **方向趋势特异**：方向变异

## 色彩搭配

### 颜色的三属性
| 属性 | 说明 | 作用 |
|------|------|------|
| 色相 | 颜色的相貌称谓（红橙黄绿青蓝紫） | 基本属性，区分颜色 |
| 明度 | 颜色的明暗深浅程度 | 影响对比度和辨识度 |
| 纯度（饱和度） | 颜色含有色成分的比例 | 影响鲜艳程度 |

### 融合型色彩搭配
| 类型 | 色环角度 | 特征 |
|------|----------|------|
| 类似色 | 60°以内 | 统一且丰富 |
| 邻近色 | 30°以内 | 更统一，变化较小 |
| 同类色 | 15°以内 | 最统一，可能单调 |

### 对比型色彩搭配
| 类型 | 色环角度 | 特征 |
|------|----------|------|
| 互补色 | 180° | 最强对比，视觉冲击 |
| 分裂补色 | 互补+类比 | 和谐且有重点 |
| 对比色 | 120° | 较强对比，相对柔和 |
| 中差色 | 90° | 接近类比色的对比 |

### 色彩造型关系三因素
1. **面积比例**：大面积主导色调，小面积突出
2. **形状**：轮廓完整则对比强，琐碎则对比弱
3. **相对位置**：距离近则对比强，远则对比弱

## 画面构图

### 常见架构形式
| 形式 | 特征 | 传递的感觉 |
|------|------|------------|
| 对称式 | 左右对称 | 庄重、仪式感 |
| 均衡式 | 非对称但平衡 | 灵活、生动 |
| 三角形式 | 三角形结构 | 稳定、集中 |
| 框架式 | 前景框住主体 | 纵深感、窥视感 |

### 空间关系表现手法
1. **景别层次**：前景-中景-远景
2. **透视参照**：近大远小、消失点
3. **空气透视**：远处色彩变淡模糊
4. **菲涅耳效应**：视线夹角与反射
