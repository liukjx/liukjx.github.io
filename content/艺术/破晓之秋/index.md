# 破晓之秋

> KK零基础绘画训练营 第0期·破晓之丘 — 49天从零开始掌握绘画观察法

**课程受众**：从未接触过电脑绘图的零基础学员  
**课程目标**：掌握"画家之眼"——用画家的角度观察事物、抓形临摹，建立手眼板一致的绘画基础能力  
**核心产出**：四个阶段系统训练 → 九宫格抓形 → 图形抓形 → 风格认知 → 光影与创作思维
