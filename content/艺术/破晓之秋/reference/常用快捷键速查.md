# 常用快捷键速查

> [!INFO] 通用原则
> - **PS**：大部分快捷键是**单键操作**（按一下切换工具），适合键鼠配合
> - **Procreate**：以**手势为主**，适合触屏/笔操作
> - 没有"最好"的习惯，选**自己肌肉记忆最牢的**那套

---

## 一、Photoshop 快捷键

### 常用工具

| 功能 | 快捷键 | 说明 |
|------|--------|------|
| 画笔工具 | **B** | 最常用的工具，按一下切换 |
| 橡皮擦 | **E** | 擦除图层内容 |
| 套索工具 | **L** | 按3次可在套索/多边形/磁性间切换 |
| 文字工具 | **T** | 横排/竖排文本 |
| 移动工具 | **V** | 移动图层/选区内容 |
| 吸管工具 | **I** / **Alt+单击** | 取色，画中按住Alt临时切换 |
| 抓手（移动画面） | **H** | 拖动平移画布 |
| 放大镜 | **Z** | 单击放大，Alt+单击缩小 |

> [!TIP] 高频操作组合
> - 画图时**左手 Alt（取色）+ 空格（抓手）+ Ctrl+Z（撤销）** 是最常用的三件套
> - **B + 空格 + Alt + Ctrl+Z** 四键配合可以覆盖80%的绘画操作

### 常用操作

| 功能 | 快捷键 | 说明 |
|------|--------|------|
| 撤销 | **Ctrl+Z** | 每次后退一步 |
| 重做 | **Ctrl+Shift+Z** | 每按一次前进一步 |
| 放大/缩小 | **Alt+滚轮** | 向上放大，向下缩小 |
| 自由变换 | **Ctrl+T** | 缩放/旋转/变形选中的内容 |
| 取消选区 | **Ctrl+H** | 隐藏/显示选区虚线 |
| 复制图层 | **Ctrl+J** | 复制当前选中的图层 |
| 合并可见图层 | **Ctrl+Shift+E** | 把所有可见图层合并成一个 |
| 反选 | **Ctrl+Shift+I** | 反转当前选区 |
| 填充前景色 | **Alt+Delete** | 用前景色填充选区或图层 |
| 填充背景色 | **Ctrl+Delete** | 用背景色填充 |
| 调整画笔大小 | **[** 或 **]** | 左中括号缩小，右中括号放大 |
| 调整画笔硬度 | **Shift+[** 或 **Shift+]** | Shift+左括号缩小，Shift+右括号放大 |
| 画直线 | **Shift+点击 → 点击** | 在两个点击点之间画一条直线 |
| 新建图层 | **Ctrl+Shift+N** | 弹出新建图层对话框 |
| 锁定透明像素 | **/** | 按一下，只画在有内容的区域 |
| 切换屏幕模式 | **F** | 标准→全屏→黑底全屏 |

### 文件操作

| 功能 | 快捷键/操作 |
|------|-----------|
| 保存PSD | **Ctrl+S** |
| 另存为 | **Ctrl+Shift+S** |
| 导出PNG | **文件 → 导出 → 快速导出为PNG** |
| 导出JPG | **文件 → 导出 → 导出为 → 选择JPG** |
| 新建文件 | **Ctrl+N** |
| 打开文件 | **Ctrl+O** |

> [!WARNING] PS 撤销注意
> PS 默认只保留**最近1步**的 Ctrl+Z。要恢复多步撤销（类似 Procreate）：
> - 方法1：**Ctrl+Alt+Z**（逐步后退）
> - 方法2：在 **编辑→首选项→性能** 中将"历史记录状态"改大（建议100步）

## 二、Procreate 快捷键

### 手势操作

| 功能 | 操作 | 说明 |
|------|------|------|
| 撤销 | **双指轻点** | 屏幕任意位置双指轻点 |
| 重做 | **三指轻点** | 屏幕任意位置三指轻点 |
| 放大/缩小 | **双指捏合** | 双指在画面捏合/张开 |
| 旋转画布 | **双指旋转** | 双指旋转改变画布方向 |
| 重置视图 | **双指双击** | 恢复100%视图和默认角度 |
| 取色 | **长按屏幕** | 长按画面任意位置吸色 |
| 直线变直 | **画完定住2秒** | 画完线不抬笔，停2秒自动变直/平滑 |
| 清理菜单 | **四指轻点** | 隐藏所有面板，全屏看画 |
| 复制 | **三指上滑** | 调出"拷贝与粘贴"菜单 |

> [!TIP] Procreate 必记手势
> **双指轻点** = 撤销（最常用）
> **画完停2秒** = 线条变直/平滑（画直线和曲线时用）
> **长按** = 吸管取色

### 图层操作

| 功能 | 操作 | 说明 |
|------|------|------|
| 新建图层 | **右上角方块 → 加号** | 在图层面板中点"+" |
| 删除图层 | **左滑** | 在图层上向左滑动，出现红色删除 |
| 调整不透明度 | **点击图层 → N → 滑动** | 点击图层右侧的"N"调整 |
| 调整透明度 | **双指单击图层** | 快捷键调整透明度（左右滑动） |
| 重命名图层 | **点击图层名称** | 修改图层名方便管理 |
| 选择图层内容 | **三指单击图层** | 选中该图层所有像素 |
| 锁定透明像素 | **点击图层 → 勾选"参考"** | 保护透明区域 |

### 选区与变换

| 功能 | 操作 |
|------|------|
| 自由变换 | **箭头工具 → 拖动图层** |
| 等比缩放 | **箭头工具 → 拖动角点** |
| 扭曲变形 | **箭头工具 → 点"等比"切换到"扭曲"** |
| 叠图检查 | **箭头工具 → 拖动图层到旁边**（临摹时检查准度） |

### 文件操作

| 功能 | 操作 |
|------|------|
| 导出PNG | **设置 → 分享 → PNG → 存储图像** |
| 导出PSD | **设置 → 分享 → PSD → 存储/发送** |
| 导出JPG | **设置 → 分享 → JPG → 存储图像** |
| 导出动画GIF | **设置 → 分享 → 动画GIF** |
| 导入图片 | **设置 → 添加 → 插入照片** |

> [!TIP] Procreate PSD 导出
> - 导出 **PSD** 可以保留所有图层，在电脑上继续用PS修改
> - 导出 **PNG** 是单张图，适合分享和交作业
> - 导出前检查图层是否命名清晰

### 笔刷与颜色

| 功能 | 操作 |
|------|------|
| 打开笔刷库 | **点击笔刷图标** |
| 调整笔刷大小 | **拖动左侧滑条** |
| 调整笔刷透明度 | **拖动右侧滑条** |
| 颜色盘 | **右上角色环** |
| 取色 | **长按屏幕** |

## 三、快速对照（PS vs Procreate）

| 操作 | Photoshop | Procreate |
|------|-----------|-----------|
| **撤销** | Ctrl+Z | 双指轻点 |
| **重做** | Ctrl+Shift+Z | 三指轻点 |
| **缩放** | Alt+滚轮 | 双指捏合 |
| **取色** | Alt+单击 | 长按屏幕 |
| **直线** | Shift+点击→点击 | 画完定住2秒 |
| **保存** | Ctrl+S | 自动保存（无需手动） |
| **导出** | 文件→导出→快速导出为PNG | 设置→分享→PNG→存储图像 |

> [!INFO] 如果从PS换到Procreate（或反过来）
> - 最需要适应的不是功能，而是"撤销"的位置——肌肉记忆最强的一步
> - PS 的 Alt 取色 vs Procreate 的长按取色，是第二需要适应的
> - 建议：**2周内只用一个软件**，不要频繁切换，等形成肌肉记忆后再接触另一个

## 四、自定义快捷键建议

> [!TIP] 设置自己的快捷键
> **PS 中自定义快捷键：**
> 编辑 → 键盘快捷键（Ctrl+Alt+Shift+K）
> - 建议把"翻转画布水平"设成一个顺手键（如 `~` 或 `F5`）
> - 建议把"液化"设成 `Ctrl+Shift+X`
>
> **Procreate 手势设置：**
> 设置 → 手势控制
> - 可以自定义双指/三指/四指的手势功能
> - 推荐把"四指轻点"设为"全屏模式"
