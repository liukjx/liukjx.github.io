# 线条控制练习指南

> [!INFO] 练习目标
> 线条是绘画的"字母"。目标不是画得"好看"，而是**画得"准确"**——想画哪就到哪，想画多直就多直。每天15-20分钟，坚持2周见效。

---

## 一、每日练习表

| 练习类型 | 目的 | 方法 | 建议时长/天 |
|---------|------|------|-----------|
| **直线斜率练习** | 掌握67.5°/45°/22.5°三种斜线 | 每类重复3次，每次画5根 | 5分钟 |
| **C/S曲线练习** | 掌握曲线控制 | 先定两端点，再用一笔连接 | 5分钟 |
| **点对点连线（走迷宫）** | 综合应用直线+曲线 | 两点一线 → 三点一线 → 多点连线 | 5-10分钟 |
| **徒手画圆** | 圆形控制 | 先定4个方向点，再一笔画圆 | 3分钟 |

### 练习一：直线斜率练习

```
目标斜率示意图：

  67.5°             45°              22.5°
    |               /                —
    |              /               ╱
    |             /              ╱
    |            /             ╱
    |           /            ╱
```

> [!TIP] 练习方法
> 1. 在纸上点两个点（间距5-8cm）
> 2. 以最快的速度、**一笔**从起点画到终点
> 3. 不要在意画出去一点点——宁快勿慢
> 4. 每类连续画5根，然后换下一个角度
> 5. 三种角度都画完算1轮，重复3轮

| 角度 | 常见用途 | 难度 |
|------|---------|------|
| 67.5°（接近垂直） | 人物站姿、建筑物竖线 | ★★☆ |
| 45°（对角线） | 面部转折、衣纹褶皱 | ★★★ |
| 22.5°（接近水平） | 水平边缘、透视消失线 | ★★☆ |

### 练习二：C/S曲线练习

```
C 曲线系列：
  弧线（C形）     反弧（反向C）      
  ╭──              ──╮
  │                   │
  ╰──              ──╯

S 曲线系列：
  正S形            反S形
  ╭──╮            ╭──╮
  │  │            │  │
  ╰──╯            ╰──╯
   ↘              ↙
```

> [!TIP] 练习方法
> 1. 先画两端点
> 2. 想象曲线的"最高点/最低点"位置
> 3. 一笔画过，中间不要停顿
> 4. C曲线和S曲线各画10根

| 曲线类型 | 常见用途 |
|---------|---------|
| C形弧线 | 脸颊、肩膀、杯子的弧面 |
| 反C形弧线 | 背部、后脑勺 |
| S形（正） | 女性身体的背部曲线、头发走势 |
| S形（反） | 腿部动态线、衣纹 |

### 练习三：点对点连线（走迷宫）

```
示例（简单→中等→复杂）：

  简单：●─────●              ● ← 目标
          ╲
  中等：●──●──●              ● ← 目标
          ╲  ╱
  复杂：●──●──●              ● ← 目标
          ╲
       ●──●──●──●
       
  练习方式：
  1. 随意在纸上点5-10个点
  2. 按顺序连接（1→2→3→4→5）
  3. 逐步增加点数
  4. 进阶：点和点之间要求走"最短路径"
```

> [!TIP] 走迷宫的进阶玩法
> - **三点一线**：三个点不在一条直线上，用一条稍微弯曲的线穿过它们
> - **连续S弯**：在纸的左右边缘交替画点，用S形连接所有点
> - **盲画版**：看着目标点但不看笔尖，训练手感记忆

### 练习四：徒手画圆

```
画圆方法：
   步骤1：定4点       步骤2：连接成圆
      ↑                    ╭──╮
   ←  ●  →             ←  │  │  →
      ↓                    ╰──╯
   
  注意：
  - 用肩膀发力，不是手腕
  - 一笔完成，不要描
  - 大小从直径5cm开始练
  - 目标是每个圆闭合时偏差<2mm
```

> [!WARNING] 常见错误
> - **画成鸡蛋**（一头大一头小）→ 四方向点定准确再画
> - **接不上**（首尾不闭合）→ 下笔前看好起点和终点的位置关系
> - **多边形**（有棱角）→ 放慢速度，保持匀速

## 二、正确姿势

| 发力方式 | 适用场景 | 特点 |
|---------|---------|------|
| **肩发力** | 画长线（>10cm）、大弧线 | 线条最稳，不易抖动 |
| **肘发力** | 画中长线（5-10cm） | 兼顾稳定和精度 |
| **腕发力** | 画短线（<5cm）、细节 | 精度高，但画长线会抖 |
| **指发力** | 极小细节（描线） | 仅用于最后微调 |

```
正确坐姿示意（俯视）：

          画板
    ┌──────────────┐
    │              │
    │   ╱ 画线方向  │          ← 视线方向
    │  ╱           │
    │ ╱            │
    └──────────────┘
         ↑
      身体中线
      
    手臂状态：
    - 上臂轻贴身体
    - 不要悬空太久
    - 画大弧线时身体跟着转
```

> [!TIP] 自检清单
> - [ ] 肩膀放松，没有耸肩
> - [ ] 画长线时肘关节锁住，用肩膀带动
> - [ ] 呼吸均匀，不要憋气
> - [ ] 画板和视线垂直（不歪头）
> - [ ] 每画5根线活动一下手腕

## 三、常见错误与对策

| 错误类型 | 俗称 | 表现 | 原因 | 解决方法 |
|---------|------|------|------|---------|
| **蹭线** | 毛线 | 一根线反复描，像毛线团 | 不敢一笔到位，追求"完美" | 接受不完美，用**橡皮重于铅笔**——先画错线再擦，而不是边画边改 |
| **甩线** | 飞线 | 起笔收笔不控制，线条飞出 | 速度过快，收笔没意识 | 想象"穿透纸"——**线要穿过终点再停**，不是到终点急刹车 |
| **抖线** | 蚯蚓 | 线不直，像蚯蚓 | 手腕发力、紧张、用错了发力部位 | 换**肩发力**，画线时屏住呼吸试试 |
| **接线** | 接龙 | 短线接成长线，每段都有小角 | 想用短线段拼长线 | 任何>5cm的线**必须一笔完成**，断了就重画不要接 |
| **死线** | 死板 | 线从头到尾一样粗一样黑，没变化 | 用笔压力均匀无变化 | 练习**轻重变化**——起笔轻→中间重→收笔轻 |

```
错误修正练习：

  蹭线修正：    甩线修正：    抖线修正：
   ────         ——→          ────
   ──            —→         ────
   ──────         →         ────
   → 只画一次！  → 控制收笔  → 换肩发力
```

## 四、笔刷建议

> [!WARNING] 笔刷配置
> 以下为**基础练习笔刷**，不包含任何特殊材质效果。练习线条时**禁止使用带压感的笔刷**。

| 软件 | 笔刷名称 | 参数设置 |
|------|---------|---------|
| **Photoshop** | 硬边圆压力不透明度 | 关掉"传递"中的"流量抖动"；画笔预设中取消"形状动态" |
| **Procreate** | 工作室笔（Studio Pen） | 流线（StreamLine）设为 **0%** |
| **纸质** | 任何不渗墨的笔 | 推荐 **中性笔/针管笔**（0.5mm以上），不要用铅笔（会产生蹭线的诱惑） |

**无压感、无材质的原则：**
- 线条练习阶段不需要笔触变化
- 关注的是**起笔到落笔的位置精度**，不是"画得多好看"
- 用硬边缘笔刷，才能清楚看到每一根线的缺陷

> [!TIP] 进阶建议
> 当你能一笔画出标准直线和曲线后：
> 1. 开启压感，练习**轻重变化**
> 2. 使用不同笔刷，感受材质差异
> 3. 练习"叠线"——用细密交叉线表现调子

## 五、两周练习计划

| 周次 | 周一 | 周二 | 周三 | 周四 | 周五 | 周末 |
|------|------|------|------|------|------|------|
| **第1周** | 直线（67.5°） | 直线（45°） | 直线（22.5°） | 曲线（C形） | 曲线（S形） | 自由组合 |
| **第2周** | 走迷宫（5点） | 走迷宫（10点） | 徒手画圆 | 综合：直线+曲线混合 | 综合：画简单的物体轮廓 | 给自己打分（看进步） |

> [!INFO] 持续性 > 单次时长
> 每天15分钟坚持两周，比周末一次练3小时效果好10倍。线条是**肌肉记忆**，需要持续刺激。
