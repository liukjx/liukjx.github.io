# 色彩与光线术语表

欢迎使用常用术语速查。按主题分类整理：

## 光线基础

| 术语 | 英文 | 定义 |
|---|---|---|
| 色温 | Color Temperature | 以开尔文（K）为单位衡量光源颜色的尺度。低色温偏暖（橙红），高色温偏冷（蓝） |
| 光源色 | Light Source Color | 光源本身发出的颜色，影响所有被照物体的色彩 |
| 反射光 | Reflected Light | 从物体表面反射后照亮其他物体的间接光 |
| 环境光 | Ambient Light | 环境中来自各个方向的综合光线 |
| 平方反比定律 | Inverse Square Law | 光照强度与距离的平方成反比 |
| 光谱 | Spectrum | 光的波长分布，可见光范围约 380-780nm |

## 光的传播

| 术语 | 英文 | 定义 |
|---|---|---|
| 镜面反射 | Specular Reflection | 光滑表面的反射，反射角等于入射角 |
| 漫反射 | Diffuse Reflection | 粗糙表面的反射，光线向各个方向散射 |
| 透射 | Transmission | 光穿过透明物体的过程 |
| 折射 | Refraction | 光穿过不同介质时方向发生偏折 |
| 次表面散射 | Subsurface Scattering (SSS) | 光线进入半透明材料内部，散射后从不同位置射出的现象 |
| 色散 | Dispersion | 不同波长的光折射率不同导致的白光分解 |

## 阴影

| 术语 | 英文 | 定义 |
|---|---|---|
| 投影 | Cast Shadow | 物体遮挡光源后投射到其他表面上的阴影 |
| 暗部 | Form Shadow | 物体自身背光面的阴影 |
| 半影 | Penumbra | 阴影边缘的模糊过渡区域 |
| 全影 | Umbra | 阴影中最暗的核心区域 |
| 闭塞阴影 | Occlusion Shadow | 两个物体接触处最暗的阴影区域 |
| 暖光冷影 | Warm Light, Cool Shadow | 晴天室外阴影偏蓝紫色的现象 |

## 色彩理论

| 术语 | 英文 | 定义 |
|---|---|---|
| 色相 | Hue | 颜色的种类：红、橙、黄、绿、蓝、紫 |
| 饱和度 | Saturation / Chroma | 颜色的纯净度或鲜艳程度 |
| 明度 | Value / Lightness | 颜色的明亮程度 |
| 色轮 | Color Wheel | 按色相顺序排列的圆形色彩图谱 |
| 互补色 | Complementary Colors | 色轮上相对位置的色彩对（红-绿、蓝-橙、黄-紫） |
| 类似色 | Analogous Colors | 色轮上相邻的色彩 |
| 固有色 | Local Color | 物体在标准白光下本来的颜色 |
| 环境色 | Environment Color | 周围环境反射到物体上的色彩 |
| 同时对比 | Simultaneous Contrast | 相邻颜色互相影响对方感知的现象 |
| 连续对比 | Successive Contrast | 注视一种颜色后再看白色会产生补色残像 |

## 大气透视

| 术语 | 英文 | 定义 |
|---|---|---|
| 大气透视 | Atmospheric Perspective | 空气介质使远处物体的色彩、明度、清晰度发生变化的视觉现象 |
| 空气散射 | Air Scattering | 空气中的微粒使短波光（蓝紫）更易散射的现象 |
| 景深 | Depth of Field | 画面中从近到远的空间深度感 |

## 光线与绘画

| 术语 | 英文 | 定义 |
|---|---|---|
| 北窗光 | North Light | 朝北窗户射入的稳定、柔和、偏冷的工作室自然光 |
| 黄金时刻 | Golden Hour | 日出后和日落前一小时左右的温暖光线时段 |
| 蓝色时刻 | Blue Hour | 日出前和日落后的蓝紫色光线时段 |
| 伦勃朗光 | Rembrandt Lighting | 肖像画中在面部暗侧形成三角形亮区的布光方式 |
| 蝴蝶光 | Butterfly Lighting | 从正上方打向模特脸部，鼻下形成蝴蝶状阴影的布光方式 |
| 边缘光 | Rim Light | 从背后来照亮物体边缘的轮廓光 |
| 高光 | Highlight | 物体表面直接反射光源的最亮区域 |

## 色彩和谐

| 术语 | 英文 | 定义 |
|---|---|---|
| 类似色和谐 | Analogous Harmony | 使用色轮上相邻颜色的配色方案 |
| 互补色和谐 | Complementary Harmony | 使用色轮上相对颜色的配色方案 |
| 三角色和谐 | Triadic Harmony | 使用色轮上等距三种颜色的配色方案 |
| 单色和谐 | Monochromatic Harmony | 使用同一色相不同明度饱和度的配色方案 |
| 统一色调 | Color Key | 在画面整体覆盖一种色调来统一色彩 |
| 明暗对比 | Chiaroscuro | 强烈的明暗对比手法，制造戏剧性效果 |

## 颜料与技法

| 术语 | 英文 | 定义 |
|---|---|---|
| 减色混合 | Subtractive Mixing | 颜料混合时颜色变暗变浊的原理 |
| 加色混合 | Additive Mixing | 光混合时颜色变亮的原理 |
| 罩染 | Glazing | 在干燥的底层颜料上涂透明色层 |
| 有限调色板 | Limited Palette | 使用少量颜色进行画面调色 |
| 光学混合 | Optical Mixing | 在画面上并置不同色点，在观看者眼中混合 |
| 外光派 | Plein Air | 在户外直接面对自然光线作画的方式 |
