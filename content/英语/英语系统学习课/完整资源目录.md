## 六、学习方法完整清单

### 听力方法

| 方法 | 核心 |
|------|------|
| **六步精听法** | 盲听→朗读→跟读→重复→复习→转泛听 |
| **意群听力法** | 按语块理解，1.2倍速训练 |
| **组合输入策略** | vlog+播客+美剧 |
| **极限听力法** | 高强度听力训练 |
| **听写法** | 初期替代跟读，检测盲区 |

### 词汇方法

| 方法 | 核心 |
|------|------|
| **场景记忆法** | 截图→录入→回忆场景→记住 |
| **17天背单词法** | 密集循环记忆 |
| **词根词缀法** | 通过构词法扩展词汇 |
| **阅读积累法** | 泛读中自然积累 |

### 口语方法

| 方法 | 核心 |
|------|------|
| **复述训练** | 听/读→用自己的话复述 |
| **影子跟读** | 同步跟读模仿 |
| **100LS训练法** | 一部材料听100遍+跟读 |
| **自言自语法** | 每天5分钟自言自语 |

### 发音方法

| 方法 | 核心 |
|------|------|
| **最小对立体训练** | 区分相似音（ship/sheep） |
| **连读弱读训练** | 掌握自然语流 |
| **录音对比法** | 录下自己的发音对比原声 |
