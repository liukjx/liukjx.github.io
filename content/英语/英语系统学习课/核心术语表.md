## 核心理念

**可理解性输入 (Comprehensible Input)**
: 语言习得的核心理念——输入的材料必须大部分能被学习者理解（70-90%），才能被大脑吸收并转化为语言能力。*避免：硬听、死磕*

**正反馈循环 (Positive Feedback Loop)**
: 学习 → 获得成就感/乐趣 → 继续学习的可持续循环。与之相对的是"负反馈循环"——听不懂→挫败→放弃。*避免：靠毅力坚持*

**反完美主义 (Anti-Perfectionism)**
: 不求甚解、大量泛听/泛读的学习心态。不追求每个词都听懂，而是追求整体理解和大规模输入。*避免：细抠、死磕*

**沉浸式输入 (Immersion Input)**
: 每天持续一定时间（建议1-2小时+）处于英语环境中，让大脑自然适应语言模式。*避免：三天打鱼两天晒网*

## 听力

**精听 (Intensive Listening)**
: 反复听同一段材料直到听清每个词的训练方式。在质不在量，每天15-25分钟即可。*避免：听写式精听（时间成本太高，除非初期检测用）*

**泛听 (Extensive Listening)**
: 大量地听，关注内容而非每个词。追求输入量而非精确度，占听力训练的80%。*避免：边听边玩手机（至少保持60%的注意力）*

**意群 (Chunk)**
: 表达一个完整意义的语块，如 "as a matter of fact"、"I dunno"。母语者按意群而非逐词处理语言。*避免：逐词翻译*

**意群听力法 (Chunk Listening)**
: 按意群整体理解的听力方法。用1.2-1.5倍速播放强迫大脑按语块处理信息。*避免：每个词都要听懂才继续*

**六步精听法 (Six-Step Intensive Listening)**
: 盲听3遍 → 朗读文本 → 跟读3遍 → 重复至流利 → 周复习 → 转泛听

**影子跟读 (Shadowing)**
: 几乎同步跟读音频/视频的口语训练方法，重点模仿节奏和语调而非单个音素。*避免：卡在某个词上打乱节奏*

**听觉词汇 (Auditory Vocabulary)**
: 听到能瞬间反应出意思的词汇。与"认知词汇"相对——视觉上认识但听觉无法快速反应的词汇。*避免：以为认识就能听懂*

## 美剧学习

**80-90% 原则**
: 选择学习材料的标准：能理解80-90%大意的材料最适合作学习材料。超过95%太简单，低于50%太难。

**词块积累 (Chunk Accumulation)**
: 有意识地留意和记忆固定搭配、常用短语、连读形式。决定美剧理解能力的关键因素。*避免：只背单个单词*

**三阶段刷剧法**
: 泛看（英文字幕理解剧情）→ 精看（关字幕抓词块+跟读）→ 输出（影子跟读+配音）

## 词汇

**场景记忆法 (Contextual Memory)**
: 通过在真实语境中遇到生词、截图记录、回忆场景的方式来记忆单词。*避免：脱离上下文的单词书背诵*

**自制词库 (Personal Vocabulary Bank)**
: 在欧路词典等工具中建立的个人生词库，按来源（如具体剧集/文章）分组。*避免：用别人的词库*

**COCA 20000**
: 基于美国当代英语语料库统计的2万高频词表。适合作为词汇量自检清单。*避免：当作背单词列表*

## 阅读

**分级阅读 (Graded Reading)**
: 按词汇量等级分级的阅读材料，如 Breaking News English (Level 0-6) 和 Oxford Graded Readers。*避免：直接挑战原版书*

**长按查词 (Tap-to-Lookup)**
: 使用欧路词典等工具快速查词的方法。需要速度快到不影响阅读流。*避免：每页超过2次查词*

## 口语

**复述训练 (Retelling Practice)**
: 听/读一段内容后，用自己的话把内容说出来的训练方法。分半复述（看关键词）和完整复述。*避免：背诵原文*

**自言自语法 (Self-Talk)**
: 每天用英语描述日常活动、想法、感受的口语练习方式。无压力、无评判。*避免：过于在意语法错误*

## 工具

**每日英语听力**
: 推荐的核心听力APP。特色功能：选词填空精听模式、视频精听、AI字幕生成。

**可可英语**
: 精听辅助APP。特色功能：中等听力模式（遮实词留虚词）。

**欧路词典**
: 推荐的核心词典APP。特色功能：截图查词、AI解释、自制词库、认识/不认识复习模式。

**PotPlayer**
: PC端视频播放器。适合视频精听：A-B循环、变速播放、逐帧跳转。
