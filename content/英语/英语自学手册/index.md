# 英语自学手册

## 关于这本书

《英语自学手册》是一本系统探讨"如何自学英语"的方法论书籍。与市面上大多数英语教材不同，这本书不教具体的英语知识（单词、语法规则），而是教**英语学习的方法**——即"元学习"（meta-learning）。作者的核心论点是：**大多数人在英语学习上的失败，不是因为不努力，而是因为方法不对**。

这本书面向的是已经有一定英语基础（初中以上水平）但始终无法突破的自学者，以及想摆脱传统应试英语教育模式的学习者。

## 全书核心论点速览

| 论点 | 核心要义 |
|------|---------|
| 自学 ≠ 学校英语 | 自学需要完全不同的策略，不能沿用课堂那一套 |
| 输入先行 | 听力和阅读是语言能力的根基，输出能力自然生长于输入 |
| 语音是基石 | 发音准确度直接影响听力和口语的天花板 |
| 语境习词 | 单词不在列表里学，而在真实的语言使用中学 |
| 语法即模式 | 语法是语言中自然浮现的规律，不是先验的规则体系 |
| 可持续重于强度 | 每天30分钟坚持一年，远胜突击三个月 |
| 主动加工 | 被动听读效果有限，需要主动注意、思考、复述 |
| 工具赋能 | 善用技术工具（SRS、语料库、有声书）大幅提升效率 |
