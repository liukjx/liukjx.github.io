# 口才训练营

> 练好口才，不怕上台

本课程笔记整理自得到《口才训练营》第1期（2022.04），主讲人：徐明旭。课程从**声音素养、内容优化、临场发挥**三大模块，系统解决当众讲话中的三大恐惧——声音不专业、内容不精彩、临场没把握。

## 课程大纲

课程分为**三大模块 + 三周进阶课**，共10讲主课：

### 模块一：声音素养
解决"声音不专业"的恐惧
- [[0001-sheng-yin-si-zhong-zou-shi|第01课：怎么一张口就抓住听众注意力]] — 声音四种走势（上山、下山、波谷、波峰）
- [[0002-sheng-yin-san-ju-gong-ju|第02课：怎么用声音展现你的魅力]] — 三种突出重点的工具（轻重变化、长短变化、停顿）
- [[0003-zhi-ti-yu-yan|第03课：怎么用肢体语言增强气场]] — 演讲台九宫格、站姿训练、手势运用
- [[0004-xiao-chu-kou-tou-chan|第04课：怎么消除口头禅，让讲话更权威]] — 录音回听训练法

### 模块二：内容优化
解决"内容不精彩"的恐惧
- [[0005-san-dian-yi-xian|第05课：怎么搭结构显得有逻辑]] — 三点一线法
- [[0006-jiang-gu-shi|第06课：怎么讲故事更有感染力]] — 给时空、给画面、找共鸣、画重点
- [[0007-jiang-shu-ju|第07课：怎么讲数据更有说服力]] — 增加类比、变换单位、引入对比

### 模块三：临场发挥
解决"临场没把握"的恐惧
- [[0008-tuo-gao-jiang|第08课：怎么做准备就能脱稿讲]] — 明任务、理大纲、做手卡
- [[0009-shang-tai-qian|第09课：上台前怎么激发最佳状态]] — 四步走法则
- [[0010-biao-da-feng-ge|第10课：怎么形成自己的表达风格]] — PDP性格表达风格

### 进阶课
- [[0011-an-li-xue-xi|第2周进阶课：典型口才案例学习]] — 手势四大空间
- [[0012-zi-wo-jie-shao|第3周进阶课：怎么准备一个自我介绍]] — 三个故事模板

## 学习建议

本课程是实战型训练，建议：
1. 每一讲都**开口出声跟着练**
2. 认真完成每次**录音作业**
3. 利用**录音回听**自我检查
4. 逐步培养**被讨厌的勇气**
