# 第08课：怎么做准备就能脱稿讲

**脱稿不是背稿**——一字不差地背不仅容易忘，而且听起来像背课文，毫无感染力。

脱稿的真相是：**记住核心结构，用自己的话讲出来。**

---

## 第一步：明任务 — 三个问题锁定最高任务

动笔之前，先问自己三个问题。如果你能回答清楚，稿子就成功了一半。

| # | 问题 | 作用 |
|---|------|------|
| 1 | **如果只有两分钟，我会告诉观众什么？** | 逼你找到最核心的信息 |
| 2 | **我解决了观众的什么问题？** | 让你站在观众视角思考 |
| 3 | **我希望观众看完之后做什么？** | 明确行动号召 |

> 示例：如果你要做一个"如何高效阅读"的分享——
>
> - 只有两分钟 → 我会告诉观众"不要从头读到尾，先看目录和结论"
> - 解决什么问题 → 帮观众解决"读了就忘、读不完"的痛点
> - 希望观众做什么 → 下次读书时先花5分钟看目录和序言

---

## 第二步：理大纲 — 归堆抱团，问题驱动

把你要讲的内容"归堆"：同类信息放一堆，每一堆提炼成一个问题。

**黄金法则**：最多五个问题，超出就合并。

> **示例：吴军老师在公司年会上的开场准备**
>
> 吴军老师用5个问题梳理了他要讲的内容：
>
> 1. 过去一年我们做得怎么样？
> 2. 行业发生了什么变化？
> 3. 我们要往哪个方向走？
> 4. 每个人需要做什么？
> 5. 我对大家的期待是什么？
>
> —— 五个问题就是五块拼图，拼在一起就是完整的演讲，不需要逐字稿。

**操作步骤**：
1. 把所有想说的内容写下来（头脑风暴）
2. 划掉不重要的，合并相似的
3. 剩下的分成 3~5 堆，每堆用一个问题命名
4. 按逻辑顺序排列（时间顺序 / 因果顺序 / 重要性顺序）

---

## 第三步：做手卡 — 四驱手卡结构

拿出一张 A6 大小的卡片（或对折A4纸），分成四个区域：

```
┌──────────────────────────┐
│                           │
│   A区                     │
│   ────────                │
│   · 关键词 / 短语         │
│   · 不写完整句子          │
│   · 一个词唤起一段话      │
│                           │
│   B区                     │  ─── D区：页码
│   ────────                │
│   临上台前想到的           │
│   补充内容 / 新的点子      │
│                           │
│                    ───────│
│                    C区     │
│                    下一张  │
│                    手卡的  │
│                    第一行  │
│                    提示    │
└──────────────────────────┘
```

### 四区说明

| 分区 | 作用 | 写什么 |
|------|------|--------|
| **A区** | 核心内容 | 关键词/短语，每个词能唤起一段话 |
| **B区** | 临场补充 | 上台前突然想到的好点子，写在B区备用 |
| **C区** | 衔接提示 | 下一张手卡的第一行，确保过渡自然 |
| **D区** | 页码 | 卡片顺序号，万一打乱能快速复原 |

**关键原则**：手卡上不要写完整句子，写了你一定会读，读了就变成了"念稿"。

---

## 第四步：三种练习方式

不要只用一种方式练。三种方式交替，效果最好。

### 1️⃣ 正常基础练习
- 像正常演讲一样从头到尾讲一遍
- 看手卡，不看稿
- 全程录音，回听找问题

### 2️⃣ 变速练习（进阶）
- **2倍速讲一遍**：逼嘴巴跟上大脑，发现卡壳点
- **慢速讲一遍**：一个字一个字慢慢说，感受语言的节奏
- 变速之后回到正常速度，你会发现从容很多

### 3️⃣ 默演练习（终极）
- 不出声，在脑子里"过电影"一样把整场演讲过一遍
- 从开场第一句话，到中间每一个故事，再到结尾
- 卡住的地方就是你需要加强的点
- 可以在任何场合做：地铁上、洗澡时、睡前

## 紧急预案：忘词怎么办？

**直接跳到下一部分。**

永远不要站在原地"嗯……啊……"地回忆。听众并不知道你的"下一部分"是什么，直接跳过去。

> "好，刚才我们讲了准备方法，接下来我们看看**练习方式**……"

—— 如果中间少讲了一部分也没关系，大部分听众根本不会发现，而你从容自信的状态比"完整但狼狈"重要一百倍。

## 课堂练习

### 练习一：理大纲
选一个你最近想分享的话题，用 **3~5 个问题** 梳理出大纲：

1. _________________________________

3. _________________________________
4. _________________________________
5. _________________________________

### 练习二：做手卡
按四驱手卡的结构，为你的大纲制作一套手卡（写在真正的卡片上）。确保A区只写关键词，C区写好下一张的衔接提示。

### 练习三：变速练习
用手机录音，按照"正常→2倍速→慢速→正常"的顺序各讲一遍。回听录音，记录下你最卡壳的两个地方，重点突破。
