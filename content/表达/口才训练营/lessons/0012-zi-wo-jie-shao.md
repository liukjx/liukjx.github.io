# 第12课（进阶）：怎么准备一个自我介绍

> 自我介绍不是"说说我是谁"，而是**在最短时间内让对方记住你、信任你、喜欢你**。

---

## 三个故事模板

> 不要念简历，讲故事。这三个模板覆盖了90%的自我介绍场景。

---

### 模板一：我很牛的故事

**结构**：难题 → 解决方案 → 成功结果

```
┌────────────┐     ┌────────────┐     ┌────────────┐
│  难题       │ ──→ │  解决方案   │ ──→ │  成功结果   │
│  (过程)     │     │  (方法)    │     │  (结果)    │
└────────────┘     └────────────┘     └────────────┘
```

#### 核心要点

> **把重点放在"难题有多难"，而不是"结果有多牛"。**

| 常见错误 | 正确做法 |
|---------|---------|
| "我带领团队完成了1000万业绩" | "当时团队只有3个人，竞争对手有50人，预算只有对手的十分之一……" |
| "我考上了清华" | "高三那年我每天只睡5小时，数学从60分提到140分……" |

**为什么？** 结果让人羡慕，但**难题让人共情**。观众只有在感受到难度之后，才会真正认可你的能力。

---

### 模板二：我为什么的故事

**结构**：背景 → 动力 → 坚持 → 结果 → 价值观

```
┌────────┐   ┌────────┐   ┌────────┐   ┌────────┐   ┌────────┐
│ 背景   │─→│ 动力   │─→│ 坚持   │─→│ 结果   │─→│ 价值观 │
│(起点)  │   │(为什么)│   │(过程)  │   │(成果)  │   │(信仰)  │
└────────┘   └────────┘   └────────┘   └────────┘   └────────┘
```

#### 核心要点

- 解释你**为什么**做一件事，比做了什么更能打动人
- 最后一定要**输出价值观**——这是快速建立信任的关键

**示例**：
> 我出生在一个小县城（背景），从小看到父母起早贪黑地工作（动力），所以我拼命读书，考上了大学（坚持）。现在我在做一个教育公益项目（结果），因为我始终相信：教育是打破阶层最好的方式（价值观）。

---

### 模板三：我的改变的故事

**结构**：旧状态 → 触发事件 → 帮助 → 转变 → 新状态

```
┌────────┐   ┌────────┐   ┌────────┐   ┌────────┐   ┌────────┐
│ 旧状态 │─→│ 触发   │─→│ 获得   │─→│ 转变   │─→│ 新状态 │
│(之前)  │   │(事件)  │   │(帮助)  │   │(过程)  │   │(之后)  │
└────────┘   └────────┘   └────────┘   └────────┘   └────────┘
```

#### 核心要点

> **强调内部世界（自己的努力）比外部帮助更重要。**

| 错误叙事 | 正确叙事 |
|---------|---------|
| "多亏了王老师帮助我……" | "王老师给了我方向，但真正让我走出来的是每天凌晨4点的练习……" |

**为什么？** 外部帮助让听众觉得你靠运气，内部努力让听众觉得你靠实力。

## 不同时长的策略

### 2-3分钟：制造矛盾冲突

**策略**：用悬念开头，制造一个"冲突"，吸引观众想知道"然后呢？"

**案例：刘楠给徐小平发短信**
> "徐老师，我是一个北大毕业生，现在在淘宝卖纸尿裤……"
> ——一个北大毕业生和"卖纸尿裤"之间的巨大反差，让徐小平立刻回了电话。

**结构建议**：
| 时间 | 内容 | 作用 |
|------|------|------|
| 0-30秒 | 抛出矛盾/悬念 | 抓注意力 |
| 30-90秒 | 故事主体（模板一/二/三） | 建立信任 |
| 90-120秒 | 价值观输出 + 今天的目的 | 清晰收尾 |

### 1分钟：突出特质

**策略**：只讲1个特质，用1个小故事佐证。

**案例：明仔和二毛子**
> "A面的我是____，B面的我也是____。A和B都是我自己。"

用一个对立统一的结构，用**30秒**就让人记住了"这个人有反差、有层次"。

**结构建议**：
| 时间 | 内容 |
|------|------|
| 前15秒 | 一句话标签（"我是一个____的人"） |
| 中间30秒 | 一个小故事证明这个标签 |
| 最后15秒 | 这个特质让我今天能____ |

### 10秒：说名字

**策略**：没有时间讲故事，那就**把名字说到让人记住**。

**三个技巧**：

| 技巧 | 说明 |
|------|------|
| **大声** | 让最后一排都听得清清楚楚 |
| **张嘴** | 咬字清晰，不要含在嘴里 |
| **慢说** | 每个字之间留半拍空隙 |

> 10秒钟只够做一件事：**让人记住你的名字**。

---

## 介绍名字的技巧

### 谐音梗

用谐音让人快速记住你的名字。

**案例：重新抄**
> "我叫重新抄。对，就是'重新抄一遍'的那个重新抄。"

一秒记住，绝不忘。

### 取名禁忌

| 禁忌 | 说明 | 替代方案 |
|------|------|---------|
| ❌ **生僻典故** | "我叫旻翯，取自《尚书》……" | 用简单的联想，比如"我叫李明，明亮的明" |
| ❌ **负面标签** | "周一的周"（周一让人丧） | "周末的周"（周末让人开心） |
| ❌ **过度自嘲** | "我姓王，隔壁老王的王" | 用中性或正面的联想 |

> 名字是第一张名片——别让观众在记住你之前，先产生了一个负面印象。

---

## 快速选择指南

| 场景 | 推荐模板 | 时长 | 重点 |
|------|---------|------|------|
| 面试/竞聘 | 我很牛（模板一） | 2-3分钟 | 难题的难度 |
| 加入新团队 | 我为什么（模板二） | 1-2分钟 | 价值观 |
| 转型/转行 | 我的改变（模板三） | 2-3分钟 | 内部努力 |
| 社交破冰 | 名字技巧 | 10秒 | 大声/张嘴/慢说 |
| 圆桌介绍 | 突出特质 | 1分钟 | 一个故事 |
