# 术语表

| Term | English | Definition | Source Lesson |
|------|---------|------------|---------------|
| 上山走势 | Upward Arc | 演讲内容的情感或逻辑强度逐渐攀升，在高潮处收尾，给听众以振奋和向上的力量。 | 演讲结构 |
| 下山走势 | Downward Arc | 演讲内容由高潮或紧张开始，逐步松弛、回落，营造余韵或反思效果。 | 演讲结构 |
| 波谷走势 | Valley Arc | 演讲先抑后扬，从低点出发逐渐推向高点，形成反差和爆发力。 | 演讲结构 |
| 波峰走势 | Peak Arc | 演讲先扬后抑，从高点出发逐渐回落至低点，制造落差和深刻印象。 | 演讲结构 |
| 半打哈欠 | Half-Yawn | 一种放松喉部、打开口腔的发声训练方法，模拟打哈欠到一半时的口腔和喉部状态，帮助获得更圆润饱满的音色。 | 声音训练 |
| 轻重变化 | Loud-Soft Variation | 通过控制音量大小来传达不同情感、突出重点的表达技巧。 | 声音训练 |
| 长短变化 | Long-Short Variation | 通过控制音节时值长短来调节语速和节奏，形成抑扬顿挫的表达技巧。 | 声音训练 |
| 停顿 | Pause | 在演讲中有意识地留出静默时间，用于换气、强调、留白或制造悬念。 | 声音训练 |
| 演讲台九宫格 | Nine-Grid Stage | 将演讲台区域划分为九个格子（左前/中前/右前/左中/正中/右中/左后/中后/右后），帮助演讲者规划走位路线。 | 舞台走位 |
| 五二六走位 | 5-2-6 Stage Movement | 一种定点走位法：五个中心位点、两个侧位、六个过渡点位，确保演讲者在台上各区域均匀覆盖。 | 舞台走位 |
| 大三角走位 | Big Triangle Movement | 以演讲台的前左、前右和后中三个顶点构成大三角，演讲者在这三点间移动，兼顾全场听众。 | 舞台走位 |
| 录音回听训练法 | Recording Review Practice | 将自己的演讲录音并回听，以旁观者视角发现问题（口头禅、语速、停顿、逻辑等），是最高效的自我提升方法之一。 | 日常训练 |
| 三点一线法（平行） | Three-Point Parallel | 用三个并列的观点支撑同一主题，观点间为平行关系，无递进或因果。 | 内容组织 |
| 三点一线法（递进） | Three-Point Progressive | 用三个层层深入的观点支撑主题，后一个观点建立在前一个基础之上，逐步推进。 | 内容组织 |
| 三点一线法（归因） | Three-Point Attribution | 围绕一个结论或现象，给出三个原因或归因分析，用因果逻辑支撑观点。 | 内容组织 |
| 三点一线法（对比） | Three-Point Contrast | 通过三组对比（正反、前后、优劣等）来凸显核心观点的说服力。 | 内容组织 |
| 给时空 | Give Time & Space | 在表达中加入具体的时间和空间信息，让抽象内容变得可感知。 | 表达技巧 |
| 给画面 | Give Visual Imagery | 用生动的语言描绘画面，调动听众的视觉想象，增强感染力。 | 表达技巧 |
| 找共鸣 | Find Resonance | 挖掘听众的共同经历、情感或价值观，建立情感连接。 | 表达技巧 |
| 画重点 | Highlight Key Points | 通过重复、强调、停顿等手法让核心信息突出，确保听众记住要点。 | 表达技巧 |
| 增加类比 | Use Analogy | 用听众熟悉的事物比喻陌生概念，降低理解门槛。 | 数据表达 |
| 变换单位 | Change Units | 将大数字换算成更直观的单位（如将秒换算成天、将元换算成碗面），让数据更有感知力。 | 数据表达 |
| 引入对比 | Introduce Comparison | 将数据与听众熟悉的数据进行对比，凸显差异和冲击力。 | 数据表达 |
| 反向换算变单位 | Reverse Unit Conversion | 将抽象概念换算回具体数字（如将效率提升换算成节省的工时/金钱），让听众直观感受价值。 | 数据表达 |
| 最高任务 | Super-Objective | 一场演讲最核心的目标和使命，所有内容组织都围绕这一最高任务展开，不偏离主题。 | 演讲准备 |
| 四驱手卡 | Four-Drive Cue Card | 一种手卡设计方法，将演讲内容提炼为四个驱动要点，每个要点用关键词/短句提示，帮助演讲者脱稿又不遗漏关键信息。 | 演讲准备 |
| 四步走法则 | Four-Step Rule | 一种演讲准备流程：定主题 → 搭框架 → 填内容 → 做演练，确保演讲结构清晰、内容扎实。 | 演讲准备 |
| 对象感 | Sense of Audience | 演讲者心中装着一个清晰具体的听众形象，在表达时仿佛在与这个具体对象对话，而非对着空气讲话。 | 对象感 |
| 手势四大空间（能量区） | Energy Zone | 手势位于胸部以上的区域，用于表达激情、号召、强调等强能量内容。 | 肢体语言 |
| 手势四大空间（舒适区） | Comfort Zone | 手势位于胸腹之间的自然区域，用于日常叙述和平实表达，最自然放松。 | 肢体语言 |
| 手势四大空间（放松区） | Relax Zone | 手势位于腹部以下的区域，用于表达放松、沉思或低能量状态。 | 肢体语言 |
| 手势四大空间（扩展区） | Expansion Zone | 手势向身体两侧展开，用于表达范围、包容、宏大概念或欢迎。 | 肢体语言 |
| 孔雀型 | Peacock Type | 性格特征：热情开朗、乐于表达、喜欢社交，演讲风格偏感性、有感染力。需要关注逻辑结构。 | 性格认知 |
| 老虎型 | Tiger Type | 性格特征：果断直接、目标感强、行动力高，演讲风格偏理性、直奔主题。需要关注情感连接。 | 性格认知 |
| 考拉型 | Koala Type | 性格特征：温和稳重、善于倾听、节奏较慢，演讲风格偏亲和、有耐心。需要关注观点提炼和气势。 | 性格认知 |
| 猫头鹰型 | Owl Type | 性格特征：严谨细致、善于分析、追求准确，演讲风格偏逻辑、数据驱动。需要关注生动性和感染力。 | 性格认知 |
