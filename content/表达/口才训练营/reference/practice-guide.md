# 结营后练习指南

> 口才不是学出来的，是练出来的。结营之后，真正的修炼才刚刚开始。

---

## 一、60秒复述法

训练目标：在60秒内清晰、有条理地复述一个观点。

### 训练步骤

| 步骤 | 操作 | 时间 |
|------|------|------|
| 1. 找素材 | 打开"罗辑思维"公众号，找一篇罗胖60秒语音的文稿 | 2分钟 |
| 2. 拆结构 | 分析这篇60秒的结构：开头怎么切入？中间用了什么逻辑？结尾怎么收？ | 3分钟 |
| 3. 出声读 | 模仿罗胖的语气、停顿、重音，大声朗读3遍 | 3分钟 |
| 4. 复述 | 不看文稿，用自己的话复述核心内容 | 1分钟 |
| 5. 发送 | 用微信给自己或朋友发送一条60秒语音，逼自己在60秒内说完 | 1分钟 |
| 6. 回听 | 听自己的语音，对比原文稿，找差距 | 3分钟 |

**每天练习一个循环，总计约15分钟。**

### 进阶玩法

- 逐渐脱离原文结构，加入自己的案例和观点
- 尝试在不同场合（通勤路上、午休时）做"即兴60秒"

## 二、每日录音回听

训练目标：巩固录音回听训练法，形成自我反馈闭环。

### 操作指南

- **时长**：每天5-10分钟
- **内容**：可以是你今天想分享的一个观点、一段工作汇报、或者对某个事件的评论
- **方法**：
  1. 打开手机录音机
  2. 说一段话（1-3分钟）
  3. 回听并记录问题
  4. 针对问题再说一遍
  5. 对比两版的差异

### 回听关注点清单

每次回听时，重点关注以下维度：

- [ ] 有没有不必要的口头禅？（嗯、啊、然后、那个）
- [ ] 语速是否太快或太慢？
- [ ] 停顿是否用在了对的地方？
- [ ] 逻辑是否清晰？别人能听懂吗？
- [ ] 开头有没有吸引力？
- [ ] 结尾有没有力量？

### 常见问题 & 解决办法

| 问题 | 解决办法 |
|------|----------|
| 口头禅多 | 意识到就是改变的开始，回听时每发现一次就记下来 |
| 语速太快 | 刻意放慢，练习中加入更长、更频繁的停顿 |
| 逻辑混乱 | 先说结论再展开，或者用"第一、第二、第三"来组织 |
| 结尾仓促 | 每次练习刻意留出20秒做结尾，总结+升华+行动号召 |

## 三、语料积累

训练目标：建立自己的语料库，随时调取好词好句。

### 工具推荐

- **Flomo（浮墨笔记）**：最推荐。打标签方便，检索快，支持多端同步
- 其他选择：Notion、印象笔记、备忘录

### 积累什么

| 类别 | 说明 | 示例标签 |
|------|------|----------|
| 好词好句 | 听到或看到的有力量的表达 | `#好句` `#金句` |
| 精彩比喻 | 生动的类比和隐喻 | `#类比` `#比喻` |
| 故事素材 | 可以用来开场的短故事 | `#故事` `#案例` |
| 数据观点 | 可以作为论据的数据和洞察 | `#数据` `#观点` |
| 排比句式 | 有节奏感的排比结构 | `#排比` `#句式` |

### 使用习惯

- **每日随手记**：看到好的表达立刻记下来，不要等"有空整理"
- **标签分类**：每条笔记至少打2个标签（内容类别 + 适用场景）
- **定期回顾**：每周翻看一遍，熟悉自己的语料库
- **刻意使用**：下次练习时，有意识地从语料库中调用一条

## 四、素材积累

训练目标：通过观摩优秀演讲，拆解学习其中的技巧。

### 推荐资源

| 资源 | 特点 | 重点关注 |
|------|------|----------|
| TED演讲 | 全球顶级演讲，18分钟以内 | 结构设计、开场方式、手势运用 |
| 得到高研院开学典礼 | 学员演讲，真实接地气 | 故事讲述、情感连接 |
| 一席演讲 | 中国本土优质演讲 | 知识类表达的清晰度 |
| 奇葩说/脱口秀 | 语言表达类节目 | 段子设计、节奏把控、互动技巧 |

### 拆解方法（每次看完做记录）

1. **结构拆解**：演讲分几个部分？各部分之间如何衔接？
2. **开场分析**：前30秒做了什么？为什么吸引人？
3. **手势观察**：关键位置用了什么手势？属于哪个手势空间？
4. **声音变化**：哪里加重了？哪里放慢了？停顿用了多久？
5. **金句收集**：记下打动你的句子，分析为什么有力

## 五、场景实战

训练目标：在真实场景中磨炼技能，获得真实的反馈。

### 主动寻找机会

- **工作中**：
  - 主动争取会议发言、工作汇报的机会
  - 在团队分享中做主讲人
  - 主持部门会议或团建活动

- **生活中**：
  - 在朋友聚会中主动分享一个观点
  - 参加读书会、演讲俱乐部（如头马Toastmasters）
  - 在社群中做线上分享

- **线上**：
  - 录制短视频发到社交平台
  - 在微信群做60秒语音分享
  - 开直播（哪怕是只有几个朋友看）

### 实战后复盘

每次讲完后，做一次系统复盘：

- [ ] 回看录像（如有）或回听录音
- [ ] 记下3个做得好的地方
- [ ] 记下3个需要改进的地方
- [ ] 下次实战前，重点改进其中1个问题

## 六、口头禅日常训练

训练目标：从根本上减少口头禅，让表达更干净流畅。

### 训练方法

每天朗读"干净语料"——即本身没有口头禅、表达精炼的高质量文本。

### 推荐语料

| 语料 | 理由 |
|------|------|
| 新闻联播（文稿） | 语言精炼、零口头禅、逻辑清晰 |
| 得到头条（文稿） | 口语化但干净，结构清晰 |
| 人民日报评论 | 用词精准，表达有力 |
| 罗胖60秒（文稿） | 60秒一个观点，精炼到极致 |

### 朗读方法

1. **每天10分钟**，找一个安静的地方
2. **出声朗读**，不是默读
3. **模仿语速和停顿**，不要一味求快
4. **录下来回听**，检查自己有没有添加多余的字

### 进阶技巧

- 读一段后，不看文稿用自己的话说一遍——如果还能保持干净，说明口头禅在真正减少
- 请朋友或家人听你的朗读，让他们帮你抓口头禅

## 七、关键词

> **坚持 + 刻意练习 + 回看反馈 = 确定的进步**

| 关键词 | 含义 | 如何做 |
|--------|------|--------|
| 坚持 | 不追求一次练很多，追求每天都练 | 每天15分钟，雷打不动 |
| 刻意练习 | 不是简单重复，而是带着目标去练 | 每次聚焦一个改进点 |
| 回看反馈 | 没有反馈的练习是低效的 | 录音、录像、请人点评 |

### 30天练习计划建议

| 周次 | 重点 | 每日练习内容 |
|------|------|-------------|
| 第1周 | 录音回听 + 口头禅清理 | 5分钟朗读 + 5分钟录音回听 |
| 第2周 | 60秒复述法 | 15分钟60秒复述循环 |
| 第3周 | 声音变化练习 | 10分钟朗读（刻意轻重_长短_停顿）+ 5分钟回听 |
| 第4周 | 综合实战 | 找一次真实发言机会 + 录下来复盘 |
