# 表达框架速查表

## 一、核心框架速查

### 有效表达五要素（原课）
```
现状 → 感受 → 原因 → 需求 → 后果
```

### NVC四要素（补充）
```
观察 → 感受 → 需要 → 请求
```

二者对应关系：
- 现状 ≈ 观察（客观描述事实）
- 感受 = 感受（情绪状态）
- 原因 → 需要（个人原因 → 人类共通需要）
- 需求 ≈ 请求（具体行动）
- 后果 → 省略（NVC省略威胁性后果）

## 二、训练方法速查

### 日常聊天

| 场景 | 方法 | 公式 |
|------|------|------|
| 开场 | 状态+感受 | "我正在……，感觉……" |
| 延续话题 | 制造挑战 | 陈述事实 + 适度陌生化信息 |
| 讲述经历 | 两段式 | "那是一个____，我记得当时____" |
| 生动表达 | 快照联想 | 三个画面 ×（看到→感到→想到） |
| 情绪传递 | 画面细节法 | 描述具体场景而非抽象标签 |

### 职场沟通

| 场景 | 方法 | 公式 |
|------|------|------|
| 汇报 | 结论先行 | 结论→理由1→理由2→理由3→建议 |
| 说服 | RIDE | Risk→Interest→Difference→Effect |
| 即兴发言 | 感谢-感受-愿景 | 感谢具体的人→真实感受→未来期望 |
| 被提问 | 3秒急救 | 复述确认→给观点→举例子 |

### 公众演讲

| 场景 | 方法 | 公式 |
|------|------|------|
| 备稿演讲 | 三段式 | 开场→主体（3论点）→结尾 |
| 即兴演讲 | PREP | Point→Reason→Example→Point |
| 自我介绍 | SCQA | 情境→冲突→问题→答案 |

### 冲突沟通

| 场景 | 方法 | 公式 |
|------|------|------|
| 表达不满 | NVC | 观察→感受→需要→请求 |
| 倾听对方 | 共情反馈 | 事实+情绪+需求 = 三层倾听 |
| 回应倾诉 | 反馈层级 | 层级4-5（共情/共情+探索），避免层级2-3 |

## 三、常见错误修正

| 错误类型 | 错误示范 | 正确做法 |
|----------|----------|----------|
| 评价对方 | "你总是迟到" | "这周你有三天9:15后到"（描述事实） |
| 论证感受 | "至于吗？有什么好生气的？" | "这件事让你很生气对吗？"（承认感受） |
| 提供方案 | "你应该跟老板沟通" | "听起来压力很大，持续多久了？"（先共情） |
| 抽象表达 | "今天心情很复杂" | "今天下班看到夕阳，突然想起大学时……"（画面细节） |
| 太长不看(线上) | 一大段文字 | 分段发送，留互动空间 |

## 四、心态口诀

- ❌ "我说得不够好" → ✅ "我的表达是为了获取反馈"
- ❌ "我必须克服紧张" → ✅ "我可以带着紧张表达"
- ❌ "对方没回=我聊得差" → ✅ "对方没回可能有多种原因"
- ❌ "我得想好再说" → ✅ "先开口，再调整"
- ❌ "沉默很尴尬" → ✅ "沉默是沟通的自然组成部分"
