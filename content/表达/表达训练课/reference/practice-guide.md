# 练习指南

## 使用说明

本指南将课程中的练习按**技能层次**和**训练阶段**重新组织，方便你根据自己的水平选择合适的练习。每个练习标注了难度（★）、所需时间、以及对应的课程来源。

---

## 一、基础练习（第1-2周）

> 目标：建立表达的基本意识和习惯

### 1.1 每日状态打卡（★☆☆ / 5min / 每日）

每天选三个时刻，出声说出"状态+感受"：

> "我刚吃完午饭，现在坐在工位上，感觉有点困。"
> "我现在在公交车上，人很多，有点挤。"

**要点**：不要评价自己的表达好不好，只要说出来就算完成。

### 1.2 观察vs评判分辨（★☆☆ / 5min / 每日）

在日常对话中，识别并记录两个例子：
- 一句"评判"（如"你太粗心了"）
- 一句"观察"（如"这个报告有三处错误"）

**来源**：[[lessons/0004-biao-da-xun-lian-chang-jian-wu-qu|第04课：表达训练常见误区]]

### 1.3 录音复盘（★★☆ / 10min / 每日）

录一段2分钟的自述（主题不限）。回听时问自己：
1. 我以为说清楚的地方，回听时是否真的清楚？
2. 有没有跳过的关键信息？
3. 语速和停顿是否自然？

**要点**：这是进步最快的练习方法。大多数人第一次回听会被自己吓到——正常现象。

## 二、进阶练习（第3-4周）

> 目标：掌握核心表达框架

### 2.1 五要素拆解（★★☆ / 15min / 每日）

选一个真实的沟通场景（工作上、和朋友聊天、和伴侣的对话），用五要素拆解：

| 要素 | 你实际上说的 | 应该说的 |
|------|-------------|---------|
| 现状 | | |
| 感受 | | |
| 原因 | | |
| 需求 | | |
| 后果 | | |

**来源**：[[lessons/0005-you-xiao-biao-da-wu-yao-su|第05课：有效表达五要素]]

### 2.2 画面细节改写（★★☆ / 10min / 每日）

把一句"抽象表达"改写成"画面细节"：

- ❌ "今天心情很复杂。"
- ✅ "今天下班时天已经黑了，地铁站人不多。我突然想起大学时也是这样从图书馆回宿舍。那个时候觉得日子很长，现在觉得日子很快。"

**来源**：[[lessons/0006-miao-shu-xi-jie-biao-da-qing-xu|第06课：描述细节表达情绪]]

### 2.3 NVC改写练习（★★★ / 15min / 每日）

找一句你最近说过的或听到的"容易引发冲突"的话，改写成NVC版本：

原始：____
- 观察（不评判）：____
- 感受（不指责）：____
- 需要（共通价值）：____
- 请求（具体行动）：____

**来源**：[[lessons/s06-fei-bao-li-gou-tong|补充课06：非暴力沟通实践]]

## 三、高级练习（第5-6周）

> 目标：提升表达的生动性和逻辑性

### 3.1 三角模型训练（★★★ / 15min / 每日）

选一个日常事物（如"今天看到一棵树"），用三角模型展开：

```
我是如何注意到它的 → 它是什么样的 → 它让我想到了什么
```

出声说3分钟，录音回听。

**来源**：[[lessons/0007-luo-ji-yu-tiao-li-xun-lian|第07课：逻辑与条理训练]]

### 3.2 快照联想法（★★★ / 15min / 隔日）

回忆一件最近印象深刻的事，提取"三张照片"（三个关键画面），每张照片用"看到→感到→想到"三层结构描述。

**来源**：[[lessons/0009-you-mo-yu-sheng-dong-biao-da|第09课：幽默与生动表达]]

### 3.3 PREP即兴训练（★★★ / 5min / 每日）

随机选一个话题（可用翻牌App或预设话题卡），用PREP框架说1-3分钟：

- **P**（观点）：一句话
- **R**（理由）：1-2句话
- **E**（例子）：具体例子
- **P**（重申）：观点+行动

---

## 四、场景化练习（第7-8周）

> 目标：在真实场景中综合运用

### 4.1 职场汇报模拟（选择场景）

选一个工作中的场景，用"结论先行"结构准备：

| 项目 | 内容 |
|------|------|
| 结论 | 一句话结论 |
| 理由1 + 数据 | |
| 理由2 + 数据 | |
| 建议 | |

出声练习3遍。如果可以，找同事试讲并收集反馈。

**来源**：[[lessons/s02-zhi-chang-gou-tong|补充课02：职场沟通专项训练]]

### 4.2 社交破冰实战（★★★ / 不限时）

在社交场合主动使用"状态+感受"开场，并准备1-2个"制造挑战"话题。

**实战后复盘**：
- 开场时对方的反应？
- 冷场时你是怎么处理的？
- 有没有做到"描述事实"而非"评价对方"？

**来源**：[[lessons/0003-po-bing-yu-liu-chang-biao-da|第03课：破冰与流畅表达]]

### 4.3 冲突沟通复盘（★★★ / 20min）

回忆一次沟通不顺利的经历，分三步复盘：
1. **客观事实**：当时发生了什么（不添加任何评价）？
2. **真实感受**：你当时的情绪是什么（不是想法，是情绪）？
3. **另一种可能**：如果用了NVC或五要素，怎么说更好？

## 五、自我评估对照表

| 技能维度 | 入门 | 进阶 | 熟练 |
|----------|------|------|------|
| 心理突破 | 敢开口 | 不怕被拒绝 | 享受表达过程 |
| 清晰度 | 对方听懂大意 | 对方能复述重点 | 对方能记住要点 |
| 生动度 | 能举例子 | 能用画面描述 | 能调动对方情绪 |
| 逻辑性 | 有观点 | 观点+理由 | 观点+理由+论据+总结 |
| 共情力 | 不打断对方 | 能复述对方感受 | 能听出潜台词 |
| 应变力 | 不冷场 | 能接住话题 | 能引导对话方向 |

> [!TIP] 练习原则
> 1. **少量高频**：每天10分钟 > 每周2小时
> 2. **录音回听**：这是最快发现问题的办法
> 3. **真实场景优先**：模拟练习是准备，真实对话才是实战
> 4. **允许不完美**：先完成，再完善
