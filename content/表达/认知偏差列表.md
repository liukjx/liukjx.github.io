认知偏差，是在判断中偏离规范和/或理性的系统模式。该主题经常在心理学、社会学和行为经济学中被进行研究。

尽管大多该些偏见的现实已被可重复的研究证实，关于如何对这些偏见进行分类或如何解释它们经常存在争议。一些认知偏差的几个理论原因是已知的，这些偏差通过其共同的生成机制（例如嘈杂的信息处理）提供了对偏差的分类。Gerd Gigerenzer 曾批评将认知偏见视为判断错误，并倾向于将其解释为与逻辑思维的理性偏差。

解释包括信息处理规则（或称心理捷径），称为启发式，大脑用来产生决定或判断。偏见有多种形式，表现为认知（"冷"）偏见，例如心理噪音，或动机（"热"）偏见，例如当信念被一厢情愿扭曲时。两种效果可以同时存在。

关于这些偏见中的一些是否被视为无用或非理性，或者它们是否会导致有用的态度或行为，也存在争议。例如，在结识他人时，人们倾向于提出引导性问题，这些问题似乎偏向于确认他们对这个人的假设。然而，这种确认偏差也被认为是社交技巧的一个例子，一种与他人建立联系的方式。

尽管这项研究绝大多数涉及人类受试者，但在非人类动物中也发现了一些表明存在偏见的发现。例如，猴子已经表现出厌恶损失，而在老鼠、鸽子和猴子中已经观察到双曲折现等现象。

## 决策、信念与行为偏差

这些偏差多半会影响信念的形成、商业与经济决策、以及其他一般的人类行为。它们是可复制与再现的，面临特定情境时，一般可预期人们会有相应的偏差倾向。

| 名称 | 原文 | 描述 | 例子 |
|------|------|------|------|
| **不明确性效应 / 厌恶不明确** | Ambiguity effect | 决策时倾向避开资讯不足的选项。 | 两只股票可选，一只是熟知的，另一只资料不全，倾向选熟知的那只，即使陌生股票可能收益更高。 |
| **锚定效应** | Anchoring effect; Focalism | 为不熟悉事物估值时，会把熟悉的类似事物或不久前接触到的无关数值当做"锚"，估出来的数值会大大倾向"锚"。 | 先问"你觉得这件衣服值2000吗？"再让给价，人们会以2000为锚出价，远高于从零开始出的价。 |
| **人类中心思维** | Anthropocentric thinking | 以人类当作类比来推测其他不熟悉的生物现象（拟人化）。或是反过来认为人所具有的特征是其他动物都没有的。 | 孩子认为"蜜蜂采蜜是因为它们喜欢甜食"——把人类动机投射到昆虫身上。 |
| **注意力偏差** | Attentional bias | 平时常想的事（注意力集中的事情），会影响我们的感知。 | 刚买了辆红色汽车，就觉得满大街都是红色汽车。 |
| **自动化的偏见** | Automation bias | 倾向于过度依赖自动化系统，可能导致错误的自动化信息覆盖正确的决策。 | GPS导航让右转，但路标明明显示禁止右转，司机仍听GPS的。 |
| **可得性捷思法** | Availability heuristic | 容易想到的事，其发生概率会受高估，然而一件事是否容易想到还受发生多久、激起情绪的程度等因素影响。 | 空难新闻铺天盖地，人们高估飞机失事的概率，实际上开车去机场的风险大得多。 |
| **可获性层叠** | Availability cascade | 一件事越常被公开谈论，就越加相信其真确性（类似"三人成虎"）。 | 一个关于"疫苗导致自闭症"的说法不断被媒体报道后，尽管被科学界否认，仍有很多人相信。 |
| **逆火效应** | Backfire effect | 遇上与自身信念抵触的观点或证据时，除非它们足以完全摧毁原信念，否则会忽略或反驳它们，原信念反而更加强化。 | 给反疫苗者看疫苗安全数据，他们不但不信，反而找来更多理由坚信疫苗有害。 |
| **从众效应** | Bandwagon effect | 倾向做很多人做的事或相信很多人相信的事。 | "身边的人都在买这个牌子的手机，那我也买一个。" |
| **信念偏差** | Belief bias | 由于相信结论，而认为推理出该结论的过程是有道理、合逻辑的。 | "人都会死，狗会死，所以狗是人"——结论荒谬，但因"人都会死"为真，有人觉得推理没问题。 |
| **偏见盲点** | Bias blind spot | 认为自己比其他人更能辨识认知偏差，也较不易受影响。 | "其他人都有偏见，但我没有，我是客观理性的。" |
| **啦啦队效应** | Cheerleader effect | 处在优秀的团体会比单独看起来更优秀。 | 一个长相普通的人站在一群帅哥美女中，看起来比单独一人时更吸引人。 |
| **支持选择偏差** | Choice-supportive bias | 对自己先前选择的评价会比实际上更好。 | 买了A牌手机后，不断说服自己A牌比当初没选的B牌好得多，即使两者性能相当。 |
| **集群错觉** | Clustering illusion | 过度期待从小样本或小型测试中发现的规律。 | 抛硬币连续5次正面，就觉得"硬币有问题"，实际上完全随机也可能出现这种序列。 |
| **舒适区效应** | Comfort zone effect | 对于过去常用的方案，高估效益或成功机会；对于过去少用的方案，低估效益或成功机会。 | 程序员总是用熟悉的语言写新项目，即使新语言更适合，也觉得用旧语言"效率更高"。 |
| **确认偏误** | Confirmation bias | 关注、寻找、诠释、记忆资讯的方向多半是能确认自己成见的方向。 | 认为"左撇子更有创造力"的人，会特别留意左撇子艺术家的例子，忽略右撇子艺术家。 |
| **相合性偏差** | Congruence bias | 直接检验假设，却没想到要检验其他可能的假设。 | 怀疑某人撒谎，就只问他能证明撒谎的问题，而不考虑他可能说真话的证据。 |
| **保守倾向 / 退缩偏差** | Conservatism; Regressive bias | 倾向保守中庸，低估高价值高概率的事而高估低价值低概率的事。 | 觉得考90分的人"其实没那么厉害"（低估），考60分的人"没那么差"（高估）。 |
| **保守倾向（贝叶斯）** | Conservatism (Bayesian) | 新证据出现时，对既有信念的修正幅度不足。 | 即使气象局更新预报说降雨概率从20%升到80%，仍坚持"应该不会下雨"而不带伞。 |
| **对比效应** | Contrast effect | 感受特质的程度主要是受与其他相关事物的对比程度影响，而非受其实际程度影响。 | 先看一个很贵的房子，再看一个普通价格的房子，会觉得普通房子很便宜——即使它本身并不便宜。 |
| **知识的诅咒** | Curse of knowledge | 懂得多的人非常难以从懂得少的人的角度思考问题。 | 资深程序员觉得"安装Python只需要三步，很简单的"，完全忘了初学者连终端是什么都不知道。 |
| **诱饵效应** | Decoy effect | 评估对A与B事物的偏好时，如有个C与B相近却略逊一筹，就会觉得B事物更好。 | 小杯咖啡25元，大杯35元，超大杯36元——很多人会选超大杯，因为和35元的大杯比"只贵1元却大很多"。 |
| **默认效应** | Default effect | 当在几个选项中进行选择时，倾向于选择默认选项。 | 器官捐献同意率：默认"同意"的国家高达90%+，默认"不同意"的国家只有约15%。 |
| **既视感** | Déjà vu | 对某些事物有强烈的熟悉感，似乎曾经接触过，且能预先想到接下来会发生什么事。 | 第一次去某个地方却觉得"我来过这里，接下来应该会看到那个拐角"。 |
| **面额效应** | Denomination effect | 即使金钱总额相同，带小面额（如多量硬币）比带着大面额（如少量纸钞）更容易消费掉。 | 人们更不愿意破开100元大钞，但一堆10元零钱花起来毫不心疼。 |
| **差异偏差** | Distinction bias | 相较于分开比较，两件事物放在一起比较，差异会显得更大。 | 单独看两台电视都觉得画质不错，放在一起才发现A的色彩明显偏黄。 |
| **过程时间忽视** | Duration neglect | 评价不愉快及痛苦的经验时，其持续时间影响不大。 | 一场2小时的牙科治疗和4小时的，事后回忆的痛苦程度差不多——主要取决于最痛的时刻和结束时的感受。 |
| **移情隔阂** | Empathy gap | 情感冷淡时，低估他人情感的强烈程度；情感强烈时，高估他人情感的强烈程度。 | 不饿的时候认为"减肥有什么难的，少吃点就行"，饿的时候完全控制不住自己。 |
| **原赋效应 / 禀赋效应** | Endowment effect | 拥有或即将拥有某物品或资产时，对其价值的评估会比没有时高出许多。 | 自己花了50元买的杯子，别人出100元都不舍得卖，但如果没有拥有它，50元都不想出。 |
| **本质主义** | Essentialism | 认为人与事物有一些不可或缺的本质，并据此分类。 | "男人就是理性的，女人就是感性的"——无视个体差异，用本质标签分类。 |
| **极端预期** | Exaggerated expectation | 实际上的情况通常不如我们所预期的极端。 | 考试前觉得"完蛋了，肯定不及格"，结果成绩出来70分。 |
| **功能固着** | Functional fixedness | 受物品的一般用途局限，无法想到用特别的方式利用物品。 | 需要用螺丝刀时找不到，想不到可以用硬币代替。 |
| **聚焦效应** | Focusing effect | 过分关注事情的某些明显面向、忽略不明显面向，导致不恰当的预期。 | 只看薪资选工作，忽略了通勤时间、同事关系、工作压力等其他重要因素。 |
| **佛瑞效应 / 巴纳姆效应** | Forer effect; Barnum effect | 人们会把他们认为是为自己量身定做的人格描述评价为高度准确，而这些描述往往十分模糊及普遍。 | "你有时外向有时内向，需要他人认可但又对自己苛刻"——几乎所有星座性格描述都是这种模式。 |
| **框架效应** | Framing effect | 同一资讯以不同方式呈现会带来不同想法。 | "手术存活率90%"比"手术死亡率10%"更让人愿意接受手术，虽然信息完全相同。 |
| **频率错觉** | Frequency illusion | 因最近注意到一件原先没注意到的事，就觉得这件事到处都在发生。 | 刚学会一个新词，接下来几天好像到处都看到这个词。 |
| **难易效应** | Hard-easy effect | 高估自认困难之事的难度，低估自认简单之事的难度。 | 觉得自己肯定做不出这道难题（实际做出来了），觉得简单的题肯定没错（实际错了）。 |
| **后见之明偏误** | Hindsight bias | 在事情发生或发展后，以为自己事前就能预测其发生与发展。 | 公司倒闭后说"我早就知道会这样"，但事前他明明投了赞成票。 |
| **敌对媒体效应** | Hostile media effect | 对于立场与自己不同的媒体，总认为它们有偏见、不客观。 | 保守派认为CNN偏自由派，自由派认为CNN偏保守派——同一家媒体被两边都骂。 |
| **当下偏差 / 现时偏差 / 双曲折现** | Present bias; Hyperbolic discounting | 看重当下利益、低估长远利益。 | "今天吃炸鸡还是健身？算了明天再健身吧。"——日复一日，明天永远不来。 |
| **可辨识受害者效应** | Identifiable victim effect | 对于少数而容易辨识的受害者反应过大，而对多数而不易辨识的受害者反应过小。 | 一个落井的小孩能引发全国捐款，但每年因空气污染死亡的数百万人却引不起同等关注。 |
| **宜家效应** | IKEA effect | 对于需要自行组装的东西给予不成比例的高评价。 | 自己组装的宜家书桌，虽然摇摇晃晃，但觉得它比商场里贵三倍的书桌还好。 |
| **控制的错觉** | Illusion of control | 高估自己对外在事件的影响力，认为事情是受自己控制或影响，但实际上可能与自己毫无关系。 | 买彩票时自己选号比随机选号感觉"中奖概率更高"。 |
| **效度的错觉** | Illusion of validity | 高估面谈或直接观察的效度且能用于提供预测。 | 面试官自信"我聊10分钟就能看出这个人行不行"，但研究表明结构化面试和测试更准确。 |
| **错觉相关** | Illusory correlation | 认为两件事应该有关系时，便会在检视经验与数据时觉得它们经常一起发生。 | 认为"满月时人会变得奇怪"，于是特别留意满月期间的异常行为，并觉得确实如此。 |
| **影响力偏差** | Impact bias | 高估感觉的强度或持续时间。 | 觉得"如果考不上大学天都要塌了"，实际上落榜几个月后人们通常就适应了。 |
| **资讯偏差** | Information bias | 倾向寻求更多资讯以做出决策，即使寻求的资讯对决策没有帮助。 | 做手术前要求做几十项检查，但多出来的检查结果不影响手术方案，只是让自己"安心"。 |
| **沉没成本谬误 / 不理性增值** | Sunk cost fallacy; Irrational escalation | 由于先前已在某事上投资很多，即使新证据显示那是不好的选择，仍倾向于加重投资。 | 等公交等了30分钟，明知可能已经停运了，但"都等了这么久"，继续等下去。 |
| **妄下结论** | Jumping to conclusions | 根据少许的资讯即做出判断与决策。 | 同事今天没打招呼，就断定"他肯定在生我的气"，实际上他只是没戴眼镜没看清。 |
| **公正世界理论** | Just-world hypothesis | 相信世界是公平的，发生在身上的都是应得的。 | "她被抢劫是因为她走夜路，自己不注意安全"——把受害归咎于受害者来维持"世界是公平的"信念。 |
| **少即是好的效应** | Less-is-better effect | 分开评估时倾向选择较小组的东西，一起评估时倾向选择较大组的东西。 | 单独看：觉得7件套的餐具缺了2件不好，宁愿要完整的5件套。一起看：又觉得7件套比5件套好。 |
| **损失趋避** | Loss aversion | 认为放弃一件事物的效益损失大于得到一件事物的效益所得。 | 捡到100元的快乐，抵不上丢了100元的痛苦。 |
| **多看效应 / 单纯接触效应** | Mere exposure effect | 对熟悉的人与事产生过多的好感。 | 一首歌最开始觉得一般，听多了反而觉得越来越好听。 |
| **货币错觉** | Money illusion | 专注于货币名目上的价值，而非其实质购买力。 | 工资涨了5%开心不已，却没注意到通胀率已经有8%，实际购买力下降了。 |
| **道德许可证效应** | Moral credential effect | 因得到某些高道德评价，反而在其他面向做了相反的事。 | 投身环保活动并受到表扬的人，往往忽略了许多自己的不环保行为——"我都这么环保了，偶尔浪费一下没关系"。 |
| **正面效应与负面效应** | Positivity effect; Negativity effect | 评价喜欢的人时，把好事归因于内在本质，坏事归因于环境；评价不喜欢的人时则相反。 | 喜欢的明星肇事逃逸→"他当时肯定有急事"；不喜欢的明星做同样的事→"这人就是没素质"。 |
| **负面偏差** | Negativity bias | 容易回想消极的回忆而不易回想积极的。 | 收到99条好评和1条差评，耿耿于怀的是那条差评。 |
| **忽略可能性** | Neglect of probability | 对于不确定的事，无法准确评估其发生几率，不是完全无视，便是过分高估。 | 买彩票中头奖的概率是1750万分之一，但很多人觉得自己"有可能中"。 |
| **正常化偏差** | Normalcy bias | 根据过去的经验了解情况，低估大灾难的可能性及其影响力。 | 台风预警已经发了，但因过去几次台风都没事，这次也不当回事。 |
| **不作为偏差** | Omission bias | 认为主动作为导致伤害比被动不作为导致伤害更糟糕。 | 医生不给病人用有风险但可能救命的药，宁愿病人"自然死亡"——不作为的责任感比作为轻。 |
| **乐观偏误** | Optimism bias | 低估负面事件发生在自己身上的可能性。 | 80%的人认为自己开车技术"高于平均水平"——在统计上不可能。 |
| **鸵鸟效应** | Ostrich effect | 忽视明显的（负面）情况。 | 信用卡账单快到期了，但选择不看，假装不存在的债务就不会爆炸。 |
| **结果偏差** | Outcome bias | 评价决策好坏时，根据其最终结果，而不是根据下决策当时的决策品质。 | 冒险一搏成功了就被赞"有远见"，失败了就被批"鲁莽"——决策过程完全相同。 |
| **过度自信效应** | Overconfidence effect | 过度相信自己回答、决策、判断的正确性。 | 人们自认为"100%确定"的答案，实际正确率只有80%。 |
| **空想性错视** | Pareidolia | 从模糊、随机的影像中看出有意义的东西。 | 从云朵中看出脸孔，或在烤焦的面包片上看到耶稣像。 |
| **悲观偏误** | Pessimism bias | 高估负面事件发生在自己身上的可能性。 | "我肯定考不过""面试肯定没戏"——实际结果往往没那么糟。 |
| **规划谬误** | Planning fallacy | 低估完成一件事需要的时间。 | "这个项目两周就能搞定"——实际上花了两个月。 |
| **正面结果偏差 / 情价效应** | Positive outcome bias; Valence effect | 认为好事比坏事更可能发生。 | 抽奖时觉得"说不定这次就中了"，但事实上中奖率远低于不中。 |
| **购后合理化** | Post-purchase rationalization | 购买后把之前的购买决定合理化。 | 买了一件昂贵但不太合身的衣服，告诉自己"这件衣服的设计就是这种宽松风格"。 |
| **支持创新偏差** | Pro-innovation bias | 对新技术过度乐观、高估其实用性，忽视其限制及弱点。 | "AI会彻底改变教育"——但实际应用中AI仍然有许多问题，如幻觉、偏见等。 |
| **假确定性效应** | Pseudocertainty effect | 预期结果是正面就选择避开风险，预期结果是负面就选择寻求风险。 | 先给一笔"奖金"，再让人赌一把，人们倾向于保本；先给一笔"损失"，再让人赌一把，人们倾向于冒险。 |
| **对抗心理 / 抗拒心理** | Reactance | 他人要求做或不做某事时，有做相反事的冲动。 | "不要按那个红色按钮"——结果人偏要去按。 |
| **反动贬低** | Reactive devaluation | 贬低敌对者的要求或方案。 | 对方提议"各退一步"，本来合理，但因为是对手提的，就觉得"肯定有诈"。 |
| **新词错觉** | Recency illusion | 感觉某些字词或语句是新发明的，然而它实际上历史悠久。 | 觉得"they作单数用"是政治正确的新发明，其实莎士比亚就这样用过。 |
| **自制偏差** | Restraint bias | 高估自己对诱惑的自制力。 | 觉得自己"肯定能只吃一块饼干"，结果打开包装就全吃完了。 |
| **韵律当理由效应** | Rhyme as reason effect | 认为有韵律的语句比较有道理。 | "三思而后行"听起来比"想清楚再做"更有道理——押韵让人更信服。 |
| **风险代偿 / 佩兹曼效应** | Risk compensation; Peltzman effect | 感觉情况安全时，会倾向冒更大的风险。 | 戴了头盔骑车后骑得更快了——安全装备反而鼓励冒险行为。 |
| **选择性注意 / 选择性知觉** | Selective attention; Selective perception | 由于对人或事有特定期待，因而倾向于注意符合期待的事件。 | 觉得某个学生"聪明"，就只注意到他答对的时候，答错时则觉得"只是粗心"。 |
| **塞麦尔维斯反射** | Semmelweis reflex | 条件反射般地否定、拒绝新证据或新知识，因其抵触现有的常规、信仰或价值观。 | 医生拒绝接受"洗手能降低产妇死亡率"（塞麦尔维斯的发现），因为这挑战了当时的医学常规。 |
| **社会比较偏差** | Social comparison bias | 抗拒雇用、提拔与自己有相似专长的人。 | 自己是唱歌的，面试另一个歌手时会下意识地挑剔，因为担心被比下去。 |
| **安于现状偏差** | Status quo bias | 倾向于维持现状。 | 更便宜的宽带套餐就在那里，但大多数人懒得换，即使换一下只需10分钟。 |
| **刻板印象** | Stereotyping | 根据事物的所属类别或群体判断其特质，而忽略其独特性。 | "程序员都穿格子衫、不善社交"——用群体标签替代个体认知。 |
| **斯德哥尔摩症候群** | Stockholm syndrome | 被害者认同加害者的某些观点和想法，并觉得自己不再受到威胁。 | 人质在绑架过程中开始理解、同情绑匪，甚至为绑匪辩护。 |
| **分开加总效应** | Subadditivity effect | 评估可能性时，对整体直接评估低于对各部分分别评估再加总。 | 问"明天会下雨的概率"，答30%；但分别问"明早下雨概率"+"明午下雨概率"+"明晚下雨概率"，加起来远超30%。 |
| **主观验证 / 主观确认** | Subjective validation | 相信某事是对的，就感觉它是对的。也会把巧合的事当做有关联。 | 相信"13号星期五不吉利"，于是在那天发生的小意外都被当作"果然不吉利"的证据。 |
| **幸存者偏差** | Survivorship bias | 专注于从某个过程中存活下来的人或事，却忽略了最大的弱点可能在未存活的人或事之中。 | 采访成功企业家总结"成功经验"，但失败了的企业家可能做了同样的事——无法从幸存者中看到全貌。 |
| **省时偏差** | Time-saving bias | 低速行进时，低估可节省的时间或高估会损失的时间；高速行进时则相反。 | 从20km/h加速到30km/h觉得"没快多少"，从100km/h加速到110km/h觉得"快了很多"。 |
| **单位偏误** | Unit bias | 认为计量单位反映合理程度。 | 一瓶500ml的饮料就想喝完，即使已经饱了——因为"一瓶就是一份"。 |
| **熟悉路线效应** | Well travelled road effect | 低估采用熟悉路线的时间，高估采用陌生路线的时间。 | 常走的路觉得"一会儿就到了"，走新路总觉得"怎么还没到"，实际上时间差不多。 |
| **只看整体效应** | Whole only effect | 选项为整套方案时，忽略个别部分有协商的可能。 | 订阅套餐包含ABC三个功能，觉得太贵，但没想过是否可以只要A和B。 |
| **零风险偏误** | Zero-risk bias | 偏好把小风险降为零，胜过把大风险降低更多。 | 花100万消除某项技术的1%风险（降到0%），而不愿花50万把10%的风险降到2%。 |
| **零和捷思** | Zero-sum heuristic | 直觉判定一个情况是零和的，但实情未必如此。 | "别人赚了就是我亏了"——实际上贸易对双方都有利，不是零和。 |
| **唤醒的错误归因（吊桥效应）** | Misattribution of arousal | 当产生莫名的生理反应或认知矛盾时，人们可能会以不相干的理由来合理化之。 | 走在吊桥上心跳加速（因为恐惧），却误以为是因为同行的异性有吸引力。 |

## 社会偏差

这些偏差大多是由归因偏差导致。

| 名称 | 原文 | 描述 | 例子 |
|------|------|------|------|
| **行为者-观察者偏差** | Actor-observer bias | 解释他人行为归因于内在个性，解释自己行为则归因于环境影响。 | "他迟到了是因为不守时"；但自己迟到是"因为堵车"。 |
| **防卫性归因** | Defensive attribution hypothesis | 把自己的成功归结于内在因素，把自己的失败归结于外在因素。 | 考了好成绩是因为"我聪明努力"，考差了是因为"老师出题太难"。 |
| **达克效应** | Dunning–Kruger effect | 能力过差的人由于无法分辨能力好与能力差的区别，因而认为大家都一样。 | 刚学了两天吉他就觉得自己可以上台表演了——不知道自己不知道。 |
| **自我中心偏差** | Egocentric bias | 过于依赖自己的观点和对自己的评价过高而不合实际情况。 | 小组作业中每个人都觉得自己贡献了超过50%。 |
| **外在激励偏差** | Extrinsic incentives bias | 认为他人需要外在激励才会做好，而自己可以靠内在激励做好。 | "我需要加薪才能更努力"——但"你需要加薪才能更努力是因为你不够热爱工作"。 |
| **错误共识效应** | False consensus effect | 高估别人对自己的认同程度，认为所有人以同一方式思考。 | "大家都支持这个方案啊"——实际上有一半人反对，只是没说出来。 |
| **基本归因错误** | Fundamental attribution error | 解释他人行为时，归因于内在特质，而非外在情境。 | 路怒时骂前面的司机"笨蛋，会不会开车"，而忽略了对方可能是为了避让路上的坑。 |
| **群体归因错误** | Group attribution error | 把个体的特质当作其所属群体的特质，或把个体的行为当作其所属群体的偏好。 | "一个程序员性格内向，所以程序员都性格内向。" |
| **团体迷思** | Groupthink | 团体决策时成员倾向让自己的观点与团队一致，令整个团体缺乏不同的思考角度。 | 一个会议上没人敢反对老板的意见，大家集体做出了明显有缺陷的决策。 |
| **月晕效应 / 晕轮效应** | Halo effect | 评价他人时，以整体观感评断特定的能力、素质。 | "长得好看的人能力也强"——因为外貌好感而高估其他方面。 |
| **认知不对称的错觉** | Illusion of asymmetric insight | 认为自己比其他人懂得更多。 | "我了解你很透彻，但你根本不了解我。" |
| **外部机构错觉** | Illusion of external agency | 由于对外部机构有主观喜好，而认为其信息是有影响力的、有洞察力的、仁慈的。 | 粉丝认为自家偶像代言的任何产品都是好产品。 |
| **透明度错觉** | Illusion of transparency | 认为自己很容易被他人看透，或认为自己很容易看透他人。 | 演讲时觉得"大家都看出我紧张了"，实际上观众根本看不出来。 |
| **优于常人效应 / 优越感偏差** | Better-than-average effect; Superiority bias | 高估自己的优点、低估自己的缺点。 | 90%的司机认为自己的驾驶技术高于平均水平。 |
| **群内偏见** | Ingroup bias | 认为对方属于自己团体，便给予较好的待遇。 | 面试官对同校的学弟打分更高。 |
| **道德运气** | Moral luck | 评价他人行为的道德时，根据结果而非根据行为时的情境。 | 酒驾撞死人的被判重刑，同样酒驾但没撞到人的判轻刑——行为相同，运气不同。 |
| **素朴犬儒主义** | Naïve cynicism | 认为其他人比自己更自我中心。 | "别人做善事肯定是为了出名，而我做善事是真心想帮忙。" |
| **素朴实在论** | Naïve realism | 相信自己所见所闻即是真相、是客观且不带偏见的。 | "事实就摆在那里，你不同意就是故意的或无知的。" |
| **外团体同质性偏见** | Outgroup homogeneity bias | 认为自己群体的成员比较多样化，而外部群体的成员是相当单一的。 | "我们公司每个人都不一样，隔壁公司的人都是一个样。" |
| **投射偏差** | Projection bias | 不自觉地以为他人（或未来的自己）和（现在的）自己有相似的情感、思想与价值观。 | 自己喜欢吃辣，就默认所有人都喜欢吃辣，聚餐时点了一桌子辣菜。 |
| **自利偏差** | Self-serving bias | 将成功归因于自己，将失败归因于环境。 | 项目成功是因为"我领导有方"，项目失败是因为"市场环境不好"。 |
| **共有资讯偏差** | Shared information bias | 团队讨论倾向花较多时间讨论所有成员都知道的事，而花较少时间讨论较少成员知道的事。 | 开会时大家反复讨论已知的信息，而真正关键的独有信息却没人提起。 |
| **系统正当化 / 制度正当化** | System justification | 人们倾向于喜好与捍卫现有的社会、经济、政治安排，贬低其他方案。 | 即使现有税制对自己不利，也倾向于为其辩护，"存在即合理"。 |
| **性格归属偏差** | Trait ascription bias | 认为自己的个性、行为、情绪是多变的，而他人是一成不变且容易预测的。 | "我的行为随情境而变，但隔壁老王永远都是一副德性。" |
| **终极归因错误** | Ultimate attribution error | 把问题归因于整个群体，而非群体中的个体。 | "那个群体的人就是这样不守信用"——把个体的行为放大到整个群体。 |
| **差于常人效应** | Worse-than-average effect | 对于高难度的事，认为自己比一般人差。 | "骑独轮车？我肯定比一般人差"——虽然大家都差不多差。 |

## 记忆错误与偏差

在心理学和认知科学中，记忆偏差是一种认知偏差，导致记忆的强化、弱化，或者记忆内容的改变。

| 名称 | 原文 | 描述 | 例子 |
|------|------|------|------|
| **怪异效应** | Bizarreness effect | 怪异的事比寻常的事更容易记住。 | 多年后还记得"有个人在公交车上唱歌"的怪事，但不记得那天其他普通细节。 |
| **支持选择偏差** | Choice-supportive bias | 回顾自己做过的选择时，倾向认为是明智的。 | 回头看自己买的股票，总觉得"当时的决定很明智"，即使亏了钱也找到理由。 |
| **改变偏差** | Change bias | 参与一件事的改变后，不易回忆过去的情况。 | 公司改革后问"以前怎么样"——多数人记不清改革前的具体状况了。 |
| **童年失忆症** | Childhood amnesia | 难以回忆四岁以前的事。 | 大多数人记不住自己三岁时的生日派对。 |
| **保守倾向 / 退缩偏差** | Conservatism; Regressive bias | 记忆会倾向中庸不极端。 | 回忆考试分数时，考了98分会记成"大概90多"，考了42分会记成"差不多50"。 |
| **一致性偏差** | Consistency bias | 记忆中他人过去的态度与行为会变得像目前的态度与行为。 | 朋友以前支持A政策，现在支持相反的B政策——你会觉得"他一直都支持B吧"。 |
| **情境效应** | Context effect | 某情境中的记忆在其他情境下较不易回想。 | 在图书馆背的单词，在考场上怎么也想不起来——因为情境变了。 |
| **跨种族效应** | Cross-race effect | 难以分辨其他种族的人。 | 亚洲人看西方人觉得"他们都长一个样"，反之亦然。 |
| **潜抑记忆** | Cryptomnesia | 接触后记得某些影像或语句，却不记得是看来听来的，误以为是自己原创。 | 写了一首歌觉得是自己原创，实际上多年前在某处听过类似的旋律。 |
| **自我中心偏差** | Egocentric bias | 回忆中的自己会美化。 | 回忆高考成绩时会比实际成绩更高。 |
| **情感衰退偏差** | Fading affect bias | 负面、不愉快的记忆比正面、愉快的记忆更快淡忘。 | 多年后记得更多的是旅行的快乐片段，迷路、吵架等不愉快反而淡忘了。 |
| **虚假记忆 / 虚谈症** | False memory; Confabulation | 产生虚构的事填补记忆空白，即使没有欺骗意图。 | 伪造某人的幼年照片给他看，他往往能说出以前做那些事的过程与回忆，但实际上他根本没做过。 |
| **自我生产效应** | Self-generation effect | 自己生产的资讯记得比较清楚，他人生产的则容易淡忘。 | 自己做的笔记比老师发的讲义更容易记住。 |
| **谷歌效应** | Google effect | 容易从网络上搜寻到的资讯比较容易遗忘。 | 朋友的手机号——存在通讯录里就背不出来了。 |
| **幽默效应** | Humor effect | 幽默的事比不幽默的事更容易记住。 | 老师上课讲的段子比知识点记得还清楚。 |
| **真相错觉效应** | Illusion of truth effect | 人们倾向认为听过的是真的（即使没意识到听过）。 | 一句"吃维生素C预防感冒"听多了就觉得是真的，虽然科学上并无充分证据。 |
| **错觉相关** | Illusory correlation | 若认为两件事相关，回忆时就会觉得两者同时发生的频率较高。 | 相信"打雷的时候电视信号会不好"，在雷雨天看电视时总觉得画面确实卡了。 |
| **延迟效应** | Lag effect | 比起短延迟时间的多次重复接触，长延迟时间的少次接触有更好的记忆与学习效果。 | 隔一周复习一次比一天复习三次效果更好。 |
| **钝化与锐化** | Leveling and Sharpening | 记忆细节在每次回忆中扭曲，重要的事会锐化被忆起，细节则会钝化遗失。 | 传话游戏：第一个人说"一个穿红衣服的老人在公园遛狗"，传到最后变成"有人在遛狗"。 |
| **处理深度效应** | Levels-of-processing effect | 用不同方式"编码"的资讯，容易记忆的程度也不相同。 | 用手写一遍（深度处理）比盯着看（浅层处理）记得更牢。 |
| **列表清度效应** | List-length effect | 列表中有越多东西，能记住的比例就越少，但能记住的项目总数会增加。 | 记5个单词能全记住，记50个单词只能记住20个，但20个比5个多。 |
| **错误讯息效应** | Misinformation effect | 记忆会受到事后资讯干扰，而变得不准确。 | 目击车祸后，警察问"那辆蓝色轿车闯红灯了吗"——如果当时车不是蓝色的，目击者也可能被误导"记成"蓝色。 |
| **模态效应** | Modality effect | 对于来自口语的讯息，最后听到的东西印象会较深刻；对于来自文字的讯息则不明显。 | 听讲座时结尾部分记得最清楚，但看书时末尾部分没有同样明显的优势。 |
| **心境相合性记忆偏差** | Mood-congruent memory bias | 与当下心境相合的资讯会比较容易回想。 | 心情不好的时候，想起的都是失败和伤心的往事；心情好的时候，想起的都是快乐的事。 |
| **轮流发言效应** | Next-in-line effect | 轮流发言时，后发言的人不易记住之前的人说过的话。 | 轮到自己发言前，因为紧张准备自己的发言，完全没听进去前面几个人说了什么。 |
| **部分项目提示效应** | Part-list cueing effect | 记忆的东西为一整组时，提示部分项目会使回想后续项目更困难。 | 回忆中国省份时给了"广东、广西"，反而不容易想起其他省份了——提示产生了干扰。 |
| **峰终法则** | Peak-end rule | 人们对一件事的体验通常是由最高峰的感觉与结尾的感觉决定，而不是由总体决定。 | 一次假期中，最精彩的景点和最后一天的经历决定了你对整个假期的评价。 |
| **创伤的持续性** | Persistence of traumatic event | 经历创伤事件后，往往会不断反复回忆。 | 经历车祸后，经常在梦中或白天不由自主地"重放"车祸画面。 |
| **图片优势效应** | Picture superiority effect | 以图片传达概念较以文字传达概念容易学习与回忆。 | "一图胜千言"——看流程图比读文字说明更容易记住工作流程。 |
| **正面效应** | Positivity effect | 老年人回忆中的内容往往会往正面扭曲。 | 爷爷奶奶回忆年轻时的艰苦岁月，却常说"那时候真好"。 |
| **初位效应 / 近时效应 / 序位效应** | Primacy effect; Recency effect; Serial position effect | 序列末尾的东西最容易回忆，其次是序列开头的，序列中间的讯息最不易记住。 | 去超市购物，最容易想起最后放进购物车的和最先放进去的，中间的经常被忘掉。 |
| **处理难度效应** | Processing difficulty effect | 处理难度高的资讯，由于花较多时间阅读与思考，因而较易记住。 | 手写的、有点潦草的讲义反而比印刷体更容易记住——因为费了更多力气辨认。 |
| **怀旧凸隆** | Reminiscence bump | 回忆人生事件时，青春期和成年早期的事特别容易想到。 | 80岁的老人回忆人生时，想到最多的是15-25岁之间的事情。 |
| **玫瑰色回忆** | Rosy retrospection | 美化过去的回忆，往往比实际情况更好。 | "以前的童年多美好啊，没有烦恼"——实际上当时也经常为作业和考试发愁。 |
| **自身相关效应** | Self-relevance effect | 与自身相关的讯息较易回想，与他人相关的较不易。 | 在派对上，你更容易记住别人提到了你的名字，而不是其他人的名字。 |
| **来源混淆** | Source confusion | 把偶发事件的记忆和其他资讯混淆，造成扭曲的记忆。 | 梦到和同事吵架，第二天真的以为和同事吵过架。 |
| **间隔效应** | Spacing effect | 比起无间隔的重复接触，有间隔的重复接触有更好的记忆与学习效果。 | 每天背20分钟英语，持续一周，比一天背140分钟效果更好。 |
| **镁光灯效应** | Spotlight effect | 高估自身言行举止受他人关注的程度。 | 衣服上沾了一点污渍，觉得"全世界都看到了"，实际上根本没人注意。 |
| **后缀效应** | Suffix effect | 在资讯尾端加上不须记忆的项目，会使前面须记忆的项目变得特别不易记住。 | 听完一串数字后加一句"这是垃圾信息"，前面记下的数字也会受影响。 |
| **可暗示性** | Suggestibility | 回想事情时，如旁人暗示了某些想法，想到的内容会受扭曲。 | "你确定他当时戴了帽子吗？"——原本不记得有帽子，被这么一问就觉得"好像是有"。 |
| **伸缩效应** | Telescoping effect | 认为近期的事比实际久远些，久远的事比实际近期些。 | 觉得上周的事像"很久以前"，而三年前的事感觉像"不久前"。 |
| **考试效应** | Testing effect | 反复书写比反复阅读更容易记住资讯。 | 做练习题背单词的效果比反复看单词表好得多。 |
| **舌尖现象** | Tip of the tongue phenomenon | 能想起一件事的一部分或相关的东西，却难以想起全部。 | "那个演员叫什么来着？姓……姓什么……就在嘴边！"——话到嘴边想不起来。 |
| **逐字效应** | Verbatim effect | 话语中的大意比完整字句更容易记住。 | 听完一个故事，你能复述情节大意，但记不住原话的每个字。 |
| **雷斯多夫效应** | Von Restorff effect | 醒目的事或特别强调的事比其他的事更容易记住。 | 一列全是黑字的名单中，有一个红色字体的名字——这个红字名字最容易被记住。 |
| **蔡格尼效应** | Zeigarnik effect | 比起已完成的事，未完成或中断的事情会记得更清楚。 | 追的剧卡在悬念处，一年后还记得那个情节；但已经看完的剧，过几个月就忘了细节。 |

## 统计与几率偏差

几率性推论是指根据有关几率的资讯推论事情的可能性，而几率的估算通常来自统计资料，因此两者密不可分。以下列出不熟悉或误用几率造成的错误认知或推理：

| 名称 | 原文 | 描述 | 例子 |
|------|------|------|------|
| **基本比率谬误 / 基本比率忽视** | Base rate fallacy; Base rate neglect | 只关注针对性的资讯，忽略一般性的资讯（基本比率），导致不恰当的认知。 | 因为酒驾较容易肇事，就认为肇事者多半是酒驾——但酒驾者占所有驾驶者的比例很小，肇事者中酒驾的比例没那么高。 |
| **合取谬误** | Conjunction fallacy | 认为较特殊性的情况比较一般性的情况更可能发生。 | 描述一个人"关心社会、热爱辩论"，人们认为"她是女权律师"的概率比"她是律师"更高——但事实上任何律师都包含女权律师。 |
| **赌徒谬误** | Gambler's fallacy | 认为某事多次发生则未来发生的概率会较小，或多次未发生则未来发生的概率会较大。 | 抛硬币连续5次正面，第6次押反面，觉得"该出反面了"——但每次都是独立50%。 |
| **逆赌徒谬误** | Inverse gambler's fallacy | 认为概率很小的事发生了，一定是做了很多次。 | 有人掷骰子掷出了6个6，你就觉得"他一定试了很多次"——但第一次就有可能。 |
| **热手谬误** | Hot Hand Fallacy | 认为某事多次发生则未来发生的概率会较大。 | 篮球队员连续投进3个三分球，就觉得"他现在手感火热，下一球肯定还能进"。 |
| **回归谬误** | Regression fallacy | 非常态发生后用乙措施处理后扭转，便断定乙措施有效。 | 运动员这赛季表现特别差（非常态），换了教练后下赛季回归正常——归功于新教练，其实只是回归均值。 |
| **检察官谬误** | Prosecutor's fallacy | 泛指多种根据不相关资讯认定被告"无辜的概率"很小的情况。 | DNA匹配概率是百万分之一，就说"被告有罪的概率是99.9999%"——但这是条件概率的混淆。 |
| **辩护人谬误** | Defendant's fallacy | 泛指多种根据不相关资讯认定被告"犯罪的概率"很小的情况。 | "这个城市有100万人，只有一个人的DNA匹配，所以被告犯罪的概率只有百万分之一。"——忽略了其他证据。 |
| **多重比较谬误** | Multiple Comparisons Fallacy | 广泛比较二个群体的各种特征，从中找出有明显差异的几个，宣称它就是造成二个群体不同的原因。 | 比较成功和失败的创业公司，发现成功的公司"办公室有绿植"，就宣称"放绿植能提高创业成功率"。 |
| **德州神枪手谬误** | Texas sharpshooter fallacy | 先射箭再画靶，把随机产生的集群当做有统计意义。 | 分析数据时发现某个数据点"恰好"在统计显著范围内，就宣称这是有意义的发现。 |
| **对样本数不敏锐** | Insensitivity to sample size | 评估统计数据时，未考虑小样本比大样本更容易观察到极端结果。 | 一家小诊所治愈率90%，大医院治愈率70%，人们就觉得小诊所更好——但小诊所样本少，治愈率波动大。 |
| **戏局谬误** | Ludic fallacy | 过度使用统计与概率预测未来。 | 用经济模型精确预测"明年GDP增长3.27%"——忽略了模型中无法量化的黑天鹅事件。 |
| **麦纳马拉谬误** | McNamara fallacy | 过度相信数据、依赖数据评估事情，忽略难以量化的事。 | 只看考试成绩评价学生好坏，忽略了创造力、情商、品德等难以量化的特质。 |

## 实验与研究偏差

这是一些科学实验或统计研究容易发生的偏差。

| 名称 | 原文 | 描述 | 例子 |
|------|------|------|------|
| **选择偏差** | Selection bias | 以偏概全，即以局部事例解释整体原因。 | 用大学本科生样本研究"人类心理"，忽略了样本不代表全体人类。 |
| **取样偏差** | Sampling bias | 筛选样本时预先排除了某些不应排除的样本。 | 用手机做问卷调查，排除没有手机的人群，导致结果偏差。 |
| **自我选择偏差** | Self-selection bias | 由于受试者自愿参与产生偏差。 | 在线课程满意度调查中，只有极端满意或不满意的学生才会填写，中间的大多数被忽略了。 |
| **谱带偏差** | Spectrum bias | 筛选样本时预先排除了某些不应排除的样本。 | 只对重症患者测试新药，效果可能比用在轻症患者上好或差，导致误判。 |
| **预筛选偏差** | Pre-screening bias | 筛选样本时预先排除了某些不应排除的样本。 | 临床试验排除了老年人和儿童，导致结果无法推广到这些群体。 |
| **排除偏差** | Exclusion bias | 研究进行时不当排除某些看似不符预期的样本。 | 实验中发现有些数据"看起来不对"就删掉了，但这些数据可能恰恰反映了真实情况。 |
| **选择性观察偏差** | Observation selection bias | 观察时受到前置条件的限制而筛选了样本，得出不适当的结论。 | 问卷调查到的人一定是个性热心、愿意填问卷的人，其结果未必能反映不愿填问卷的人的想法。 |
| **观察者期望效应** | Observer-expectancy effect | 由于研究者期待某种结果，因而下意识中不适当地操作实验或诠释资料。 | 研究员相信新药有效，于是无意识中对实验组的病人更友善、更关心。 |
| **受试者期望效应** | Subject-expectancy effect | 由于受试者期待某种结果，因而下意识地扭曲了回报内容。 | 参加药物试验的病人因为知道自己可能在用药组，就报告"感觉好多了"。 |
| **安慰剂效应 / 伪药效应** | Placebo effect | 给予无效的药物或治疗，病人却相信或觉得情况改善。 | 给病人吃糖丸，告诉他是止痛药，结果病人真的觉得不痛了。 |
| **反安慰剂效应 / 反伪药效应** | Nocebo effect | 给予有效的药物或治疗，病人却相信或觉得情况恶化。 | 告诉病人可能的副作用，病人即使服的是真药，也会因为心理作用而出现副作用。 |
| **实验者偏差 / 期望偏差** | Experimenter's bias; Expectation bias | 实验者倾向相信、认可、发布符合他们期望的结果。 | 科学家只发表支持自己假设的结果，"不漂亮"的数据藏在抽屉里（文件抽屉效应）。 |
| **循环分析** | Circular analysis | 用同一数据既做分析又做验证。 | 用A数据训练模型，又用A数据验证模型的准确率——过度拟合。 |
| **遗漏变数偏差** | Omitted-variable bias | 统计模型中遗漏了重要的变量。 | 研究"咖啡是否导致心脏病"，没有考虑吸烟这一混杂变量——喝咖啡的人中吸烟的比例也高。 |
| **经费偏差** | Funding bias | 选择研究方法或诠释研究结果时，倾向迎合经费提供者的立场。 | 烟草公司资助的研究更可能得出"吸烟没有显著危害"的结论。 |
| **通报偏差** | Reporting bias | 说明自己的看法时，倾向于多报符合社会期许的实情，少报不符合的。 | 调查性行为时，男性多报性伴侣数量，女性少报。 |
| **社会期许偏差** | Social desirability bias | 倾向给出符合社会期望的答案。 | 问"你投票了吗？"多数人答"投了"，即使实际投票率没那么高。 |
| **资料探勘偏差** | Data-snooping bias | 反复挖掘同一数据，总会找到统计显著的"假关系"。 | 把1000个变量放在一起分析，总有5%在p=0.05水平上显著——纯属巧合，不是真正的因果。 |
| **前导时间偏差** | Lead-time bias | 早期诊断使生存时间看起来更长了，但实际并未延长寿命。 | 筛查提早发现了癌症，患者"从诊断到死亡"的时间变长了，但死亡时间并未推迟。 |
| **时距偏差** | Length-time bias | 病程较长的疾病更容易被检测到。 | 每年体检发现的癌症往往生长缓慢，让人误以为早期筛查效果很好——因为快速致命的癌症在体检间隔中就已经致死了。 |
| **过度诊断偏差** | Overdiagnosis bias | 诊断出了永远不会造成症状或死亡的疾病。 | 尸检发现很多男性生前有前列腺癌，但从未因此受到影响——过度诊断导致过度治疗。 |

## 成因理论

以下列出解释认知偏差成因的常见理论：

- **有限理性** — 理性与最佳化的限制
- **前景理论**
- **心理账户**
- **适应偏差** — 在资讯有限下做出决策而造成偏差，并以可能的错误为代价
- **属性替代** — 建立复杂、困难的判断，却不自觉地换成简单地判断
- **归因理论**
- **显著性**
- **素朴实在论**
- **认知失调**，及相关的：印象管理、自我知觉理论
- **判断与决策的捷思**，包括：
  - **可用性捷思** — 估计哪些比较容易从记忆中取得，例如生动的、不寻常的、或激起情绪的例子
  - **代表性捷思** — 根据相似性判断可能性
  - **情感捷思** — 根据情绪反应决策，而非计算风险与效益
- **情感的一些其他理论**，如：情绪二因论、体细胞标记假说、内省错觉
- **统计的误解与误用**；数学盲

2012年一篇《心理学公报》文章表明，至少有八种看似无关的偏差可由同一种信息论的产生机制产生，此机制假设从人类记忆储存与提取资讯时，杂乱的资讯处理过程导致了偏差。
