# 说服技巧速查表

## 应对三种听众的核心策略

| 听众类型 | 核心目标 | 主要技巧 | 关键行动 |
|----------|----------|----------|----------|
| 🟢 反对听众 | 削弱（黑转路） | 道歉→辩护→转化 | 承担情绪、找出情绪点、说出情绪 |
| 🟡 支持听众 | 强化（顺从→投入） | 激励→抵御→拆分行动 | 需求清单、保护忠诚、小步启动 |
| ⚪ 中立听众 | 拉拢（无感→关注） | 间接告知→涉入→比较 | 展现实力、勾起兴趣、甜蜜点 |

## 道歉公式

```
有效道歉 = 承担情绪 + 承诺改变
```

> [!WARNING] 关键提醒
> **承担情绪比承诺改变更重要**。道歉不是为了让自己好过（"别生气了"），而是让对方感觉被理解。

### 找出情绪点的步骤

1. **识别第二情绪**：看到对方的生气、愤怒、指责
2. **追问第一情绪**：生气背后是羞耻？害怕？担忧？失望？委屈？困惑？
3. **说出情绪**：用语言精准表达对方的真实感受
4. **不要解释**：说出情绪后，让对方消化，不要急着辩护

> [!TIP] 换位思考公式
> 错误的换位思考："如果我是你，我会怎么做"（优越感）
> 
> 正确的换位思考："如果我是你，我会有什么感觉"（共情）

## 说服力三要素总结

| 要素 | 核心原理 | 操作方法 |
|------|----------|----------|
| 专业感 | 人倾向于相信专家 | 展示专业背景、引用具体数据、使用专业术语适度 |
| 诚实感 | 人倾向于相信坦诚者 | 主动暴露弱点、承认不足（"出丑效应"） |
| 讨喜感 | 人倾向于答应喜欢的人 | 相似性、称赞、接触频率、合作姿态 |

## 进阶技巧速查

### 互惠法则

```mermaid
flowchart LR
    A[先给] --> B[建立亏欠感]
    B --> C[再取]
    C --> D[对方更易答应]
```

> 关键：礼物要"有份量"且"对方真正需要"，而不是随意给予

### 高球策略（Door-in-the-Face）

```
第一步：提一个对方一定会拒绝的大要求
第二步：对方拒绝后，提真正的小要求
第三步：对方因"让步互惠"而接受
```

### 低球策略（Foot-in-the-Door）

```
第一步：让对方接受一个容易做到的小要求
第二步：逐步升级要求的难度
第三步：对方因"一致性"而持续配合
```

### 一致性原理

```
让对方做出''公开承诺'' → 承诺会被"绑定"到其自我认知
→ 为维持"人设"，对方会做出与承诺一致的行为
```

## 说服四步骤（实战工具）

| 步骤 | 行动 | 目标 |
|------|------|------|
| ① 分类听众 | 判断对方是反对/中立/支持 | 选对策略 |
| ② 设定目标 | 明确想让对方到达的位置 | 确定方向 |
| ③ 选择技巧 | 根据分类选择对应技巧 | 精准施力 |
| ④ 评估反馈 | 观察对方反应，调整策略 | 持续优化 |

## 常见误区

| 误区 | 正确认知 |
|------|----------|
| 说服需要好口才 | 说服需要正确观念，不是口才 |
| 说服就是争辩 | 说服是让对方听进去，不是辩倒对方 |
| 道歉就是认错 | 道歉是承担情绪，不一定是承认错误 |
| 反对我的人都是反对听众 | 可能是支持不够或中立无感 |
| 沟通能解决一切冲突 | 只有弱势方想沟通，强势方需要说服
