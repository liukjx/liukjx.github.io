# 谈判经典案例集

本文件汇集高志凯谈判课程中引用的经典案例，按类型分类，便于复习和快速查阅。

## 外交谈判案例

### 板门店谈判（抗美援朝）

| 要素 | 内容 |
|------|------|
| 时间 | 1951-1953年 |
| 参与方 | 中国人民志愿军、美军、朝鲜人民军、韩国军队 |
| 核心特征 | 战争与谈判互动——谈打结合 |
| 战术启示 | 谈判桌上受阻，就在战场上决胜负；用打仗促谈判 |
| 优势分析 | 中方：气多（士气）、夜战、近战；美方：钢多（装备）、制空权 |

### 中美上海公报谈判（1972年）

| 要素 | 内容 |
|------|------|
| 关键人物 | 周恩来、尼克松、基辛格 |
| 核心分歧 | 台湾问题：中华人民共和国 vs 中华民国的称谓 |
| 僵局突破 | 基辛格提出"海峡两岸"的中性表述 |
| 破局策略 | 周总理安排美方杭州之行——换环境以降压 |
| 语言关键 | "Acknowledge" vs "承认"的用词选择 |

### 中英香港问题谈判（1982年）

| 要素 | 内容 |
|------|------|
| 关键人物 | 邓小平、撒切尔 |
| 核心分歧 | 新界租约1997年到期 vs 香港岛"永久割让" |
| 英方策略 | 以谈新界续约为掩护，保留香港岛 |
| 中方底线 | 1997年全部收回，否则"我就是李鸿章" |
| 突破方案 | 一国两制、50年不变 |

### 中英1997年条约续约试探（80年代初）

| 要素 | 内容 |
|------|------|
| 事件 | 英国外交大臣要求见中国最高领导人 |
| 表面诉求 | 谈1997年到期条约的续约问题 |
| 真实意图 | 以续约新界为掩护，锁定香港岛和九龙的永久占有 |
| 应对策略 | 领导人火眼金睛，直接定性为"回归问题"而非"续约问题" |

### 南海仲裁案（2016年）

| 要素 | 内容 |
|------|------|
| 事件 | 菲律宾就南海领土纠纷向海牙仲裁庭提起仲裁 |
| 仲裁关键 | 仲裁需双方同意——中方未同意，仲裁本身即违法 |
| 中方立场 | 仲裁结果是"一张废纸"；仲裁程序自始非法 |
| 谈判启示 | 从程序合法性入手反击，而非只争结果 |

### 中美关税战（2025年起）

| 要素 | 内容 |
|------|------|
| 事件 | 美国以关税为武器发动对华贸易战 |
| 中方优势 | 市场规模（大豆需求）、稀土储量与精炼技术 |
| 谈判地点 | 日内瓦、伦敦、斯德哥尔摩、马德里、吉隆坡、华盛顿 |
| 中方立场 | "谈大门敞开"；"不吃你这一套" |
| 关键逻辑 | 中美经济相互依赖，非一边倒 |

## 商务谈判案例

### 挪威与丹麦北海划界谈判

| 要素 | 内容 |
|------|------|
| 核心 | 按照海洋法公约划分专属经济区和大陆架 |
| 丹麦诉求 | 渔业资源丰富的水域 |
| 挪威诉求 | 潜在的石油天然气海域（当时未经勘探证实） |
| 结果 | 挪威以渔场换海域，后发现巨大石油天然气储量 |
| 启示 | 劣势可以转化；远见和洞察力比眼前利益更重要 |

### 酒店名画收购案

| 要素 | 内容 |
|------|------|
| 卖方目的 | 出售一家酒店以获取资金 |
| 买方目的 | 收购酒店大堂悬挂的一幅价值连城的名画 |
| 买方策略 | 配合卖方谈酒店，但要求所有附属资产（含画作）打包 |
| 关键技巧 | 不转移聚光灯到真实目标上 |

### 铁道部高铁招标谈判

| 要素 | 内容 |
|------|------|
| 参与方 | 中国铁道部、多国高铁公司 |
| 策略 | 调动多方竞争，形成"他们之间的零和博弈" |
| 对手类型 | 自视甚高者（不愿妥协）、灵活应变者、联合谈判者 |
| 启示 | 不同对手不同策略，利用对方之间的竞争 |

### 银行上市投行选聘

| 要素 | 内容 |
|------|------|
| 事件 | 大型银行上市选聘承销商 |
| 常规做法 | 直接找行长/董事长 |
| 顶级策略 | 找到"行长听谁的话"——上上级、恩师、关键决策者 |
| 启示 | 谈判对象不一定是表面上的决策者 |

### 欧洲水泥厂收购案

| 要素 | 内容 |
|------|------|
| 事件 | 欧洲最大建材公司在中国珠三角收购水泥厂 |
| 僵局 | 对方认为中方要求与市场前景不符，威胁退出 |
| 应对 | 坚持讲述中国市场长期前景（入世、双位数增长） |
| 结果 | 成交后对方获得丰厚回报 |

### 日军新加坡谈判（二战）

| 要素 | 内容 |
|------|------|
| 事件 | 日军包围新加坡英军后进行谈判 |
| 实力对比 | 日军弹尽粮绝，英军仍有实力 |
| 谈判策略 | 日军将领虚张声势，将英军吓到投降 |
| 启示 | 必须知彼——对方实力是真是假 |

## 个人与职业案例

### 个人优势选择分析

高志凯以自身为例：身高1.70m不适合打篮球，但可以做篮球教练、评论员或英文翻译。优势不是绝对的，取决于你选择的方向和赛道。

### 耶鲁法学院模拟法庭训练

每周写一篇论文，从甲方和乙方两个对立角度分析同一事实；通过模拟法庭（moot court）训练辩论能力。

### 李嘉诚原则

"什么事都可以做交易，关键是个价格问题。"——长江和记黄埔的谈判哲学，体现出高度的灵活性与务实态度。
